# История результатов тестирования

Отчёт преподавателя использует только снимок completed-сессии, связанной с этой попыткой, пользователем и уроком. Текущий банк вопросов не запрашивается. Старые попытки без снимка сохраняют исходные баллы; вместо деталей и вычисления «верно/неверно» показано «Исходная редакция вопросов не подтверждена». Исходный passed имеет приоритет, иначе используется сохранённый passing_score. При отсутствии сохранённого порога решение не выдумывается.

Старые attempts, sessions, answers, score, max_score, progress и owner-only repair journal не обновляются. Никакой реконструкции из журнала нет. Новая функция требует исходного authenticated caller, активную учётную запись и существующее can_access_course(course,'students.read'). Она не предоставляет студентам право читать сессии/ключи, не меняет table RLS/grants и отклоняет всю смешанную/чужую группу UUID.

## Проверка

При установленных зависимостях проекта из корня репозитория:

    node node_modules/vitest/vitest.mjs run --config tests/course-test-history/vitest.config.mjs --configLoader native --maxWorkers=1 --no-file-parallelism

Один фактический локальный запуск: 19/19 PASS (13 pure resolver/XLSX + 6 actual hook), 2 suites, 1 worker, natural exit 0, stderr empty, selected source drift 0. SQL-отказ в hook тестируется через явно изолированный SDK port; это не исполнение PostgreSQL authorization. React-компонент отчёта прочитан независимо, но не монтировался в этих 19 тестах. Whole-app TSC и hosted browser/XLSX acceptance этим пакетом не заявляются.

SQL-кандидат расположен отдельно: CANDIDATE_TEACHER_HISTORY_SNAPSHOT_ONLY_DEFAULT_ROLLBACK.sql. Он намеренно заканчивается ROLLBACK. Перед выпуском owner выбирает canonical migration/stamp и выполняет отдельную rollback-проверку реальной SQL-функции. На этой стадии SQL не исполнялся. UI должен выпускаться вместе с доступной новой RPC: ошибка загрузки не маскируется пустой историей и не включает current-bank fallback.

Пределы: текущие подписи уроков/профилей остаются существующими метаданными; это не неизменяемые исторические паспорта личности/названия. Существующий способ выборки списка attempts и его серверные лимиты не расширялись. Снимок с некорректным замороженным ключом не исправляется по нынешнему банку: балл остаётся, оценка конкретного ответа неизвестна.
