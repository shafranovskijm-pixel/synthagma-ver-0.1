# Ограничение ожидания предпросмотра

Обычный целевой запуск: node node_modules/vitest/vitest.mjs run --config tests/file-preview-timeout/vitest.config.mjs --configLoader native --maxWorkers=1 --no-file-parallelism

Семь проверок исполняют настоящий FilePreviewDialog и настоящий классификатор источника с прежними изолированными UI-портами. Проверяются 15-секундное ожидание и переход к исходной ссылке без автоматической передачи другому просмотрщику, load/error, смена URL/имени/типа, закрытие/повторное открытие/размонтирование и запрет всех ссылок при allowDownload=false. Публичный Office-режим сохраняется.

Токен NON_SECRET_TEST_TOKEN является явной синтетической строкой. Настоящие подписанные URL, секреты и байты клиентов не используются. Сеть, API, SQL, почта и внешние просмотрщики не вызываются. Поддержка браузерного PDF, причина отсутствующего load/error, фактическое получение файла и отсутствие server-side egress этими jsdom-тестами не подтверждаются. Верхняя кнопка «Скачать» сохраняет прежнюю навигацию в новую вкладку; это не принудительный download.

Фактический один запуск на Node 24: 7/7, natural exit 0, без пропусков и изменения пяти входных файлов. Проверена именно эта переносимая .mjs-конфигурация; Node 20 отдельно не запускался. Полная проверка приложения выполняется отдельно перед выпуском.
