# Scoped readable homework HTML

Candidate only: nine meaningful cases prepared, not executed. Overlay the six production paths and these four support paths on root's complete merged158 source composition. Do not run this partial directory as a standalone app. Use the existing verified runtime and dependencies; install nothing.

```sh
node node_modules/vitest/vitest.mjs run --config tests/homework-html/vitest.config.mjs
```

Tests execute the actual DOMPurify-based `sanitizeCourseHtml`, shared description renderer and actual `HomeworkSubmission`. SDK homework-history reads are explicit offline ports; writes, upload and fetch throw. Preview/page source wiring is reviewed separately, not claimed mounted by these tests.

Only a current direct platform owner with matching route/course/lesson link enables rich HTML. Plain text, unknown ownership, stale context and client custom courses retain escaped text. No `source_course_id`, title, matching content or static QA ID grants rich rendering. Existing outer task/preview classes remain; readable own HTML gets prose/table/list formatting inside that container. The sanitizer and its policy are unchanged.

Submission, review, score, completion, permissions and finance are untouched. Own admin learning view shows task contents read-only and retains the no-submit message.

Acceptance constraint: an ordinary cloned course is outside the source-platform guard and therefore keeps the old text rendering. A future synthetic QA/client-clone HTML mode requires separately proven exact source-version provenance and explicit scope; this package does not infer permission from lineage or enable a blanket client rewrite. No new synthetic clone is claimed verified here.
