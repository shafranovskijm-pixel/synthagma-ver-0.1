# Уточнение оснований ДПО

Один обычный запуск четырёх проверок фактического TXT-экспорта:

`node node_modules/vitest/vitest.mjs run --config vitest.citations.config.mjs --configLoader native --maxWorkers=1 --no-file-parallelism`

Проверяются три прямые ссылки №266 (п.17,22–23,15), явная неизвестность действия/замены №845/369 и№438 после01.09.2026, сохранение отметок о неподтверждённой актуальности и отсутствие изменения входного каталога при экспорте всех17 проектов. Исполняются настоящие catalog/adaptationDrafts; сети, SDK, базы и сервисов в этом профиле нет. Проверки не удостоверяют текущую редакцию закона и не утверждают документы центра.

Первый фактический запуск прежнего входа4/4 завершился успешно на Node24 с конфигурацией .ts. Для изменённой редакции v2 предназначен новый запуск той же четвёрки с публикуемым .mjs; результат записан в доказательстве выпуска. Конфигурация содержит те же JavaScript-байты и поддерживает загрузку в Node20.19+, но сам Node20 здесь не проверялся.

Уточнения оснований входят в новую редакцию проектов uc029-substantive-drafts-2026-10-26-v2. Ранее скачанные файлы v1 и сохранённая история не переписываются. ADAPTATION_EDITION обозначает редакцию текста проекта; формальная CATALOG_VERSION, нормативные статусы и решения центра не меняются. В четвёртой проверке строка v2 проверяется в реальном экспорте каждого из17проектов.

Фактическая проверка изменённой v2: 4/4, обычный Vitest с публикуемым .mjs на Node 24, natural exit 0, без пропусков и изменения пяти входных файлов. В CB04 проверяется строка новой редакции в каждом из 17 экспортов. Прежний результат v1 сохранён отдельно.
