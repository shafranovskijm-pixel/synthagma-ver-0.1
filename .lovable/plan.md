

# Напоминания о переобучении на курсах

## Что будет сделано

Система напоминаний, привязанная к курсам, которая автоматически отслеживает даты прохождения обучения и напоминает о необходимости повторного обучения.

## Основные возможности

1. **Настройка периодичности на курсе** -- новое поле "Периодичность переобучения" в настройках курса (1 год, 3 года, произвольное значение)
2. **Автоматическое создание напоминаний** -- при завершении курса учеником автоматически создается напоминание на дату, рассчитанную по периодичности
3. **Готовый пул шаблонов комментариев** -- предзагруженные тексты напоминаний (охрана труда, первая помощь, электробезопасность и т.д.)
4. **Напоминания для 3 сторон**: обучающая организация, компания-заказчик, слушатель
5. **Отображение напоминаний** -- новая вкладка "Напоминания" в модальном окне курса с таблицей предстоящих уведомлений

---

## Техническая реализация

### 1. Миграция базы данных

**Новые колонки в `courses`:**
- `retraining_period_months` (integer, nullable) -- периодичность переобучения в месяцах (12, 36 и т.д.)

**Новая таблица `course_reminders`:**
- `id` (uuid, PK)
- `course_id` (uuid, FK -> courses)
- `enrollment_id` (uuid, FK -> enrollments)
- `user_id` (uuid) -- слушатель
- `organization_id` (uuid) -- обучающая организация
- `company_id` (uuid, nullable) -- компания-заказчик
- `completed_at` (timestamptz) -- дата завершения обучения
- `reminder_date` (date) -- дата напоминания
- `reminder_text` (text) -- текст напоминания
- `notify_organization` (boolean, default true)
- `notify_company` (boolean, default true)
- `notify_student` (boolean, default true)
- `is_sent` (boolean, default false)
- `is_dismissed` (boolean, default false)
- `created_at`, `updated_at`

RLS: доступ для org-пользователей и админов по `organization_id`.

### 2. Настройки курса (CourseDetailsModal -- вкладка "Настройки")

Добавить в секцию настроек:
- Выпадающий список "Периодичность переобучения": Нет / 1 год / 3 года / Ввести вручную (мес.)
- Сохраняется в `courses.retraining_period_months`

### 3. Пул шаблонов комментариев

Константный файл `src/constants/reminderTemplates.ts` с предзагруженными шаблонами:
- Охрана труда (3 года) -- текст из запроса пользователя
- Пожарная безопасность (3 года)
- Первая помощь (3 года)
- Электробезопасность (1 год / 3 года)
- БДД (3 года)
- Санминимум (1 год)
- Общий шаблон

### 4. Автоматическое создание напоминания

При завершении курса (когда `enrollments.status` = 'completed'):
- Триггер БД или логика на клиенте проверяет `retraining_period_months`
- Если задан -- создает запись в `course_reminders` с рассчитанной датой
- Текст берется из шаблона или дефолтный

### 5. Вкладка "Напоминания" в CourseDetailsModal

Новая вкладка с иконкой Bell:
- Таблица: Слушатель | Компания | Дата прохождения | Дата напоминания | Статус | Текст
- Кнопка ручного создания напоминания с выбором даты, шаблона и получателей
- Возможность редактировать дату и текст
- Кнопка "Отправить сейчас" для ручной отправки
