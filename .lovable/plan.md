

# Упрощение добавления блоков — один клик вместо двух

## Проблема

Сейчас в попапе «Добавить блок» нужно:
1. Кликнуть карточку блока (выделяется рамкой)
2. Прочитать описание внизу
3. Нажать «Далее» внизу попапа

На устройствах со срезанным/коротким экраном кнопка «Далее» оказывается ниже границы, и завершить добавление невозможно. Лишний шаг также замедляет работу опытных пользователей.

## Решение: «один клик = добавление»

Убираем шаг подтверждения. Клик по карточке блока сразу добавляет его на холст и закрывает попап. Описание показываем заранее — на ховере карточки (tooltip), а не отдельной нижней панелью. Это убирает половину высоты попапа и делает интерфейс гарантированно помещающимся.

### Изменения в `src/components/course-builder/block-editor/blocks/AddBlockButton.tsx`

**`BlockPicker`:**
- Убираем `useState<GridItem | null>(selected)` и обработчик `handleConfirm`.
- Карточка блока теперь сразу вызывает `onSelect(item)` по клику — попап закрывается, блок добавляется.
- Удаляем нижний блок «описание выбранного» (строки 124–135).
- Удаляем футер с кнопками «Отмена / Далее» (строки 137–141).
- Описание блока (`blockDescriptions[type]` или `description` для AI) переносим в `title`-атрибут карточки + `Tooltip` из `@/components/ui/tooltip` (плавный показ на ховере, ~400 мс delay).
- Заголовок «Выберите тип блока» сокращаем до одной строки, подзаголовок ужимаем — освобождаем вертикальное пространство.
- Поиск (`Input` с `autoFocus`) сохраняется. Добавляем поддержку `Enter`: если после фильтрации остался единственный блок — Enter сразу его добавляет (быстрый ввод с клавиатуры).
- `Esc` закрывает попап (стандартное поведение Popover, проверяем работоспособность).

**`BlockGrid`:**
- Убираем визуальное состояние `isActive` (выделение рамкой выбранного) — оно больше не нужно. Оставляем только hover-состояние.
- Карточки получают `title={description}` для нативной подсказки на десктопе как fallback к Tooltip.

**`PopoverContent`:**
- Уменьшаем максимальную высоту скролл-области с `max-h-[420px]` до `max-h-[60vh]`, чтобы попап адаптивно умещался на любом экране.
- Добавляем `collisionPadding={16}` через проп Popover — Radix автоматически сдвинет попап от краёв окна.

### Совместимость

- `AddBlockButton` и `InlineAddBlockButton` используют один и тот же `BlockPicker` — оба обновятся автоматически.
- Сигнатура `onAdd(type, pendingAI)` не меняется — все вызывающие компоненты продолжают работать.
- AI-блоки (`AI-картинка`, `AI-озвучка`, `AI-тест`) добавляются тем же одним кликом, флаг `pendingAI` ставится в той же функции `resolvePick` — далее открывается отдельный AI-диалог как и раньше.

### Версия и память

- `src/lib/appVersion.ts` → `1.0.70`.
- Обновить `mem://features/course-builder/system-and-logic` коротко: «Селектор блоков работает по принципу одного клика, без подтверждения».

## Что получает пользователь

- Попап стал ниже примерно на 110 px → гарантированно помещается на экранах от 720 px высотой и любых мобильных.
- Добавление блока — 1 клик вместо 3 действий.
- Описание блока появляется в подсказке при наведении — информация остаётся доступной, но не занимает места.
- Поиск + Enter = добавление за 2 нажатия с клавиатуры.
