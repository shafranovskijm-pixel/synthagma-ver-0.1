

# План: один курс с ipo.msk.ru → полностью оформленный товар в маркетплейсе

## Что сделаю

Возьму **одну реальную программу профессиональной переподготовки** с ipo.msk.ru, прогоню её через ту же цепочку, что уже работает в админке маркетплейса, но запущу всё **из скрипта в едином проходе**, чтобы получить готовую витринную карточку: курс + категория + структура уроков + контент уроков + обложка + цена + описание + публикация.

Никакого нового UI — только переиспользую существующие edge functions и таблицы.

## Какой курс возьму

Из направления **«Охрана труда»** (категория уже существует в маркетплейсе) программу:
**«Специалист по охране труда»**, 256 ак. часов, источник `https://ipo.msk.ru/professionalnaja-perepodgotovka/ohrana-truda/specialist-po-ohrane-truda/`.

Почему именно её:
- стандартная ПП-программа, нейтральная тематика — легко сгенерировать корректный контент;
- 256 часов — типичный объём ПП, попадает в `frdo_duration_hours`;
- категория **«Охрана труда»** уже существует, лишних артефактов в БД не создам;
- на маркетплейсе сейчас нет дубликата (проверю перед вставкой через SQL по нормализованному названию).

Если по факту такая программа уже есть — возьму следующую из направления ОТ («Руководитель службы охраны труда» / «Инженер по охране труда»).

## Этапы

### 1. Создание скелета курса в БД
- Вставлю запись в `courses`:
  - `organization_id = MARKETPLACE_ORG_ID`
  - `category_id` = id категории «Охрана труда»
  - `title`, `slug` (с уникальным суффиксом)
  - `duration = "256 ч."`
  - `frdo_program_type = "Профессиональная переподготовка"`
  - `frdo_duration_hours = 256`
  - `frdo_profession_name = "Специалист по охране труда"` (чтобы колонка L экспорта ФРДО была корректной)
  - `is_published = false` пока генерится контент
- Вставлю запись в `marketplace_courses` с `is_active=false`, `is_validated=false`, `price_student=0`.
- Запись в `marketplace_import_catalog` со `status="imported"`, чтобы было видно в админке вкладки «Импорт ИПО».

### 2. Генерация структуры урока через `generate-course-structure`
- Вызываю edge function с `title` и `description` курса.
- Ожидаемый результат: ~20-30 уроков, разбитых на модули по стандарту ПП:
  1. Введение и нормативная база
  2. Управление охраной труда
  3. Опасные и вредные производственные факторы
  4. Расследование и учёт несчастных случаев
  5. Средства индивидуальной защиты
  6. Обучение и инструктажи
  7. Промежуточные и итоговый тесты
- Уроки пишутся в `lessons` с правильным `order_index` и `module_id`.

### 3. Генерация контента уроков через `generate-lesson-content`
- Для каждого урока типа `text`/`lesson` → текстовый блочный контент (700+ слов, JSON-блоки).
- Для уроков типа `test` → банк вопросов (15 шт.) через стандартный пайплайн.
- Запросы делаю последовательно с 1.5-сек паузой, чтобы не упереться в rate-limit GigaChat.
- Использую существующий `safeInvoke`-эквивалент: ретраи на 429/5xx до 3 раз.

### 4. Генерация обложки через `generate-cover`
- Вызываю с `courseId` и `type="course"`.
- Обложка сохраняется в `courses.cover_image_url`.
- Дополнительно копирую URL в `marketplace_courses.preview_image_url`.

### 5. Описание и цена для витрины
- Через AI gateway (`google/gemini-3-flash-preview`) генерирую:
  - `description_short` (150-200 символов, лид витрины);
  - `description` курса (3-4 абзаца, с маркировкой кому подходит и что получит выпускник).
- Цену ставлю **15 000 ₽** для студента (среднерыночная для ПП «Охрана труда» 256ч).
- `price_organization` = 12 000 ₽ (внутренняя оптовая для других школ).

### 6. Публикация
- `courses.is_published = true`
- `marketplace_courses.is_active = true`, `is_validated = true`
- Финальная проверка: SELECT по join → курс действительно отображается на витрине маркетплейса.

## Технические детали

| Действие | Инструмент |
|---|---|
| Создание скелета + категории | `psql` insert |
| Вызов edge functions генерации | `curl` к `https://atxwvjxbqjgkbjlhsdch.supabase.co/functions/v1/...` с `SUPABASE_SERVICE_ROLE_KEY` |
| Описание/short-описание | скрипт `lovable_ai.py` (модель `gemini-3-flash-preview`) |
| Финальная активация | `psql` update |
| Лог | в `marketplace_import_catalog.error_message` пишу прогресс, чтобы было видно в UI |

## Что НЕ делаю
- Не сканирую весь каталог ipo.msk.ru заново — беру конкретный URL.
- Не трогаю таблицу `course_categories` — категория «Охрана труда» уже существует.
- Не меняю UI админки — всё через существующие функции.
- Не публикую курс на главной landing — только в маркетплейсе.

## Ожидаемый результат
В админке `/admin` → «Маркетплейс» → «Каталог» появится новый курс **«Специалист по охране труда»** в категории «Охрана труда» с обложкой, ценой 15 000 ₽, кратким описанием, ~25 уроками (текст + тесты), статусом «Активен». В каталоге для организаций он будет доступен к покупке.

## Риски
- GigaChat может вернуть отказ на каком-то уроке — обработаю фоллбеком на Gemini через `lovable_ai.py`.
- Обложка может не сгенерироваться — поставлю плейсхолдер из существующего набора маркетплейса.
- Если ИПО изменил URL программы — переключусь на «Инженер по охране труда» из той же категории.
