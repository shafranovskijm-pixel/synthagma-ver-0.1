

## План: страница профиля ученика, визуальное разделение каталога по категориям, табы Курсы/Вебинары, увеличение элементов в шапке

### 1. Создать отдельную страницу профиля ученика `/student/profile`

Новая страница `src/pages/StudentProfile.tsx` с табами (как на скриншоте SkillSpace):
- **Мой профиль** — баннер организации с аватаром и именем, кнопка «Выйти». Ниже: настройки профиля (email, аватар, имя, телефон), справа — изменить email, сменить пароль
- **Идентификация** — текущий компонент VideoIdentification (встроенный, не диалог)
- **Согласие на ПД** — текущий StudentConsentForm (встроенный)
- **Документы** — текущий StudentDocumentsUpload (встроенный)
- **Достижения** — текущий AchievementsPanel (встроенный)
- **Тема оформления** — выбор светлая/тёмная/системная (перенести из dropdown)
- **Партнёрская программа** — ссылка на `/partner` или встроенная секция с реферальным кодом студента

### 2. Обновить шапку `StudentHeader.tsx`

- Убрать из выпадающего меню: Идентификация, Согласие, Документы, Достижения, тему оформления
- Оставить в меню: Мой профиль (переход на `/student/profile`), Что нового?, Выйти
- Увеличить иконки уведомлений и помощи с `w-5 h-5` до `w-6 h-6`, кнопки с `size="icon"` на чуть больший размер
- Увеличить текст имени с `text-sm` до `text-base`, аватар с `w-8 h-8` до `w-10 h-10`

### 3. Визуальное разделение каталога по категориям

В `CourseCatalog.tsx`:
- Вместо единой сетки — группировка курсов по `category_name`
- Каждая группа: заголовок с цветной точкой (цвет категории) + горизонтальный разделитель
- Внутри группы — сетка карточек (4 столбца как сейчас)
- Курсы без категории — в группе «Другое»

### 4. Табы «Курсы» и «Вебинары» под hero-баннером

В `StudentDashboard.tsx` на табе каталога, под `OrgBanner`, добавить переключатель «Курсы | Вебинары»:
- По умолчанию «Курсы» — показывает текущий CourseCatalog
- «Вебинары» — список вебинаров организации (если есть данные, иначе заглушка «Вебинары пока не запланированы»)

### 5. Маршрутизация

В `App.tsx` добавить маршрут `/student/profile` внутри `ProtectedRoute`.
