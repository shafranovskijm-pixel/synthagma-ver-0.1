

# Кнопка «Ссылка для участников» во встроенном плеере + ведение эфира из окна организации

## Что не так сейчас

1. **На скрине — Sheet встроенного плеера** в админ-панели (`AdminWebinarsOverview` → кнопка ▶). Я добавил `ShareWebinarDialog` и счётчик участников **только** в `WebinarsManager` (карточки) и `WebinarLive.tsx` (полная страница). Внутри Sheet с `EmbeddedWebinarPlayer` — **никакой шапки с публичной ссылкой**, поэтому кнопки «Ссылка для участников» там и нет.
2. **«Войти как ведущий» / «Войти в эфир»** в `WebinarsManager` сейчас открывают `/webinar/:id/live` либо в новой вкладке (`target="_blank"`), либо через `window.location.href` — то есть рабочий стол организации сворачивается. Пользователь хочет вести эфир **прямо во всплывающем окне** на дашборде, не уходя со страницы.

## Что сделаю

### A. Добавлю шапку с «Ссылка для участников» во встроенный плеер LiveKit

В `EmbeddedWebinarPlayer.tsx` (компонент `LiveKitEmbed`) над самой комнатой LiveKit покажу мини-панель:

- 🔴 «В эфире» + название
- **Кнопка «Ссылка для участников»** — копирует `https://sintagma.com.ru/w/<public_token>` в буфер + toast «Скопировано»
- Кнопка с иконкой QR (Popover) — рисует QR 200×200 для сканирования с телефона
- Счётчик «👥 N» через `useParticipants()` из `@livekit/components-react`
- Кнопка «⚙ Настройки доступа» — открывает существующий `ShareWebinarDialog` (toggle гостей + пароль)

Чтобы плеер сам знал токен, добавлю в `Props` поле `publicToken?: string | null` и `allowGuests?: boolean`. На стороне `AdminWebinarsOverview` и любых других вызовов передам их из записи `webinars`.

В `SELECT_FIELDS` `AdminWebinarsOverview.tsx` добавлю `public_token, allow_guests, guest_password`. Сейчас этих полей в выборке нет — это вторая причина, почему кнопка не появилась бы даже если бы я её отрендерил.

### B. Режим «вебинар в окошке» вместо отдельной страницы

В `WebinarsManager.tsx`:

- Кнопки **«Войти как ведущий»** (live-баннер сверху) и **«Войти в эфир»** (карточка) больше не делают `<a href="/webinar/.../live" target="_blank">`. Вместо этого открывают **большой полупрозрачный Sheet/Dialog поверх дашборда** — `WebinarLiveSheet`.
- Внутри Sheet монтируется `EmbeddedWebinarPlayer` с теми же ID + новой шапкой (см. пункт A) → эфир идёт во всплывающем окне, дашборд организации остаётся под ним.
- Слева вверху Sheet — кнопка «Развернуть на весь экран» (при необходимости), которая делает `navigate('/webinar/:id/live')` для тех, кому удобнее старый режим.
- Добавлю кнопку «Завершить эфир» прямо в шапке Sheet (PATCH `status='ended'` + `room.disconnect()`).

Это даёт ровно тот UX, который пользователь нарисовал на скрине: **окно с эфиром поверх рабочего стола**, без перехода на отдельную страницу.

### C. То же окно — в админке

В `AdminWebinarsOverview.tsx` в существующий Sheet `playerWebinar` добавлю передачу `publicToken/allowGuests/guestPassword` в `EmbeddedWebinarPlayer`, и шапка с «Ссылка для участников» автоматически появится — ровно так, как ожидал пользователь на скриншоте.

| (опционально) `src/components/webinars/LiveWebinarSheet.tsx` | Тонкий wrapper-Sheet с шириной `max-w-5xl` + ESC-закрытие |

## Безопасность и логика

- Кнопка «Ссылка для участников» рендерится только если `publicToken` есть (для kinescope/external показываем `embed_url` или прячем).
- Sheet/Dialog с эфиром при закрытии вызывает `room.disconnect()` через коллбэк `onDisconnected`, чтобы камера/микрофон не оставались висеть.
- При закрытии Sheet **эфир НЕ завершается автоматически** (другие участники остаются) — для завершения есть отдельная кнопка «Завершить эфир».
- В админ-панели «Завершить эфир» доступна только если у админа права на `webinars.status` (RLS уже это разрешает глобальным админам).

## Что пользователь увидит

1. Жмёт ▶ на вебинаре в админке (или «Войти в эфир» в кабинете организации) → справа выезжает большой Sheet с **полноценным LiveKit-плеером + шапкой**.
2. В шапке: 🔴 название, кнопка **«Ссылка для участников»** (копирует), QR, счётчик «👥 3», «Завершить эфир», «Развернуть».
3. Дашборд платформы остаётся под Sheet — можно закрыть Sheet, посмотреть статистику и вернуться к эфиру (камера переподключится автоматически).
4. Никакой новой вкладки / навигации. Эфир ведётся прямо «в окошке».

## Чего НЕ делаю

- Не трогаю саму страницу `/webinar/:id/live` — она остаётся как опция «развернуть». 
- Не меняю Kinescope/external плееры (там нет публичных токенов LiveKit).
- Не добавляю запись эфира — это отдельная задача.
