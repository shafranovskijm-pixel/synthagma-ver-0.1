

# Переработка вкладки «Закрывающие» → три суб-вкладки + хук в админку

## Что нужно

Вкладка «Закрывающие» в разделе «Документы» должна содержать три суб-вкладки:

1. **Договоры** — договоры с Синтагмой (платформой). Пока таблицы нет — создать.
2. **Счета** — счета из `subscription_invoices`, которые организация генерирует через вкладку «Подписка». Отображаются здесь же со статусом оплаты, суммой, датой.
3. **Закрывающие документы** — акты из `org_billing_documents`. Текущий функционал (генерация акта, просмотр, скачивание, удаление) переезжает сюда.

Также нужен хук в админ-панель: админ видит все счета и закрывающие документы по всем организациям.

## Изменения

### 1. Миграция — таблица `org_contracts`
Новая таблица для хранения договоров организации с платформой:
- `id`, `organization_id`, `contract_number`, `contract_date`, `file_url`, `file_path`, `status`, `created_at`
- RLS: организация видит свои, админ — все

### 2. `DocumentsTab.tsx` — суб-вкладки в «Закрывающие»
Заменить текущий плоский список `billingDocs` на `Tabs` с тремя вкладками:
- **Договоры** — список из `org_contracts`, пока пустой state с заглушкой
- **Счета** — данные из `subscription_invoices` для этой организации, таблица как на референсе (номер, сумма, статус оплаты, дата)
- **Закрывающие** — текущие `org_billing_documents` + кнопка «Сформировать акт»

### 3. Админ-панель — новый компонент для просмотра счетов и закрывающих
Добавить возможность просмотра всех счетов (`subscription_invoices`) и закрывающих документов (`org_billing_documents`) по всем организациям в админке (поиск, фильтр по организации, статус).
