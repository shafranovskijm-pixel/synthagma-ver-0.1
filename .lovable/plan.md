
## Что просит пользователь
Сейчас уведомление "Запрошены правки по документу" в попапе уведомлений не кликабельно — клик никуда не ведёт. Нужно: при клике на это уведомление переходить в раздел документооборота организации и открывать конкретный документ с правками.

## Анализ
Уведомление имеет:
- `type = 'signature'`
- `related_id` = ID записи в `document_signatures`

В `OrgNotifications.tsx` обработчик клика сейчас обрабатывает только `subscription_expiry` → `/invoice/:id`. Для `signature` ничего нет.

Нужно найти:
1. Маршрут раздела документооборота организации.
2. Как открывается конкретный документ (диалог/страница).
