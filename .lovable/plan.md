
## Предпросмотр курсов в магазине для студентов

### Проблема
Сейчас при клике на карточку курса в магазине студентов сразу открывается диалог заявки. Нет возможности посмотреть подробную информацию о курсе: полное описание, список уроков, длительность.

### Решение
Добавить диалог детального просмотра курса, который открывается при клике на карточку. Из него уже можно будет оставить заявку.

### Что будет сделано

#### 1. Новый диалог предпросмотра курса в `StudentCourseStore.tsx`

При клике на карточку курса откроется полноэкранный диалог (Sheet) с:

- **Изображение превью** (если есть `preview_image_url`) или градиентный баннер
- **Название курса** и организация-продавец
- **Полное описание** курса (из `courses.description`, не обрезанное)
- **Длительность** (академические часы)
- **Список уроков** курса (название + тип: лекция / видео / тест / презентация) -- загружается при открытии
- **Цена** и кнопка "Оставить заявку" внизу (sticky footer)

#### 2. Загрузка уроков курса

При открытии диалога будет выполняться запрос к таблице `lessons` для получения списка уроков выбранного курса (только `title`, `type`, `order_index` -- без контента). Уроки будут показаны как нумерованный список с иконками по типу.

#### 3. Обновление карточек в каталоге

Карточки станут кликабельными целиком (открывают предпросмотр), а кнопка "Оставить заявку" останется для быстрого заказа без предпросмотра.

### Технические детали

**Затрагиваемый файл:** `src/components/student/StudentCourseStore.tsx`

Изменения:
- Новый state: `previewCourse` (выбранный курс для просмотра), `previewLessons` (уроки), `isLoadingPreview`
- Функция `fetchPreviewLessons(courseId)` -- загрузка уроков из таблицы `lessons`
- Компонент Sheet (из ui/sheet) для отображения детальной информации
- Иконки по типу урока: FileText (лекция), Video (видео), ClipboardList (тест), Presentation (презентация), Headphones (аудио)
- Кнопка "Оставить заявку" в footer диалога переключает на существующий диалог заявки
