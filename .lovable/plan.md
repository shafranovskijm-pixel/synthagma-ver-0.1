

## Универсальная установка приложения из любого браузера

### Проблема
Сейчас страница `/install` показывает инструкции только для конкретных браузеров (Chrome, Safari, Яндекс). Если пользователь открывает в другом браузере (Samsung Internet, Firefox, Opera, UC Browser и т.д.) — инструкции могут быть неточными или отсутствовать.

### Что будет сделано

#### 1. Расширенное определение браузеров
Добавить определение популярных мобильных браузеров:
- Samsung Internet
- Firefox
- Opera / Opera Mini
- UC Browser
- Mi Browser (Xiaomi)
- Huawei Browser

#### 2. Универсальная структура страницы
Вместо жёсткой привязки к браузерам -- показывать:

**Блок 1 (если доступен beforeinstallprompt):** Кнопка "Установить" -- работает в Chrome, Edge, Samsung Internet, Opera

**Блок 2 (всегда виден):** Универсальная карточка с инструкциями, адаптированная под текущий браузер:
- **Яндекс Браузер**: меню внизу справа -> "Добавить на главный экран"
- **Safari (iOS)**: "Поделиться" -> "На экран Домой"
- **Samsung Internet**: меню -> "Добавить на главный экран"
- **Firefox**: меню -> "Установить" или "Добавить на главный экран"
- **Opera**: меню -> "Главный экран"
- **Chrome / другие**: меню -> "Установить приложение"

**Блок 3:** Кнопки "Скопировать ссылку" и "Обновить страницу" -- всегда видны

#### 3. Логика отображения
- Определяем браузер и ОС
- Показываем одну карточку с инструкциями именно для этого браузера
- Если браузер не распознан -- показываем универсальную инструкцию "Откройте меню браузера и найдите пункт «Добавить на главный экран» или «Установить»"
- На десктопе показываем инструкции и для iOS, и для Android

### Технические детали

**src/pages/Install.tsx:**

Новая логика определения браузера:
```typescript
const getBrowserName = (): string => {
  const ua = navigator.userAgent;
  if (/YaBrowser|YaSearchBrowser/.test(ua)) return 'yandex';
  if (/SamsungBrowser/.test(ua)) return 'samsung';
  if (/Firefox|FxiOS/.test(ua)) return 'firefox';
  if (/OPR|Opera/.test(ua)) return 'opera';
  if (/UCBrowser/.test(ua)) return 'ucbrowser';
  if (/MiuiBrowser/.test(ua)) return 'miui';
  if (/HuaweiBrowser/.test(ua)) return 'huawei';
  if (/EdgA|Edg/.test(ua)) return 'edge';
  if (/CriOS|Chrome/.test(ua)) return 'chrome';
  if (/Safari/.test(ua)) return 'safari';
  return 'unknown';
};
```

Для каждого браузера -- объект с названием, иконкой и шагами установки. Если браузер не определён -- универсальная инструкция.

Карточка "Скопировать ссылку" остаётся для всех браузеров как альтернатива.
