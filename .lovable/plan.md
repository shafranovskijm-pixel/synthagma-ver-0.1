## Чего объективно не хватает (по индустрии: Zoom / Webinar.fm / Bigbluebutton / Whereby)

### 🔴 Критично (блокирует продажи Pro-тарифа)

1. **Авто-запись (LiveKit Egress → Lovable Cloud Storage)**
   Сейчас запись только ручная — это анти-фича для DPO/корпоратов. Egress пишет MP4 напрямую в наш бакет `course-files/webinar-recordings/`, без внешнего S3. Триггер: хост стартует эфир → edge `livekit-start-recording` запускает RoomCompositeEgress → webhook `livekit-egress-webhook` сохраняет URL в `webinars.recording_url`.

2. **Напоминания участникам о вебинаре** (email за 24ч / 1ч / 15мин до начала + iCal-вложение)
   Edge `webinar-reminders-cron` через `pg_cron`. Сейчас человек просто забывает.

3. **Регистрация на вебинар + лендинг `/w/<token>/register`**
   Сейчас гость сразу попадает в комнату. Нужна форма «ФИО + email + согласие на обработку» → запись в новую таблицу `webinar_registrations` → отправка персональной ссылки + iCal на email. Это даёт лиды.

4. **Обратная связь после эфира** (NPS + комментарий)
   Окно «Оцените вебинар» при выходе из комнаты → таблица `webinar_feedback`. Метрика для организации.

### 🟠 Важно (улучшит UX)

5. **Модерация участников хостом**
   - Замьютить/размьютить участника, выкинуть из комнаты, передать слово, «поднять руку».
   - В UI: правый сайдбар «Участники» с действиями. У LiveKit `roomAdmin: true` уже выдаётся хосту — нужно только UI.

6. **Q&A панель** (отдельная от чата — модерируемые вопросы)
   Таблица `webinar_questions` (question, author, upvotes, answered_by, answered_at). В UI вкладка «Вопросы» рядом с чатом. Хост помечает «отвечено».

7. **Опросы / Polls в реальном времени**
   Хост запускает опрос («Понятно ли вам?», варианты, или открытый), участники голосуют, мгновенный результат. Таблица `webinar_polls` + `webinar_poll_votes`. Realtime через Supabase channel.

8. **Демонстрация экрана и виртуальный фон**
   Screen-share в LiveKit уже доступен (просто кнопка), но сейчас её нет в нашей UI-обёртке — нужно включить в `controls` пропсе `VideoConference`.

9. **«Отметка о посещении» → автоматическое начисление в `enrollments` / журнал посещаемости вебинара**
   Сейчас `webinar_participants` пишется, но не используется в журналах ДПО. Нужна интеграция с `AutoDocumentRegistrationJournal` и автоначисление прогресса по курсу, к которому привязан вебинар.

10. **Аналитика вебинара** (отдельная вкладка)
    - Уникальных зрителей, среднее время просмотра, пик одновременных, CTR на ссылки в чате, сколько досмотрело до конца.
    - Полезно для отчётов организации.

### 🟢 Полезно (premium-фичи)

11. **Live-трансляция в YouTube/VK через RTMP-egress**
    LiveKit умеет ретранслировать в любой RTMP — даём больше охвата без покупки отдельного стримера.

12. **Брендирование комнаты**
    Лого организации в углу плеера, цветовая тема, кастомный текст «Добро пожаловать».

13. **Виртуальная «приёмная» (waiting room)**
    Участник заходит → видит «Эфир скоро начнётся» → хост впускает (или авто-впуск). Сейчас все попадают сразу.

14. **Электронный сертификат участника вебинара**
    После просмотра ≥80% времени → автогенерация PDF-сертификата (через существующий `document-printing-system`). Привязать к достижениям.

15. **Запись скачивается / стримится ученикам курса**
    Когда `recording_url` есть и `course_id` привязан → запись автоматически появляется как урок типа «Видео» в курсе.

16. **Дашборд использования LiveKit-минут в админке**
    Виджет «Использовано X из 5000 минут в этом месяце» через LiveKit Analytics API. Прогноз исчерпания тарифа.

17. **Серии вебинаров / повторяющиеся** (RRULE: каждый вторник в 19:00)
    Поле `recurrence_rule` в `webinars` + cron-генерация инстансов.

## Архитектурные риски, которые надо закрыть

- **Нет таблицы `webinar_chat_messages`** — чат живёт только в памяти LiveKit, после эфира всё пропадает. Нужен webhook от LiveKit Data Channel → сохранение в Postgres → доступно в записи.
- **`livekit-issue-token` выдаёт `roomAdmin` только хосту** — корректно, но нет роли «модератор» (помощник хоста). Расширить на `org_staff` с ролью editor.
- **Лимит 5000 participant-minutes/мес** — при росте надо мониторить и автопереключать на Kinescope Live или платный тариф LiveKit. Сейчас «упадём молча».
- **В `webinars.guest_password` хранится в открытом виде** — должен быть `pgp_sym_encrypt` (нарушение нашего стандарта шифрования PII).

## Что предлагаю сделать в ближайшем спринте (приоритизация)

**Спринт 1 — Базовый профессиональный набор (≈ 4 итерации)**
1. ✅ Авто-запись через LiveKit Egress в Lovable Cloud Storage (MP4 → bucket `course-files`).
2. ✅ Email-напоминания за 24ч/1ч + iCal-вложение в письмо.
3. ✅ Модерация: панель участников с mute/kick + screen-share в UI.
4. ✅ Q&A панель + опросы Polls (realtime).

**Спринт 2 — Лиды и аналитика (≈ 3 итерации)**
5. Регистрация на вебинар (лендинг + форма + iCal).
6. Аналитика по вебинару (уникальных, среднее время, пик).
7. NPS-feedback после эфира.

**Спринт 3 — Премиум-фичи (≈ 3 итерации)**
8. Запись = автоматический урок в привязанном курсе.
9. Сертификат участника при ≥80% просмотра.
10. Серии вебинаров (RRULE) + дашборд минут LiveKit.

## Что НЕ предлагаю (намеренно)

- **Свой WebRTC-стек** — LiveKit/Kinescope полностью закрывают потребность.
- **Whiteboard / Miro-like** — для DPO/корпоративов overkill, можно интегрировать через iframe позже.
- **Breakout rooms** (микро-комнаты) — есть в LiveKit, но сложно в UI; добавим только при явном запросе клиентов Pro/Max.
