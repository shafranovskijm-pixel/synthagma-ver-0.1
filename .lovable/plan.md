

## План: Добавление FRDO-настроек в карточку курса

### Цель
Добавить настройки ФИС ФРДО на уровне курса, чтобы при экспорте данных в ФРДО значения (тип программы, область деятельности, группа специальностей и т.д.) автоматически подтягивались из курса, а не вводились вручную для каждого студента.

### Шаг 1: Миграция базы данных

Добавить новые колонки в таблицу `courses`:

| Колонка | Тип | Описание |
|---------|-----|----------|
| `frdo_program_type` | text | "dpo" или "po" (ДПО/ПО) |
| `frdo_document_type` | text | Вид документа |
| `frdo_professional_area` | text | Область профессиональной деятельности |
| `frdo_specialty_group` | text | Укрупненная группа специальностей |
| `frdo_qualification_name` | text | Наименование квалификации/специальности |
| `frdo_profession_name` | text | Наименование профессии (для ПО) |
| `frdo_qualification_rank` | text | Квалификационный разряд (для ПО) |

---

### Шаг 2: Обновление интерфейса CourseDetailsModal

В вкладке "Настройки" добавить новый раздел "Настройки ФИС ФРДО":

**Поля с выпадающими списками:**

1. **Тип программы** (Select):
   - Повышение квалификации (ДПО)
   - Профессиональная переподготовка (ДПО)
   - Профессиональное обучение (ПО)

2. **Вид документа** (Select, зависит от типа):
   - Для ПК: "Удостоверение о повышении квалификации"
   - Для ПП: "Диплом о профессиональной переподготовке"
   - Для ПО: "Свидетельство о профессии рабочего, должности служащего"

3. **Область профессиональной деятельности** (Input с подсказками)

4. **Укрупненная группа специальностей** (Input с подсказками)

5. **Наименование квалификации** (Input)

6. **Для ПО дополнительно:**
   - Наименование профессии
   - Квалификационный разряд

---

### Шаг 3: Интеграция с FRDO-экспортом

Обновить логику в:
- `FRDOManager.tsx` — использовать FRDO-настройки из курса при массовом экспорте
- `FRDOExportDialog.tsx` — при загрузке данных курса подтягивать FRDO-настройки и подставлять в соответствующие поля

**Логика приоритета:**
1. Если у курса заданы FRDO-настройки → использовать их
2. Иначе → использовать данные из `student_frdo_data` (текущее поведение)

---

### Ожидаемый результат

После реализации организация сможет:
1. Один раз настроить FRDO-параметры для каждого курса
2. При экспорте в ФИС ФРДО эти параметры будут автоматически подставляться для всех студентов курса
3. Это значительно сократит ручной ввод при массовом экспорте данных
