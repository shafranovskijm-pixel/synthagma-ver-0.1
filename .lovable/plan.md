

# Отзывы от зарегистрированных организаций на лендинге

## Что будет сделано

Заменить статичные отзывы на динамические, которые оставляют реальные зарегистрированные организации. Система автоматически рассчитывает стаж использования платформы на основе даты регистрации организации.

## Основные возможности

1. **Форма отзыва** -- организация авторизуется и оставляет отзыв с рейтингом (1-5 звезд), текстом и коротким заголовком (highlight)
2. **Автоматический стаж** -- система сама считает "Пользуется N месяцев" по дате `created_at` из таблицы `organizations`
3. **Модерация** -- отзывы отображаются только после одобрения администратором (поле `is_approved`)
4. **Авторизация** -- вход через существующий аккаунт организации (роль `organization`), без регистрации новых пользователей
5. **Статичные отзывы сохраняются** -- текущие 3 отзыва остаются как fallback, пока нет одобренных из БД

## Техническая реализация

### 1. Новая таблица `testimonials`

```
- id (uuid, PK)
- organization_id (uuid, FK -> organizations)
- user_id (uuid) -- кто оставил
- content (text) -- текст отзыва
- highlight (text) -- короткий заголовок-бейдж
- rating (integer, 1-5)
- author_name (text) -- ФИО автора
- author_role (text) -- должность
- is_approved (boolean, default false)
- created_at (timestamptz)
```

**RLS-политики:**
- SELECT: `is_approved = true` для всех (публичный показ)
- INSERT: только пользователи с ролью `organization`
- UPDATE/DELETE: только admin
- Орг-пользователи могут видеть свои отзывы (даже неодобренные)
