

# Улучшение партнёрского кабинета: древо сети, материалы, оферта, схемы

## Что делаем

### 1. Визуальное дерево партнёрской сети (вкладка «Моя сеть»)

Заменяем текущие две таблицы (Уровень 1 / Уровень 2) на интерактивное древо:
- Корень — текущий партнёр (вы)
- Ветки уровня 1 — прямые партнёры, каждый раскрывается и показывает своих партнёров (уровень 2)
- Уровень 2 раскрывается в уровень 3
- Каждый узел: код партнёра, статус (цветной индикатор), дата, заработано
- Сворачивание/разворачивание через Collapsible
- Линии-связи через CSS (border-left + padding) — стиль «дерево файлов»
- Также подгружаем привлечённые организации каждого партнёра (clients count)

### 2. Новая вкладка «Материалы»

Рекламные материалы для партнёров:
- Готовые баннеры (3 шт) — SVG/inline визуалы в стиле Синтагма (teal/cyan), разных размеров
- Готовые тексты для соцсетей/мессенджеров (3 варианта) с кнопкой «Копировать» — текст автоматически подставляет реферальную ссылку партнёра
- QR-код реферальной ссылки (генерация через canvas/SVG inline)
- Презентация-одностраничник «Почему Синтагма» — краткий текст с ключевыми преимуществами

### 3. Новая вкладка «Как это работает» (схемы обучения)

Пошаговая инструкция + визуальные схемы:
- Схема «Как работает комиссия» — 3 уровня с процентами, визуализация потока денег
- Схема «Путь клиента» — от перехода по ссылке до начисления комиссии
- Пример расчёта дохода (как на лендинге, но интерактивный — ввод суммы → показ комиссий по уровням)
- FAQ: частые вопросы с ответами

### 4. Ссылка на оферту

- В шапке партнёрского кабинета добавить ссылку «Оферта» → `/partner/offer`
- В StudentPartnerTab: заменить inline-оферту на ссылку на полную страницу `/partner/offer`
