

# Табы в Настройках + реструктуризация Профиля

## Что будет сделано

### 1. Страница «Настройки» (`OrganizationSettings`) — переделать на вкладки
Вместо scroll-секций с `<details>` — использовать `<Tabs>` как в Профиле:
- **Разделы меню** — toggles для пунктов бокового меню
- **Robokassa** — платёжные настройки
- **Настройки ЛК ученика** — достижения, ИИ-чат, catalogMode
- **Управление разделами** — навигация к Сотрудникам/Документам/Журналам/ФРДО

### 2. Страница «Профиль» (`OrganizationProfile`) — новые вкладки
Убрать вкладку «Настройки». Новая структура:
- **Мой профиль** — личные данные + значок организации + email/пароль + тема оформления + данные для входа (OrgCredentials)
- **Брендирование** — цвета, лого, обложка, название
- **Брендирование страницы входа** — LoginBrandingSettings
- **Настройки уведомлений** — таблица уведомлений
- **Партнёрская программа** — PartnerCabinet

### 3. Перемещение компонентов
- `ThemePersonalization` и `OrgCredentialsSettings` из `OrgProfileSettings` → в таб «Мой профиль» в `OrganizationProfile`
- Брендирование и Login Branding из `OrgProfileSettings` → отдельные табы в `OrganizationProfile`
- Настройки ЛК ученика из `OrgProfileSettings` → таб в `OrganizationSettings`
- `OrgProfileSettings.tsx` можно упразднить (всё разнесено по табам)
