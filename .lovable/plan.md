
## Задача
В диалоге «Медиатека» (выбор ранее загруженных файлов) сейчас показываются файлы всех организаций — это и нарушение приватности, и тормозит загрузку (72 файла из чужих курсов). Нужно показывать только файлы текущей организации.

## Исследование
Нужно найти:
1. Компонент диалога «Медиатека» (на скриншоте — заголовок «Медиатека N файл(ов)», поиск по имени файла, превью справа).
2. Откуда он берёт список файлов — скорее всего, листинг бакета `course-files` без фильтра по организации.
3. Как фильтровать по `organization_id` — через path-префикс в бакете либо через таблицу-индекс файлов.
