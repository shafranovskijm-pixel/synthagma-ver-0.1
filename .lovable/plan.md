
# Скрытие настроек ФИС ФРДО для тарифов без доступа

## Проблема

Сейчас блок "Настройки ФИС ФРДО" в настройках курса отображается для всех тарифов, включая бесплатный, хотя категория `frdo` доступна только в тарифах "Профессиональный" и "Максимальный".

## Какие тарифы имеют доступ к ФРДО

| Тариф | Категория `frdo` | Настройки ФРДО в курсе |
|---|---|---|
| Бесплатный | Нет | Скрыть |
| Старт | Нет | Скрыть |
| Стандарт | Нет | Скрыть |
| Профессиональный | Да | Показать |
| Максимальный | Да | Показать |

## Что будет сделано

### Файл: `src/components/organization/dialogs/CourseDetailsModal.tsx`

1. Добавить импорт `useOrgFeatures` из `@/hooks/useOrgFeatures`
2. Вызвать хук: `const { isEnabled } = useOrgFeatures(organizationId)`
3. Обернуть весь блок "Настройки ФИС ФРДО" (строки 875-1085) в условие `{isEnabled('frdo') && ( ... )}`

Это использует существующую систему фич, которая уже учитывает подписку организации: в хуке `useOrgFeatures` при применении ограничений тарифа категория `frdo` автоматически выключается, если она отсутствует в `enabledCategories` плана.

### Результат

- Бесплатный/Старт/Стандарт: блок настроек ФИС ФРДО полностью скрыт во вкладке "Настройки" курса
- Профессиональный/Максимальный: настройки отображаются как раньше
- Никаких изменений в БД не требуется
