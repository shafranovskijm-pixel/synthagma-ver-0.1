

# Унифицированный дизайн чатов с аватарами

## Что нужно
По образцу из скриншота — во всех списках контактов/переписок добавить круглые цветные аватары с инициалами (как в мессенджерах). Это касается:
- `OrgChatsTab` (список слушателей)
- `AdminChatsManager` (список организаций)
- `ColleagueChatPanel` (список коллег)

## Изменения

### 1. Создать компонент `ChatAvatar`
`src/components/chat/ChatAvatar.tsx` — круглый аватар с инициалами на цветном фоне. Цвет генерируется стабильно по имени (hash). Размер настраивается через пропс.

### 2. Обновить `OrgChatsTab.tsx`
- Добавить `ChatAvatar` перед именем каждого слушателя в списке
- Для «Администрация платформы» — аватар с иконкой Shield

### 3. Обновить `AdminChatsManager.tsx`
- Добавить `ChatAvatar` перед именем каждой организации в списке
- Аватар в шапке открытого чата

### 4. Обновить `ColleagueChatPanel.tsx`
- Добавить `ChatAvatar` перед именем каждого контакта
- Аватар в шапке открытого чата

### 5. Обновить `ChatTab.tsx` (чат org-student)
- Аватар отправителя в пузырьках сообщений (опционально, как в мессенджере)

## Детали `ChatAvatar`
```text
┌──────────┐
│  ИМ      │  ← Инициалы (первая буква имени + фамилии)
│  (цвет)  │  ← Цвет фона из палитры по hash имени
└──────────┘
```

Палитра: ~10 приятных цветов (розовый, фиолетовый, синий, зелёный, оранжевый и т.д.) — как на скриншоте.
