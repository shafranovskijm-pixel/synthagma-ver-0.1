

# Обогащение 3 демо-курсов: изображения, кейсы, тесты, кнопки на книги

## Что есть сейчас

3 курса (`Психолог-консультант`, `Специалист по охране труда`, `HR-менеджер`) — по 12 уроков ~10k символов чистого текста (JSON-блоки только heading/paragraph/bullet) + 1 итоговый тест на 15 вопросов. Обложка есть, но **внутри уроков нет ни одной картинки, ни одного callout, ни одной кнопки, ни одного аккордеона, ни одной мини-проверки**.

## Что добавлю — для каждого из 36 уроков

### 1. Иллюстрация в начало урока (1 изображение)
- Генерирую через **Nano Banana 2** (`google/gemini-3.1-flash-image-preview`) — быстро + качественно.
- Промпт привязан к теме урока + единый стиль: «luxury minimalism, teal/cyan accent, soft gradient, professional editorial illustration, 16:9».
- Загружаю в `course-files/lesson-images/<course_id>/<lesson_id>.png`.
- Вставляю как блок `image` сразу после первого `heading1`.

### 2. Callout-блоки по тексту (2-3 на урок)
В существующий текст вставляю:
- **`callout-info`** — нормативная база («Согласно ст. 209 ТК РФ…»)
- **`callout-tip`** — практический совет от эксперта
- **`callout-warning`** — типичная ошибка / красный флаг

### 3. Аккордеоны с кейсами (1-2 на урок)
- Реальные мини-кейсы из практики: `accordion` со свёрнутым названием («Кейс: клиент с тревожным расстройством») и развёрнутым разбором ситуации + решение.
- Контент кейсов генерирую через **Gemini 3 Flash** под конкретную тему урока.

### 4. Mini-quiz по ходу урока (1 quiz-блок)
- Не итоговый тест, а проверка понимания внутри урока: 1 вопрос с 3-4 вариантами + объяснением.
- Тип блока `quiz` (поддерживается `BlockRenderer`).

### 5. Кнопки на источники / книги (2-3 на урок)
- Блок `button` с `buttonVariant: 'outline'` или `'primary'`.
- Ссылки: реальные книги на **ЛитРес / Альпина / MyBook** + статьи на **КонсультантПлюс** (для нормативки) + Google Scholar для научных публикаций.
- Примеры:
  - «📖 Купить книгу Р. Кочюнаса "Основы психологического консультирования"» → litres.ru
  - «⚖️ Открыть ст. 209 ТК РФ на КонсультантПлюс» → consultant.ru
  - «📚 Глава из книги М. Армстронга "Практика управления HR"» → alpinabook.ru

### 6. Дополнительная плашка-резюме в конце урока
- `callout-success` с итогами «Что вы узнали» (3-5 пунктов) + `divider` + блок-кнопок «Куда двигаться дальше».

## Дополнительно для всего курса (не для каждого урока)

### A. Материалы курса (через `course_documents`)
По 5-7 материалов на курс:
- **Глоссарий специальности** — генерирую PDF через Gemini → загружаю в `course-files`
- **Чек-лист первого приёма / первого аудита** (PDF)
- **Шаблон рабочих документов**:
  - для психолога: бланк информированного согласия, шаблон контракта с клиентом
  - для ОТ: шаблон инструкции по охране труда, форма Н-1
  - для HR: шаблон должностной инструкции, KPI-матрица
- **Список рекомендуемой литературы** (PDF с обложками + ссылками на покупку)
- **Нормативная база** — ссылочный документ со ссылками на ТК РФ / 273-ФЗ / профстандарты

### B. Дополнительные тесты-врезки между модулями
Не трогаю итоговый тест на 15 вопросов, но добавляю **2 промежуточных теста** между модулями (после 4-го и после 8-го урока):
- `lesson.type = 'test'`, по 5 вопросов каждый
- Темы: «Контрольная по теории» и «Контрольная по практике»

### C. Кейс-урок в каждый курс
Добавляю 13-й урок типа `text` — **«Разбор реального кейса от эксперта»**:
- 5-7 развёрнутых кейсов в формате аккордеонов
- В каждом: ситуация → диагноз/анализ → решение → результат
- Вступление с фото эксперта (AI-сгенерированное)

## Как реализую

1. Копирую `knowledge://skill/ai-gateway/scripts/lovable_ai.py` в `/tmp/lovable_ai.py`.
2. Пишу один скрипт `/tmp/enrich_demo_courses.py`:
   - Для каждого из 36 уроков: парсит текущие JSON-блоки → передаёт Gemini Flash контекст («вот контент, верни обогащённый список блоков с картинкой/callout/quiz/buttons по такой-то схеме») → получает новый JSON.
   - Для каждой картинки: вызывает Nano Banana 2 → загружает в storage через REST API.
   - Для книг/ссылок: использую заранее подготовленный список реальных URL (litres, alpinabook, consultant.ru, garant.ru) — Gemini подбирает релевантные из моего списка под тему урока, чтобы не выдумывал битых ссылок.
   - PDF-материалы: генерирую HTML → конвертирую в PDF через существующую edge-функцию или через `weasyprint` локально → загружаю в `course-files/course-materials/<course_id>/`.
3. Все изменения делаю через `psql` (UPDATE lessons SET content = …, INSERT INTO course_documents …, INSERT INTO lessons … для новых уроков-кейсов и тестов).
4. По каждому курсу — отчёт: «12 уроков обогащено, +1 кейс-урок, +2 промежуточных теста, +6 материалов в библиотеку».

## Расход токенов Lovable

| Задача | Вызовов | Примерно |
|---|---|---|
| Обогащение уроков (Gemini 3 Flash) | 36 × ~5k токенов | ~180k |
| Иллюстрации уроков (Nano Banana 2) | 36 × ~1k | ~36k |
| Кейс-уроки (Gemini Flash) | 3 × ~8k | ~24k |
| Промежуточные тесты | 6 × ~3k | ~18k |
| PDF-материалы (Gemini) | 21 × ~4k | ~84k |
| Иллюстрация эксперта | 3 × ~1k | ~3k |
| **Итого** | | **~340-370k токенов** |

Это уже заметный расход подписки Lovable — но в рамках одного демо-прогона приемлемо. Большая часть — на иллюстрации (36 шт).
