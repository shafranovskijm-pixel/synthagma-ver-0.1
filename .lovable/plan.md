
# Исправление подписания документов

## Баг 1: Печать и подпись перепутаны
В рендеринге canvas и при генерации PDF используется `o.type === 'stamp' ? stampImg : sigImg`. Нужно поменять местами — `stamp` должен использовать `sigImg`, а `signature` — `stampImg`. Скорее всего сами файлы ассетов перепутаны по смыслу. Самый надёжный способ — поменять маппинг в трёх местах:
- Строка 125: рендеринг canvas
- Строка 231: генерация PDF (`stImg` / `sgImg`)

## Баг 2: При подписании сохраняется только одна печать и подпись
Сейчас все оверлеи рисуются на последней странице (`lastPage`, строка 227). Оверлеи не привязаны к конкретным страницам.

**Решение:** Добавить поле `page: number` в `Overlay`. При переключении страниц — показывать только оверлеи текущей страницы. При подписании — рисовать каждый оверлей на его странице.

### Изменения в `DocumentSigning.tsx`:

1. **Интерфейс `Overlay`** — добавить `page: number`
2. **`defaultOverlays()`** — привязать к `activePage`
3. **Рендеринг canvas** — фильтровать `overlays.filter(o => o.page === activePage)`
4. **Контекстное меню** — при добавлении оверлея записывать текущую страницу
5. **`handleSign`** — группировать оверлеи по `page`, рисовать на соответствующих страницах
6. **Поменять маппинг изображений** — swap `stampImg`/`sigImg` в рендеринге и генерации
