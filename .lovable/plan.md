

# Улучшения подписания документов

## Что делаем

1. **Масштабирование печати** — добавить ползунок (slider) для изменения размера печати
2. **Добавление подписи правой кнопкой мыши** — ПКМ на canvas ставит дополнительную подпись в точку клика
3. **Удаление элементов** — каждый оверлей (печать/подпись) можно удалить кнопкой-корзинкой

## Изменения в `DocumentSigning.tsx`

### Модель данных
- Заменить одиночные `stampPos`/`sigPos` на массив оверлеев:
  ```ts
  interface Overlay {
    id: string;
    type: 'stamp' | 'signature';
    x: number; y: number;
    scale: number; // 0.5–2.0, default 1.0
  }
  ```
- `overlays` state — массив всех наложенных элементов
- `selectedOverlayId` — текущий выбранный (для масштабирования и удаления)

### Масштабирование печати
- Под canvas добавить Slider (из UI) для `scale` выбранного оверлея (0.5x–2.0x)
- Базовые размеры: печать 120x120, подпись 150x60 — умножаются на `scale`
- Slider виден только когда выбран оверлей

### Правая кнопка мыши — добавить подпись
- `onContextMenu` на canvas: предотвратить дефолтное меню, добавить новый оверлей типа `signature` в точку клика
- Toast: «Подпись добавлена»

### Удаление оверлеев
- При выборе оверлея (клик) показывать кнопку «Удалить» с иконкой корзины
- Кнопка удаляет выбранный оверлей из массива

### Рендеринг
- В useEffect отрисовки — итерировать по `overlays`, рисовать каждый с его `scale`
- При подписании (handleSign) — аналогично итерировать по `overlays`

### Начальное состояние
- При загрузке файла автоматически добавляются 1 печать и 1 подпись (как сейчас)

### UI панель управления
- Под подсказкой «Перетаскивайте...» добавить строку с:
  - Текст выбранного элемента или «Нажмите на элемент»
  - Slider масштаба (когда выбран)
  - Кнопка удаления (корзинка)
- Обновить подсказку: «ЛКМ — перетащить, ПКМ — добавить подпись»
