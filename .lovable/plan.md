

## План: Онбординг-экран для пустого хранилища

### Что делаем

Заменяем «Хранилище пусто / Загрузите файлы...» (строки 513-519 в `StorageManager.tsx`) на красивую карточку с описанием возможностей хранилища — только когда `files.length === 0`. Если файлы есть, но фильтр пуст — оставляем «Нет файлов по фильтру».

### Содержание карточки

**Заголовок:** «Ваше облачное хранилище готово к работе»

**Описание функционала (продающий стиль):**
- Автоматический сбор файлов из всех курсов — видео, изображения, документы в одном месте
- Инлайн-предпросмотр — смотрите видео, PDF, изображения и аудио прямо в браузере
- Умная группировка по разделам с поиском и фильтрацией по типу
- Безопасный доступ — приватные документы студентов через подписанные URL
- Загрузка файлов в один клик — через интерфейс или напрямую из курсов
- Интеграция с внешним хранилищем для масштабирования

**Кнопка:** «Загрузить первый файл» (вызывает существующий `handleUploadClick`)

### Визуал

Одна широкая карточка с градиентом, иконки фич в 2 колонки, кнопка внизу — аналогично компаниям.
