
# Улучшение интерфейса конструктора шаблонов договора

## Проблема
Сейчас все элементы (выбор шаблона, кнопки действий, панель переменных, редактор, валидация, статистика) расположены вертикально друг под другом в узком аккордеоне. Это создаёт ощущение нагромождённости -- пользователь видит много кнопок и панелей до того, как доберётся до самого редактора.

## Решение

### 1. Убрать аккордеон, открыть редактор на полную высоту
Вместо сворачиваемого аккордеона -- всегда видимый компонент с увеличенной областью редактирования (min-height: 500px вместо 400px). Заголовок остаётся, но без сворачивания.

### 2. Компактная панель инструментов
Объединить все кнопки действий в одну строку-тулбар:
- Слева: выбор шаблона (Select) + "Сохранить как..." + "Удалить" + "История"
- Справа: "Загрузить DOC/PDF", "Добавить переменные", "Предпросмотр", "Сбросить", "Сохранить"

Вместо двух рядов кнопок -- один компактный тулбар с иконками и без текста на мобильных.

### 3. Панель переменных -- боковая (на десктопе)
На экранах шире 1024px панель переменных отображается справа от редактора (30% ширины), а редактор занимает 70%. На мобильных -- сворачиваемая панель сверху (как сейчас).

### 4. Валидация и статистика -- в строку состояния
Перенести валидацию и статистику переменных в компактную строку-статусбар под редактором: иконка статуса + краткое сообщение + клик раскрывает детали.

## Технические изменения

### ContractTemplateEditor.tsx
- Убрать обёртку `Accordion` / `AccordionItem`, заменить на обычный `div`
- Объединить две строки кнопок в один flex-тулбар
- На кнопках без текста на мобильных использовать `hidden sm:inline` для текста

### HighlightedTemplateEditor.tsx
- Изменить layout: на десктопе flex-row (редактор + панель переменных), на мобильных flex-col
- Увеличить min-height редактора до 500px
- Перенести легенду категорий внутрь панели переменных (убрать из основной области)
- Валидацию показывать в компактном виде (одна строка), с раскрытием по клику

### VariableInsertPanel.tsx
- Адаптировать для бокового расположения: вертикальный список категорий вместо grid на десктопе
- Убрать кнопку-тоггл "Вставить переменную" -- на десктопе панель всегда видна

### TemplateValidation.tsx
- Добавить компактный режим: одна строка со статусом, раскрытие деталей по клику

## Итоговая структура на десктопе

```text
+-------------------------------------------------------+
| [Для юр. лица v] [+Сохранить как] [История]  [Загрузить] [AI] [Просмотр] [Сбросить] [Сохранить] |
+--------------------------------------+----------------+
|                                      |  Переменные    |
|   Редактор шаблона                   |  [Договор]     |
|   (70% ширины, 500px высота)         |  contract_num  |
|                                      |  contract_date |
|   г. Владивосток                     |  [Организация] |
|   « {{contract_date}} »              |  org_name      |
|                                      |  org_inn ...   |
+--------------------------------------+----------------+
| v Валидация: Шаблон корректен (12 переменных)          |
+-------------------------------------------------------+
```
