

## Расширение настройки «Доступ»: даты открытия модулей и индивидуальные правила

### Что делаем

В разделе курса **Настройки → Доступ** добавляем новый блок **«Расписание открытия модулей»**. Для каждого модуля курса можно:

1. Задать **глобальную дату открытия** — модуль (и все его уроки) будут заблокированы у всех зачисленных учеников до этой даты.
2. **Переопределить** дату для отдельных учеников — выбрать конкретных зачисленных и поставить им свою дату (раньше или позже глобальной).

До даты открытия модуль виден в плеере, но заблокирован: подпись «Откроется DD.MM.YYYY», клик невозможен. Все уроки внутри модуля автоматически блокируются вместе с ним.

---

### Архитектура

#### 1. База данных (новая миграция)

Две таблицы:

**`module_access_schedules`** — глобальное правило для модуля:
- `id`, `module_id` (FK → course_modules, unique), `course_id`, `unlock_at` (timestamptz), `created_at`, `updated_at`
- RLS: чтение/запись — менеджеры организации, владеющей курсом; чтение для зачисленных учеников курса.

**`module_access_overrides`** — индивидуальные переопределения:
- `id`, `module_id` (FK), `user_id`, `unlock_at` (timestamptz, nullable — `null` = открыт сразу), unique(module_id, user_id)
- RLS: запись — менеджеры организации курса; чтение — менеджеры + сам ученик (только своя строка).

Оба правила оцениваются на клиенте: для каждого модуля берём override → если нет, берём global schedule → если нет, модуль открыт.

#### 2. UI: новый компонент `ModuleAccessSchedule`

Подключается во вкладке «Доступ» в `CourseSettingsTabbed.tsx` под существующими полями. Структура:

```text
┌─ Расписание открытия модулей ─────────────────────┐
│ Настройте дату открытия модулей. По умолчанию все │
│ модули открыты сразу после зачисления.            │
│                                                   │
│ ▸ Модуль 1: Введение                              │
│   [Открыть с: __.__.____ ▼]   [Сбросить]          │
│   👤 Индивидуально для 2 учеников ▼               │
│                                                   │
│ ▸ Модуль 2: Основы                                │
│   [Открыть с: 15.01.2026 ▼]                       │
│   👤 Индивидуально для 0 учеников ▼               │
│      └─ [+ Добавить учеников] (открывает попап    │
│         со списком зачисленных + чекбоксы +       │
│         выбор даты)                               │
└───────────────────────────────────────────────────┘
```

Поведение:
- Date picker (shadcn `Calendar` в `Popover`) — только календарная дата, время = 00:00 по часовому поясу клиента.
- «Сбросить» — удаляет запись из `module_access_schedules` (модуль снова открыт сразу).
- Раскрывающаяся секция «Индивидуально для N учеников» показывает список переопределений с возможностью изменить дату или удалить.
- Кнопка «+ Добавить учеников» — диалог с поиском по списку зачисленных (`courseStudents` уже доступен в контексте) + выбор даты → массовая вставка в `module_access_overrides`.

#### 3. Применение блокировки в плеере ученика

В `useCourseLearning` (`src/hooks/course-learning`):
- Подгружаем `module_access_schedules` для курса и `module_access_overrides` для текущего пользователя.
- Для каждого урока считаем `effectiveUnlockAt = override?.unlock_at ?? schedule?.unlock_at ?? null`.
- Если `effectiveUnlockAt > now()` — урок помечается `is_locked = true` с дополнительным полем `locked_until` (для отображения даты).

В UI плеера (там, где сейчас отображается `is_locked`): добавить плашку «Откроется DD.MM.YYYY в HH:MM» вместо/рядом с замком. Сам клик по уроку блокируется как уже сейчас при `is_locked`.

#### 4. Серверная защита

В edge-функциях, проверяющих доступ к уроку (просмотр контента, отметка прохождения), добавить серверный чек: если для модуля урока есть активная блокировка по дате — вернуть 403. Это страховка против ручных запросов.

### Edge-кейсы

- Если модуль удалён — каскадно удаляются `module_access_schedules` и `module_access_overrides` (через `ON DELETE CASCADE`).
- Если ученик отчислен — записи в `module_access_overrides` остаются, но не применяются (нет активного `enrollments`). При повторном зачислении правила снова актуальны.
- Если модуль не задан у урока (`module_id IS NULL`) — расписание не применяется, урок открыт.
- Часовой пояс: дата хранится в UTC (`timestamptz`), отображается в локальном TZ браузера.
