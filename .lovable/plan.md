

# Объединение Синтагма + Плательщики → Контрагенты

## Суть

Убираем из левого меню отдельные пункты «Синтагма» и «Плательщики». Всё переносим в единый раздел «Контрагенты». Сверху — переключатель контрагента (Синтагма, компании-заказчики, плательщики-физлица), ниже — вкладки «Договоры», «Счета», «Закрывающие».

## Изменения

### 1. `DocumentsTab.tsx` — убрать лишние пункты меню

- Удалить из `NAV_ITEMS` записи `billing` и `payers`
- Удалить из `DocumentSubTab` тип `billing` и `payers` (в `useDocumentsTab.ts`)
- Убрать рендер `BillingDocumentsSection` и `PayersSection` из контентной области
- Перенести кнопки действий (счёт, акт) в новый объединённый раздел

### 2. `CounterpartiesSection.tsx` — добавить переключатель контрагентов сверху

- Вверху — горизонтальный список/селектор: «Синтагма» (платформа), далее компании-заказчики из `companies`, далее плательщики из `org_payers`
- При выборе «Синтагма» — показывать данные из `BillingDocumentsSection` (договоры с платформой, счета `subscription_invoices`, закрывающие `org_billing_documents`)
- При выборе компании — показывать `company_documents` этой компании
- При выборе плательщика — показывать его документы (пока заглушка)
- Внизу — всегда одинаковые вкладки: Договоры / Счета / Закрывающие

### 3. `useDocumentsTab.ts` — упростить типы

- Убрать `BillingSubTab` — заменить на единый `CounterpartySubTab` = `"contracts" | "invoices" | "closing" | "faq"`
- Данные `billingDocs`, `invoices` оставить, но привязать к выбранному контрагенту «Синтагма»
- Добавить состояние `selectedCounterpartyId` и `selectedCounterpartyType` (`platform | company | payer`)

### 4. Кнопки действий в шапке

- «Создать договор» — при выбранном контрагенте-компании
- «Сформировать счёт» — при вкладке «Счета» и контрагенте «Синтагма»
- «Сформировать акт» — при вкладке «Закрывающие» и контрагенте «Синтагма»
- Кнопка «Добавить плательщика» — при выбранной категории плательщиков (через диалог из `PayersSection`)

## Технические детали

- `NAV_ITEMS` теряет `billing` и `payers`, остаётся `counterparties` с label «Контрагенты»
- Переключатель контрагентов — кнопки-чипы сверху контентной области (как на скриншоте)
- `CounterpartiesSection` получает новые пропсы: `invoices`, `billingDocs`, `payers`, `onViewDoc`, `onDownloadDoc`, `onDeleteDoc`, `onShowInvoiceDialog`, `onShowActDialog`
- Файл `BillingDocumentsSection.tsx` можно удалить — его логика встраивается в `CounterpartiesSection`
