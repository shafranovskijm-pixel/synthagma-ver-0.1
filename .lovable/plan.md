

# Карточка компании: два счёта + экспорт + брендинг + ссылка

## Что делаем

1. **Два расчётных счёта** — добавляем оба в `KNOWN_DATA` и отображаем в секции «Банковские реквизиты» (один банк, один БИК, один корр. счёт, два расчётных)

2. **Экспорт в PDF/Word** — кнопки «Скачать PDF» и «Скачать Word» в шапке карточки. Генерируем через edge-функцию с AI-брендированным фоном (Gemini генерирует фоновое изображение Синтагмы в teal/cyan стиле, кешируем в storage). PDF через reportlab, Word через docx-js

3. **AI-фон** — при первом экспорте генерируем брендированный фон через Lovable AI (Gemini flash image), сохраняем в storage bucket `company-assets`. При повторных — используем кешированный

4. **Публичная ссылка** — создаём публичную страницу `/company-card/:token` (токен — UUID, хранится в `app_settings`). Кнопка «Скопировать ссылку» в шапке карточки. Страница отображает те же данные в красивом read-only виде

## Изменения

### `CompanyCard.tsx`
- Добавить второй счёт в `KNOWN_DATA`: `account2: '40802810200000522079'`
- Отобразить оба счёта в секции банковских реквизитов
- Добавить кнопки: «Скачать PDF», «Скачать Word», «Скопировать ссылку»
- PDF/Word — вызов edge-функции `generate-company-card`

### Edge-функция `generate-company-card`
- Принимает `format: 'pdf' | 'docx'`
- Генерирует брендированный документ с фоном (AI-картинка из storage или генерация)
- Возвращает файл

### Публичная страница `/company-card/:token`
- Новый компонент `PublicCompanyCard.tsx`
- Роут в App.tsx
- Отображает реквизиты в read-only формате с брендированным дизайном
- Токен генерируется один раз и хранится в `app_settings`

### Миграция
- Добавить запись `company_card_public_token` в `app_settings` (UUID)

## Технические детали

- AI-фон: промпт «Минималистичный teal/cyan абстрактный фон для карточки компании образовательной платформы Синтагма, волны, геометрия, 1200x800»
- PDF: edge-функция с html2pdf или reportlab
- Word: docx-js в edge-функции
