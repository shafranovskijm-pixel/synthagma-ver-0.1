
## Задача
Когда пользователь добавляет видео через «+» (быстрое добавление блока), показывается старый упрощённый UI (просто поле для ссылки + «Выбрать из загруженных» + «Загрузить видео»). Нужно показывать тот же расширенный UI, что и в полном видеоуроке (скриншот 2): табы «Kinescope (рекомендуется)» / «На сервер (до 2 ГБ)», поле для ссылки/iframe, прикреплённые файлы (лекции PDF/DOC).

## Исследование
Нужно найти:
1. Компонент полного видеоурока (с табами Kinescope / На сервер) — он рендерится для блока «Новый видеоурок»
2. Компонент быстрого добавления видео через «+» (старый UI на скриншоте 1)
3. Понять, можно ли переиспользовать первый во втором.

Опираясь на структуру проекта — это `src/components/course-builder/`. Нужно посмотреть конкретные файлы блоков.

## План действий

1. **Найти оба компонента** — полный видеоурок (с табами Kinescope/Сервер) и упрощённый видео-блок, который открывается через «+».
2. **Заменить упрощённый UI на тот же компонент**, который используется в «Новый видеоурок»: табы Kinescope / На сервер (до 2 ГБ), поле ссылки/iframe, прикреплённые файлы (лекции).
3. **Сохранить совместимость данных** — структура блока остаётся прежней (поле `content` со ссылкой, прикреплённые файлы и т. д.), меняется только UI ввода.

## Технические детали
- Файлы в `src/components/course-builder/` — там лежат блоки уроков и их редакторы.
- Скорее всего, есть компонент типа `VideoLessonEditor` (полный) и какой-то inline-редактор для быстрого блока. Нужно использовать первый в обоих местах.
- Никаких изменений БД и edge-функций не требуется.
