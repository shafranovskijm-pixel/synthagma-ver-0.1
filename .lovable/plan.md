

## Добавить карточку «Учебные материалы» в Hero

### Что делаем
Добавляем 4-ю карточку в ряд feature-карточек Hero-секции с акцентом на то, что 200+ готовых курсов Ростехнадзора входят в комплект. Меняем сетку с 3 на 4 колонки.

### Изменения

**`src/components/landing/Hero.tsx`**:
1. Добавить иконку `BookOpen` в импорт из `lucide-react`
2. Добавить 4-й элемент в массив `features`:
   ```
   { icon: BookOpen, label: "200+ готовых курсов" }
   ```
3. Изменить сетку с `sm:grid-cols-3` на `sm:grid-cols-4` и убрать `max-w-2xl` → `max-w-3xl`

Итого — 4 компактные карточки в одну линию на десктопе, 1 колонка на мобильном.
