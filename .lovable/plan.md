

# Расширенный редактор лендинга курса — как в SkillSpace

## Что будет сделано

Полная переработка редактора лендинга с функционалом как на скриншотах SkillSpace:

### 1. Управление секциями (все секции)
Каждая секция получает hover-toolbar с кнопками:
- **↑ / ↓** — перемещение секции вверх/вниз
- **👁 (скрыть/показать)** — скрытие секции без удаления
- Секции становятся перетаскиваемыми по порядку

### 2. Секция «Кому подойдёт» — карточки с иконками
Вместо простых строк → карточки с тремя колонками (как на скриншоте):
- Каждая карточка: **иконка** (из банка иконок) + **заголовок** + **описание** (длинный текст)
- Кнопка удаления (красная корзина) при наведении
- Кнопка **+** между карточками для добавления

### 3. Секция «Что вы узнаете на курсе» (НОВАЯ)
Список с иконками и описаниями (как на скриншоте):
- Каждый пункт: **иконка** (круглая, цветная) + **заголовок** + **описание**
- Подзаголовок-описание секции (редактируемый)
- Добавление (+) и удаление (корзина)

### 4. Секция «Как проходит обучение» (НОВАЯ)
Блок с rich-text описанием формата обучения (как на скриншоте):
- Текстовое поле с пунктами

### 5. Банк иконок (диалог)
При клике на иконку в любой секции открывается модалка:
- Две вкладки: **Библиотека иконок** / **Загрузить изображение**
- Поиск по названию
- Сетка ~50 популярных Lucide-иконок (как на скриншоте с FontAwesome)

### 6. Кнопка «Скрыть цену в этом блоке»
В Hero-секции добавить toggle для скрытия/показа цены.

```json
{
  "sections_order": ["hero", "audience", "learn", "program", "process", "benefits", "cta"],
  "sections_hidden": ["process"],
  "audience": {
    "title": "...",
    "description": "...",
    "items": [
      { "icon": "image", "title": "Начинающим", "description": "Длинное описание..." }
    ]
  },
  "learn": {
    "title": "Что вы узнаете на курсе",
    "description": "Добавьте описание...",

    "content": "- Онлайн формат..."
  }
}
```
