

## Исправление бесконечного цикла автоисправления курсов

### Проблема

Цепочка `handleValidateCourse → autoFixCourse → handleValidateCourse` зацикливается бесконечно. Причины:

1. **Нет лимита циклов**: после `autoFixCourse` всегда вызывается `handleValidateCourse` (строка 1145), который при обнаружении проблем снова вызывает `autoFixCourse` (строка 469) — без ограничений.
2. **Ошибки 402/429 не останавливают цикл**: `autoFixCourse` ловит ошибки в `catch` внутри каждой фазы, но не прерывает весь процесс. Функция "завершается успешно", показывает "Курс исправлен!", запускает повторную проверку — проблемы остаются — цикл повторяется.

### Решение

**Файл: `src/components/admin/AdminMarketplaceManager.tsx`**

1. **Добавить счётчик циклов** — `useRef<Map<string, number>>` для отслеживания количества автоматических проходов `проверка → исправление → проверка` для каждого курса. Максимум — **2 цикла**.

2. **В `handleValidateCourse` (строка 464-469)**: перед вызовом `autoFixCourse` проверять счётчик. Если лимит достигнут — показать toast с результатами и НЕ запускать исправление. Пользователь сможет запустить вручную.

3. **В `autoFixCourse` (строка 1143-1145)**: после завершения, при повторном вызове `handleValidateCourse`, увеличивать счётчик. Если лимит — показать "Автоисправление завершено, оставшиеся проблемы требуют ручного вмешательства" вместо перезапуска.

4. **Обработка 402/429 ошибок**: в `autoFixCourse` добавить флаг `hadCriticalError`. Если любая фаза (контент, тесты, медиа) получила 402 или 429 — установить флаг. В конце функции: если `hadCriticalError` — показать предупреждение "Исчерпан лимит ИИ-кредитов" и НЕ запускать повторную проверку.

5. **Ручной сброс счётчика**: при клике на курс для ручной проверки (не автоматической) — сбрасывать счётчик для этого курса.

### Технические детали

```text
Текущий поток:
  validate → issues? → autoFix → "Исправлен!" → validate → issues? → autoFix → ... (∞)

Новый поток:
  validate → issues? → cycle < 2? → autoFix → "Исправлен!" → validate → issues? → cycle < 2? 
    YES → autoFix (цикл 2) → validate → issues? → cycle >= 2 → СТОП: "Требуется ручное вмешательство"
    NO  → СТОП

  Если 402/429 в любой фазе → СТОП сразу, без повторной проверки
```

Изменения только в одном файле: `AdminMarketplaceManager.tsx`.
