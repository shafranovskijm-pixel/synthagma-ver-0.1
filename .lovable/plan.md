

## Шаблоны КП, предпросмотр, PDF и онлайн-ссылка

### Что будет сделано

1. **Готовые шаблоны КП** -- при создании КП можно выбрать один из 5 готовых шаблонов (по одному на каждый тариф: Старт, Стандарт, Профессиональный, Максимальный + "Индивидуальный"). Каждый шаблон автоматически заполняет таблицу услуг с описанием функций, лимитов и ценами из `SUBSCRIPTION_PLANS`.

2. **Предпросмотр КП** -- кнопка "Предпросмотр" открывает модальное окно с красиво оформленным КП: шапка с логотипом, реквизиты компании, таблица услуг, итого, примечание, срок действия.

3. **Скачать в PDF** -- кнопка "Скачать PDF" генерирует PDF через `window.print()` со специальными print-стилями (без внешних зависимостей).

4. **Онлайн-ссылка** -- новая публичная страница `/proposal/:id` отображает КП в красивом виде. Кнопка "Скопировать ссылку" для отправки клиенту.

### Технические детали

#### 1. Шаблоны КП (`src/constants/proposalTemplates.ts` -- новый файл)

Массив из 5 предустановленных шаблонов, каждый содержит:
- `id`, `name`, `description`
- `tariffPlan` (ключ из SUBSCRIPTION_PLANS)
- `serviceLines[]` -- предзаполненные позиции с ценами из тарифа

Шаблоны:
- **Старт** -- Тариф "Старт" x12 мес + Настройка платформы (разовая) + Техподдержка
- **Стандарт** -- Тариф "Стандарт" x12 мес + Настройка + Брендирование + Техподдержка
- **Профессиональный** -- Тариф "Профессиональный" x12 мес + Настройка + Брендирование + Генерация документов + Техподдержка
- **Максимальный** -- Тариф "Максимальный" x12 мес + Все услуги + Интеграция ФРДО + Персональный менеджер
- **Индивидуальный** -- пустой шаблон для ручного заполнения

- Добавить секцию "Выбрать шаблон" вверху -- горизонтальный ряд карточек-шаблонов

Стили:
- Белый фон, минималистичный дизайн
- Шрифт serif для заголовков
- Таблица с чередованием строк
- Логотип Синтагма вверху
- Print-friendly CSS через `@media print`

#### 4. Генерация PDF

Используем `window.print()` с iframe-подходом:
- Создаем скрытый iframe с HTML-содержимым КП
- Применяем print-стили
- Вызываем `iframe.contentWindow.print()`
- Удаляем iframe после печати

Это не требует новых зависимостей.

#### 5. Публичная страница КП (`src/pages/ProposalPublic.tsx` -- новый файл)

- Загружает данные КП из `commercial_proposals` + `commercial_proposal_services` по ID
- Отображает тот же `ProposalPreview` компонент но в полноэкранном режиме
- RLS: добавить SELECT-политику для anon-роли на `commercial_proposals` и `commercial_proposal_services` по `status = 'sent'` (только отправленные КП видны публично)
