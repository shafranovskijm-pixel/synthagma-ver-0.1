

# Настройки: вертикальное меню вместо горизонтальных вкладок

## Суть
Переделать `OrganizationSettings.tsx` — заменить горизонтальные `Tabs/TabsList` на двухколоночный layout с вертикальной навигацией слева (как в DocumentsTab), с cyan-подсветкой при наведении.

## Что будет сделано

### Изменить `src/pages/OrganizationSettings.tsx`
- Убрать горизонтальный `TabsList` 
- Добавить двухколоночный layout: `flex-col lg:flex-row`
- Левая колонка — вертикальное меню с 4 пунктами (Разделы меню, Касса, Настройки ЛК, Сотрудники)
- Активный пункт: `bg-primary/15 text-primary border-r-2 border-primary`
- Hover: `hover:text-primary hover:bg-primary/10` (cyan)
- На мобильных — горизонтальный скролл (как в DocumentsTab)
- Правая колонка — контент активного раздела
- Группировки с разделителями (опционально)

Структура скопирована с DocumentsTab для единообразия.
