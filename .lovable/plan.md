### Технические детали

**Запрос секрета:** в этом сообщении вызову UI-инструмент добавления секрета `TELEGRAM_BOT_TOKEN`. Вы вставите токен от `@BotFather` (или существующего бота `@SintagmaNotificationsBot`) — он сохранится в безопасное хранилище Lovable Cloud и сразу станет доступен edge-функциям.

**UTM-захват:**
```ts
// utils/leadTracking.ts (новый)
export function captureLeadSource() {
  const params = new URLSearchParams(location.search);
  const utm = ['utm_source','utm_medium','utm_campaign','utm_term','utm_content']
    .reduce((acc, k) => params.get(k) ? { ...acc, [k]: params.get(k) } : acc, {});
  if (Object.keys(utm).length || !sessionStorage.getItem('lead_source')) {
    sessionStorage.setItem('lead_utm', JSON.stringify(utm));
    sessionStorage.setItem('lead_source', document.referrer || location.hostname);
  }
}
```
Вызывается один раз в `CourseLanding.tsx` при монтировании.

- Добавляется проверка `course.is_published = true` перед любым `instant`-зачислением (защита от утечки доступа к черновикам).

### Критерии готовности
1. После вставки токена бот шлёт сообщение в указанный chat_id при новой заявке (любой режим).
2. В заявке видны source/UTM, заполняются автоматически с лендинга с `?utm_source=vk&utm_campaign=test`.
3. На `/o/<slug>` есть поиск, фильтр по платности, корректное OG-превью при шаринге в Telegram/VK.
4. В кабинете организации видна миниатюра витрины и индикатор «Telegram настроен / не настроен».
5. Версия в футере виджета поддержки → 1.0.46 (21.04). В `/whats-new` есть свежая запись.
