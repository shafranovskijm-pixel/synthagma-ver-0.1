

# 3 проблемы вебинара: «Эфир не найден», окно вместо новой вкладки, запись

## Проблема 1. «Эфир не найден / Failed to send a request to the Edge Function»

**Причина найдена:** функция `webinar-public-info` физически **не задеплоена** на сервер, хотя файл есть и в `supabase/config.toml` прописана. Прямой вызов её URL отвечает:

```
HTTP 404 — {"code":"NOT_FOUND","message":"Requested function was not found"}
```

При этом запись в БД с токеном `1eb9ea33…` существует (статус `ended`, `livekit`). То есть БД и токен в порядке, проблема **только в деплое**.

**Что сделаю:**
1. Принудительно задеплою `webinar-public-info` и `livekit-issue-token` (последняя могла не пере-деплоиться после правок гостевой ветки).
2. Проверю обе через `curl`:
   - `webinar-public-info` с реальным токеном → должен вернуть `ok: true`.
   - `livekit-issue-token` с `{ publicToken, guestName }` → должен вернуть JWT.
3. Поскольку текущий тестовый вебинар имеет статус `ended`, страница покажет «Эфир завершён» — это правильно. Создам новый live-вебинар через UI, дам прямую ссылку для проверки.

## Проблема 2. «Опять открывается в новом окошке»

**Причина:** в кабинете **организации** Sheet поверх дашборда уже работает (`liveSheetWebinar`), но:
- В **админ-панели** (`AdminWebinarsOverview` — пользователь сейчас на `/admin`) Sheet тоже есть, но узкий, без явного ощущения «эфир в окне». Нужно расширить и подключить ту же шапку через `EmbeddedWebinarPlayer`.
- В `WebinarsManager` кнопка «Развернуть» в Sheet до сих пор делает `window.open(..., "_blank")` → если её случайно нажать, открывается новая вкладка.

**Что сделаю:**

### A. Админка
- В `AdminWebinarsOverview.tsx` расширить Sheet до `w-full sm:max-w-[min(1100px,95vw)]` (как в организации).
- `EmbeddedWebinarPlayer` уже умеет рендерить шапку «Ссылка / QR / 👥 N / Завершить» — он получит `publicToken/allowGuests/guestPassword` (поля уже в `SELECT_FIELDS`).

### B. Организация
- Заменить `window.open(_, "_blank")` в кнопке «Развернуть» на `navigate(...)` в той же вкладке. Либо вообще убрать эту кнопку — Sheet и так работает «в окне на дашборде».
- Никаких `target="_blank"` в карточках по умолчанию.

### C. Полная унификация
- В обоих местах — один и тот же `EmbeddedWebinarPlayer` с шапкой → одинаковый UX в админке и в организации.

## Проблема 3. Запись вебинара

**Что есть сейчас:**
- В таблице `webinars` уже **есть** поля `recording_url` и `recording_size_bytes`.
- Для **Kinescope** запись работает — менеджер вручную вставляет Video ID после эфира.
- Для **LiveKit** записи **нет**. LiveKit Cloud поддерживает Egress API, но edge-функции для этого в проекте нет.

**Что предлагаю — гибридное решение, делаю в этой же итерации:**

### Часть 1 (быстро, прямо сейчас) — ручное прикрепление записи
- Кнопка **«📎 Прикрепить запись»** в карточке завершённого LiveKit-вебинара.
- Менеджер загружает свой MP4 (запись OBS / Mac Screen Recorder / встроенная запись браузера) → файл уходит в `course-files/webinar-recordings/<id>.mp4`.
- Запись сохраняется в `recording_url` → в карточке появляется бейдж «Запись доступна» + кнопка **«Смотреть»** (нативный `<video>`).
- **5 минут работы, сразу даёт результат.**

### Часть 2 (опционально, обсудим отдельно) — авто-запись через LiveKit Egress
- Edge-функция `livekit-start-recording` (старт через Egress API) + `livekit-egress-webhook` (приём результата, апдейт `recording_url`).
- Кнопка **«🔴 Запись»** в шапке плеера у хоста.
- **Требует** настройки S3-совместимого бакета в LiveKit Cloud (либо использования Supabase Storage с S3-ключом). Это +1 час настройки и небольшая правка в LiveKit Cloud дашборде.
- Сделаю **только если подтвердите** — сейчас в плане только ручная загрузка, чтобы у вас уже была работающая запись.

## Проверка после деплоя

1. Открою `https://sintagma.com.ru/w/1eb9ea33ab15ad9ee163b456caa98e62` через `code--fetch_website` → должна показаться страница с «Эфир завершён» (вместо «Failed to send»).
2. Создам новый тестовый вебинар через SQL → дам прямую ссылку → проверю через `curl`, что `webinar-public-info` отдаёт `status: 'live'`, и что `livekit-issue-token` выдаёт гостевой JWT.
3. В UI проверю, что Sheet эфира открывается поверх дашборда и в админке, и в организации.
4. Проверю кнопку «Прикрепить запись» — загружу любой 5-секундный MP4 → запись должна появиться в карточке.
