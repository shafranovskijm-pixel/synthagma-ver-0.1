## Проблема

Раздел «Менеджеры» существует, но лежит в `salesExtraItems` (меню под аватаром), поэтому в левой иконочной панели админ-центра продаж его не видно. Приглашение по ссылке и созданные менеджеры доступны только оттуда — пользователь их не находит.

## Что сделаю

1. **Вынесу «Менеджеры» в основной иконочный рейл**
   - `src/components/admin/sales/SalesSidebar.tsx`: перенесу пункт `{ id: 'managers', label: 'Менеджеры', icon: Users }` из `salesExtraItems` в группу «Главное» (после «Отчёт»). Иконка `Users` уже импортирована.
   - `salesMenuGroups` продолжит собираться из рейла + «Прочее», поэтому мобильное меню и подписи не сломаются.

2. **Добавлю блок «Менеджеры» на «Обзор продаж»**
   - `src/components/admin/sales/SalesOverview.tsx`: новая карточка со списком последних менеджеров (аватар/ФИО, статус, кол-во лидов/КП) и двумя кнопками в шапке:
     - «Пригласить по ссылке» → открывает существующий `InviteSalesManagerDialog`;
     - «Все менеджеры» → `onJump('managers')`.
   - Каждая строка получит быстрые действия «Войти как» и «Открыть».

3. **Добавлю кнопку «Пригласить менеджера» в шапку «Обзора»**
   - Рядом с уже существующим редактированием плана — иконка `Link2` + `Пригласить`, чтобы генерация ссылки была доступна прямо со стартового экрана.

Изменения только фронтовые, БД и роли не трогаю.

## Технические детали

- В `SalesSidebar.tsx` порядок в «Главное» станет: `overview → tasks → report → managers`.
- В `SalesOverview` использую уже подключённые `useSalesManager` (`managers`, `leads`, `proposals`) — новых запросов не нужно.
- `InviteSalesManagerDialog` уже готов и используется в `SalesManagersList` — переиспользую без правок.
- Мобильный `Sheet` в `SalesManager.tsx` продолжит показывать полный список групп, т.к. читает `salesMenuGroups`.
