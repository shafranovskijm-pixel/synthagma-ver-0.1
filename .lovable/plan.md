

# Режим ведущего для демо-ссылок

## Проблема
Сейчас кнопка «Открыть» ведёт на `/demo/:token` — страницу регистрации участника. У ведущего нет способа попасть в демо-дашборд, чтобы видеть то же, что видят участники.

## Решение

### 1. Кнопка «Превью ведущего» в DemoLinksManager
Добавить кнопку с иконкой `Eye` рядом с существующими действиями. По клику открывает `/demo/:token/dashboard?kinescope=LIVE_ID` в новой вкладке — ведущий попадает сразу в демо-кабинет без регистрации.

### 2. DemoDashboard — читать kinescope из URL-параметра
Сейчас `kinescopeLiveId` берётся только из `location.state` (который не работает при открытии в новой вкладке). Добавить fallback на `searchParams.get('kinescope')`.

### 3. Убрать требование авторизации для dashboard-маршрута
Маршрут `/demo/:token/dashboard` уже публичный — просто убедиться, что ведущий может зайти без прохождения формы регистрации.

## Файлы

| Файл | Изменение |
|------|-----------|
| `src/components/admin/sales/DemoLinksManager.tsx` | Добавить кнопку «Превью» с иконкой Eye, открывает dashboard с query-параметром |
| `src/components/demo/DemoDashboard.tsx` | Читать `kinescopeLiveId` из `searchParams` как fallback к `location.state` |
