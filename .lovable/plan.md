

# Группировка тем по цветовым семействам + исправление сайдбара настроек

## Проблемы

1. **Темы не сгруппированы** — все 8 тем в плоской сетке, трудно ориентироваться
2. **Светлая/Тёмная тема ниже** — должна быть в самом верху
3. **OrgSettingsSidebar не подхватывает тему** — в `OrgSettingsSidebar.tsx` нет подписки на `visual-theme-change`, поэтому при переходе в настройки профиля сайдбар остаётся бирюзовым

## Что будет сделано

### 1. `src/components/ui/ThemeSelector.tsx` — группировка по цветовым семействам

Заменить плоскую сетку на раскладку по группам:

```text
🟢 Природа        → Свежесть, Офис с зеленью
⚪ Офис           → Офис
🟠 Закат          → Нью-Йорк, Закат, Гавайи
🟣 Стиль          → Минимализм
🔵 Вода           → Бирюза
```

При клике на группу — раскрывается аккордеон с вариантами внутри неё. Если в группе один элемент — сразу выбирается без раскрытия.

### 2. `src/components/ui/ThemePersonalization.tsx` — порядок секций

Переместить блок «Режим оформления» (Светлая/Тёмная) **выше** визуальных тем. Порядок:
1. Режим оформления (светлая / тёмная)
2. Визуальная тема (группы)
3. Акцентный цвет
4. Плотность и радиус

### 3. `src/components/organization/OrgSettingsSidebar.tsx` — подписка на тему

Добавить `useEffect` + `useState` для `visual-theme-change` (как в `AdminSidebar` и `OrgSidebar`). При активной теме — использовать `theme.accent` для `--primary` стилей сайдбара и `theme.sidebarClass` для фона `<aside>`.

### 4. `src/constants/admin-themes.ts` — добавить поле `group`

Добавить в `AdminTheme` поле `group: string` для группировки:
- `"nature"` — Свежесть, Офис с зеленью
- `"office"` — Офис
- `"sunset"` — Нью-Йорк, Закат, Гавайи
- `"style"` — Минимализм
- `"water"` — Бирюза

## Технические детали

- Группы определяются как массив `{ id, label, emoji }` в `ThemeSelector`
- Внутри группы — горизонтальная строка карточек
- Раскрытие группы через `useState<string | null>` (id открытой группы)
- `OrgSettingsSidebar` получит тот же паттерн подписки на `visual-theme-change`, что и `AdminSidebar`
- ~4 файла, ~80 строк изменений
