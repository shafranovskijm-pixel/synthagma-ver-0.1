

# Добавить информативные подсказки-заглушки во все вкладки настроек курса

## Суть
В диалоге «Настройки страницы курса» (`CoursePageSettingsContent.tsx`) добавить описательные блоки-подсказки в верхнюю часть каждой вкладки, объясняющие назначение раздела. Особенно для Промокодов — заменить пустое сообщение на продающую заглушку.

## Что будет сделано

### 1. Вкладка «Промокоды» — продающая заглушка
Заменить `Промокоды не добавлены` (строка 494) на информативную карточку:
- Иконка `Tag` с gradient-фоном
- Заголовок: **«Промокоды для курса»**
- Описание: «Создавайте промокоды со скидками в процентах или фиксированной сумме. Делитесь кодами с партнёрами, в рассылках или соцсетях — отслеживайте количество использований каждого кода.»
- Стрелка к форме добавления сверху

### 2. Подсказки-описания для остальных вкладок
Добавить компактный блок-подсказку (1-2 строки в `text-muted-foreground`) в начало каждой вкладки:

- **Страница**: «Настройте URL, цвет и цену вашего курса. Эти параметры отображаются на публичной странице.»
- **SEO**: «Оптимизируйте курс для поисковых систем — заполните метатеги вручную или с помощью ИИ.»
- **Форма записи**: «Настройте внешний вид формы записи на курс — текст кнопки, подзаголовок и дополнительные поля.»
- **Аналитика**: «Подключите счётчики Яндекс.Метрики, Google Analytics и Meta Pixel для отслеживания конверсий на странице курса.»
