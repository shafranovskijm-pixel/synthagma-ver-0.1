

## Оптимизация меню настроек блока (Карандаш)

### Проблема
Сейчас при нажатии на карандаш открывается одно большое окно со всеми настройками вместе — это перегружает интерфейс.

### Решение
Разделить содержимое Popover на **вкладки (Tabs)** для компактности:

1. **Вкладка "Стиль"** — текстовые стили (жирный, курсив и т.д.), выравнивание, цвет текста, фон блока
2. **Вкладка "Шрифт"** — шрифт (обычный/моно), размер текста (A- A A+), межстрочный интервал
3. **Вкладка "Рамка"** — рамка (нет/тонкая/жирная/пунктир), скругление
4. **Вкладка "Шаблоны"** — готовые стили (Акцент, Заметка, Важно и т.д.)

### Технические детали

**Файл:** `src/components/course-builder/BlockEditor.tsx`

Изменения в PopoverContent (строки ~549-657):

- Заменить плоский список секций на компонент `Tabs` (из `@radix-ui/react-tabs`, уже установлен)
- `TabsList` с 4 компактными вкладками: иконки `Type` (стиль), `ALargeSmall` (шрифт), `Square` (рамка), `Sparkles` (шаблоны)
- Каждая `TabsContent` содержит только свою группу настроек
- Ширину Popover оставить `w-72`, высота уменьшится т.к. показывается только одна вкладка

Группировка:

```text
Вкладка "Стиль":
  - Выравнивание (left/center/right)
  - Стиль текста (bold/italic/strike/underline/uppercase)
  - Цвет текста (пресеты)
  - Фон блока (пресеты)

Вкладка "Шрифт":
  - Шрифт (Обычный / Моно)
  - Размер текста (A- / A / A+)
  - Межстрочный интервал (Плотный / Обычный / Свободный)

Вкладка "Рамка":
  - Рамка (Нет / Тонкая / Жирная / Пунктир)
  - Скругление (⬜ / ◻️ / ⭕)

Вкладка "Шаблоны":
  - Готовые стили (сетка 3x2)
```

Кнопка сброса стиля (Ластик) останется доступна внизу в каждой вкладке или вынесена отдельно в тулбар.
