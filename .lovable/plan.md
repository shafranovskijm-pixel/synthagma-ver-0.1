

# Приветственный курс и вид по умолчанию для новых организаций

## Что будет сделано

### 1. Edge function: `seed-welcome-course`
Новая edge function, которая создаёт приветственный курс "Добро пожаловать в СИНТАГМА" для организации. Курс содержит 5-7 уроков с готовым контентом (не ИИ-генерация, а заранее написанный текст):

- **Урок 1**: Знакомство с платформой — обзор возможностей
- **Урок 2**: Создание и настройка курсов — конструктор, ИИ-помощник
- **Урок 3**: Управление учениками — зачисление, группы, приглашения
- **Урок 4**: Тестирование и аттестация — виды тестов, видеоидентификация
- **Урок 5**: Документооборот и ФРДО — сертификаты, выгрузка
- **Урок 6**: Аналитика и отчёты — журналы, статистика
- **Тест**: Проверка знаний о платформе

Каждый урок — с Markdown-контентом, описывающим фишки платформы. Курс создаётся опубликованным (`is_published: true`), с обложкой (можно сгенерировать или использовать placeholder).

### 2. Автоматический вызов при регистрации организации
В `RegisterOrganization.tsx` после успешного создания организации (шаг 4, после role upgrade) вызвать:
```typescript
await supabase.functions.invoke("seed-welcome-course", {
  body: { organizationId: orgId }
});
```
Аналогично в `OrganizationsManager.tsx` при создании организации админом.

### 3. Вид по умолчанию
Текущий вид с вкладками "Курсы / Вебинары / 3D-тренажёры" уже является видом по умолчанию — он показывается всем организациям. Приветственный курс обеспечит, что новая организация сразу видит контент в каталоге.

## Файлы

| Файл | Изменение |
|---|---|
| `supabase/functions/seed-welcome-course/index.ts` | Новая edge function — создаёт курс + уроки + тест |
| `src/pages/RegisterOrganization.tsx` | Вызов `seed-welcome-course` после создания организации |
| `src/components/admin/OrganizationsManager.tsx` | Вызов `seed-welcome-course` после создания организации админом |

## Контент курса
Контент будет написан статически в edge function (не через ИИ), чтобы гарантировать качество и скорость. Описывает все ключевые фишки платформы: ИИ-генерация курсов, конструктор уроков, видеоидентификация, тесты, документооборот, ФРДО, аналитика, вебинары, 3D-тренажёры.
