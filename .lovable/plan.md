

# Отправка обращений в Telegram через раздел "Помощь"

## Описание

Добавить в диалог "Помощь" возможность отправить обращение в Telegram-бот поддержки. Пользователь описывает проблему, может прикрепить скриншот, а система автоматически собирает логи (URL, браузер, роль, время) и отправляет все одним сообщением через уже существующую edge-функцию `send-telegram-notification`.

## Что будет реализовано

### 1. Форма обращения в диалоге "Помощь"

В нижней части диалога подсказок добавляется блок "Сообщить о проблеме":
- Текстовое поле для описания проблемы/ошибки
- Кнопка "Прикрепить скриншот" (загрузка изображения)
- Кнопка "Отправить в поддержку"

### 2. Автоматический сбор логов

При отправке система автоматически собирает:
- Текущий URL страницы (`window.location.href`)
- Информация о браузере (`navigator.userAgent`)
- Роль пользователя (организация/ученик)
- Имя пользователя и email из профиля
- ID организации (если есть)
- Текущая вкладка/раздел
- Дата и время обращения
- Последние console.error из `window.onerror` / `console` перехвата (до 5 последних ошибок)

### 3. Перехват ошибок консоли

Создается небольшой хук `useErrorLogger`, который перехватывает `console.error` и `window.onerror`, сохраняя последние 10 ошибок в массив. При отправке обращения эти ошибки прикладываются автоматически.

### 4. Отправка скриншота

Скриншот загружается в storage bucket `org-documents` (или `student-documents` для учеников), генерируется публичная ссылка, которая вставляется в Telegram-сообщение.

### 5. Формат сообщения в Telegram

```text
-- Обращение в поддержку --

Пользователь: Иванов Иван (ivan@mail.ru)
Роль: Организация
Организация ID: xxx-xxx
Раздел: Ученики
Время: 2026-02-13 10:45:03

Описание проблемы:
Не загружаются данные учеников при фильтрации по группе

Браузер: Chrome 120, Windows 10
URL: /organization (вкладка students)

Последние ошибки:
1. TypeError: Cannot read property 'map' of undefined
2. 404 /rest/v1/student_groups?...

Скриншот: https://...storage-link...
```

## Технические детали

### Настройка Telegram chat_id

В настройках организации (или глобально в админке) нужен `chat_id` для бота. Варианты:
- Хранить в таблице `organizations` (новая колонка `telegram_support_chat_id`)
- Или использовать единый `chat_id` из секрета `TELEGRAM_SUPPORT_CHAT_ID`

Для простоты -- добавим секрет `TELEGRAM_SUPPORT_CHAT_ID` для единого чата поддержки, а также колонку `telegram_chat_id` в `organizations` для индивидуальных настроек.

### Edge-функция

Обновить `send-telegram-notification`:
- Если передан `photo_url`, использовать `sendPhoto` вместо `sendMessage` с `caption` вместо `text`
- Если `photo_url` нет -- работает как раньше через `sendMessage`

### Логика отправки

1. Пользователь заполняет описание проблемы
2. Опционально прикрепляет скриншот (файл загружается в storage)
3. Хук `useErrorLogger` предоставляет последние ошибки
4. Формируется HTML-сообщение со всей информацией
5. Определяется `chat_id`: сначала из `organizations.telegram_chat_id`, если пусто -- из глобального секрета
6. Вызывается `supabase.functions.invoke("send-telegram-notification", { body: { chat_id, message, photo_url } })`
7. Пользователь видит toast "Обращение отправлено!"

### Интерфейс формы

- Textarea с placeholder "Опишите проблему или ошибку..."
- Input type="file" accept="image/*" для скриншота
- Превью прикрепленного скриншота
- Кнопка "Отправить" с иконкой Send и состоянием загрузки
- Авто-заполненные данные (URL, браузер) показываются мелким текстом "Будет автоматически приложено: URL, браузер, логи ошибок"
