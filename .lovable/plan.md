

## Исправление парсера SkillSpace — уроки не импортируются

### Корневая причина

Анализ сетевых запросов SkillSpace показал:

1. **`/api/rest/student/course/{id}/groups` — возвращает 404** (такого эндпоинта не существует)
2. **`/api/rest/student/course/{id}/flow` — не возвращает ожидаемых данных** (или не работает для данного аккаунта)
3. Эндпоинт `/api/rest/student/course/{id}` возвращает метаданные курса (название, 20 групп, 81 урок), но **не содержит список уроков**
4. В ответе курса есть объект `flowToAddAfterPayment.access.lessons` с 6 числовыми ID уроков — это единственный доступный список
5. Запрос на `/api/rest/student/lesson/{uuid}` возвращает **403** — студент не имеет доступа

Вывод: студентский аккаунт имеет доступ только к урокам своего потока (flow), а не ко всему курсу. Нужно использовать **конструктор/админ API** для получения полной структуры.

### Решение

Переписать edge-функцию `parse-skillspace-course/index.ts` с новой стратегией:

#### 1. Попробовать несколько API-путей для получения списка уроков

```text
Приоритет:
1. /api/rest/constructor/course/{id}        — admin/constructor API
2. /api/rest/course/{id}/constructor        — альтернативный путь
3. /api/rest/student/course/{id}            — извлечь lesson IDs из flow данных  
4. Парсинг HTML страницы конструктора       — как fallback
```

#### 2. Извлечь lesson IDs из всех доступных flow-ов в ответе курса

Текущий ответ содержит `flowToAddAfterPayment.access.lessons: [1016350, 2060537, ...]`. Нужно:
- Собрать все lesson IDs из всех flow-ов
- Попробовать загрузить уроки как по ID, так и по UUID
- Использовать endpoint `/api/rest/student/lesson/{id}` (числовой ID, не UUID)

#### 3. Добавить подробное debug-логирование

- Логировать статус и первые 500 символов ответа каждого API-вызова
- Логировать структуру найденных данных (ключи объектов)
- Это позволит быстро понять, какой API-путь работает

#### 4. Улучшить обработку ошибок и результата

- Если ни один путь не вернул уроки — вернуть понятное сообщение с рекомендацией использовать аккаунт владельца школы
- Показать в результате, какие эндпоинты были опробованы

### Техническая стратегия получения уроков

```text
Step 1: Auth (уже работает)
Step 2: GET /api/rest/student/course/{id} → получаем метаданные
Step 3: Пробуем получить полный список уроков:
  a) GET /api/rest/constructor/course/{id}/groups
  b) GET /api/rest/constructor/course/{id}/lessons  
  c) GET /api/rest/course/{id}/groups
  d) Парсим flow из course response → собираем все lesson IDs
  e) GET HTML /course/{id}/constructor/{flowUuid} → парсим sidebar
Step 4: Для каждого найденного урока:
  - GET /api/rest/student/lesson/{id или uuid}
  - Если 403 — пропускаем с пометкой "нет доступа"
Step 5: Сохраняем в БД
```
