

# Doom-style 3D-лабиринт с монстрами, оружием и звуками

## Суть
Превратить простой лабиринт в мини-Doom: улучшить контраст/видимость, добавить полноэкранный режим, монстров с лицами актёров (спрайты-билборды), систему здоровья (3 сердечка), оружие с выбором, звуковые эффекты и HUD.

## Что будет сделано

### 1. Улучшение контраста и визуала
- Стены: яркие кирпичные цвета с чередованием (красный/коричневый вместо тёмно-синего)
- Пол: видимый паттерн (шахматный или текстурированный)
- Увеличить освещение: ambient 0.5, добавить фонарик (spotlight от камеры)
- Увеличить дальность тумана (fog far: 14→22)
- Потолок убрать или сделать прозрачным для лучшей видимости

### 2. Полноэкранный режим
- Кнопка «На весь экран» (Maximize) в шапке
- Используем `element.requestFullscreen()` на контейнере игры
- При полноэкранном режиме канвас растягивается на весь экран, кнопки управления overlay поверх

### 3. Монстры-спрайты с лицами актёров
- Скопировать загруженные фото актёров в `src/assets/`
- Компонент `Monster` — плоский спрайт (PlaneGeometry + текстура), всегда повёрнутый к камере (billboard)
- 4-5 монстров расставлены по лабиринту в проходах
- Монстры медленно двигаются к игроку (простой AI — шаг к игроку каждые N кадров, с проверкой коллизий)
- При столкновении монстра с игроком — минус одно сердечко, монстр исчезает
- При 0 сердечек — Game Over с кнопкой перезапуска

### 4. Оружие и стрельба
- HUD: пистолет/кулак внизу экрана (CSS overlay, спрайт-анимация)
- Кнопка «Выстрел» (или клик мыши / тап) — проверка raycast вперёд
- Если луч попадает в монстра в радиусе 8 клеток — монстр уничтожается
- Выбор оружия: кнопки 1-2-3 или переключатель (кулак / пистолет / ракетница — визуально разные, урон одинаковый)
- Анимация выстрела — CSS scale/translate на спрайте оружия

### 5. HUD (интерфейс поверх канваса)
- 3 сердечка (❤️) вверху слева — при ударе монстра одно исчезает
- Счёт убитых монстров вверху справа
- Выбранное оружие внизу по центру
- Мини-карта (опционально, маленькая сетка в углу)

### 6. Звуковые эффекты
- Используем Web Audio API (new Audio() + .play())
- Звуки генерируются программно через OscillatorNode (без внешних файлов):
  - Шаги: тихий «тук-тук» при движении
  - Выстрел: короткий шумовой burst
  - Попадание в монстра: взрыв/крик
  - Потеря сердечка: болезненный звук
  - Победа: фанфары
- Кнопка Mute в шапке

### 7. Увеличить лабиринт
- Расширить карту до 14x14 для более интересного геймплея
- Больше комнат и тупиков
