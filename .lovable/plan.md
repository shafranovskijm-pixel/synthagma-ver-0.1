

## Расширение вариантов стилей и типов блоков

Сейчас для текстового блока доступно: 6 типов преобразования (Информация, Предупреждение, Совет, Цитата, Аккордеон, Обычный текст) и настройки стиля (выравнивание, цвет, размер, начертание). Предлагаю добавить несколько новых возможностей:

### 1. Готовые стилевые шаблоны (Quick Styles)

Добавить в меню Pencil (настройки стиля) секцию **"Готовые стили"** с предустановленными комбинациями оформления, которые применяются одним кликом:

- **Акцент** -- жирный текст на цветном фоне (жёлтый/зелёный)
- **Заметка на полях** -- мелкий серый курсивный текст, выравнивание по правому краю
- **Важно!** -- красный фон, жирный белый текст, крупный размер
- **Код/Моно** -- серый фон, моноширинный шрифт (новое свойство `fontFamily`)
- **Выделение маркером** -- жёлтый фон, обычный текст (эффект "подсветки")
- **Заголовок секции** -- крупный жирный текст по центру, верхний регистр

Каждый шаблон -- это просто набор значений для уже существующих свойств блока (`bold`, `italic`, `bgColor`, `textColor`, `textSize`, `textAlign`, `uppercase`), поэтому не нужно менять структуру данных.

### 2. Новые типы блоков

Добавить в `BlockType` и меню "+" / меню преобразования:

- **`callout-success`** -- зелёный коллаут с галочкой (CheckCircle) -- "Выполнено / Результат"
- **`callout-danger`** -- красный коллаут с крестом (XCircle) -- "Ошибка / Запрещено"
- **`highlight`** -- блок-выделение с градиентной левой полосой и ярким фоном

### 3. Рамка и отступы блока (Border & Padding)

Добавить в панель Pencil:
- Выбор рамки: нет / тонкая / жирная / пунктирная
- Радиус скругления: прямые углы / скруглённые / сильно скруглённые

Новые свойства в `ContentBlock`: `borderStyle`, `borderRadius`.

   - Добавить массив `quickStyles` с предустановленными комбинациями
   - В панели Pencil (PopoverContent) добавить секцию "Готовые стили" -- ряд кнопок-карточек
   - В `blockTypeConfig` добавить конфигурацию новых типов
   - В `wrapTargets` добавить новые типы для меню преобразования
