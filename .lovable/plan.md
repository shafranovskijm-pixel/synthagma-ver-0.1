

## Исправление загрузки больших видео

### Проблемы

1. **Баг** (строка 124, `useLessonMedia.ts`): `xhr.send(file)` отправляет оригинал вместо сжатого файла `fileToUpload`
2. **FFmpeg.wasm не справляется с файлами >1 ГБ**: загружает весь файл в память браузера дважды (вход + выход), что приводит к зависанию или краху вкладки
3. **Нет таймаута и retry**: если загрузка прерывается, пользователь просто ждёт бесконечно

### Решение

**1. Исправить баг с отправкой файла**
- Строка 124: заменить `xhr.send(file)` на `xhr.send(fileToUpload)`

**2. Ограничить сжатие разумным размером**
- Сжимать только файлы от 500 МБ до 1 ГБ (FFmpeg.wasm может справиться)
- Для файлов > 1 ГБ: пропускать сжатие, загружать напрямую с предупреждением "Файл очень большой, загрузка может занять длительное время"

**3. Добавить chunked upload для больших файлов**
- Для файлов > 100 МБ: загрузка частями (chunks) по 50 МБ через `tus` протокол (Supabase Storage поддерживает `tus` из коробки)
- Это даёт: возможность возобновления загрузки, меньше шансов на разрыв соединения, прогресс-бар работает точнее
- Для файлов <= 100 МБ: оставить текущий XHR-подход

**4. Добавить таймаут и автоматический retry**
- Таймаут: если нет прогресса 60 секунд -- предложить отменить или повторить
- При ошибке соединения: автоматически повторить до 2 раз

### Технические детали

**Файл: `src/hooks/useLessonMedia.ts`**

```text
Изменения:
- Строка 124: file -> fileToUpload (баг-фикс)
- Порог сжатия: 500 МБ - 1 ГБ (было: > 500 МБ без верхней границы)
- Для файлов > 100 МБ: использовать tus-upload вместо XHR
- Добавить stall detection (нет прогресса > 60с)
```

**Файл: `src/utils/videoCompressor.ts`**

```text
Изменения:
- Добавить проверку размера: если > 1 ГБ, выбросить ошибку (catch вернёт оригинал)
- Добавить таймаут: если сжатие длится > 5 минут, прервать
```

**Файл: `src/utils/tusUpload.ts` (новый)**

```text
Утилита для chunked upload через tus-протокол Supabase:
- Размер чанка: 50 МБ
- Поддержка возобновления (resumable)
- Прогресс-бар
- Автоматический retry при обрыве (до 3 попыток)
```

Supabase Storage поддерживает tus-протокол нативно по URL:
`{baseUrl}/storage/v1/upload/resumable`

### Порядок реализации

1. Исправить баг `xhr.send(file)` -> `xhr.send(fileToUpload)`
2. Создать `tusUpload.ts` для chunked upload
3. Обновить `useLessonMedia.ts`: использовать tus для больших файлов
4. Обновить `videoCompressor.ts`: ограничить макс. размер для сжатия

### Пользовательский опыт после изменений

- Файл < 100 МБ: загрузка через XHR (как сейчас, быстро)
- Файл 100 МБ - 500 МБ: chunked upload без сжатия
- Файл 500 МБ - 1 ГБ: сжатие + chunked upload
- Файл 1 ГБ - 2 ГБ: chunked upload без сжатия, с предупреждением о длительности
