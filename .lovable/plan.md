

# Три исправления в панели ученика

## 1. Поменять баннеры местами
Сейчас порядок: OrgBanner (баннер организации) сверху, затем «Мои курсы», затем HeroBannerSwiper (прогресс). Пользователь хочет поменять их местами — HeroBannerSwiper (прогресс) сверху, OrgBanner ниже (или наоборот).

**Решение:** В `CatalogContent` (внутри `StudentDashboard.tsx`) поменять порядок — сначала `HeroBannerSwiper` с прогрессом, затем `OrgBanner`. В `CourseCatalog.tsx` вынести баннер прогресса обратно в `CatalogContent` перед `OrgBanner`, чтобы контролировать порядок на уровне layout.

## 2. Добавить кнопку «Посмотреть» на карточки доступных курсов
Сейчас для платных курсов показываются 2 кнопки: «Купить» и «Оставить заявку». Нужна третья — «Посмотреть» (переход на лендинг курса).

**Решение:** В `CourseCardNew.tsx` добавить кнопку «Посмотреть» (иконка Eye) перед «Купить» и «Оставить заявку». По клику — вызов `onClick` (переход на лендинг). Для 3 кнопок использовать вертикальный stack или compact layout.

## 3. Чат должен показываться с хедером
Сейчас `StudentHeader` обёрнут в `hidden md:block` — на десктопе видно, на мобильных — нет. Но и на десктопе, судя по скриншоту, хедер в чате тоже может не отображаться.

**Решение:** Убедиться, что `StudentHeader` показывается на всех вкладках, включая чат. На мобильных — добавить компактный мобильный хедер (имя, лого, уведомления) над контентом чата.
