

# Озвучка на главной: предзаписанный аудиофайл из Storage

## Проблема

Сейчас при нажатии "Озвучить урок" на главной странице каждый раз отправляется запрос к ElevenLabs API. Это расходует лимиты API, добавляет задержку и может не работать (ошибки Free Tier).

## Решение

Текст демо-урока статичный и не меняется. Поэтому:

1. Сгенерировать аудио один раз через API
2. Сохранить MP3-файл в Storage (бакет `public`)
3. На главной проигрывать файл напрямую из Storage -- мгновенно, без API

## Что будет сделано

### 1. Загрузка аудиофайла в Storage

- Создать публичный бакет `demo-assets` (или использовать существующий)
- Сгенерировать MP3 через edge-функцию `elevenlabs-tts` для текста демо-урока
- Загрузить файл в Storage как `demo-assets/editor-demo-voice.mp3`

### 2. Упрощение EditorDemo.tsx

Заменить весь блок с fetch-запросом к API на простое воспроизведение статического файла:

```text
handleSpeak() {
  // Было: fetch -> elevenlabs-tts -> blob -> play
  // Стало: new Audio(storageUrl).play()
}
```

Конкретные изменения:
- Убрать fetch к `elevenlabs-tts`
- Убрать обработку ошибок API (401, 402)
- Убрать `isLoading` состояние (файл грузится мгновенно)
- Оставить только `isPlaying` для управления воспроизведением
- URL аудио: прямая ссылка на файл в Storage

### 3. Удаление "Мобильное приложение" из дорожной карты

Убрать элемент из массива `roadmapItems` и неиспользуемый импорт `Smartphone`.

### Логика воспроизведения

```text
const DEMO_AUDIO_URL = "<storage-url>/demo-assets/editor-demo-voice.mp3";

handleSpeak() {
  if (isPlaying) {
    audio.pause();
    return;
  }
  audio = new Audio(DEMO_AUDIO_URL);
  audio.play();
}
```

### Два варианта аудио

Демо-текст меняется когда пользователь нажимает "Сгенерировать абзац" (добавляется 4-й блок). Поэтому будет два предзаписанных файла:
- `editor-demo-3blocks.mp3` -- базовый текст (3 блока)
- `editor-demo-4blocks.mp3` -- текст с добавленным абзацем (4 блока)

Компонент выбирает нужный файл в зависимости от `blocks.length`.

### Преимущества

- Нулевой расход API-лимитов на демо
- Мгновенное воспроизведение (нет задержки на генерацию)
- Работает всегда, независимо от статуса ElevenLabs
- Убирается сообщение об ошибке TTS на главной
