

Пользователь хочет добавить кнопку «Начать вебинар сейчас» по аналогии с Яндекс Телемост («Новая видеовстреча — начнётся прямо сейчас»). Текущий поток: открыть диалог → ввести данные → создать. Нужен второй поток: один клик → создаётся Телемост-конференция → сразу открывается окно встречи.

## План: Кнопка «Начать вебинар сейчас»

### Что добавляем
В `WebinarsManager.tsx` рядом с существующей кнопкой «Создать вебинар» появится вторая кнопка **«Начать сейчас»** (с иконкой `Video`/`PlayCircle`).

### Поведение «Начать сейчас»
1. Один клик — без диалога.
2. Вызывается `telemost-create-conference` с дефолтным заголовком вида «Вебинар — 19.04.2026, 14:32».
3. Запись сохраняется в `webinars`:
   - `source_type: 'telemost'`
   - `status: 'live'` (а не `planned`)
   - `scheduled_at: now()`
   - `external_url`/`embed_url` — из ответа Яндекса
   - `course_id: null` (без привязки)
4. Сразу после создания:
   - `window.open(join_url, '_blank')` — у организатора открывается окно Телемоста
   - toast «Вебинар начат»
   - список вебинаров обновляется (вверху появляется «В эфире»)

### Существующая кнопка «Создать вебинар»
Остаётся как есть — для запланированных вебинаров с датой, описанием, привязкой к курсу.

### Файлы
- `src/components/organization/WebinarsManager.tsx` — добавить кнопку «Начать сейчас» и обработчик `handleStartNow` (loading state, вызов edge-функции, insert в БД, открытие окна).

### Технически
```text
[Создать вебинар]   → диалог с полями → planned-вебинар
[Начать сейчас]     → 1 клик → telemost-create-conference 
                    → insert webinar (status='live') 
                    → window.open(join_url) 
                    → refresh list
```

Никаких новых таблиц, миграций или edge-функций — переиспользуем уже задеплоенный `telemost-create-conference`.
