
## Диагностика проблемы Русских И.А.

**Ситуация в БД:**
- Курс «Менеджер по качеству», 4 урока (slider, video, video, test)
- В `lesson_progress`: ✅ Презентация, ❌ СМК ч.1 (16 448 сек = 4.5 ч просмотрено!), ❌ СМК ч.2, ✅ Тест 8/8
- В `enrollments`: progress=25%, status='active' — курс не завершён

**Корневая причина:** оба видеоурока — это внешние iframe-ссылки `https://ckevl.ktalk.ru/recordings/...` (КонтурТолк). Для iframe-видео **нет события `timeupdate`** (это нативный HTML5 API), поэтому автозавершение по 90% **физически не может сработать**. Студент посмотрел видео в iframe, но прогресс не записался.

**Дополнительные проблемы в коде:**

1. **Кнопка «Завершить урок» скрыта для видео, пока `videoWatchProgress < 90`** (`CourseLearning.tsx:368`). А для iframe-видео `videoWatchProgress` всегда = 0 → кнопки **никогда нет**, ученик заперт без выхода.

2. **Прогресс enrollments считается только на клиенте.** Если ученик закрыл вкладку до сохранения, прогресс не обновится — нет триггера, который бы пересчитал `enrollments.progress` по факту записей в `lesson_progress`.

3. **Triger `trigger_auto_complete_enrollment` срабатывает только при UPDATE.** Если progress обновился в офлайн-очереди, но ушёл криво — статус не пересчитается.

4. **Триггер `auto_complete_enrollment` использует `BEFORE UPDATE`** — он не сработает на INSERT и не запустит каскад документов (`trigger_auto_create_education_document` идёт после изменения `status`, проверяет переход → completed).

## План исправления

### 1. UI: показывать кнопку «Завершить урок» для всех видеоуроков

В `CourseLearning.tsx:368` убрать условие `videoWatchProgress >= 90` для видео типа iframe / Kinescope / внешний URL — оставить только для нативного `<video>` плеера. Для iframe-видео сразу давать кнопку с подсказкой «Подтвердить просмотр».

### 2. БД-триггер: автоматический пересчёт прогресса при изменении lesson_progress

Создать триггер `recalc_enrollment_progress` на `lesson_progress` (AFTER INSERT/UPDATE/DELETE):
- найти курс урока → найти enrollment пользователя
- посчитать `count(completed)/count(*) * 100` по всем урокам курса
- обновить `enrollments.progress` (триггер `auto_complete_enrollment` подхватит и завершит курс при 100%)

Это гарантирует, что **прогресс всегда совпадает с фактом**, даже если клиент рассчитал его неверно или офлайн-синк прошёл частично.

### 3. Бэкфилл существующих данных

Для курсов, где у студента lesson_progress уже есть, но enrollments.progress отстал — пересчитать одной миграцией. Конкретно для Русских И.А. — это пересчитает 4/4 = ничего, потому что lesson_progress тоже отстал. Но восстановит данные у других учеников с такой же проблемой.

### 4. Ручная починка для Русских И.А.

После деплоя триггеров — отметить два видео как пройденные (16 448 сек на «СМК ч.1» — это реально 4.5 часа просмотра, тест сдан на 100%), что автоматически закроет курс, сгенерирует протокол и удостоверение.

### 5. Защита от потери прогресса при закрытии вкладки

В `markLessonComplete` уже есть `sendBeacon`, но он шлёт только время. Добавить второй beacon на `lesson_progress` upsert при закрытии — чтобы если пользователь нажал «Завершить» и сразу закрыл вкладку, запись всё равно ушла.

### 6. Память

Обновить `mem://features/learning/automated-completion-logic` — добавить про iframe-видео и серверный пересчёт прогресса.
