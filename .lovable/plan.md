## Что меняем в админ-генераторе документов

### 1. Тариф в предмете договора
- Добавить в шаге «3. Параметры документа» селект **«Тариф»** (Старт, Базовый, Профессиональный, Максимальный) — появляется только для `paid_contract` и `mixed_package`.
- Для `free_contract` тариф всегда «Бесплатный» — селект скрыт, значение подставляется автоматически.
- Хранить выбранный тариф в `AdminDocVariables.plan`. При смене тарифа автоматически перегенерировать текст «Предмета» из нового справочника `PLAN_CONTRACT_SUBJECTS[plan]` (пользователь всё ещё может отредактировать вручную).
- В `src/lib/adminDocTemplates/index.ts` добавить константы `FREE_PLAN_CONTRACT_SUBJECT` и словарь по всем тарифам, использовать их как дефолт вместо жёсткого `START_PLAN_CONTRACT_SUBJECT`.

### 2. Кнопка «Скачать PDF»
- Рядом с «DOC» и «Печать / PDF» добавить кнопку **«PDF»** — генерирует настоящий PDF-файл (не диалог печати) через `html2canvas` + `jsPDF` (уже используются в `exportPlatformProposalPdf.ts`), сохраняет `Договор_<номер>.pdf`.
- Такую же кнопку PDF добавить в карточку истории (рядом с «глазом» и принтером).

### 3. Отправка контрагенту
- Добавить кнопку **«Отправить контрагенту»** в панели действий и в карточке истории.
- Диалог подтверждения: показывает email из `counterparty_email`, позволяет отредактировать, приложить сопроводительный текст.
- По нажатию:
  1. Сохранить документ в историю (если ещё не сохранён), поставить `status = 'sent'`, записать `sent_at`, `sent_to_email`, `sent_to_organization_id` (если контрагент найден по ИНН в `organizations`).
  2. Вызвать существующий edge-function отправки почты (`send-transactional-email` / SMTP-хук админки) с прикреплённым PDF/DOC.
  3. Если по ИНН найдена организация-клиент СИНТАГМЫ — создать запись в `org_documents` (тип `admin_contract`) и `org_notifications` (заголовок «Новый документ от СИНТАГМЫ», ссылка на документ). Тогда документ появится у заказчика во вкладке «Документы» и в колокольчике уведомлений.
- Статус в истории отображать бейджем: `draft` / `sent` / (при клике по «Отправить ещё раз» — обновлять `sent_at`).

### 4. Технические детали
- Миграция: добавить в `admin_generated_documents` колонки `sent_at timestamptz`, `sent_to_email text`, `sent_to_organization_id uuid references organizations(id)`; добавить в `AdminDocVariables` поле `plan`.
- Новых edge-функций не создаём — переиспользуем существующую отправку писем.
- Тип `PLAN_CONTRACT_SUBJECTS` экспортируем из `adminDocTemplates`, чтобы использовать в UI.

### Файлы, которые тронем
- `src/lib/adminDocTemplates/index.ts` — словарь предметов по тарифам, `plan` в типах, дефолты для free/paid.
- `src/components/admin/AdminDocumentsManager.tsx` — селект тарифа, кнопки PDF/Отправить, диалог отправки, статусы, PDF-экспорт хелпер.
- `src/utils/adminDocPdf.ts` (новый) — экспорт HTML → PDF через html2canvas/jsPDF.
- Миграция БД для новых колонок в `admin_generated_documents`.
