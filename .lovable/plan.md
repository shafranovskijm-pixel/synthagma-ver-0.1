

## План: Аккордеон по умолчанию свёрнут + продающий онбординг для журналов

### Что делаем

1. **Категории свёрнуты по умолчанию** — меняем инициализацию `expandedCategories` с `JOURNAL_CATEGORIES.map(c => c.id)` на пустой массив `[]`.

2. **Продающий блок над категориями** — добавляем карточку с описанием возможностей системы журналов (аналогично курсам, компаниям, хранилищу):

**Заголовок:** «Полная система учёта для организаций ДПО»

**Описание функционала (продающий стиль):**
- Обязательные журналы — посещаемость, контроль успеваемости, итоговая аттестация, регистрация документов — всё в одном месте
- Автоматическое заполнение — данные из курсов подтягиваются автоматически, не нужно вводить вручную
- Электронные журналы онлайн — ведите учёт прямо в браузере с еженедельной сеткой и быстрым вводом оценок
- Экспорт и шаблоны — скачайте готовые шаблоны или выгрузите заполненные журналы в Excel
- Пользовательские журналы — создавайте свои журналы с произвольными полями под задачи вашей организации
- Видеоидентификация — верификация личности студентов с фотографиями и контролем статуса

### Логика отображения

Блок показывается **всегда** над списком категорий (не зависит от наличия данных), заменяя текущий простой заголовок «Журналы учёта / Обязательные и рекомендуемые...». Кнопки «Видеоидентификация» и «Создать журнал» остаются.

### Визуал

Широкая карточка с градиентом, 6 фич в 2 колонки с иконками, кнопки справа сверху.

### Проверка работоспособности

API запрос к `journal_instances` возвращает 200 — база работает. Редактор журналов (`JournalEditor`) загружается корректно. Автоматические журналы (посещаемость, оценки, аттестация) открываются через отдельные компоненты. Проблем в консоли нет — журналы работают.
