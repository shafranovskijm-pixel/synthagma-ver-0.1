
## План: ИИ-преподаватель как тип урока в конструкторе курсов

### Концепция (уточнённая)

- **Студенты сами ничего не запускают.** Карточка в кабинете ученика рядом с «3D-тренажёрами» — это **просто маркетинговая заглушка** «такая возможность есть», без кнопки «Попробовать».
- **Реальное использование** — внутри курса. В конструкторе появляется новый **тип урока «ИИ-аватар»**. Организация добавляет его в курс, настраивает аватара/промпт/голос. Ученик при прохождении курса попадает в этот урок и общается с ИИ-преподавателем.
- **Лимит** — 5 минут на сессию (пробный период), потом расширим. Лимит на уровне урока (настраиваемый, дефолт 5 мин).

### 2. Новый тип урока `ai_avatar`

**База:**
- Расширяем CHECK на `lessons.type` — добавляем `'ai_avatar'`.
- Новые опц. колонки в `lessons` (или один JSON `ai_avatar_config`):
  - `ai_avatar_name`, `ai_avatar_image_url`, `ai_avatar_voice_id`
  - `ai_avatar_system_prompt`, `ai_avatar_greeting`
  - `ai_avatar_subject`, `ai_avatar_style` (friendly/strict/mentor)
  - `ai_avatar_session_minutes` (default 5)
  - `ai_avatar_model` (default `google/gemini-3-flash-preview`)

Таблица `ai_tutor_sessions` уже есть — добавляем `lesson_id uuid` для привязки к уроку и учёта.

**Конструктор курсов (`LessonTypeConfig.ts`):**
- Добавляю тип `ai_avatar` с иконкой `Sparkles`, лейблом «ИИ-аватар», цветом фиолетово-розовый градиент.
- В сайдбаре «Добавить урок» появляется новая кнопка.

**Редактор урока (новый `AIAvatarLessonEditor.tsx`):**
Три секции:
1. **Аватар:** имя, фото (Generate AI / Upload), голос SaluteSpeech (с превью), стиль общения.
2. **Поведение:** system prompt (+ кнопка «Сгенерировать ИИ»), приветствие, лимит минут (1–25, дефолт 5), модель.
3. **Тема:** предмет/контекст для ИИ.

**Edge-функции:**
- `ai-avatar-generate-prompt` — Lovable AI генерит черновик system-prompt по теме/стилю.
- `ai-avatar-generate-image` — Nano Banana генерит портрет аватара.
- Правлю `livekit-ai-tutor-start` — принимает `lesson_id`, читает настройки из урока, лимит = `ai_avatar_session_minutes`.

---

### 3. Воспроизведение урока учеником

Новый компонент `LessonAIAvatar.tsx` (в `LessonContent`):
- Показывает карточку аватара (имя, фото, тема), кнопку «Начать сессию (5 мин)».
- При клике → `livekit-ai-tutor-start` → редирект в LiveKit-комнату `WebinarLive` в режиме «AI tutor» (1 ученик + ИИ).
- После завершения сессии (по таймеру или ручному «Закончить») урок помечается завершённым.
- Плашка «Бета — голосовой ИИ скоро оживёт» (агент-воркер ещё не задеплоен).
