## Обновление блока «Скрипт звонка» (v1.1)

Заменяю текущий скрипт на версию из ТЗ (заточен под Синтагму: холодные звонки учебным центрам и ДПО). Меняю только скрипт и связанные с ним поля результата звонка — CRM-логику, статусы, импорт Excel и телефонию не трогаю.

### 1. `src/constants/coldCallScript.ts` — переписать
- Новые переменные шаблона: `{company_name}`, `{manager_name}`, `{contact_name}`, `{phone}`. Функция `fillScriptTemplate` расширяется.
- 4 вкладки со свежими репликами:
  - **Старт** — 5 реплик про Синтагму/СДО/ДПО.
  - **Вопросы** — 6 квалификационных вопросов.
  - **Возражения** — 7 возражений (Не нужно, Уже есть платформа, Пришлите на почту, Нет времени, Дорого, Обучаем очно, Директора нет) с полями `answer` + опциональными `follow_up`, `follow_up_if_has_lms`, `follow_up_if_not_relevant`.
  - **Закрытие** — 4 реплики.
- Экспорт `shortScript30s` — короткий блок «30 секунд» (5 реплик).
- Обновить `CALL_RESULTS` под список ТЗ: Не дозвонился, Не ЛПР, Не актуально, Есть интерес, Отправить информацию, Назначить демо, Перезвонить, Чёрный список (с маппингом на `sales_leads.status`).
- Новые константы `PAIN_OPTIONS` (8 вариантов), `NEXT_ACTION_OPTIONS` (5 вариантов), `SEND_INFO_CHANNELS` (WhatsApp/Telegram/email).

### 2. `src/components/admin/sales/ColdCallScriptCard.tsx`
- У каждой реплики — кнопка «Скопировать реплику» (иконка). Верхняя кнопка «Скопировать весь скрипт» остаётся.
- В вкладке «Возражения» — раскрывающиеся карточки с `answer` + вложенными follow-up блоками (тоже копируются).
- Отдельный сворачиваемый блок «Скрипт на 30 секунд» под табами.
- Быстрые кнопки результата обновляются под новый список (открывают `CallResultModal` с preset).

### 3. `src/components/admin/sales/CallResultModal.tsx`
- `Боль клиента` — теперь `Select` из `PAIN_OPTIONS` (не Textarea), с опцией «Своё» → раскрывается Textarea.
- `Следующий шаг` — `Select` из `NEXT_ACTION_OPTIONS`.
- Адаптивные поля по выбранному шагу:
  - «Отправить информацию» → выбор канала (WhatsApp/Telegram/email) + телефон/email из карточки.
  - «Назначить демо» → дата/время + комментарий (уже есть).
  - «Перезвонить» → дата/время (уже есть).
  - «Передать руководителю» → поле с именем/должностью.
- Итоговое сохранение в `sales_lead_activities.description` формирует структурированную запись (Результат / Боль / Следующий шаг / Канал / Дата).
- Автомапинг статусов лида по `CALL_RESULTS[].status`.

### 4. Что НЕ меняю
- `CompanyDrawer`, таблицу компаний, KPI-полосу, импорт, звонки Novofon, `sales_leads` схему, RLS.
- Хук `useSalesManager`, `useSalesTasks` — используются как есть.

### Критерии приёмки
- В карточке компании во вкладке «Скрипт» — 4 вкладки со свежим текстом, `{company_name}`/`{manager_name}` подставляются.
- Кнопка «Скопировать» есть у каждой реплики и общая сверху.
- Кнопки результата и модалка обновлены: боль/следующий шаг из списков, адаптивные поля.
- Сохранение результата пишет активность и (по правилам) меняет статус лида.
