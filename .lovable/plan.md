## Где сейчас «Отправить КП»
Форма быстрой отправки уже есть — она живёт на вкладке **«Документы»** (последняя вкладка справа) внутри `CompanyDrawer.tsx`. Там подгружаются 8 активных шаблонов КП (проверил БД — есть «СИНТАГМА — платформа ДО», «СИНТАГМА — общие услуги», «СДО под ключ», «Коробочная», «ФИС ФРДО», «Готовый каталог 300+», «Корпоративное обучение», «Разработка сайта»). Просто вкладка не бросается в глаза, поэтому кажется, что кнопки нет.

## Что делаем
Поднимаем «Отправить КП» на верх карточки — рядом с «Позвонить» и «Результат», чтобы не нужно было переключать вкладку.

### 1. Хедер `CompanyDrawer` — новая кнопка «Отправить КП»
- Третья кнопка в ряду `flex gap-2 pt-1`: `<Send /> КП`.
- Клик открывает `Popover` (shadcn) с готовой мини-формой:
  - Select со всеми шаблонами (используем существующий `proposalTemplates`, значение из `selectedTpl`).
  - Input email (по умолчанию `lead.email`, редактируемый).
  - Кнопка «Отправить с нашей почты» → тот же `handleSendProposal`.
  - Ссылка «Открыть вкладку Документы» — переключает `Tabs` на `docs` (через `useState` для `activeTab`).
- Бейдж-счётчик на кнопке с количеством доступных шаблонов (`{proposalTemplates.length}`), чтобы было видно, что КП подтянуты.

### 2. Вкладка «Документы» — оставляем как есть
Она уже содержит расширенный вариант формы + кнопки «Создать своё КП» / «Создать договор». Не дублируем логику — Popover и вкладка используют одни и те же `selectedTpl` / `sendEmail` / `handleSendProposal`.

### 3. Активная вкладка контролируется состоянием
- `Tabs` из `defaultValue="summary"` меняем на управляемый `value={activeTab}` + `onValueChange`.
- Ссылка «Открыть вкладку Документы» в поповере вызывает `setActiveTab('docs')` и закрывает Popover.

### 4. Ничего в БД/edge-функциях не трогаем
`send-platform-proposal` и таблица `commercial_proposals` уже готовы; шаблоны в БД присутствуют.

## Итого пользователь увидит
В шапке карточки компании три кнопки в один ряд:
`[ 📞 Позвонить +7 (383) 373‑07‑73 ]  [ Результат ]  [ ✉ КП · 8 ]`
Клик по «КП» открывает мини-форму — выбор шаблона, email клиента (подставлен), «Отправить». Одним движением, без переключения вкладок.
