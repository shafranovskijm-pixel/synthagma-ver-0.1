

# Исправление парсера для пустых уроков SkillSpace

## Проблема

При импорте некоторых курсов (например, «Школа Целительства» — 37 уроков) API `/api/rest/school/lesson/{uuid}` возвращает всего ~487 байт — только метаданные без контента. Текущий fallback через `/page/list` тоже не срабатывает. В результате все уроки получают заглушку «Пустой урок».

Для сравнения: курсы с контентом (КУРС ЭНЕРГОПРАКТИКИ, Мастер Света) возвращают 4000–24000 байт на урок.

## Решение

Расширить парсер, добавив дополнительные стратегии извлечения контента:

1. **Дополнительные API-эндпоинты** — попробовать:
   - `/api/rest/school/step/{uuid}` (step вместо lesson)
   - `/api/rest/school/step/{uuid}/page/list?version=published`
   - `/api/rest/student/step/{uuid}` (студентский API для step)
   - `/api/rest/school/lesson/{uuid}/content`

2. **Логирование тела ответа** — для уроков с ≤500 байт записывать полный JSON ответа в debug-лог (первые 500 символов), чтобы понять структуру данных.

3. **Кнопка «Перепарсить контент»** — добавить в интерфейс пакетного импорта возможность повторного парсинга только контента для уже импортированных курсов (без создания дублей), используя режим обновления.

## Технические детали

### Файлы для изменения:
- `supabase/functions/parse-skillspace-course/index.ts` — расширить fallback-стратегии и добавить подробное логирование для маленьких ответов
- `src/components/admin/SkillspaceBatchImportDialog.tsx` — добавить кнопку повторного парсинга с обновлением контента

### Логика fallback (в edge-функции):
```text
1. /api/rest/school/lesson/{uuid}?version=published  (текущий)
2. /api/rest/school/lesson/{uuid}                      (текущий)
3. /api/rest/school/step/{uuid}?version=published      (НОВЫЙ)
4. /api/rest/school/step/{uuid}                        (НОВЫЙ)
5. Если ответ ≤ 600 байт → логировать полный JSON
6. Fallback: /page/list через step API                 (НОВЫЙ)
7. Fallback: /api/rest/student/step/{uuid}             (НОВЫЙ)
```

### Режим обновления контента:
При повторном парсинге передаётся флаг `updateContentOnly: true`, парсер обновляет только `content` существующих уроков без создания новых записей.
