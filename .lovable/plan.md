

## Добавить тултипы-подсказки ко всем элементам конструктора курсов

### Что сделать

Обернуть все интерактивные элементы в `CourseBuilder.tsx` в компоненты `Tooltip`, чтобы при наведении пользователь видел пояснение.

### Файл: `src/pages/CourseBuilder.tsx`

Добавить один `TooltipProvider` на верхнем уровне, затем обернуть каждый элемент:

| Элемент | Подсказка |
|---------|-----------|
| Кнопка «Назад» | «Вернуться к списку курсов» |
| Кнопка «Предпросмотр» | «Посмотреть курс глазами ученика» |
| Кнопка «Импорт» | «Загрузить уроки из файлов: .docx, .txt, .md, .html» |
| Кнопка «AI Структура» | «Автоматически сгенерировать структуру уроков по названию и описанию курса» |
| Кнопка «Сохранить курс» | «Сохранить все изменения курса» |
| Карточка «Текст» | «Урок с текстовым содержимым и блочным редактором» |
| Карточка «Видео» | «Урок с видео: YouTube, VK, Rutube или загрузка файла» |
| Карточка «Тест» | «Проверочный тест с вопросами и вариантами ответов» |
| Карточка «AI Генерация» | «Сгенерировать урок с помощью искусственного интеллекта» |
| Карточка «Слайды» | «Урок-презентация с несколькими слайдами» |
| Карточка «Аудио» | «Аудиоурок: загрузите файл или вставьте ссылку» |

### Техническая реализация
- Импортировать `Tooltip, TooltipTrigger, TooltipContent, TooltipProvider` из `@/components/ui/tooltip`
- Обернуть весь return в `<TooltipProvider delayDuration={300}>`
- Каждую кнопку/карточку обернуть в `<Tooltip><TooltipTrigger asChild>...</TooltipTrigger><TooltipContent>текст</TooltipContent></Tooltip>`
