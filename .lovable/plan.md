

# План: чинить раскрытое меню + следующая волна улучшений интуитивности

## Что не так сейчас (по вашему скриншоту)

1. **Сайдбар полупрозрачный** — `backgroundColor: hsl(brand / 0.07)`. При раскрытии 220px текст контента просвечивает сквозь меню → «не видно меню».
2. **Контент не «подвинулся» визуально** — баннер шапки (Hero) растягивается на всю ширину окна и стоит под сайдбаром, а не рядом с ним. Quick-Start карточка тоже наезжает.
3. **Заголовок «ООО ЦКЭ» внутри сайдбара** не нужен в раскрытом виде — он дублирует то, что уже есть в шапке, и съедает место.
4. **Плашки секций (`Обучение / Клиенты / Инструменты`)** — в раскрытом виде они выглядят как кнопки, а не как заголовки; пользователь думает, что это активный пункт.
5. **Кнопка «Свернуть»** спрятана внизу сайдбара — это контр-интуитивно. Она должна быть сверху рядом с логотипом.

## Этап 3 — фиксим раскрытие + добавляем интуитивности

### 1. Сделать сайдбар непрозрачным (`OrgSidebar.tsx`)
- Заменить `hsl(brand / 0.07)` на сплошной фон: в светлой теме — `bg-card` с лёгким brand-тонированием через тонкую вертикальную полоску слева, в тёмной — `bg-background` + `border-r border-border/50`.
- Внутренние плашки секций оставить тонированными (`hsl(brand / 0.10)`) — контраст между фоном и группами сохранится.
- Добавить `backdrop-filter: none` явно, чтобы убрать остаточную прозрачность.

### 2. Перенести кнопку «Свернуть/Развернуть» наверх
- В шапку сайдбара (рядом с логотипом) добавить компактную кнопку-стрелку. В свёрнутом — `›`, в раскрытом — `‹`.
- Из футера эту же кнопку убрать (там оставить только Помощь, Что нового, Выйти).

### 3. Раскрытый сайдбар: показывать название организации сверху
- В раскрытом виде под логотипом — название школы (truncate, 1 строка), под ним мелким серым — план («Бесплатный»).
- Это превращает «полоску иконок» в нормальную панель навигации в стиле Notion / Linear.

### 4. Заголовки секций — сделать «не-кликабельными» визуально
- Убрать у них фоновую плашку, оставить только мелкий серый caps-текст: `Обучение` без подложки.
- Иконки секции внутри уже сгруппированы своим отступом — обводка не нужна.

### 5. Убрать «лесенку» в раскрытом виде
- Сейчас в раскрытом виде иконки + длинный текст создают неровный край. Зафиксировать ширину иконки 18px + gap 12px + текст с `truncate`.
- Высота кнопки везде 40px, активная — насыщенный brand, неактивная — прозрачный hover.

### 6. Контент должен «дышать», когда меню раскрыто
- В `OrganizationDashboard.tsx` при `sidebarExpanded === true` уменьшать максимальную ширину карточек Hero/QuickStart до доступной зоны (`max-w-[1100px]`), чтобы они не лезли под сайдбар на узких экранах.
- На экранах < 1280px при `expanded` — авто-сворачивать сайдбар обратно (через `useEffect` + `matchMedia`), чтобы не было «давки».

### 7. Глобальный поиск как видимая «омнибокс-плашка» в шапке (доделать)
- Сейчас в шапке маленькая плашка `[🔍 ⌘K]`. Сделать её **полноценной центральной строкой** (max-w-md, по центру шапки), с placeholder «Найти раздел, ученика, курс, документ…». Клик по ней открывает существующий `GlobalCommandPalette`.
- Это известный паттерн (Linear, Notion, Vercel) — пользователь сразу видит главный способ навигации.

### 8. Новинки интуитивности

**a) Закладки/«Избранное» в сайдбаре.** Над секциями добавить мини-блок «Закрепить»: правый клик по любому пункту → «Закрепить наверху». Закреплённые пункты сохраняются в `localStorage` (`org-sidebar-pinned`) и показываются над секциями. Решает проблему «у меня 12 пунктов, но я хожу только в 3».

**b) Индикатор «новое» возле пунктов.** На иконку пункта вешать оранжевую точку, если в этом разделе есть непрочитанное:
- «Чаты» — уже есть badge (оставляем).
- «Домашние работы» — точка, если есть `pending_review > 0`.
- «Продажи» — точка, если есть лиды без касания > 24ч.
- «Что нового» — точка, если есть непросмотренные `platform_updates`.

**c) Хлебные крошки кликабельные.** В шапке `Школа › Обучение › Курсы` — клик по «Обучение» открывает мини-выпадайку с пунктами секции. Быстрое перемещение между сёстрами без возврата к сайдбару.

**d) Ховер-превью раздела.** При наведении на иконку в свёрнутом сайдбаре — вместо тултипа из 1 слова показывать мини-карточку: иконка + название + 1-строчное описание + счётчик («14 курсов», «47 учеников»). Решает «что это за иконка?» один раз и навсегда.

**e) «Часто используемые действия» в шапке-омнибоксе.** Под омнибоксом при фокусе — 3-4 чипа по последним действиям пользователя из `localStorage`: «Создать курс», «Отправить КП», «Загрузить ФРДО». Прямой ярлык без кликов.

**f) Контекстный help-баббл.** На каждой странице — маленькая `?` в правом верхнем углу контента, открывающая короткое объяснение раздела (2-3 предложения + ссылка на полную статью). Не залезать в Help-центр ради одной справки.

**g) Звук/анимация при переходе между разделами.** Лёгкая 150ms анимация подсветки активного пункта + микро-сдвиг контента — мозг легче «привязывает» иконку к экрану.
