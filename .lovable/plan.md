

# Категории и список в каталоге маркетплейса

## Анализ данных

58 курсов естественно группируются в 11 категорий по префиксу названия (до " — "):

| Категория | Кол-во |
|-----------|--------|
| Правила устройства электроустановок | 8 |
| Правила технической эксплуатации электроустановок потребителей | 8 |
| Правила технической эксплуатации электрических станций и сетей РФ | 8 |
| Правила работы с персоналом в организациях электроэнергетики РФ | 8 |
| Правила по охране труда при эксплуатации электроустановок | 8 |
| Мероприятия по оказанию первой помощи | 8 |
| Правила противопожарного режима в РФ | 4 |
| Правила переключений в электроустановках | 3 |
| Охрана труда при работах на высоте (1, 2, 3 группы) | 3 |

## Подход

Категории извлекаются из названий курсов на клиенте — без изменений в БД. Префикс до первого " — " = категория.

## Изменения

### 1. `useAdminMarketplace.ts`
- Добавить состояние `selectedCategory` (string, default "all")
- Добавить `viewMode` ("list" | "grid", default "list")
- Вычислять `categories` из списка курсов (уникальные префиксы)
- Расширить `filteredCourses` фильтром по категории

### 2. `AdminMarketplaceManager.tsx` — вкладка "Каталог"
- Добавить горизонтальный список категорий (кнопки/badges с возможностью выбора) над поиском
- Переключатель вида grid/list (иконки Grid/List)
- **Режим "Список"** (по умолчанию): компактная таблица — название (укороченное, без категории), группа/напряжение, цены, статус, действия
- **Режим "Сетка"**: текущие карточки (без изменений)
- Показывать счётчик курсов в выбранной категории

Список будет более компактным: в каждой строке — короткое название (только часть после категории, например "до 1000 В — Группа II"), цены студент/орг, переключатель видимости, кнопки действий.
