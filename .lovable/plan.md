

# Настройки группы — диалог с вкладками (как в SkillSpace)

## Что сейчас
При клике на шестерёнку группы открывается простой диалог с названием, цветом, датами и удалением. Нет расширенных настроек.

## Что будет
Заменим текущий простой диалог на полноценный диалог настроек группы с 4 вкладками (по аналогии со скриншотами SkillSpace):

### Вкладки

**1. Общие настройки**
- Название группы (редактируемое поле)
- Цвет группы
- Кнопка «Удалить группу»
- Тоггл: «Ограничить кол-во мест в группе» (с полем для числа) — с подсказкой (?)
- Тоггл: «Назначить куратора» — с подсказкой (?)

**2. Процесс обучения**
- Тоггл: «Ограничить время доступа к курсу» — с подсказкой (?)
- Тоггл: «Открывать доступы по расписанию» — с подсказкой (?)
- Тоггл: «Строгая последовательность занятий» — с подсказкой: "Ученик сможет приступить к следующему занятию только после прохождения предыдущего"
- Тоггл: «Заблокировать отправку повторных ответов» — с подсказкой (?)

**3. Доступ к обучению**
- Тоггл: «Отображать недоступные занятия в списке» — с подсказкой (?)
- Список занятий курса с чекбоксами (включить/выключить доступ)

**4. Доступ к чату**
- Тоггл: «Канал в сообщениях» — с подсказкой (?)
- Тоггл: «Групповой чат в сообщениях» — с подсказкой (?)
- Тоггл: «Запретить ученикам начинать новые диалоги с сотрудниками» — с подсказкой (?)

### Техническая реализация

1. **Миграция БД** — добавить столбцы в `student_groups`:
   - `max_seats` (integer, nullable)
   - `curator_id` (uuid, nullable, FK → profiles)
   - `strict_order` (boolean, default false)
   - `limit_access_time` (boolean, default false)
   - `schedule_access` (boolean, default false)
   - `block_resubmit` (boolean, default false)
   - `show_locked_lessons` (boolean, default true)
   - `enable_channel` (boolean, default false)
   - `enable_group_chat` (boolean, default false)
   - `block_student_dialogs` (boolean, default false)

2. **Новый компонент** `GroupSettingsDialog.tsx` — диалог с боковыми вкладками (как на скриншотах), каждый тоггл с иконкой `HelpCircle` и Tooltip с пояснением.

3. **Обновить `StudentsTab.tsx`** — добавить иконку шестерёнки на карточку группы, при клике открывать `GroupSettingsDialog`.

4. **Кнопка «Сохранить»** внизу — обновляет `student_groups` запись в БД.
