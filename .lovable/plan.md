
# Улучшение интерфейса "Помощь" и проверка Telegram

## Статус Telegram

Отправка в Telegram работает корректно -- тестовое сообщение успешно доставлено (message_id: 2). Секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_SUPPORT_CHAT_ID` настроены.

## Что будет сделано

### 1. Подсказки в аккордеон

Текущие карточки подсказок заменяются на компонент `Accordion` (уже есть в проекте). Каждая подсказка -- раскрывающийся элемент с заголовком, который можно развернуть для просмотра описания. Это экономит место и выглядит аккуратнее (как на скриншоте-референсе).

### 2. Улучшение интерфейса диалога "Помощь"

- Увеличить ширину диалога до `sm:max-w-lg`
- Разделить контент на две секции с визуальным разделителем:
  - Секция "Подсказки" с аккордеоном
  - Секция "Сообщить о проблеме" с формой
- Добавить иконки к каждой подсказке в аккордеоне
- Улучшить стилизацию формы поддержки: добавить иконку `MessageSquare` в заголовок, мягкий фон для всего блока

### 3. Исправление warning в консоли

Исправить предупреждение "Function components cannot be given refs" для `SupportRequestForm` -- обернуть компонент в `React.forwardRef` или убрать передачу ref.

### Структура аккордеона

Каждый `AccordionItem` содержит:
- `AccordionTrigger`: заголовок подсказки (жирный, `text-sm`)
- `AccordionContent`: описание подсказки (`text-xs text-muted-foreground`)
