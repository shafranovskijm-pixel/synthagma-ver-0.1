
# Кабинет менеджера v2

Сейчас `/sales` открывается на «Обзоре», шапка пустая, лиды живут глубоко внутри. Перестраиваем так, чтобы интерфейс был похож на кабинет организации, а главный экран — рабочий список контактов.

## 1. Шапка как в кабинете организации

В `src/pages/SalesDashboard.tsx` поднимаем настоящий header (по образцу `OrgDashboardHeader`):

- Логотип Σ + «Кабинет менеджера» + хлебные крошки активного раздела.
- Кнопки справа: **RadioPlayerButton** (фоновое радио + переключение станций), переключатель темы (исп. существующий `useOrgTheme`/`admin-themes` → выпадашка «Тема интерфейса»), «Наши реквизиты», профиль/выход.
- Sticky, glass-эффект как у `OrgDashboardHeader`.

Кнопку «Наши реквизиты» из тела `SalesManager.tsx` убираем (переезжает в шапку).

## 2. Контакты — главный экран

В `src/components/admin/sales/SalesSidebar.tsx` добавляем новый верхний пункт **«Контакты»** (иконка `Contact`) — он становится дефолтным `activeTab` в `SalesManager.tsx` вместо `overview`. «Обзор» остаётся, но вторым.

Создаём `src/components/admin/sales/ContactsHub.tsx` — обёртка над `LeadsManager`, которая:

- Сверху показывает плашку «Необработанные базы»: считает `sales_leads` со `status='new'` (и/или `assigned_manager_id IS NULL`) по загруженным пакетам. Группировка по `source` / дате загрузки → карточки «База от 12.06 · 451 контакт · необработано 312» с кнопкой «Открыть» (выставляет фильтр).
- Ниже — текущий `LeadsManager` с региональными чипами и таблицей.

## 3. Местное время по региону

Добавляем `src/utils/regionTimezones.ts` — карта `region → IANA TZ` для всех 85 субъектов РФ (Калининград UTC+2, Москва +3, Самара +4, Екатеринбург +5, Омск +6, Красноярск +7, Иркутск +8, Якутск +9, Владивосток +10, Магадан +11, Камчатка/Чукотка +12). Хелпер `getRegionLocalTime(region)` возвращает `HH:mm` и `MSK ±N ч`.

В `LeadsManager.tsx`:

- Рядом с активным региональным чипом и в Select показываем мини-бейдж `🕐 14:32 (МСК+6)`, обновляется раз в минуту.
- В строке лида — маленькая подпись времени, чтобы менеджер сразу видел, удобно ли звонить.

## 4. Мелочи

- `SalesDashboard.tsx` оборачиваем в `OrgThemeProvider`-аналог (или просто читаем `useOrgTheme` глобально), чтобы переключатель темы реально перекрашивал кабинет.
- Кнопка «Войти как ученик»-баннер остаётся.
- Контекст «Контакты» добавляем в `TABS` и в выбор `currentItem` для мобильного меню.

## Технические детали

- Файлы на правку: `src/pages/SalesDashboard.tsx`, `src/components/admin/SalesManager.tsx`, `src/components/admin/sales/SalesSidebar.tsx`, `src/components/admin/sales/LeadsManager.tsx`.
- Новые файлы: `src/components/admin/sales/ContactsHub.tsx`, `src/components/admin/sales/SalesDashboardHeader.tsx`, `src/utils/regionTimezones.ts`.
- Без миграций БД — данные о «необработанных» считаем из существующих `sales_leads.status='new'` + `assigned_manager_id IS NULL`.
- Радио и темы переиспользуют существующие компоненты (`RadioPlayerButton`, `admin-themes`), новых зависимостей не добавляем.

После подтверждения — реализую за один проход.
