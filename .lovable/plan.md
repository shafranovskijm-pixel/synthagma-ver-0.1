

# Разделение кнопок "Купить" и "Записаться" в карточках курсов

## Что будет
- **Купить** — инициирует оплату через T-Bank (как сейчас работает «Записаться»)
- **Записаться** — отправляет сообщение в чат организации + уведомление (org_notifications) с просьбой записать на курс

## Изменения

### 1. `src/components/student/AvailablePaidCourses.tsx`
- Переименовать текущую кнопку «Записаться» → **«Купить»** (с иконкой `CreditCard`)
- Добавить вторую кнопку **«Записаться»** (с иконкой `ClipboardCheck`) — `variant="outline"`
- По клику «Записаться»:
  - Вставка в `chat_messages` (role: "user", content: заявка на запись с именем ученика и курсом)
  - Вставка в `org_notifications` (type: "enrollment_request", title/message с именем и курсом)
  - Toast: «Заявка отправлена! Учебный центр свяжется с вами»
- Для получения имени ученика — запрос `profiles` по `userId`

### 2. `src/components/student/CourseCardNew.tsx`
- Для незаписанных платных курсов: показывать две кнопки «Купить» и «Записаться» вместо одной
- Передать callback пропсы `onBuy` и `onEnroll` вместо единого `onClick`

### 3. Диалог подтверждения
- Сохранить существующий AlertDialog для оплаты (кнопка «Купить»)
- Добавить отдельный AlertDialog для заявки на запись («Записаться») с текстом «Ваша заявка будет отправлена в учебный центр»
