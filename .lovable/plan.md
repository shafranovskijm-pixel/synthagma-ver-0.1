

# Перенос разделов из сайдбара в настройки

## Что делаем

Убираем из левого меню разделы, которые не являются основными рабочими:
- **DevTools** → в настройки
- **ИИ-провайдеры** → в настройки  
- **Контент** → в настройки
- **Аналитика** → в настройки
- **Обновления** → убираем (уже есть «Что нового?» в правом верхнем)

**В сайдбаре останется только 5 пунктов:** Организации, Пользователи, Маркетплейс, Продажи, Чаты

## Что меняем

### 1. `AdminSidebar.tsx` — оставить 5 пунктов

Убрать из `navItems`: analytics, content, ai, updates, devtools. Оставить:
- Организации, Пользователи, Маркетплейс, Продажи, Чаты

### 2. `AdminSettings.tsx` — добавить 4 новых секции

Добавить в конец настроек 4 раскрываемых секции (через `<details>`), каждая рендерит существующий компонент:
- 📊 **Аналитика** → `<AdminAnalytics />`
- 📝 **Контент** → `<BlogManager />`
- 🤖 **ИИ-провайдеры** → `<AISettingsManager />`
- 🛠 **Developer Tools** → `<DevToolsPanel />`

### 3. `AdminDashboardHeader.tsx` — убрать «Что нового?» дубликат если нужно

Оставить как есть — «Что нового?» в dropdown переключает на `updates` таб, который по-прежнему рендерится в `AdminDashboard.tsx`.

## Файлы

| Действие | Файл |
|---|---|
| Изменить | `src/components/admin/AdminSidebar.tsx` — убрать 5 пунктов из navItems |
| Изменить | `src/components/admin/AdminSettings.tsx` — добавить 4 секции с импортами компонентов |
