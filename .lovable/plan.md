

# Полноценная страница «Помощь» для всех ролей

## Что делаем

Создаём единую страницу `/help` в стиле Skillspace — с поиском, категориями-карточками, FAQ-аккордеоном и контактами. Доступна всем: ученикам, организациям, компаниям, админу.

## Структура страницы

```text
┌─────────────────────────────────────────┐
│  Hero-баннер (градиент primary)         │
│  "Справочный центр"                     │
│  Подзаголовок + строка поиска           │
├─────────────────────────────────────────┤
│  Категории (карточки с иконками, 2x3)   │
│  • Начало работы     • Курсы и обучение │
│  • Тарифы и оплата   • FAQ              │
│  • Что нового        • Документы        │
├─────────────────────────────────────────┤
│  "Начало работы" — табы по ролям        │
│  (Для организаций / Для учеников)       │
│  Список статей-ссылок внутри каждого    │
├─────────────────────────────────────────┤
│  "Часто задаваемые вопросы" (Accordion) │
│  10-15 вопросов с ответами              │
├─────────────────────────────────────────┤
│  Контакты: Telegram, Email              │
│  Документы: Оферта, Политика, Согл.     │
└─────────────────────────────────────────┘
```

## Изменения

### 1. Новый файл: `src/pages/HelpCenter.tsx`
- Hero с градиентом и строкой поиска (фильтрует FAQ)
- 6 карточек-категорий с иконками (клик скроллит к секции)
- Табы «Для организаций / Для учеников» со списком инструкций
- FAQ-аккордеон (Accordion из shadcn) — вопросы про создание курсов, оплату, сертификаты и т.д.
- Блок контактов (Telegram, email) и ссылки на юр. документы

### 2. `src/routes/publicRoutes.tsx`
- Добавить `<Route path="/help" element={<HelpCenter />} />`

### 3. Обновить навигацию во всех хедерах:
- **AdminDashboardHeader** — `navigate("/help")` вместо `window.open("https://t.me/...")`
- **OrgPageLayout** — `navigate("/help")` вместо `navigate("/organization/help")`
- **StudentHeader** — `navigate("/help")` вместо `window.open("https://sintagma.com.ru/blog")`
- **OrganizationCourseDetails** — аналогично

### 4. Удалить старый `src/pages/OrganizationHelp.tsx`
- Убрать импорт и роут из `organizationRoutes.tsx`
