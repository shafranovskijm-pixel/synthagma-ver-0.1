

# Исправление 5 проблем: прогресс, картинки в тестах, перемешивание, видео

## Найденные проблемы и решения

### 1. Прогресс больше 100% (110%, 130%, 120%)

**Причина**: В нескольких местах прогресс отображается без ограничения максимумом:
- `CourseDetailsModal.tsx` -- строки 500-501 (средний прогресс), 567, 571, 731-732
- `CourseStudentsDialog.tsx` -- строки 170-171

**Решение**: Добавить `Math.min(..., 100)` во все эти места, как уже сделано в других компонентах.

---

### 2. Картинки в тестах не отображаются

**Причина (две проблемы)**:
- Серверное представление `test_questions_for_students` **не включает колонку `image_url`** -- студенты её просто не получают из базы
- В `CourseLearning.tsx` при рендеринге вопросов теста (строки 2126-2164, 2167-2221) **нет кода для отображения картинки**, даже если бы данные были

**Решение**:
1. Миграция: обновить VIEW `test_questions_for_students`, добавив `image_url`
2. Код: добавить `<img>` для `question.image_url` в оба блока рендеринга вопросов (до ответов и после ответов)

---

### 3. Вопросы не перемешиваются

**Причина**: Функция `selectRandomQuestions` перемешивает только когда `count < allQuestions.length` (строка 1267). Если "Показывать вопросов" не задано или >= общего числа, все вопросы показываются **в исходном порядке** (строка 1269).

**Решение**: Всегда перемешивать вопросы перед показом, даже когда показываются все.

---

### 4. Курс показывается пройденным раньше времени

**Причина**: Прогресс считается как `(completedCount + 1) / lessons.length * 100` при каждом завершении урока. Если урок засчитывается дважды (например, видео автозавершается + ручное нажатие), прогресс может превысить 100%. Также `lesson_progress` загружается без фильтра по `course_id` (строка 1163-1167), что может включать прогресс из других курсов.

**Решение**:
- Фильтровать `lesson_progress` только по урокам текущего курса
- Ограничить `newProgress` максимумом 100 при записи в `enrollments`

---

### 5. Видео не воспроизводится

**Причина**: Скриншот показывает видео, которое выглядит как внешняя запись (возможно, запись конференции). Если URL не распознается как встраиваемый, видеоплеер пытается его воспроизвести как прямой файл. Если формат не поддерживается браузером, видео не запустится.

**Решение**: Добавить обработку ошибки загрузки видео (`onError`) в нативный `<video>` плеер с fallback-кнопкой "Открыть видео в новом окне".

---
