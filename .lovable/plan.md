

# Исправление кнопки ссылки в редакторе

## Проблема

`prompt()` вызывает потерю фокуса и выделения текста в `contenteditable`. Браузер сбрасывает selection при открытии системного диалога, поэтому `createLink` не срабатывает. Также нужна возможность вставить ссылку как текст (без предварительного выделения).

## Решение

Заменить `prompt()` на React-попап (Popover) с полем ввода URL прямо в тулбаре блока.

### Логика работы кнопки ссылки

1. При нажатии кнопки Link2 сохраняем текущий selection/range в `useRef`
2. Открывается Popover с полем ввода URL и двумя режимами:
   - **Если текст выделен** — поле URL + кнопка «Обернуть в ссылку» (execCommand createLink)
   - **Если текст НЕ выделен** — два поля: «Текст ссылки» + «URL», кнопка «Вставить ссылку» (вставляет `<a href="..." target="_blank">текст</a>` через execCommand insertHTML)
3. После применения — закрыть попап, вернуть фокус в редактор

### Изменения в файле `BlockEditor.tsx`

- Добавить state: `linkPopoverOpen`, `linkUrl`, `linkText`, `savedRange` (useRef)
- Заменить блок кнопки Link2 (строки 955-993) на `<Popover>` с `<PopoverContent>`:
  - Поле Input для URL
  - Опционально поле Input для текста (если нет выделения)
  - Кнопка «Применить»
- При открытии попапа: сохранить `sel.getRangeAt(0)` в ref
- При применении: восстановить range из ref, выполнить `createLink` или `insertHTML`, добавить `target="_blank"`
