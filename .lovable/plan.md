

## План: встроить настройки в виджет конвейера

### Проблема
Настройки маркетплейса (промты, импорт Excel, ценообразование) вынесены в отдельную вкладку «Настройки». Пользователь хочет видеть их прямо в том же карточке-виджете конвейера на вкладке «Каталог», а также видеть список курсов в очереди и историю обработки.

### Проверка безопасности тестов
Код проверен — тесты защищены в обоих местах:
- `autoFixCourse` (строка 221): `.filter(gl => gl.type !== "test")` — новые тесты не создаются
- `BulkPipelineWidget` (строка 69): `.filter(gl => gl.type !== "test")` — аналогично
- Вопросы не генерируются — только решаются существующие (`generate_answers`)
- Удаление уроков нигде не вызывается

### Что нужно сделать

**1. Расширить `BulkPipelineWidget.tsx`** — добавить три раскрываемых секции прямо внутри карточки конвейера:

- **Секция «Очередь»** (Collapsible) — список курсов в очереди с иконками статуса (ожидает / обрабатывается / готово / ошибка). Каждый курс показывает что было сделано: сколько уроков заполнено, сколько тестов решено.
- **Секция «Промты ИИ»** (Collapsible) — три текстовых поля для промтов (структура, контент, тесты). Значения читаются/сохраняются через `getMarketplacePrompts`/`localStorage`.
- **Секция «Быстрый импорт»** (Collapsible) — загрузка Excel, превью таблицы, кнопка создания.
- **Секция «Настройки доступа»** (Collapsible) — бесплатность для организаций, цены по умолчанию.

**2. Убрать вкладку «Настройки»** из `AdminMarketplaceManager.tsx`:
- Удалить `TabsTrigger value="settings"` и `TabsContent value="settings"`
- Изменить сетку табов с `grid-cols-5` на `grid-cols-4`
- Убрать импорт `MarketplaceSettings`

**3. Перенести логику из `MarketplaceSettings.tsx`** в `BulkPipelineWidget.tsx`:
- Промты ИИ (с дефолтами, сброс, сохранение)
- Excel-импорт (парсинг XLSX, превью, массовое создание)
- Настройки доступа (переключатель бесплатности, цены)

Компонент `MarketplaceSettings.tsx` можно оставить для экспорта типов и дефолтных промтов, либо переместить их в виджет.
