
# Кнопка "Войти как ученик" в таблице учеников

## Что будет сделано

В таблице учеников (таб "Ученики" в детальном просмотре организации в админ-панели) будет добавлена колонка **"Действия"** с кнопкой для входа в кабинет конкретного ученика.

## Как это работает

При нажатии на кнопку (иконка глаза) рядом с учеником:
1. В `localStorage` сохраняется `previewStudentDashboard: true`
2. Сохраняется `previewStudentUserId` с ID выбранного ученика
3. Открывается `/student` в новой вкладке

Администратор видит кабинет от лица конкретного студента.

## Технические детали

### Файл: `src/components/admin/OrganizationDetailsView.tsx`

1. Добавить колонку "Действия" в заголовок таблицы (после "Статус", строка 831)
2. В каждой строке (строка 901) добавить ячейку с кнопкой:

```typescript
<TableCell>
  <Button
    variant="ghost"
    size="sm"
    onClick={() => {
      localStorage.setItem('previewStudentDashboard', 'true');
      localStorage.setItem('previewStudentUserId', student.user_id);
      window.open('/student', '_blank');
    }}
    title="Войти в кабинет ученика"
  >
    <Eye className="w-4 h-4" />
  </Button>
</TableCell>
```

3. Обновить `colSpan` в пустом состоянии с 5 на 6 (строка 906)
