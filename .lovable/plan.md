
# Исправление приветственного курса: контент, обложка, озвучка

## Проблема
Контент уроков записан с неправильными типами блоков (`"heading"`, `"text"` вместо `"heading1"`, `"paragraph"`) и без обязательного поля `id` — редактор не может их отобразить, поэтому уроки выглядят пустыми.

## Что будет сделано

### 1. Переписать edge function `seed-welcome-course`
Контент каждого урока будет записан в правильном формате блоков:
- Правильные типы: `heading1`, `heading2`, `paragraph`, `callout-info`, `callout-tip`, `callout-warning`, `highlight`, `accordion`
- Каждый блок с уникальным `id`
- Красивое оформление: аккордеоны, инфо-блоки, подсказки, выделения
- Использование HTML-форматирования внутри блоков (жирный, списки)

### 2. Генерация обложки курса
После создания курса — вызов Lovable AI (Gemini image model) для генерации обложки. Изображение сохраняется в storage bucket `course-files`, URL записывается в `cover_image_url`.

### 3. Генерация аудио-лекции
Для первого урока ("Знакомство с платформой") — вызов SaluteSpeech через существующую edge function для озвучки вводного текста. Аудио-блок добавляется в контент урока.

### 4. Обновление существующих курсов
После деплоя — вызов функции с `seedAll: true` и параметром `forceUpdate: true`, чтобы обновить контент уже созданных приветственных курсов (перезаписать пустые уроки правильным контентом).

## Пример блока контента (правильный формат)
```json
[
  { "id": "b1", "type": "heading1", "content": "Добро пожаловать в СИНТАГМА! 🎓" },
  { "id": "b2", "type": "paragraph", "content": "СИНТАГМА — современная платформа..." },
  { "id": "b3", "type": "callout-info", "content": "<b>Что умеет платформа:</b><br>..." },
  { "id": "b4", "type": "accordion", "content": "Подробнее о возможностях...", "accordionTitle": "Все функции", "accordionOpen": false },
  { "id": "b5", "type": "highlight", "content": "Приступим! 🚀" }
]
```
