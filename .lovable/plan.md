## Цель
Довести админский раздел «Продажи» до единого рабочего центра: создание менеджера с авто‑логином/паролем + пригласительной ссылкой, постановка задач (админ и сам менеджер), сводный отчёт.

## 1. Создание менеджера — авто‑логин и пароль
Файл: `src/components/admin/sales/SalesManagersList.tsx` + edge `create-sales-manager`.
- В диалоге «Новый менеджер»: поля Email/пароль делаем необязательными, добавляем чекбокс **«Сгенерировать автоматически»** (по умолчанию включён) и кнопку 🎲 рядом с каждым полем.
- Логин по шаблону `имя.фамилия@sales.sintagma.local` (транслит из ФИО, при коллизии — суффикс `-2`), пароль 12 символов (буквы+цифры), генерация на клиенте через `crypto.getRandomValues`.
- После создания показываем блок «Данные для передачи» с копированием одной кнопкой (логин + пароль + прямая ссылка на /login) и share‑кнопками Telegram / WhatsApp / Email / «Скопировать» (как в `InviteSalesManagerDialog`).
- Оставляем существующую кнопку «Пригласить по ссылке» без изменений.

## 2. Единый экран «Продажи» в админке
Файл: `src/components/admin/SalesTab.tsx` (или текущий контейнер вкладки).
Табы сверху: **Обзор · Менеджеры · Лиды · Задачи · КП · Отчёт**.
- **Обзор**: KPI‑плитки (лидов всего / в работе / КП отправлено / договоров / выручка за месяц) + топ‑5 менеджеров + список просроченных задач.
- **Менеджеры**: текущий `SalesManagersList` + клик «Войти как» (уже есть) + новая кнопка «Поставить задачу» на карточке.
- Остальные табы — уже существующие компоненты (`LeadsManager`, `SalesTasks`, proposals list).

## 3. Инструмент постановки задач
Новый диалог `AssignTaskDialog.tsx` (переиспользуется в админке и в /sales).
Поля: тип (звонок/письмо/встреча/КП/другое), заголовок, описание, срок (DatePicker+время), приоритет (низкий/средний/высокий), исполнитель (Select менеджеров — админ выбирает; у менеджера скрыт, ставится на себя), привязка к лиду и/или компании (поиск по `sales_leads` / `sales_companies_db`).
Пишем в существующую `sales_tasks`. Если нужных полей нет — миграция добавит `priority text`, `due_at timestamptz`, `type text`, `assigned_by uuid`.
Точки вызова:
- Админ: кнопка «Поставить задачу» в `SalesManagersList` (для конкретного менеджера) и в `LeadsManager` (для лида).
- Менеджер: кнопка «Новая задача» в шапке `/sales` → в `SalesTasks`.
Realtime‑подписка на `sales_tasks` уже используется — список обновится сам.

## 4. Отчёт по продажам и задачам
Новый компонент `SalesReport.tsx` (вкладка «Отчёт»).
- Фильтр периода (7/30/90 дней, произвольный).
- Таблица по менеджерам: лиды, звонки (из `call_logs`), КП отправлено/принято (из `commercial_proposals`), договоры (из `sales_contracts`), сумма выручки, задачи выполнено/просрочено.
- Кнопка «Экспорт в Excel» (используем существующий `xlsxHelper`).

## Технические детали
- Миграции: добавить недостающие колонки в `sales_tasks` (проверить перед применением); RLS: админ — всё, менеджер — свои задачи (`assigned_manager_id = <его manager_id>`) + задачи которые он поставил (`assigned_by = auth.uid()`).
- Edge `create-sales-manager`: принимать `full_name` + опциональные `email`/`password`; если не заданы — генерировать на сервере, возвращать в ответе (нужно один раз для показа админу).
- Никаких изменений в кабинете менеджера, кроме кнопки «Новая задача» и открытия того же `AssignTaskDialog` в режиме self‑assign.
