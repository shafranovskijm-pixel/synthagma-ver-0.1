
## Оптимизация навигации админ-панели

### Текущие проблемы
1. **«Заявки на курсы»** — дублирует вкладку «Заявки» внутри Маркетплейса
2. **«Подписчики»** — дублирует вкладку «Подписчики» внутри Блога (BlogManager уже загружает и отображает подписчиков)
3. Слишком много пунктов в сайдбаре (11 штук) — можно сократить до 8

### План изменений

**1. Удалить «Заявки на курсы» из сайдбара**
- Убрать пункт `orders` из `AdminSidebar.tsx`
- Убрать тип `orders` из `AdminTabType`
- Убрать рендер `ServiceOrdersManager` и импорт из `AdminDashboard.tsx`
- Заявки уже доступны через Маркетплейс -> вкладка «Заявки»

**2. Удалить «Подписчики» из сайдбара**
- Убрать пункт `subscribers` из `AdminSidebar.tsx`
- Убрать тип `subscribers` из `AdminTabType`
- Убрать рендер `SubscribersManager` и импорт из `AdminDashboard.tsx`
- Подписчики уже доступны через Блог -> вкладка «Подписчики»

**3. Объединить «Отзывы» с «Блог» (опционально, рекомендация)**
- Добавить вкладку «Отзывы» внутрь BlogManager (третья вкладка)
- Убрать отдельный пункт «Отзывы» из сайдбара
- Логика: блог + подписчики + отзывы = единый раздел «Контент»

### Итоговая структура сайдбара (8 пунктов вместо 11)

```text
 Организации
 Тарифы
 Пользователи
 Контент (бывш. Блог) — статьи, подписчики, отзывы
 Маркетплейс — каталог, создание, заявки
 Аналитика
 Dev Tools
 Настройки
```

### Технические детали

**Файлы для изменения:**

1. `src/components/admin/AdminSidebar.tsx`
   - Удалить `orders`, `subscribers`, `testimonials`, `blog` из `AdminTabType`
   - Добавить `content` в `AdminTabType`
   - Заменить 4 кнопки (Блог, Подписчики, Отзывы, Заявки) на 1 кнопку «Контент»
   - Иконка: `FileText`

2. `src/pages/AdminDashboard.tsx`
   - Удалить импорты `ServiceOrdersManager`, `SubscribersManager`, `TestimonialsManager`
   - Заменить рендер `blog`, `subscribers`, `testimonials` на единый `content` -> `BlogManager`
   - Удалить рендер `orders`
   - Обновить `getTabTitle`

3. `src/components/admin/BlogManager.tsx`
   - Добавить третью вкладку «Отзывы» с содержимым из `TestimonialsManager`
   - Импортировать логику отзывов

Компонент `ServiceOrdersManager` и `SubscribersManager` останутся в проекте на случай повторного использования, но не будут рендериться из сайдбара.
