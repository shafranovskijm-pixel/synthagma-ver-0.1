

# ИИ-генерация в редакторе страницы курса

## Что будет сделано

Добавить кнопку «Сгенерировать с ИИ» (Sparkles) в тулбар редактора лендинга и в тулбар каждой секции. По нажатию — диалог с выбором, что генерировать для данной секции.

### 1. Кнопка ИИ в SectionToolbar

Файл: `src/components/course-landing/SectionToolbar.tsx`

- Добавить опциональный проп `onAIGenerate?: () => void`
- Если передан — рендерить кнопку с иконкой Sparkles рядом с кнопками перемещения/скрытия
- Кнопка появится на каждой секции

### 2. Диалог генерации для лендинга

Создать компонент `src/components/course-landing/LandingAIGenerateDialog.tsx` — специализированный диалог для лендинга (не путать с AIGenerateDialog из конструктора курсов). Варианты генерации:

- **Обложка** (фоновое изображение шапки) — генерация через GigaChat/Lovable AI image model
- **Тексты секции** — генерация заголовков, описаний, пунктов для текущей секции на основе названия курса

Диалог принимает `sectionId` и в зависимости от секции предлагает релевантные опции (для hero — обложка + подзаголовок, для audience — тексты пунктов, для faq — вопросы-ответы и т.д.).

### 3. Интеграция в CourseLandingEditor

Файл: `src/pages/CourseLandingEditor.tsx`

- Добавить state для открытия диалога и текущей секции
- Передать `onAIGenerate` в каждый `SectionToolbar`
- При генерации текстов — вызвать edge-функцию `gigachat` с action `generate_content`, передав контекст секции, и заполнить поля лендинга результатом
- При генерации обложки — вызвать генерацию изображения и загрузить результат в storage

### 4. Кнопка ИИ в верхнем тулбаре

В общий тулбар редактора (sticky header) добавить кнопку «Сгенерировать с ИИ» для генерации всех текстов лендинга целиком (заполнить все секции разом на основе названия и описания курса).

## Технические детали

- Генерация текстов: через существующую edge-функцию `gigachat` (action: `generate_content`), промпт будет формироваться на клиенте под конкретную секцию
- Генерация обложки: через edge-функцию `gigachat` (генерация изображений через GigaChat, как уже реализовано в проекте)
- Результат обложки загружается в `course-files/{courseId}/landing-hero.{ext}` через Supabase Storage
- Результат текстов парсится и вставляется в соответствующие поля `landing` state
