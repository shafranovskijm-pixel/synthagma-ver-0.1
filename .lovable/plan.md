

# Вертикальное меню продаж + Демо-регистрация организаций + Трансляция

## Что будет сделано

### 1. Вертикальное меню в разделе «Продажи» (admin)
Заменить горизонтальные табы в `SalesManager.tsx` на вертикальный сайдбар слева (как в других разделах). 7 пунктов: КП, Услуги, Менеджеры, База компаний, Договоры, Контроль, Сравнение + новый пункт «Демо-ссылки».

### 2. Демо-регистрация организации
Новая вкладка «Демо-ссылки» в продажах. Админ создаёт ссылку → получает URL вида `/demo/:token`. Потенциальный клиент переходит, вводит имя и название организации → автоматически создаётся временная организация + профиль → клиент попадает в кабинет организации с демо-данными и встроенной трансляцией.

**БД:** Новая таблица `sales_demo_links` (id, token, created_by, label, kinescope_live_id, is_active, created_at, expires_at). Новая таблица `sales_demo_sessions` (id, demo_link_id, org_id, user_id, created_at) для отслеживания.

### 3. Трансляция Kinescope Live в демо-кабинете
При создании демо-ссылки админ указывает Kinescope Live ID (или создаёт трансляцию через существующий API). В демо-кабинете организации вверху отображается embed-плеер с трансляцией. Админ ведёт стрим через OBS/Kinescope.

### 4. Переключение на экран админа
Кнопка «Показать админку» в интерфейсе трансляции — по сути, screen share через OBS. Дополнительно можно добавить в демо-кабинет пометку «Сейчас ведущий показывает свой экран» когда админ переключает режим.

## Как работает поток

```text
Админ (Продажи → Демо-ссылки)
  │
  ├─ Создаёт демо-ссылку (название, Kinescope Live ID)
  ├─ Копирует URL: sintagma.com.ru/demo/abc123
  │
  └─ Запускает стрим в OBS → Kinescope Live
  
Клиент
  │
  ├─ Переходит по /demo/abc123
  ├─ Вводит имя + название организации
  ├─ Edge function создаёт org + user
  └─ Попадает в кабинет организации
      ┌─────────────────────────┐
      │ ▶ Kinescope Live Player │  ← трансляция админа
      ├─────────────────────────┤
      │ Кабинет организации     │  ← реальный интерфейс
      │ (курсы, настройки...)   │
      └─────────────────────────┘
```

Переключение на экран админа — через OBS (screen share). В интерфейсе трансляции это просто смена сцены у стримера.
