## Ответ по дефолтному номеру
Исходящие звонки идут с купленного номера Novofon **+7 (967) 555-13-83** (`NOVOFON_PUBLIC_NUMBER = 79675551383`, статус active, employee_id 668253 «Администратор»). Именно он подставляется в `virtual_phone_number` при `handleQuickCall` → `novofon-call-start`.

## Что делаем с доп. телефонами
Сейчас в карточке компании (`CompanyDrawer`) звонить можно только по `lead.phone`. Доп. номера, которые парсер положил в `lead.notes` («Доп.телефоны: +7 (383) 363-63-63, +7 (953) 877-84-97, …»), просто выводятся текстом и кликнуть на них нельзя. Сделаем автоматическое распознавание и кнопки-чипы для каждого номера.

### 1. Утилита `src/utils/phoneParser.ts` (новая)
- `extractPhones(text: string): string[]` — regex по всем российским форматам (`+7…`, `8…`, `7…`, скобки, дефисы, пробелы; допускает `доб. 123` и обрезает добавочные).
- Нормализация в `+7XXXXXXXXXX` (E.164) и `formatRuPhone(e164)` для отображения `+7 (XXX) XXX-XX-XX`.
- Удаление дублей, исключение основного `lead.phone` из результата.

### 2. `src/components/admin/sales/CompanyDrawer.tsx`
- Собрать `extraPhones` через `useMemo` из `lead.notes` (+ `lead.raw_data`, если есть строковые поля) минус `lead.phone`.
- `handleQuickCall(number?: string)` — принимает опциональный номер; по умолчанию `lead.phone`. Метка активности активности логируется с реально набранным номером.
- Под основной кнопкой «Позвонить» — горизонтальный ряд чипов `Button variant="outline" size="sm"` с иконкой `Phone`, текстом `formatRuPhone(n)`. Клик → `handleQuickCall(n)` + `setActivePhone(n)` для караоке-подсветки.
- Если доп. номеров нет — блок не рендерится.
- В карточке контактов «Телефон» — подсветить основной как «основной», доп. номера показать списком-кнопками (те же обработчики).

### 3. `src/components/admin/sales/LeadsManager.tsx` (inline «Позвонить»)
- Если у лида есть доп. телефоны — рядом с основной кнопкой показать иконку `ChevronDown`, по клику `DropdownMenu` со списком номеров-кнопок, каждая вызывает существующий `handleCall(lead, phone)` (сигнатуру расширим тем же способом).

### 4. Прочее
- Ничего в БД не меняем — доп. номера продолжают жить в `notes`.
- `KaraokeScript` и запись активности переиспользуются как есть.
- Тесты вручную: карточка ООО «ИТ-1988» (скриншот) — 8 доп. номеров превратятся в 8 чипов, клик на любом инициирует звонок с +7 967 555‑13‑83.

## Технические заметки
- Regex: `/(?:\+7|7|8)[\s\-()]*\d{3}[\s\-()]*\d{3}[\s\-()]*\d{2}[\s\-()]*\d{2}/g`, затем `replace(/\D/g,'')` и приведение первой `8` → `7`.
- Если в notes встречается email (`cash@it1988.ru`) — regex его не захватит; фильтруем по длине 11 цифр.
- Чипы обрезаются в `flex-wrap gap-1.5`; на мобильном стек в колонку.
