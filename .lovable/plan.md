
# Исправление: заявка на покупку курса не отправляется в чат и уведомления

## Проблема

В `CourseLanding.tsx` (строки 192-195) при нажатии «Купить курс» для платного курса код просто показывает toast-уведомление и ничего не делает:

```typescript
if (finalPrice > 0) {
  toast.info("Заявка отправлена", { description: "Организация свяжется с вами для оплаты" });
  return; // ← Ничего не отправляется!
}
```

Организация не получает ни сообщения в чат, ни уведомления в колокольчик.

## Решение

**Файл**: `src/pages/CourseLanding.tsx` — заменить пустой блок (строки 192-195) на полноценную отправку:

1. Получить профиль ученика (имя, email)
2. Вставить сообщение в `chat_messages` с деталями заявки (название курса, цена, имя ученика)
3. Вставить запись в `org_notifications` (тип `order`) для колокольчика организации
4. Показать toast «Заявка отправлена»

Логика аналогична `AvailablePaidCourses.tsx`, где это уже работает корректно (строки 78-105).

Также нужно проверить обработчик `handleEnroll` при вызове из CTA-формы (нижняя форма на лендинге) — та же проблема: формой собираются name/email/phone, но при `finalPrice > 0` они игнорируются. Нужно использовать `formData` для отправки заявки, если пользователь заполнил форму.
