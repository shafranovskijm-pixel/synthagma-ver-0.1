

## Улучшение интерфейса «Автозаполнение документов»

### Текущее состояние

Сейчас раздел «Автозаполнение документов» в настройках содержит только:
- Реквизиты организации (с автозаполнением по ИНН)
- Конструктор шаблона договора
- Генератор согласия на обработку ПД

Протоколы, удостоверения и дипломы генерируются по захардкоженным HTML-шаблонам без возможности настройки. Нет единого центра управления шаблонами документов.

### Что будет сделано

#### 1. Переработка раздела «Автозаполнение документов» в «Центр документов»

Раздел в настройках будет перестроен с использованием вкладок:

```text
[Реквизиты] [Договор] [Протокол АК] [Удостоверение] [Диплом] [Согласие ПД] [Печать/Штамп]
```

Каждая вкладка -- отдельный конструктор шаблона соответствующего документа.

#### 2. Конструктор шаблона протокола АК

Новый компонент `ProtocolTemplateEditor.tsx`:
- Редактируемый текстовый шаблон протокола (аналогично `ContractTemplateEditor`)
- Переменные: `{{org_name}}`, `{{director_name}}`, `{{director_position}}`, `{{protocol_number}}`, `{{protocol_date}}`, `{{course_name}}`, `{{course_duration}}`, `{{students_table}}`, `{{commission_members}}`
- Настройка состава комиссии (председатель + члены) -- сохраняется в `branding` JSON организации
- Шаблон сохраняется в поле `branding.protocolTemplate` организации
- AI-обработка шаблона (загрузка DOCX -> автоматическая расстановка переменных)

#### 3. Конструктор шаблона удостоверения/диплома

Новый компонент `CertificateTemplateEditor.tsx`:
- Настройки для удостоверений о повышении квалификации:
  - Серия и начальный номер документа
  - Город выдачи
  - Регистрационный номер (формат)
  - Текст программы (шаблон)
- Настройки для дипломов о профессиональной переподготовке:
  - Аналогичные поля
  - Дополнительно: присвоенная квалификация
- Сохранение в `branding.certificateSettings` / `branding.diplomaSettings`

#### 4. Печать документов из Синтагмы

Обновить генераторы (`generateAttestationProtocol.ts`, `generateEnrollmentOrder.ts`, журнал образовательных документов), чтобы:
- При генерации подтягивать сохраненный шаблон из настроек организации
- Подставлять реальные данные вместо переменных
- Добавлять печать и подпись (если загружены) в документ
- Генерировать готовый к печати HTML с правильными `@media print` стилями

#### 5. Вынос загрузки печати/подписи в отдельную вкладку

Переместить `StampSignatureUploader` из разных мест в единую вкладку «Печать и подпись» внутри центра документов, чтобы эти изображения использовались во всех генерируемых документах.

---

### Технические детали

**Новые файлы:**
1. `src/components/organization/ProtocolTemplateEditor.tsx` -- конструктор шаблона протокола с переменными и AI-обработкой
2. `src/components/organization/CertificateTemplateEditor.tsx` -- настройки удостоверений и дипломов (серии, номера, город, формат рег. номера)

**Файлы для изменения:**
1. `src/components/organization/tabs/SettingsTab.tsx` -- переделать секцию «Автозаполнение документов»: добавить табы (Реквизиты / Договор / Протокол / Удостоверение / Диплом / Согласие / Печать), вставить новые компоненты
2. `src/utils/generateAttestationProtocol.ts` -- загружать шаблон из `branding.protocolTemplate`, подставлять состав комиссии из настроек, добавлять печать/подпись
3. `src/components/organization/EducationDocumentsJournal.tsx` -- при создании записи подтягивать серию/номер/город из настроек организации
4. `src/hooks/useEducationDocumentsJournal.ts` -- загружать настройки шаблонов из branding организации

**Структура данных (в существующем JSON-поле `branding`):**
```text
branding: {
  ...existing fields,
  protocolTemplate: "текст шаблона протокола с переменными",
  commissionMembers: [
    { name: "ФИО", position: "Должность", role: "chairman" | "member" }
  ],
  certificateSettings: {
    series: "АА", startNumber: 1, city: "г. Владивосток",
    regNumberFormat: "{{year}}-{{number}}"
  },
  diplomaSettings: {
    series: "ДПП", startNumber: 1, city: "г. Владивосток",
    regNumberFormat: "{{year}}-{{number}}"
  }
}
```

Миграции БД не требуются -- всё хранится в существующем JSONB-поле `branding`.
