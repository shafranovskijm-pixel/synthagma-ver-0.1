## Вариант А — доводим PWA до продакшн-качества

Цель: чтобы пользователь на синтагма.рф (Android/iOS/десктоп) мог одним действием поставить СИНТАГМУ на главный экран и получить полноэкранное «приложение». Без сторов, без нативной сборки. NGINX-прокси и домен синтагма.рф трогать не нужно — PWA полностью статичен и раздаётся тем же билдом.

### Что не так сейчас
1. В `vite.config.ts` manifest ссылается на `/pwa-192x192.png` и `/pwa-512x512.png`, но этих файлов в `public/` физически нет. Итог: браузер загружает manifest, но иконки битые → Chrome отказывает в установке, iOS ставит серый квадрат.
2. В `index.html` `apple-touch-icon` тоже ссылается на несуществующий `/pwa-192x192.png`.
3. На лендинге (`MobileApp.tsx`) висит кнопка **«Скачать APK»** — заглушка с toast «в разработке». Даёт ложное обещание.
4. `Install.tsx` не проверяет, что пользователь на «правильном» домене — на синтагма.рф всё ок, но при заходе через `sintagma.com.ru` install prompt по PWA-правилам считается другим origin. Ничего не ломает, просто пользователь установит две копии, если ходит с разных доменов. Достаточно короткого пояснения на странице.

### Что делаем

1. **Генерируем PWA-иконки под бренд СИНТАГМА** (teal/cyan, буква «С» или логотип-«ромб»):
   - `public/pwa-192x192.png` — 192×192, непрозрачный фон #0F1729 или белый.
   - `public/pwa-512x512.png` — 512×512, тот же дизайн, используется и как `any`, и как `maskable` (в `vite.config.ts` уже есть обе записи, поэтому одна картинка с safe-zone ~10% отступа по краям подойдёт для обеих ролей).
   - `public/apple-touch-icon.png` — 180×180 (iOS обрезает углы сама, фон обязательно непрозрачный).
   - Используем `imagegen--generate_image` с `model: "premium"`, чтобы буква/логотип были чёткими.

2. **Обновляем `index.html`:**
   - Меняем `apple-touch-icon` на `/apple-touch-icon.png` (180×180) вместо `/pwa-192x192.png`.
   - Добавляем `apple-touch-icon` с `sizes="180x180"` — этого достаточно для всех iOS.
   - Больше ничего в head не трогаем.

3. **`vite.config.ts` — ничего менять не нужно**, manifest уже корректный. После билда `vite-plugin-pwa` сам положит `/manifest.webmanifest`, `sw.js`, `registerSW.js` в `dist/`.

4. **Лендинг `src/components/landing/MobileApp.tsx`:**
   - Убираем кнопку **«Скачать APK»** целиком (это Вариант B/C, сейчас не делаем).
   - Оставляем одну кнопку «Установить приложение» → `/install`.
   - Меняем подзаголовок: вместо «Обучение в кармане» уточняем «Устанавливается прямо из браузера, работает на iOS и Android — без App Store».

5. **`src/pages/Install.tsx`:**
   - Добавляем короткий блок «Работает на синтагма.рф и sintagma.com.ru» — чтобы пользователь понимал, откуда ставить (совет: ставить с того домена, которым пользуется каждый день, иначе на телефоне будут две иконки — это ограничение любых PWA, не наше).
   - Оставляем существующую логику `beforeinstallprompt` — она работает через NGINX без изменений (это чисто клиентский API браузера).

6. **Проверка (после мержа):**
   - `curl -I https://синтагма.рф/manifest.webmanifest` → должен вернуть 200 и `content-type: application/manifest+json`. Если NGINX отдаёт как `text/plain`, добавим в NGINX-конфиг одну строку `types { application/manifest+json webmanifest; }` — но обычно `vite-plugin-pwa` расширение делает всё сам, и NGINX на Timeweb этот тип уже знает.
   - Chrome DevTools → Application → Manifest: все поля заполнены, иконки без ошибок, «Installable ✓».
   - iPhone Safari → Поделиться → На экран «Домой»: иконка цветная, приложение открывается в fullscreen.

### Чего НЕ делаем в этом плане
- Не трогаем Capacitor и `capacitor.config.ts` — они остаются как заготовка на будущее (Вариант B/C).
- Не меняем service worker и cache-стратегии в `vite.config.ts` — они уже проверены под наши антивирус/VPN сценарии.
- Не трогаем NGINX-конфиг (`src/utils/nginxProxyConfig.ts`) — PWA-файлы раздаются напрямую хостингом Lovable/Timeweb, через прокси не идут.
- Не создаём фейковый APK.

### Файлы, которые изменятся
- `public/pwa-192x192.png` — новый
- `public/pwa-512x512.png` — новый
- `public/apple-touch-icon.png` — новый
- `index.html` — 1 строка (apple-touch-icon)
- `src/components/landing/MobileApp.tsx` — удаление кнопки APK
- `src/pages/Install.tsx` — короткая подсказка про домены

Работы примерно на 20–30 минут. После деплоя PWA сразу заработает на синтагма.рф.
