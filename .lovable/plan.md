
Проблема теперь понятна точнее.

## Что на самом деле сломано

Сейчас ссылки не работают не потому, что “цвет не применился”, а потому что во многих местах ссылка вообще не становится тегом `<a>`.

Есть две разные проблемы:

1. `RichTextEditor` умеет linkify, но только для блоков, которые реально используют `RichTextEditor`
2. В `BlockEditor.tsx` часть блоков до сих пор редактируется через обычные `Input` / `Textarea`:
   - `heading1`
   - `heading2`
   - `bulletList`
   - `numberedList`

Для них URL сохраняется как обычный текст, поэтому:
- в редакторе он не подкрашивается
- клик не работает
- в превью это тоже просто текст, потому что рендерер не превращает plain URL в `<a>`

По скриншоту видно именно это: URL хранится plain text, не как anchor.

## Что нужно исправить

### 1. Привести все текстовые блоки к единой логике ссылок
В `BlockEditor.tsx` убрать разнобой:
- либо перевести `heading1` / `heading2` / списки на `RichTextEditor`
- либо вынести общий `linkify + sanitize + normalize anchors` helper и применять его и в редакторе, и в рендерере

Предпочтительный вариант:
- заголовки тоже сделать через `RichTextEditor`
- для списков сохранить удобный ввод по строкам, но при сохранении каждую строку пропускать через linkify

### 2. Добавить linkify не только в редактор, но и в рендер
В `BlockEditor.tsx` для `RenderBlock` нужно рендерить не просто `sanitizeHtml(block.content)`, а:
- сначала преобразовать plain URL в `<a>`
- затем санитизировать
- затем рендерить

Это закроет кейсы, где в базе уже лежит старый plain-text URL.

### 3. Нормализовать ссылки в одном месте
Сделать единый helper:
- `linkifyHtml`
- `sanitizeAndNormalizeLinks`

Он должен:
- превращать `http://`, `https://`, `www.` в `<a>`
- добавлять `target="_blank"` и `rel="noopener noreferrer"`
- не оборачивать уже существующие `<a>`
- безопасно санитизировать HTML

### 4. Исправить кликабельность в редакторе
В `RichTextEditor.tsx` оставить обработчик клика, но усилить логику:
- искать anchor через `closest('a')`
- открывать ссылку только если нет активного выделения
- при необходимости добавить `onMouseDown`/`onPointerDown` защиту, если `contenteditable` съедает обычный click

### 5. Усилить видимость ссылок
Если anchor уже есть, он должен быть явно виден:
- `text-primary`
- `underline`
- `underline-offset-2`
- `cursor-pointer`
- `break-all`

Если нужно, поднять специфичность классов, чтобы стили prose их не перебивали.

## Ожидаемый результат
После правки:
- URL, вставленный в параграф, callout, quote, accordion, highlight — становится ссылкой
- URL в `heading1`, `heading2` и списках тоже становится ссылкой
- ссылка видна визуально как ссылка
- в редакторе по ней можно кликнуть
- в предпросмотре по ней тоже можно кликнуть
- старые plain-text URL в уже созданных уроках тоже начинают отображаться как ссылки

## Техническая причина текущего поведения
Сейчас логика ссылок реализована частично. Она есть в `RichTextEditor`, но не покрывает все типы блоков, а рендер превью ожидает уже готовый HTML. Из-за этого система работает только для части сценариев и выглядит как будто “не работает вообще”.
