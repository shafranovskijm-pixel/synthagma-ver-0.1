

# Контекстное меню для вставки переменных (правый клик)

## Что будет сделано

При правом клике на текст в редакторе шаблона появится кастомное контекстное меню с категориями переменных. Пользователь выбирает категорию, затем конкретную переменную — она вставляется в позицию курсора.

## Реализация

### 1. Новый компонент `VariableContextMenu.tsx`
Кастомное контекстное меню (абсолютное позиционирование по координатам клика):
- Первый уровень: категории (Договор, Организация, Заказчик и т.д.) с цветными иконками
- При наведении/клике на категорию раскрывается подменю с переменными
- Каждая переменная показывает читаемое название (например «Номер договора» вместо `contract_number`)
- Клик по переменной вставляет `{{variable}}` в позицию курсора и закрывает меню
- Меню закрывается при клике вне него или по Escape

### 2. Интеграция в `HighlightedTemplateEditor.tsx`
- Перехват `onContextMenu` на textarea — предотвращаем стандартное меню браузера, открываем кастомное
- Позиция меню = координаты клика мыши
- При вставке переменной используется уже существующая функция `insertVariable`

### 3. Подсказка для пользователя
- В пустом редакторе placeholder будет содержать подсказку: «Правый клик для вставки переменной»
- Маленькая подсказка под редактором рядом со статистикой

## Структура меню

```text
┌─────────────────────────┐
│ 📋 Вставить переменную  │
│─────────────────────────│
│ 🔵 Договор           ► │ → contract_number, contract_date...
│ 🟢 Организация       ► │ → org_name, org_inn...
│ 🟡 Заказчик           ► │ → company_name, company_inn...
│ 🟣 Курс              ► │ → course_title, course_hours...
│ 🔷 Физ. лицо         ► │ → individual_name...
│ 🔴 Оплата            ► │ → price, total_price...
└─────────────────────────┘
```
