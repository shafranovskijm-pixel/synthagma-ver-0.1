

# Клиенты в контрагентах + пульсирующая справка

## Что делаем

1. **Клиенты (компании) как контрагенты** — компании уже загружаются в `CounterpartiesSection`, но отображаются с типом `company`. Нужно убедиться, что они видны как чипы с иконкой `Building2` и подписью «Клиент» рядом с «Синтагма». Для них работают те же вкладки: Договоры, Счета, Закрывающие.

2. **Справка 273-ФЗ** — убрать из TabsTrigger. Вместо этого разместить иконку-кнопку (восклицательный знак или лампочку) с пульсирующей анимацией рядом с заголовком контрагентов. По клику открывать `ContractLegalFaq` в диалоге или аккордеоне.

## Изменения

### `CounterpartiesSection.tsx`

**Справка → пульсирующая иконка:**
- Убрать `TabsTrigger value="faq"` и `TabsContent value="faq"` из табов
- Добавить рядом с чипами контрагентов кнопку-иконку `Lightbulb` с CSS-анимацией `animate-pulse` и кольцом `ring`
- По клику — открывать `ContractLegalFaq` в `Dialog` (или показывать/скрывать блок под чипами)
- Убрать `"faq"` из `CounterpartySubTab` типа

**Клиенты — визуальное разделение:**
- Группировать чипы: сначала «Синтагма» (платформа), затем разделитель `|`, затем компании-клиенты с подписью «Клиенты», затем плательщики
- Компании уже загружаются — убедиться, что для текущей организации они появляются

### `useDocumentsTab.ts`

- Убрать `"faq"` из типа `CounterpartySubTab` → станет `"contracts" | "invoices" | "closing"`

### Технические детали

- Пульсирующая анимация: `animate-pulse` + `ring-2 ring-primary/30` на кнопке
- Диалог справки: `Dialog` с `ContractLegalFaq` внутри
- Никаких новых таблиц или миграций не требуется
