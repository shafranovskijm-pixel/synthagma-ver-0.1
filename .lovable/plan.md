

## Улучшение диалога создания ученика

### Что будет сделано

1. **Выбор нескольких курсов** -- вместо одного Select с выбором одного курса, добавить список курсов с чекбоксами (multi-select). При создании ученик будет зачислен на все выбранные курсы.

2. **Установка логина/пароля при создании** -- добавить опциональные поля "Логин" и "Пароль" прямо в диалог создания. Если не заполнены -- генерируются автоматически (как сейчас). Если заполнены -- используются указанные значения. Рядом с каждым полем будет кнопка "Сгенерировать" для быстрого заполнения.

### Технические детали

**1. Изменения в `src/components/organization/dialogs/OrgDialogs.tsx` (AddStudentDialog)**

- Заменить `courseId: string` на `courseIds: string[]` (массив)
- Заменить `Select` курса на список с `Checkbox` для каждого опубликованного курса + поиск
- Добавить два новых поля: "Логин (необязательно)" и "Пароль (необязательно)"
- Кнопки генерации рядом с полями логина и пароля (иконка Dice/RefreshCw)
- Обновить `onSubmit` для передачи массива курсов и credentials

**2. Изменения в `src/components/organization/dialogs/DialogsContainer.tsx`**

- Обновить вызов `onSubmit` для передачи новых параметров (courseIds, login, password)

**3. Изменения в `src/hooks/useStudentManagement.ts` (createStudent)**

- Принимать `courseIds: string[]` вместо `courseId: string`
- Принимать `login?: string` и `password?: string`
- Первый вызов `register-student` -- с первым курсом (или без курса)
- Далее цикл `enrollments.insert` для остальных курсов
- Передавать кастомный login/password в edge-функцию если указаны

**4. Изменения в `supabase/functions/register-student/index.ts`**

- Принимать опциональные поля `custom_login` и `custom_password`
- Если `custom_login` указан -- использовать его вместо `student_XXXXX`
- Проверка уникальности кастомного логина перед созданием
- Если `custom_password` указан -- использовать его вместо сгенерированного
