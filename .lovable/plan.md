
## Кастомизация цвета и анимация в чате поддержки + проверка кнопки

### Проверка кнопки «Свернуть»
В коде кнопки `onClose` корректные, обработчики на месте, `pointer-events-none` уже добавлены к starfield. Кнопка **должна работать**. После реализации проверим вживую через browser tools и сессионный реплей. Если проблема всё-таки есть — она в z-index канваса на конкретном desktop-вьюпорте; добавим `z-20` к самим кнопкам header'а для гарантии.

### Что добавляем

#### 1. Палитра тем чата (выбор цвета)
- Новый компонент `ChatThemePicker` — маленькая иконка-палитра (Palette из lucide) в шапке `HomeView` рядом с кнопкой свернуть.
- При клике — выезжает popover с 5 темами:
  - **Teal** (174 72% 46%) — текущая, по умолчанию
  - **Royal Purple** (270 60% 55%)
  - **Sunset Orange** (24 90% 55%)
  - **Deep Ocean** (210 80% 45%)
  - **Crimson** (350 75% 50%)
- Выбор сохраняется в `localStorage` (`sintagma_chat_theme`).
- Применяется через CSS-переменную `--chat-accent` на корневом контейнере чата — все градиенты header'а, кнопка отправки и FAB читают её.

#### 2. Анимации на выбор
В том же popover'е — переключатель «Анимация шапки»:
- **Звёзды** (по умолчанию) — текущий `StarfieldCanvas`
- **Аврора** — плавные мерцающие градиентные пятна (CSS `@keyframes` blur + translate)
- **Волны** — медленные SVG-волны снизу шапки
- **Без анимации** — статичный градиент

Каждая опция — отдельный лёгкий компонент в `src/components/support/chat-backgrounds/` (Aurora.tsx, Waves.tsx). Все с `pointer-events-none`, чтобы не ломать клики.

#### 3. Проверка кнопки «Свернуть»
- Добавить `z-20` явно на обе кнопки `onClose` (в `HomeView` и `ChatView`) для страховки.
- После имплементации — открыть preview через browser tools, кликнуть FAB → кликнуть «Свернуть» → убедиться, что виджет закрывается.

### Файлы
- `src/components/support/SupportChatWidget.tsx` — подключить тему/фон через CSS-vars, добавить `z-20` на кнопки close
- `src/components/support/ChatThemePicker.tsx` *(новый)* — popover с цветами + анимациями
- `src/components/support/chat-backgrounds/Aurora.tsx` *(новый)*
- `src/components/support/chat-backgrounds/Waves.tsx` *(новый)*
- `src/hooks/useChatTheme.ts` *(новый)* — хук для чтения/записи темы из localStorage

### Результат
Маленькая иконка-палитра в шапке чата открывает popover, где пользователь выбирает цвет акцента и тип анимации фона. Выбор сохраняется. Кнопка «Свернуть» гарантированно работает (z-index фикс + проверим в браузере).
