

# Исправление видимости текста в карточках кейсов

## Проблема
Текст в карточках «Новичок», «Активный партнёр» и «Лидер сети» использует белые цвета (`text-white/50`, `text-white/35`), а фон карточек — полупрозрачные светлые градиенты. На светлой теме белый текст на светлом фоне не читается.

## Решение
Заменить все `text-white/*` на контрастные цвета, подходящие для обеих тем:

| Было | Станет |
|---|---|
| `text-white/50` (лейблы строк) | `text-muted-foreground` |
| `text-teal-400` (значения) | `text-teal-600 dark:text-teal-400` |
| `text-white/70` (Итого) | `text-foreground` |
| `text-white/35` (примечание) | `text-muted-foreground/70` |
| `text-white` (заголовок) | `text-foreground` (или оставить белый на баннере — он на тёмном overlay) |
| `border-white/10` (разделитель) | `border-border` |
