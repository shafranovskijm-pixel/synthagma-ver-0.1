

## Что меняем на странице курса (организация)

Сейчас при клике на курс открывается `CourseDetailsTab` поверх `OrgPageLayout`: остаётся Hero-баннер организации (он и просвечивается как «дублированная картинка на весь экран»), показываются 3 виджета и левое sub-меню с длинным списком вкладок.

### Новый макет

```text
┌─────────────────────────────────────────────────────────────┐
│ ← Назад к курсам    Название курса         [Удалить]        │
├─────────────────────────────────────────────────────────────┤
│  [Конструктор] [Ученики] [Заявки] [Материалы] [История]     │  ← группа «Обучение»
│  [Тесты] [Группы] [Достижения] | [Просмотр] [Стр. курса]    │  ← разделитель | группа «Настройки»
│                                  [Настройки] [Напоминания]  │
├──────────────┬──────────────────────────────────────────────┤
│ УРОКИ (11)   │                                              │
│  1. Урок 1   │   Содержимое выбранной вкладки               │
│  2. Урок 2   │   (по умолчанию — Конструктор: открыт        │
│  3. Урок 3   │    первый урок, без дублирования снизу)      │
│  ...         │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

### 1. Скрыть Hero-баннер организации на странице курса
В `OrgPageLayout` (или через флаг в `OrgDashboardContext` / `tabNavigation.activeTab`) при `activeTab === "course-details"` — не рендерить `OrgDashboardHeader` Hero-баннер и `AtmosphericBleed`. Sticky-хедер с лого/тарифом остаётся. Это убирает «просвечивающуюся картинку на весь экран».

### 2. Удалить виджеты
В `CourseDetailsContent` полностью убрать блок из 3 карточек (Средний прогресс / Активных учеников / Завершаемость), строки 76–89. Шапка курса остаётся короткой: название + статус + счётчики «N учеников · N уроков» + кнопки действий.

### 3. Перенести меню вкладок в верхнюю горизонтальную панель
Заменить левый `<nav>` (строки 95–127) на горизонтальные табы под шапкой курса в виде двух визуальных групп с разделителем:
- **Обучение:** Конструктор · Ученики · Заявки · Материалы · История · Тесты · Группы · Достижения
- **Настройки:** Просмотр · Страница курса · Настройки · Напоминания

Реализация: один ряд кнопок-«пилюль» (как сейчас в sidebar, только горизонтально) с тонким вертикальным разделителем между группами. На мобильном — горизонтальный скролл (уже паттерн в проекте). Активный таб подсвечивается текущим стилем `bg-primary/15`.

### 4. По умолчанию открывается «Конструктор»
В `CourseDetailsTab.tsx` поменять стартовое значение:
```ts
useState<...>("editor")  // вместо "students"
```
В `useEffect` сбрасывать выбор обратно на `editor` при смене `courseId`.

### 5. Левое меню уроков — основная навигация в Конструкторе
Уже работает: при `activeTab === "editor"` левый `nav` со списком вкладок скрывается, его место занимает `CourseBuilderLessonsNav` (sticky-список уроков). Убедимся, что:
- Открывается **первый урок** автоматически при входе на вкладку (через `setActiveLessonId(lessons[0].id)` если ничего не выбрано — это нужно проверить/добавить в `useCourseBuilder`).
- В embedded-режиме внизу не дублируется список других уроков. Сейчас в `CourseBuilder.tsx` есть правая sticky-aside «Добавить урок» — оставляем; нижней мобильной полосы с уроками нет, всё ок.

### 6. Технические детали и затрагиваемые файлы
- `src/components/organization/CourseDetailsContent.tsx` — убрать виджеты (76–89), переписать sidebar-навигацию (95–127) в горизонтальный таб-бар над контент-панелью, убрать левую колонку в `flex lg:flex-row` (строка 93).
- `src/components/organization/tabs/CourseDetailsTab.tsx` — стартовый таб `"editor"`, при смене `courseId` сбрасывать на `"editor"`.
- `src/components/organization/OrgPageLayout.tsx` (или `OrgDashboardHeader`) — условно скрывать Hero-баннер + `AtmosphericBleed`, когда активный таб = `course-details`. Добавить проп / читать `d.tabNavigation.activeTab`.
- `src/hooks/useCourseBuilder.ts` — убедиться, что при загрузке embedded-режима `activeLessonId` инициализируется первым уроком (если уже есть — не трогаем).
- Никаких изменений в БД, миграций, RLS не требуется.

### Что НЕ делаем
- Не трогаем сам конструктор уроков (логика, автосейв, левая навигация уроков `CourseBuilderLessonsNav`).
- Не меняем кнопки `Просмотр / Редактировать / Удалить` в шапке курса — они дублируются вкладками `Просмотр / Конструктор`, но пользователь явно хотел кнопку «Редактировать», поэтому оставляем.
- Тему/баннер организации в других вкладках (Курсы, Ученики, Дашборд) не трогаем — изменение касается только страницы конкретного курса.
