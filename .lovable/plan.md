

## Исправление ошибки генерации акта

### Проблема

Supabase Storage отклоняет файл с ошибкой `Invalid key` из-за кириллического символа `А` в имени файла: `act_А-417864_...html`.

Строка 50 в `generateAct.ts`:
```ts
const actNumber = `А-${Date.now().toString().slice(-6)}`;
```

Буква `А` — кириллическая, Storage требует только ASCII-символы в ключах.

### Исправление

**Файл: `src/utils/generateAct.ts`**

1. Заменить кириллическую `А` на латинскую `A` в генерации имени файла (строка 50):
   ```ts
   const actNumber = `A-${Date.now().toString().slice(-6)}`;
   ```

2. В отображаемом имени документа (строка 167) оставить кириллическое «Акт» — оно идёт в базу, не в Storage:
   ```ts
   const docName = `Акт № ${actNumber} от ${formattedDate} — ${basis}`;
   ```

Одна строка — одно исправление. Всё остальное работает корректно.
