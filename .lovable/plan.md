

## Исправление страницы установки приложения на телефоне

### Проблема
Страница `/install` на телефоне показывает пустой контент — только заголовок и "Преимущества", но без инструкций по установке. Это происходит потому что:
- Браузер не отправляет событие `beforeinstallprompt` (нет кнопки)
- Определение Android/iOS может не сработать на всех устройствах
- Service Worker не регистрируется явно

### Что будет сделано

#### 1. Регистрация Service Worker (src/main.tsx)
Добавить явную регистрацию Service Worker для корректной работы PWA.

#### 2. Типы для PWA модуля (src/vite-env.d.ts)
Добавить TypeScript-определения для `virtual:pwa-register`.

#### 3. Переработка страницы установки (src/pages/Install.tsx)
- **Всегда показывать инструкции** — не зависеть от `beforeinstallprompt`
- На Android: всегда показывать шаги через меню Chrome (три точки -> Установить приложение)
- На iOS: всегда показывать шаги через Safari (Поделиться -> На экран Домой)
- Если устройство не распознано — показывать **обе** инструкции (и для Android, и для iOS)
- Кнопку автоустановки показывать как бонус сверху, если браузер предлагает
- Добавить кнопку "Обновить страницу" для повторной попытки

### Технические детали

**src/main.tsx:**
```typescript
import { registerSW } from 'virtual:pwa-register';
registerSW({ immediate: true });
```

**src/vite-env.d.ts:**
```typescript
declare module 'virtual:pwa-register' {
  export function registerSW(options?: { immediate?: boolean }): (reloadPage?: boolean) => Promise<void>;
}
```

**src/pages/Install.tsx — ключевые изменения:**
- Убрать условие `!deferredPrompt` для показа Android-инструкций
- Если ни iOS, ни Android не определены — показывать инструкции для обеих платформ (вместо только десктопных)
- Добавить кнопку "Обновить страницу и попробовать снова"
- Кнопку `beforeinstallprompt` показывать дополнительно при наличии
