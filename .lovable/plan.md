
# Объединение каталога + исправление баннера + мобильная адаптация

## Что будет сделано

### 1. Убрать вкладку «Мои курсы» — оставить только «Каталог»
В «Каталоге» сначала показывать назначенные курсы (с прогрессом, кнопками «Продолжить»/«Пройти заново»), затем баннер «Общий прогресс» (между блоками), затем доступные курсы с 3 кнопками (Посмотреть, Купить, Записаться).

### 2. Исправить стрелки Hero Banner
Кнопки навигации используют `hidden sm:flex` — на мобильных (390px) они скрыты. А на десктопе `opacity-0 group-hover:opacity-100` — нужен hover. Сделать кнопки **всегда видимыми** на десктопе (убрать hover-зависимость) и на мобильных тоже показать маленькие стрелки.

### 3. Доступные курсы — 3 кнопки в каталоге
В `CourseCatalog` для незачисленных платных курсов передавать `onBuy` и `onEnroll` в `CourseCardNew`, чтобы отображались 3 кнопки (Посмотреть курс — по клику на карточку, Купить, Оставить заявку). Логика оплаты и заявок берётся из `AvailablePaidCourses`.

### 4. Мобильная адаптация всей панели
- Нижняя навигация (bottom tabs) вместо гамбургер-меню с Sheet — 3 иконки (Каталог, Чат, Профиль)
- Баннер прогресса уменьшить для мобильных
- Сетка курсов — 1 колонка на мобильных (уже есть)
- Убрать лишние отступы на мобильных
