

## Что меняем на странице курса (организация)

Пользователь просит:
1. Вернуть **обложку курса** в виде hero-баннера сверху страницы курса (как на 4-м скриншоте — большой баннер с названием курса, кнопкой «Все курсы»).
2. Перенести строку табов **под** баннер курса.
3. Сократить 11 табов до **3 верхних категорий**: «Ученики», «Страница курса», «Настройки» (+ оставить «Конструктор» как стартовый раздел или убрать в одну из групп — уточнено ниже).
4. При переключении категории — открывается её внутренний набор разделов (вторичная навигация).

### Новая структура

```text
┌──────────────────────────────────────────────────────────────┐
│  [← Все курсы]                                               │
│   ОБЛОЖКА КУРСА (cover_image_url) — hero-баннер              │
│   Название курса                                             │
├──────────────────────────────────────────────────────────────┤
│   [Конструктор] [Ученики] [Страница курса] [Настройки]       │  ← 4 верхних таба
├──────────────────────────────────────────────────────────────┤
│   Контент выбранной категории                                │
└──────────────────────────────────────────────────────────────┘
```

### Группировка 11 разделов в 4 категории

| Категория | Что внутри |
|---|---|
| **Конструктор** | Редактор уроков (как сейчас, со списком уроков слева). Открывается по умолчанию. |
| **Ученики** | Ученики · Заявки · Группы · История · Достижения · Напоминания |
| **Страница курса** | Страница курса (landing-редактор) · Просмотр · Материалы |
| **Настройки** | Настройки курса · Тесты |

Внутри «Ученики», «Страница курса», «Настройки» — горизонтальная подвкладка (sub-tabs) сверху контента, чтобы переключаться между разделами этой категории.

> Уточнение нужно по «Тестам» и «Материалам» — логически они могут быть в разных группах. Предлагаю разместить как выше, но если нужно иначе — скажи.

### Технические изменения

**1. Hero-баннер курса**
- Файл: `src/components/organization/CourseDetailsContent.tsx`
- Добавить вверху hero-блок: `bg` = `course.cover_image_url`, оверлей с градиентом, кнопка «Все курсы» (заменяет текущий `← Назад к курсам` из `CourseDetailsTab.tsx`), название курса белым текстом, статус (Опубликован/Черновик) и счётчики «N учеников · N уроков».
- Высота ≈ `h-48 md:h-64`, `object-cover`, `rounded-2xl`.
- Если у курса нет обложки — fallback на градиент (как сейчас в карточке курса).

**2. Удалить дублирующую кнопку «Назад»**
- Файл: `src/components/organization/tabs/CourseDetailsTab.tsx`
- Убрать `<Button>Назад к курсам</Button>` (строки с `ArrowLeft`), т.к. она теперь в hero-баннере.

**3. Перестроить табы в 4 группы**
- Файл: `src/components/organization/CourseDetailsContent.tsx`
- Заменить текущий горизонтальный список из 12 табов на 4 крупных таба: `Конструктор · Ученики · Страница курса · Настройки`.
- Стиль — как на 4-м скриншоте: подчёркнутый/pill активного таба, выровнено по центру, светлый фон.

**4. Вторичная навигация внутри групп**
- Внутри `CourseDetailsContent` добавить состояние `subTab` (зависит от выбранной категории).
- Для каждой категории при первом входе открывать первый sub-tab:
  - Ученики → `students`
  - Страница курса → `landing`
  - Настройки → `settings`
- Sub-tabs рендерятся горизонтальной полоской сразу под основными табами, более компактные.

**5. Маппинг текущих ключей вкладок**
В `activeTab` уже есть значения: `students`, `materials`, `history`, `tests`, `landing`, `settings`, `reminders`, `groups`, `requests`, `achievements`, `editor`, `preview`. Просто перегруппируем их в:

```ts
const TAB_GROUPS = {
  editor: { label: "Конструктор", subTabs: [] },
  students: { label: "Ученики", subTabs: ["students","requests","groups","history","achievements","reminders"] },
  landing: { label: "Страница курса", subTabs: ["landing","preview","materials"] },
  settings: { label: "Настройки", subTabs: ["settings","tests"] },
};
```

**6. Скрытие org Hero сохраняем**
`OrgDashboardHeader` уже скрывается на `course-details` — оставляем, новый hero курса заменяет его.

- Внутренняя логика каждого раздела (`StudentsTab`, `LandingEditorTab`, `SettingsTab` и т.д.) — без изменений.
- БД, миграции, RLS — не нужны.
- Конструктор уроков (левый список уроков, автосейв) — без изменений.
