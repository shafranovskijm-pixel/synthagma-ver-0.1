

# Улучшение DOOM-лабиринта: заглушка, музыка, визуальные эффекты оружия и пули

## Что будет сделано

### 1. Заглушка-баннер над игрой
Добавить блок над лабиринтом: «Скоро здесь будут 3D-тренажёры! А пока — сыграйте в DOOM-лабиринт 🎮». Стилизованный баннер с gradient-фоном.

### 2. Фоновая музыка в стиле Doom
В `MazeSounds.ts` добавить функцию `playBGMusic()` — зацикленный синтезаторный трек через Web Audio API (басовая линия из осцилляторов, ритмичный паттерн с square/sawtooth волнами, ~120 BPM). Музыка запускается при старте игры, останавливается при win/game over/mute. Кнопка mute управляет и музыкой.

### 3. Разные звуки для каждого оружия
- Кулак: короткий глухой удар (низкочастотный noise burst)
- Пистолет: текущий звук выстрела (резкий noise)
- Ракетница: более длинный взрыв (low-freq oscillator + noise)

Функция `playShoot()` принимает параметр `weapon: number` и играет соответствующий звук.

### 4. Визуальное оружие в HUD (нижняя часть экрана)
В `MazeHUD.tsx` добавить SVG-спрайт оружия внизу по центру (как в Doom):
- Кулак: SVG кулака
- Пистолет: SVG пистолета
- Ракетница: SVG ракетницы

При стрельбе — CSS-анимация отдачи (translateY + scale). Вспышка выстрела (muzzle flash) — яркий круг на мгновение.

### 5. Видимая пуля / снаряд
В `MazeGame.tsx` при выстреле создавать 3D-объект (маленькая сфера/цилиндр), летящий от камеры вперёд по направлению взгляда. Пуля живёт ~1 сек или до столкновения со стеной/монстром. Для ракетницы — более крупный светящийся снаряд. Массив `bullets` в gameState, обновляется в useFrame.
