

# Кнопка «AI Проверка» курса в конструкторе

## Что делаем

Добавляем третью кнопку рядом с «Импорт» и «AI Структура» в конструкторе курсов. При нажатии ИИ анализирует весь контент курса: проверяет актуальность законодательства, корректность тестов, находит ошибки и пробелы. Результат показывается в попапе со списком замечаний, где пользователь может принять или отклонить каждое предложение.

## Этапы

### 1. Edge-функция `review-course`

Новая функция `supabase/functions/review-course/index.ts`:
- Принимает `courseId`, загружает все уроки и тесты из БД
- Формирует подробный промпт для ИИ с инструкциями:
  - Проверить ссылки на законодательные акты (номера, даты, актуальность)
  - Проверить тестовые вопросы (корректность формулировок, правильность ответов, покрытие материала)
  - Найти фактические ошибки, устаревшую информацию
  - Предложить недостающие темы или вопросы
- Использует tool calling для структурированного ответа (массив замечаний с типом, описанием, предложенным исправлением, привязкой к уроку)
- Использует существующий `callAIWithTools` из `_shared/gigachat-client.ts`

### 2. Компонент `CourseReviewDialog.tsx`

Попап с результатами проверки:
- Список замечаний, сгруппированных по урокам
- Каждое замечание содержит: тип (законодательство / тест / ошибка / предложение), описание, рекомендацию
- Кнопки «Принять» / «Отклонить» у каждого замечания
- При принятии — применяет изменение к контенту урока или тесту через существующие `updateLesson` / supabase update
- Общие кнопки «Принять все» / «Закрыть»
- Индикатор загрузки во время анализа

### 3. Интеграция в CourseBuilder.tsx

- Новая кнопка между «Импорт» и «AI Структура»:
  ```
  [🔍 AI Проверка]
  Актуальность и ошибки
  ```
- Кнопка доступна только когда есть сохранённые уроки (нужен `resolvedCourseId` и `lessons.length > 0`)
- При клике — вызывает edge-функцию и открывает `CourseReviewDialog`

### 4. Хук `useCourseReview.ts`

- Состояния: `isReviewing`, `reviewResults`, `appliedIds`
- Функция `startReview(courseId)` — вызов edge-функции
- Функция `applyFinding(id)` — применение конкретного замечания
- Функция `applyAll()` — применение всех

```json
      "type": "legislation",

      "description": "Ссылка на ФЗ-35 от 2006 г. — проверьте актуальные поправки 2024 года",
      "suggestion": "Добавить упоминание поправок от 28.04.2024 №...",
      "auto_fix": null
    },
    {
      "type": "test",
      "lesson_title": "Итоговый тест",
      "description": "Вопрос 3: все варианты ответов похожи, сложно отличить правильный",

    }
  ]
}
```
