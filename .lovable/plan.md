
## Хранилище файлов организации

### Проблемы сейчас
1. Медиатека показывает файлы ВСЕХ организаций — нет фильтрации по текущему пользователю
2. Нет превью/миниатюр для файлов
3. При удалении курса файлы остаются в хранилище, но пользователь не может ими управлять
4. Раздел «Библиотека» в сайдбаре не связан с медиафайлами курсов

### Что будет сделано

**1. Фильтрация файлов по организации**
- Медиатека будет загружать только файлы из папок курсов текущей организации
- Сначала запрашиваем список `course.id` для текущей `organization_id`, затем листим только эти папки в хранилище
- Это решает проблему «чьи это файлы»

**2. Переименование «Библиотека» -> «Хранилище» в сайдбаре**
- Пункт меню `library` переименуется в «Хранилище» с иконкой `HardDrive`
- Содержимое вкладки заменяется на полноценный файловый менеджер

**3. Полноценный файловый менеджер (замена LibraryManager)**
- Новый компонент `StorageManager` заменит `LibraryManager` на вкладке `library`
- Отображает все файлы из бакетов `course-files` и `course-videos`, принадлежащие курсам организации
- Группировка по типу: Видео / Изображения / Аудио / Документы
- Для каждого файла: имя, размер, дата загрузки, превью (для изображений)
- Возможность удалять файлы
- Возможность загружать новые файлы
- Общий объем занятого пространства

**4. Превью изображений**
- Для файлов типа `image` — показывать миниатюру (img тег с URL из хранилища)
- Для видео — иконка Video
- Миниатюры кешируются браузером (URL стабильные)

**5. Сохранение файлов при удалении курса**
- При удалении курса файлы в хранилище НЕ удаляются (текущее поведение — Supabase Storage не каскадирует удаление)
- Файлы остаются доступными в «Хранилище» и могут быть переиспользованы или удалены вручную

### Технические детали

**Файлы для изменения:**

1. `src/components/organization/OrgSidebar.tsx`
   - Изменить текст «Библиотека» на «Хранилище»
   - Заменить иконку `Library` на `HardDrive`

2. `src/components/organization/StorageManager.tsx` (новый)
   - Основной компонент файлового менеджера
   - Загружает список курсов организации, затем листит файлы только из папок этих курсов
   - Фильтры по типу (видео/изображения/аудио/документы/все)
   - Поиск по имени
   - Превью изображений (миниатюры)
   - Кнопка удаления файла
   - Загрузка новых файлов
   - Отображение общего объема

3. `src/components/organization/tabs/TabContentRenderer.tsx`
   - Заменить рендер `LibraryManager` на `StorageManager` для вкладки `library`

4. `src/components/course-builder/MediaLibraryDialog.tsx`
   - Добавить проп `organizationId` (опциональный)
   - Фильтровать файлы только по папкам курсов данной организации
   - Добавить превью-миниатюры для изображений

**Логика фильтрации:**
- Запрос: `SELECT id FROM courses WHERE organization_id = ?`
- Полученные `courseId` используются как имена папок в хранилище
- `supabase.storage.from(bucket).list(courseId)` — для каждого courseId
- Это гарантирует что организация видит только свои файлы
