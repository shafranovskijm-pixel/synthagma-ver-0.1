
# Исправление отображения SEO-менеджера

## Проблема

Список страниц в левой колонке содержит 15 элементов и растягивает весь блок по вертикали. Правая часть с полями редактирования не выровнена с левой — при прокрутке видны пустые области, и пользователю приходится скроллить всю страницу, чтобы увидеть поля ввода.

## Решение

Добавить ограничение высоты и внутренний скролл для списка страниц в левой колонке.

## Технические детали

### Файл: `src/components/admin/SEOSettingsManager.tsx`

**Изменение 1** — Добавить `max-h` и `overflow-y-auto` к контейнеру списка страниц:

Текущий код (строка ~286-287):
```typescript
<div className="md:w-64 border-b md:border-b-0 md:border-r border-border">
  <div className="p-2">
```

Новый код:
```typescript
<div className="md:w-64 border-b md:border-b-0 md:border-r border-border">
  <div className="p-2 max-h-[400px] overflow-y-auto">
```

Это ограничит высоту списка страниц до 400px и добавит вертикальную прокрутку, когда элементов больше, чем помещается в область.
