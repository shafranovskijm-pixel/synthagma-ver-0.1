

# Исправление воспроизведения видео в курсе

## Диагностика

Курс содержит 2 видеоурока:
- **Видео 1** (.webm, 471 МБ) -- хранится на внутреннем хранилище. Файл очень большой, браузер может не справиться с загрузкой без правильных настроек.
- **Видео 2** (.mp4) -- хранится на внешнем хранилище. Файл может быть недоступен из-за настроек бакета на внешнем сервере.

Текущие проблемы в коде:
1. У тега `<video>` нет атрибута `preload="metadata"` -- браузер пытается буферизировать весь файл, что для 471 МБ вызывает зависание.
2. Нет индикатора загрузки -- пользователь видит пустой чёрный прямоугольник и думает, что видео сломано.
3. Нет возможности повторить загрузку при сбое сети.
4. Нет обработки состояния "ожидание буферизации" (`waiting` / `stalled` события).

## Решение

### Файл: `src/pages/CourseLearning.tsx` (компонент `VideoPlayerInline`)

1. **Добавить `preload="metadata"`** к тегу `<video>` -- браузер загрузит только метаданные (размер, длительность), а потом будет подгружать по мере воспроизведения. Критично для больших файлов.

2. **Добавить состояние загрузки видео** (`videoLoading`) с индикатором `Loader2`:
   - `true` по умолчанию
   - Сбрасывается в `false` при `onLoadedData` или `onCanPlay`
   - Показывается при `onWaiting` (буферизация)
   - Скрывается при `onPlaying`

3. **Добавить кнопку "Повторить загрузку"** в блок `videoError`:
   - При нажатии сбрасывает `videoError` в `false` и принудительно перезагружает `<video>` через `videoRef.current.load()`

4. **Добавить обработку `onStalled`** -- если видео застряло на загрузке более 15 секунд, показать сообщение "Видео загружается медленно" с кнопкой открытия в новом окне.

5. **Добавить `crossOrigin="anonymous"`** для поддержки CORS при загрузке с внешнего хранилища.

## Технические детали

### Новые состояния:
```
videoLoading: boolean (начальное: true)
stalledTimer: useRef<ReturnType<typeof setTimeout>>
```

### Изменения в JSX `<video>`:
- Добавить: `preload="metadata"`, `crossOrigin="anonymous"`
- Новые обработчики: `onCanPlay`, `onWaiting`, `onPlaying`, `onStalled`

### Индикатор загрузки (overlay поверх видео):
При `videoLoading === true` показывать полупрозрачный overlay с `Loader2` и текстом "Загрузка видео..."

### Кнопка повторной загрузки:
В блоке `videoError` добавить вторую кнопку "Попробовать снова" рядом с "Открыть видео в новом окне".

### Итого
- 1 файл с изменениями
- Улучшенный UX: индикатор загрузки, повторная попытка, поддержка больших файлов
