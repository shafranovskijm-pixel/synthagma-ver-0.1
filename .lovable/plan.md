

## Редактирование изображений через ИИ

### Что будет сделано

Добавить возможность редактировать уже загруженное/сгенерированное изображение в блоке `ImageBlock` — пользователь вводит инструкцию (например, "Исправь текст ЗАБОЕВАНИЙ на ЗАБОЛЕВАНИЙ"), и ИИ возвращает отредактированную версию.

### Изменения

**1. Edge-функция `generate-image` — добавить режим редактирования**

Добавить поддержку параметра `imageUrl` в теле запроса. Если он передан, изображение отправляется в модель как входное вместе с текстовой инструкцией:

```text
POST body: { prompt: "Исправь текст...", imageUrl: "https://..." }
```

Модель получит сообщение с двумя частями:
- `type: "text"` — инструкция пользователя
- `type: "image_url"` — текущее изображение

Результат загружается в хранилище и возвращается как новый URL.

**2. UI в `BlockEditor.tsx` (компонент `ImageBlock`)**

Когда изображение уже загружено, рядом с кнопкой "ИИ генерация" появится кнопка **"Редактировать через ИИ"** (иконка `Wand2` или `Pencil`). По нажатию:
- Открывается поле ввода с placeholder "Опишите что исправить..."
- Кнопка "Применить" отправляет запрос с `prompt` + `imageUrl` текущего изображения
- После получения результата изображение заменяется на отредактированное

### Технические детали

- В edge-функции: если `imageUrl` присутствует, формируется `content` как массив `[{type:"text",...}, {type:"image_url",...}]` вместо простой строки
- Если `imageUrl` — это base64 data URL или публичный HTTPS URL, оба варианта поддерживаются моделью
- Сгенерированное изображение перезаписывает предыдущее в хранилище (новый файл с новым timestamp)
