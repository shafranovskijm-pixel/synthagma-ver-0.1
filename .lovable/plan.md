

# Плавная бесконечная карусель «Инструменты для обучения»

## Проблема
Сейчас карточки переключаются дискретно (прыжками каждые 4 секунды) с мерцанием. Нужно: плавное непрерывное движение справа налево на весь блок, заголовок поверх карточек.

## Что будет сделано

### Переработка Features.tsx
- Убрать `AnimatePresence` / дискретные `key`-перерендеры
- Реализовать **бесконечный CSS marquee**: два одинаковых набора карточек (`features` x2) в одном `flex`-контейнере, анимация `translateX` через CSS `@keyframes` (60-80 секунд на полный цикл)
- Карточки занимают всю ширину блока (edge-to-edge, без контейнера)
- Заголовок «Инструменты для обучения» + подзаголовок — `absolute` поверх карточек по центру, с полупрозрачным фоном/тенью для читаемости
- При hover — анимация останавливается (`animation-play-state: paused`)
- Стрелки и точки-индикаторы убираются (бесконечный поток не нуждается в них)

### Техническая реализация
```text
┌──────────────────────────────────────────────┐
│  [card1][card2][card3]...[card10][card1]...   │  ← flex, translateX animation
│           ┌─────────────────┐                 │
│           │  ПЛАТФОРМА      │                 │  ← absolute overlay
│           │  Инструменты... │                 │
│           └─────────────────┘                 │
└──────────────────────────────────────────────┘
```

- CSS keyframes: `@keyframes scroll { 0% { transform: translateX(0) } 100% { transform: translateX(-50%) } }`
- Длительность: ~60s для медленного плавного движения
- Карточки: `min-w-[380px]` на десктопе, `min-w-[280px]` на мобильном
