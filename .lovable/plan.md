

## Модули в курсе (группировка уроков с аккордеоном)

На скриншоте Skill Space видно: «+ Модуль» как кнопка, модуль — раскрывающийся блок с названием, внутри — уроки. Сделаем то же в нашем стиле.

### Поведение
- В сайдбаре уроков сверху появляется кнопка **«+ Модуль»** (рядом/над «+ Добавить урок»).
- Каждый модуль = аккордеон: клик по строке модуля сворачивает/раскрывает список уроков внутри.
- Внутри раскрытого модуля — кнопка **«+ Добавить урок»** (открывает существующий popup с типами).
- При наведении на название модуля — иконка-карандаш или клик по тексту → inline-редактирование названия (как у уроков сейчас).
- Меню «...» у модуля: Переименовать / Удалить / Свернуть все / Развернуть все.
- Уроки **без модуля** (старые курсы) показываем как «Без модуля» / в корне списка — обратная совместимость.
- Drag-and-drop: уроки можно перетаскивать **внутри модуля** и **между модулями**; модули — переставлять между собой. (Используем существующий `@dnd-kit`.)
- Счётчик в шапке: «Уроки (N)» считает все уроки во всех модулях.
- При удалении модуля — спросить: «Удалить модуль вместе с N уроками?» (или «Перенести уроки в корень»).

### БД (миграция)

Новая таблица `course_modules`:
```
id uuid pk
course_id uuid fk → courses(id) on delete cascade
title text not null default 'Новый модуль'
order_index int not null default 0
created_at, updated_at timestamptz
```
RLS: те же политики, что у `lessons` (доступ владельцу/менеджерам организации курса, глобальный admin override).

В `lessons` добавить колонку:
```
module_id uuid null references course_modules(id) on delete set null
```
- nullable → старые уроки остаются без модуля, ничего не ломается.
- on delete set null → удаление модуля не удаляет уроки автоматически (UI спросит, что делать).

### Frontend
**Новые компоненты:**
- `src/components/course-builder/ModuleAccordionItem.tsx` — строка модуля (аккордеон, inline-rename, меню «...», sortable handle, кнопка «+ урок» внутри).

**Изменяемые:**
- `src/components/course-builder/CourseBuilderLessonsNav.tsx` — рендер модулей вместо плоского списка уроков; кнопка «+ Модуль»; группировка `lessons` по `module_id`; «Без модуля» как первый раздел, если есть лишние уроки; drag-and-drop с двумя SortableContext (модули и уроки внутри каждого модуля).
- `src/pages/CourseBuilder.tsx` — загрузка `course_modules`, CRUD-операции (createModule, renameModule, deleteModule, reorderModules), пробрасывание в сайдбар; при `addLesson(type, moduleId?)` сохранять `module_id`; активный урок ищется так же по `id`.
- `src/types/course.ts` — добавить `interface CourseModule` и поле `module_id?: string | null` в `Lesson`.

### Что НЕ трогаем
- Popup выбора типа урока (уже сделан).
- Внутренний редактор урока — не меняется.
- Прогресс ученика, lesson_progress — модули чисто структурные, ничего не считают.
- Логика автосейва, AI-генерация — без изменений (новые уроки от ИИ пойдут в активный модуль или «Без модуля»).
- Дублирование курса — отдельная задача (надо будет потом добавить копирование `course_modules`).
