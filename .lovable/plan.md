
# Исправления для студенческого дашборда

## Проблема 1: Библиотека видна студентам по умолчанию

В коде `useStudentDashboard.ts` (строка 172) настройка `showLibrary` по умолчанию `true` (`s.showLibrary !== false`). Нужно изменить на `false` по умолчанию (`s.showLibrary === true`), чтобы библиотека была скрыта, если организация явно не включила её.

## Проблема 2: Чат должен иметь два режима

Сейчас кнопка "ИИ-помощник" в боковом меню ведёт только к ИИ-чату. Нужно добавить выбор между:
- **Чат с учебным центром** -- переписка с организацией через таблицу `org_student_messages`
- **ИИ-помощник** -- текущий ИИ-чат через edge function `student-chat`

---

## Технические шаги

### Шаг 1. Исправить значение по умолчанию для библиотеки
В `src/hooks/useStudentDashboard.ts` (строка 172):
```
showLibrary: s.showLibrary === true  // было: s.showLibrary !== false
```

Аналогично в `src/hooks/useDashboardSettings.ts` убедиться что начальное значение `showLibrary: false`.

### Шаг 2. Добавить режим чата в StudentDashboard
В `src/pages/StudentDashboard.tsx`:
- Заменить кнопку "ИИ-помощник" на кнопку "Чат" (общая)
- При нажатии на "Чат" показывать экран выбора: "Чат с учебным центром" или "ИИ-помощник"
- Добавить состояние `chatMode: 'select' | 'org' | 'ai'`

### Шаг 3. Интегрировать ChatTab для переписки с организацией
- Использовать уже существующий компонент `ChatTab` из `src/components/organization/student-detail/ChatTab.tsx` (или адаптировать его)
- Студент будет отправлять сообщения в `org_student_messages` со своим `user_id` как `sender_user_id`

### Шаг 4. Обновить хук useStudentDashboard
- Добавить `chatMode` состояние и экспортировать его
- Добавить `organizationId` для передачи в ChatTab

---

## Ожидаемый результат
- Библиотека скрыта у всех студентов по умолчанию
- В меню одна кнопка "Чат" вместо "ИИ-помощник"
- При нажатии студент выбирает: общаться с организацией или с ИИ
