

# Кнопка «Оформить с ИИ» в редакторе блоков

## Что делаем

Добавляем кнопку «✨ Оформить с ИИ» в панель инструментов BlockEditor рядом с Undo/Redo. При нажатии ИИ анализирует весь текущий контент (все блоки), находит ссылки, структурирует текст — разбивает на заголовки, списки, callout-блоки, аккордеоны, выделяет ключевые термины, делает ссылки кликабельными. Результат заменяет текущие блоки.

## Как работает

1. Собирает весь текст из текущих блоков в единую строку
2. Отправляет в edge function `generate-lesson-content` с новым `lessonType: "format"` 
3. ИИ получает промпт: «Вот сырой текст, оформи его красиво — структурируй, найди ссылки, добавь callout/accordion/highlight блоки»
4. Результат (JSON-блоки) заменяет текущие блоки с сохранением в undo-историю

## Промпт для форматирования

```
Ты — эксперт по оформлению образовательного контента. Тебе дан сырой текст, скопированный пользователем. Твоя задача — красиво оформить его, НЕ меняя содержание:

1. Разбей на логические секции с заголовками (heading1, heading2)
2. Найди все URL-ссылки и оберни их в HTML-теги <a href="..." target="_blank">
3. Выдели ключевые определения в highlight-блоки
4. Оберни практические советы в callout-tip
5. Важные предупреждения — в callout-warning
6. Справочную/дополнительную информацию — в accordion
7. Перечисления оформи как bulletList или numberedList
8. Длинные абзацы разбей на параграфы по 2-3 предложения
9. НЕ удаляй и не меняй смысл текста — только оформление
```
