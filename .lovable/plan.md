

# Программы: курсы → программы + заказ с уведомлениями

## Что будет сделано

### 1. Переделать раздел «Программы» — показывать курсы организации
Вместо текущего файлового менеджера (ProgramsManager) раздел будет показывать **список курсов организации** из таблицы `courses`. Каждый курс отображается карточкой с:
- Названием курса
- Статусом: есть программа / нет программы
- Кнопкой «Заказать программу» (если программы нет)

Сверху — информационный блок: «По законодательству у каждого курса должна быть образовательная программа. Добавьте программу самостоятельно или закажите у нас.»

### 2. Кнопка «Заказать программу» — заявка
При нажатии создаётся запись в `service_orders` (уже есть таблица) с `service_id = "program"`, `service_title = "Разработка программы"`, и `notes` с названием курса. После этого:
- Уведомление в Telegram через существующую edge-функцию `send-telegram-notification`
- Уведомление в админку (см. п.3)

### 3. Колокольчик в админке — система уведомлений
Сейчас Bell-иконка ведёт на вкладку «Обновления». Нужно:
- Создать таблицу `admin_notifications` (id, type, title, message, is_read, metadata jsonb, created_at)
- При создании заявки на программу — вставлять запись в `admin_notifications`
- В AdminDashboard: показывать badge с количеством непрочитанных на колокольчике
- Dropdown/панель с последними уведомлениями при клике на колокольчик

### 4. Edge-функция для отправки заявки
Создать edge-функцию `notify-program-order` или расширить существующую `notify-course-order`:
- Принимает organization_id, course_title
- Отправляет в Telegram: «📋 Заявка на разработку программы! Организация: X, Курс: Y»
- Вставляет запись в `admin_notifications`
