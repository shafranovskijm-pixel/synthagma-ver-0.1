

# Прокрутка страницы наверх при переходе по ссылкам

## Проблема

При клике на ссылку (например, переход на `/feature/documents`) страница не прокручивается наверх — пользователь видит контент с той же позиции прокрутки, что и на предыдущей странице.

## Решение

Добавить компонент `ScrollToTop`, который слушает изменение маршрута через `useLocation` и вызывает `window.scrollTo(0, 0)` при каждом переходе.

## Что будет сделано

### 1. Создать компонент `src/components/ScrollToTop.tsx`

```text
useEffect(() => {
  window.scrollTo(0, 0);
}, [pathname]);
```

### 2. Подключить в `src/App.tsx`

Добавить `<ScrollToTop />` внутрь `<Router>`, перед `<Routes>`. Это обеспечит автоматическую прокрутку наверх при каждой смене маршрута.
