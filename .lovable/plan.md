

# Космическая анимация в подвале главной страницы

## Что будет сделано

Добавить Canvas-анимацию звёздного неба в фон футера лендинга — летящие звёзды с эффектом параллакса, переливающиеся цветовые туманности (teal/cyan палитра), и редкие «падающие звёзды» (shooting stars).

## Технические детали

### Новый компонент `StarfieldCanvas`
- Отдельный компонент `src/components/landing/StarfieldCanvas.tsx`
- HTML5 Canvas с `requestAnimationFrame` для плавной 60fps анимации
- **Звёзды (150-200 шт):** разного размера (0.5-2.5px), плавно двигаются вверх (эффект полёта сквозь космос), мерцают с разной фазой
- **Туманности:** 3-4 плавно движущихся градиентных пятна в teal/cyan/purple оттенках с низкой прозрачностью, анимированных через `sin/cos` для органичного перемещения
- **Падающие звёзды:** раз в 3-5 секунд — быстрая яркая линия с хвостом
- Canvas абсолютно позиционирован за контентом (`z-index: 0`), контент поверх (`z-index: 1`)
- Используем `useRef` + `useEffect` + `useCallback` для чистого lifecycle

### Изменения в `Footer.tsx`
- Импортировать и вставить `<StarfieldCanvas />` как первый дочерний элемент footer
- Убрать статичные gradient overlays и radial glows (заменены живой анимацией)
- Контент-обёртка получает `relative z-10`

### Производительность
- Canvas рендерит только когда footer виден (IntersectionObserver)
- `will-change: transform` не используется (Canvas сам по себе GPU-ускоренный)
- Cleanup в `useEffect` для остановки анимации при unmount
