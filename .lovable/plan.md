
# Исправить видимость и кликабельность ссылок в редакторе

## Что происходит сейчас
По коду видно, что стили и клик уже работают для настоящих тегов `<a>`. Проблема в другом: когда пользователь просто вставляет или печатает URL, редактор сохраняет его как обычный текст, а не как ссылку. Поэтому:
- текст не подкрашивается
- клик не работает
- в предпросмотре тоже это выглядит как обычный текст

На скриншоте как раз видны plain-text URL без обёртки в `<a>`.

## Что нужно изменить

### 1. Добавить автопревращение URL в ссылки в `RichTextEditor.tsx`
Сделать авто-linkify для текста вида:
- `https://...`
- `http://...`
- `www....`

Это должно срабатывать:
- при вставке текста
- при вводе/редактировании
- при blur/санитизации

Итог: если пользователь просто вставил ссылку в текст, редактор автоматически обернёт её в `<a href="...">...</a>`.

### 2. Сохранить уже сделанную ручную вставку ссылок
Текущую логику через dialog в `BlockEditor.tsx` оставить, но дополнить так, чтобы после вставки ссылка сразу была визуально заметной и не терялась при последующей санитизации.

### 3. Усилить стили ссылок в редакторе
В `RichTextEditor.tsx` сделать стили более явными, чтобы ссылка отличалась от обычного текста:
- `text-primary`
- `underline`
- `underline-offset`
- `break-all` или `break-words` для длинных URL
- hover-состояние

### 4. Сделать клик по ссылке в редакторе надёжным
Сейчас есть `onClick`, открывающий `<a>` в новой вкладке. Нужно усилить поведение:
- использовать `closest("a")`
- не ломать обычное редактирование текста рядом со ссылкой
- по обычному клику по ссылке открывать её в новой вкладке
- при необходимости не открывать ссылку, если пользователь именно выделяет текст

### 5. Проверить санитизацию
Убедиться, что авто-linkify и ручная вставка не вырезаются санитайзером:
- `a` уже разрешён
- `href`, `target`, `rel` уже разрешены
Нужно лишь сохранить единый формат ссылок:
- `target="_blank"`
- `rel="noopener noreferrer"`

## Файлы
- `src/components/course-builder/RichTextEditor.tsx` — основное исправление
- при необходимости небольшая доработка в `src/components/course-builder/BlockEditor.tsx` для согласованности с auto-linkify

## Ожидаемый результат
После исправления:
- если вставить URL в текст, он сразу станет ссылкой
- ссылка будет визуально подкрашена и подчёркнута
- по обычному клику в редакторе ссылка будет открываться
- в предпросмотре и в других местах ссылка тоже останется кликабельной

## Технические детали
Лучше не пытаться “красить” plain text как ссылку через CSS. Нужно именно преобразовывать URL в HTML-ссылки на уровне содержимого редактора. Иначе ни стили, ни клик работать стабильно не будут.
