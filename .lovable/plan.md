

## Исправление импортированных курсов без повторного импорта

### Что можно исправить без повторного импорта

**1. Очистка `&nbsp;` из контента уроков** — ДА, можно
В базе уже лежит JSON-контент с артефактами. Можно написать Edge Function или кнопку, которая пройдёт по всем урокам курса и очистит `&nbsp;` из текстовых полей.

**2. Добавление тестовых вопросов** — НЕТ, без повторного обращения к SkillSpace невозможно
Вопросы не были сохранены при первом импорте. Их нет ни в базе, ни в кэше. Единственный способ — повторно запросить данные с SkillSpace.

### Предлагаемое решение

**Вариант A — Повторный импорт того же курса**
Добавить в парсер логику «обновления»: если курс с таким названием уже существует, обновить контент уроков (очистить `&nbsp;`) и добавить тестовые вопросы к пустым тестовым урокам, не создавая дублей.

**Вариант B — Только очистка `&nbsp;` + ручной ввод тестов**
Создать кнопку «Очистить контент» в админке, которая уберёт `&nbsp;` из всех уроков курса. Тесты придётся заполнять вручную.

### Рекомендация

**Вариант A** — самый полный. Изменения:

**`supabase/functions/parse-skillspace-course/index.ts`:**
- Добавить параметр `existing_course_id` — если передан, не создавать новый курс, а обновлять существующий
- При обновлении: для каждого урока по `order_index` — обновить `content` (с очисткой `&nbsp;`)
- Для тестовых уроков с 0 вопросов — извлечь вопросы из SkillSpace и вставить в `test_questions`
- Не трогать уроки, у которых уже есть вопросы

**`src/components/admin/OrganizationDetailsView.tsx`:**
- Добавить кнопку «Обновить из SkillSpace» рядом с кнопкой миграции медиа
- Она вызывает тот же `parse-skillspace-course`, но с `existing_course_id`
- Показывает результат: сколько уроков обновлено, сколько тестов заполнено

Для этого нужны те же данные, что и при первом импорте: URL школы и учётные данные (email/пароль). Они уже хранятся в `organization_credentials`.
