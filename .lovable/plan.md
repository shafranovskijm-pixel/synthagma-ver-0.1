

## Просмотр деталей тестирования из журнала итоговой аттестации

### Что сейчас
Журнал итоговой аттестации показывает только итоговый балл и статус (ЗАЧЁТ/НЕЗАЧЁТ). Нет возможности посмотреть, какие именно вопросы студент ответил правильно, а какие — нет.

### Что будет сделано

Добавить кнопку «Просмотр ответов» (иконка `Eye`) в каждую строку журнала. При нажатии — открывается диалог с детальным разбором ответов: каждый вопрос, выбранный ответ студента и правильный ответ с цветовой индикацией (зелёный/красный). Аналогично тому, как работает `TestAttemptDetail` в карточке студента.

### Реализация

**1. Расширить `FinalAttestationRecord`** — добавить поле `test_attempt_id` (ID лучшей попытки), чтобы по нему загружать данные.

**2. Добавить диалог просмотра ответов** в `AutoFinalAttestationJournal.tsx`:
- State: `selectedAttemptId`, `attemptDetails` (вопросы + ответы), `detailsLoading`
- При нажатии на иконку `Eye` — загрузить из БД:
  - `test_attempts` — получить `answers`, `shown_question_ids`
  - `test_questions` — получить вопросы, варианты, правильные ответы
- Показать в `Dialog` список вопросов с цветовой индикацией (зелёный — правильно, красный — ошибка), аналогично `TestAttemptDetail`

**3. Изменения в таблице** — новый столбец «Действия» с кнопкой `Eye` (только если тест сдан).

### Файлы
- `src/components/organization/AutoFinalAttestationJournal.tsx` — единственный изменяемый файл

### Результат
Менеджер нажимает иконку глаза → открывается диалог с полным разбором ответов студента, включая ошибочные вопросы с пояснениями.
