

# Полная переработка презентации платформы

## Что сейчас
Презентация — 19 слайдов в формате 1920x1080 с устаревшими данными (старые цены, неполный функционал). Генерация PDF через html2canvas ненадёжна. На мобильных — плохо читается.

## Новый подход: Лендинг-презентация вместо слайдов

Вместо имитации PowerPoint — **вертикальная прокручиваемая страница** в стиле premium landing page. Преимущества:
- Идеально работает на мобильных без масштабирования
- Можно скачать как PDF (уже закешированный)
- Можно отправить ссылку руководителю — он просто скроллит
- Красивее, современнее, профессиональнее

## Структура новой презентации

| Секция | Содержание |
|---|---|
| **Hero** | Логотип, название, подзаголовок «Платформа для образовательных организаций», 4 тега (LMS, Документооборот, ИИ, ФИС ФРДО) |

| **ИИ-ассистент** | Генерация курсов/тестов, TTS-озвучка, обложки, чат-помощник |
| **Документооборот** | Договоры, акты, счета, протоколы, приказы — всё авто |
| **ФИС ФРДО** | 3 шага: заполнение → XML → выгрузка |
| **Охрана труда** | Модуль для обучения по ОТ |
| **Кабинеты** | Организация / Ученик / Компания — 3 интерфейса |
| **Магазин курсов** | 200+ курсов Ростехнадзора, брендирование |
| **Сравнение с конкурентами** | Таблица Синтагма vs GetCourse / iSpring / Moodle — данные из CompetitorComparison.tsx |
| **Тарифы** | 5 планов с актуальными ценами |
| **Мобильное приложение** | PWA, оффлайн, push |
| **CTA** | Начать бесплатно, контакты |

## Ключевые улучшения

1. **Вертикальный скролл** вместо слайдов — нативно на всех устройствах
2. **Встроенная сравнительная таблица** — переключатель конкурента прямо в презентации
3. **Актуальные цены** — из memory (Бесплатный 0, Старт 3490, Стандарт 6990, Профессиональный 16990, Максимальный 24990)
4. **Кнопка «Скачать PDF»** — использует уже существующий кеш из storage
5. **Кнопка «Скопировать ссылку»** — для отправки руководителю
6. **Анимации при скролле** — framer-motion intersection observer

## Технические детали
- Один файл ~600 строк вместо текущих 947
- Используются существующие компоненты UI (не нужны новые зависимости)
- framer-motion `whileInView` для анимаций при скролле
- Tailwind responsive — `md:` брейкпоинты для мобильной адаптации
- Таблица сравнения: 3 таба (GetCourse / iSpring / Moodle) с цветовой индикацией
- Sticky header с навигацией и кнопками скачивания
