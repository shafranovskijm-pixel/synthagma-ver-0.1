

# План: проверка рассылок + объединение Продаж и Документооборота в Организации

## Что я нашёл

### 1. Рассылки в админке — рабочие, но 1 риск надёжности

Цепочка `useEmailCampaigns → run-email-campaign → send-campaign-email` функционирует:
- Авторизация по JWT, проверка квоты `consume_email_quota`, шаблоны с переменными, iCal-вложение, трекинг открытий через `track-email-open`, статусы кампании (draft/sending/paused/completed).
- SMTP: для платформы — env, для организации — `get_decrypted_org_smtp` (расшифровка через RPC).

**Слабое место**: `send-campaign-email` вызывается из `run-email-campaign` циклом по 1 письму с задержкой 1.5 сек, **но без `EdgeRuntime.waitUntil` обёртки на сам `await` внутри цикла** — если отправка длится дольше лимита Edge Function (~150 сек × ~100 писем = 150 сек, на грани), хвост получателей уйдёт в `paused`. Это **не баг**, а проектное решение (продолжение через «Запустить» снова), но менеджер этого не понимает — статус `paused` выглядит как ошибка. Добавлю автодоотправку каждые 5 минут через cron + понятный бейдж «Продолжается автоматически».

### 2. В Организации уже есть свой раздел «Продажи» (OrgSalesLayout)

Это `src/components/organization/sales/OrgSalesLayout.tsx` — отдельный набор вкладок (Рассылки, Шаблоны, КП, Каталог услуг, Договоры, SMTP, Лиды-soon). **Включается через настройку `menuSettings.showSales === true`** (по умолчанию выключен, скрытый toggle). На скриншоте админки этого нет — это другой (свой) раздел.

Текущие проблемы орг-Продаж:
- Дизайн «полоска вкладок сверху» — не такой удобный, как новый сайдбар админки с группировкой.
- Нет «Обзора», нет канбана, нет задач, нет трекинга открытий — всё то, что мы только что сделали для админки, в Организации отсутствует.
- Нет связи с её документооборотом (Договоры в Продажах vs Договоры в `DocumentsTab → counterparties`/`signatures`/`incoming` — это **два разных места**).

### 3. Документооборот в Организации — расщеплён на 3 точки

- **`DocumentsTab`** (раздел «Документы» сайдбара): KPI, Контрагенты, Входящие, Приказы, Протоколы, Удостоверения, Дипломы, Свидетельства, Программы, Журналы, ФРДО, Конструктор, Документы орг., Подписания, Запросы ПД, Корзина — **15 подразделов**.
- **`OrgSalesLayout`** (раздел «Продажи»): Договоры, КП — **дублируют** «Контрагенты» из DocumentsTab.
- **`OrgProfileTab → menu`** (раздел «Профиль»): toggle видимости разделов меню — здесь же скрыт `showSales`.

Получается: Договоры с клиентами B2B-продаж лежат в `OrgSalesLayout.contracts`, а договоры по реквизитам (с уч-ся, контрагентами) — в `DocumentsTab.counterparties`. Менеджер каждый раз думает «куда мне идти».

## Что предлагаю — 3 варианта на ваш выбор

### Вариант A — Минимум (1 заход, ~30 минут)

**Только починка**:
1. **Cron-доотправка**: добавить `process-paused-campaigns` (каждые 5 минут продолжает кампании в `paused` со статусом `pending` получателей).
2. **Понятный статус**: badge «Продолжается автоматически» в `CampaignsManager` для `paused`, кнопка «Продолжить вручную».
3. **Ничего не объединяю** — оставляю как есть.

### Вариант B — Перенос Продаж админки в Организацию (рекомендую)

**Цель**: единый «новый» движок Продаж и для платформы, и для организации.

1. **Создать `OrgSalesManager.tsx`** по образцу `SalesManager` — с тем же сайдбаром (Обзор, Задачи, Сделки 360°, Компании, КП, Договоры, Подписание, Услуги, Рассылки, Контроль, Менеджеры) и группировкой. Заменит `OrgSalesLayout`.
2. **Скоупом данных** — фильтрация по `organization_id` во всех хуках/запросах. Менеджер организации видит только свои сделки/КП/задачи.
3. **Удалить дублирующий раздел «Договоры» из Продаж** в пользу единого «Контрагенты» в DocumentsTab — сделать из «Договоры» в Продажах быструю ссылку «Открыть в Документах → Контрагенты».
4. **Cron-доотправка + бейдж** (как в варианте A).
5. **`showSales` по умолчанию `true`** для всех тарифов от Стандарт+ (сейчас скрыт).

### Вариант C — Полное единое «Кабинет менеджера» (большой спринт, 3-4 захода)

Всё из B + новый super-раздел **«Клиенты и продажи»** в сайдбаре организации, который:
- Объединяет в одно дерево: Сделки 360° → Компания → её Договоры (из counterparties) → её Подписания → её Входящие сканы → её КП → её Платежи (из FinanceTab).
- В карточке компании на правой панели — все документы с этим контрагентом одним списком.
- В «Сделки 360° → тайм-лайн» — показывает события и из Продаж, и из Документов (отправлен договор, подписан ПЭП, пришёл скан, выставлен счёт).
- Раздел «Документы» остаётся как «справочник/архив», а ежедневная работа менеджера идёт из «Клиенты».

## Что НЕ делаю

- Не меняю структуру таблиц БД (всё уже есть: `commercial_proposals`, `sales_companies_db`, `org_contracts`, `org_documents`, `incoming_documents` и т.д.).
- Не трогаю Финансы — это отдельный домен.
- Не делаю интеграцию с телефонией/Outlook — отложено.
- Не объединяю «Конструктор шаблонов» (договоров/протоколов) — он остаётся в Документах, потому что это редактор, а не работа со сделкой.
