

# Всегда генерировать логин и пароль для всех слушателей

## Суть изменения

Убрать путь `no_login` из edge-функции `register-student`. Все слушатели будут создаваться с auth-аккаунтом, логином и паролем -- без исключений. Галочка "Без входа в систему" будет убрана из интерфейса.

При этом сохраняется возможность указывать один и тот же email для нескольких студентов, т.к. email -- контактная информация, а для входа используется автоматически сгенерированный логин (`student_XXXXX@student.local`).

## Изменения

### 1. Edge-функция `supabase/functions/register-student/index.ts`
- Удалить блок `if (no_login)` (строки 157-212) целиком
- Все студенты проходят через стандартный путь с созданием auth-аккаунта
- Изменить проверку дублирования по email: если email уже существует у другого студента -- НЕ блокировать создание, а просто создать нового с уникальным логином (email не является уникальным идентификатором, логин -- является)

### 2. `src/hooks/useStudentManagement.ts`
- Убрать состояние `noLoginStudent` и передачу `no_login` в вызов функции
- Убрать условную проверку email (строка 67: `if (!effectiveNoLogin && ...`)  -- email снова становится необязательным для всех

### 3. `src/components/organization/dialogs/OrgDialogs.tsx`
- Убрать галочку "Без входа в систему" из диалога добавления ученика (строки 155-163)
- Убрать prop `noLogin` из `onSubmit`
