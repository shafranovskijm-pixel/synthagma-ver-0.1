

## Проблемы

### 1. «Скачать подписанный PDF» — открывается, но не скачивается
`window.open(result.url, "_blank")` в браузере просто открывает PDF во встроенном вьюере (новая вкладка), а не скачивает. Чтобы файл реально упал в «Загрузки», нужно либо:
- скачать blob через `<a download="...">` с `URL.createObjectURL`,
- или установить `Content-Disposition: attachment` при upload в storage.

Самое надёжное и работающее с уже сохранённым файлом — fetch URL → blob → программный клик по `<a download>`.

### 2. «Скачать вложение» — без штампов/справок
`handleDownloadAttachment()` сейчас просто открывает `scanUrl || attachedUrl` — это **исходный** загруженный файл без штампов и без листа принятых правок. Кнопка вводит в заблуждение: пользователь ждёт «вложение к подписанному документу», а получает голый исходник.

Решение: убрать кнопку «Скачать вложение» вовсе и оставить **одну** «Скачать подписанный PDF» (она уже включает оригинал + штампы + правки + скан). Вторая кнопка только путает.

## Что меняем

### Файл `src/components/signing/SignedDocumentPreview.tsx`

1. **Реальное скачивание PDF**:
   - Новая утилита `triggerDownload(url, filename)`: `fetch(url) → blob → URL.createObjectURL → <a download> → click → revoke`.
   - В `handleDownloadPdf` вместо `window.open` вызывать `triggerDownload(result.url, "<documentTitle>_подписанный.pdf")`. Имя файла транслитерировать ASCII (как делается в других местах проекта — см. `mem://architecture/document-storage-and-pdf-standards`).

2. **Убрать кнопку «Скачать вложение»**:
   - Удалить `handleDownloadAttachment` и сам `<Button>`.
   - В футере остаётся только «Скачать подписанный PDF».

### Файлов больше не трогаем
Логика сборки PDF (`signedDocumentPdf.ts`) и хэш-кеш — без изменений: они уже корректно отдают финальный документ со штампами/правками/сканом.

## Этапы

1. Добавить вспомогательную функцию `downloadBlobFromUrl(url, fileName)` в `SignedDocumentPreview.tsx` (локально).
2. Заменить `window.open` на `downloadBlobFromUrl(...)` в `handleDownloadPdf`.
3. Удалить `handleDownloadAttachment` и кнопку «Скачать вложение».
4. Проверка end-to-end:
   - Открыть подписанный договор → «Скачать подписанный PDF» → файл реально загружается в «Загрузки» с осмысленным именем.
   - Открытый PDF содержит: исходный документ + страницу принятых правок (для PDF-вложения) + скан (если есть) + финальную страницу со штампами обеих сторон.
