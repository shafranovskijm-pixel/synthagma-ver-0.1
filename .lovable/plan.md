

## Улучшение конструктора шаблонов договоров

### Проблемы
1. **AI удаляет текст** при добавлении переменных вместо точечной замены конкретных данных
2. **Нет обработки ИП** -- для индивидуальных предпринимателей не нужна строка "в лице Генерального директора, действующего на основании Устава"
3. **Нет склонений** -- ФИО руководителя нужно в родительном падеже ("Трегубовой Екатерины Владимировны"), а "действующего/действующей" должно зависеть от пола

### Решение

#### 1. Улучшение AI-промпта (edge function `process-contract-template`)

Переписать системный промпт с акцентом на:
- **Строго заменять ТОЛЬКО конкретные данные** (ИНН, ФИО, адреса, суммы) на переменные
- **Весь остальной текст оставлять без изменений** -- ни слова не удалять, не перефразировать
- Добавить правило: для ИП убирать фразу "в лице ... действующего на основании Устава"
- Добавить новые переменные для склонений

#### 2. Новые переменные в шаблоне

Добавить в массив `PLACEHOLDERS`:
- `{{org_director_name_genitive}}` -- ФИО в родительном падеже (Трегубовой Екатерины Владимировны)
- `{{org_director_acting}}` -- "действующего" / "действующей" в зависимости от пола

#### 3. Автоматическое склонение ФИО при генерации договора (`useContractGenerator.ts`)

Добавить функцию определения пола по отчеству:
- Оканчивается на "-вна", "-чна" = женский -> "действующей"
- Оканчивается на "-вич", "-чич" = мужской -> "действующего"

Добавить функцию склонения в родительный падеж:
- Простое правило для русских ФИО: Иванов -> Иванова, Иванова -> Ивановой
- Имя/отчество: Екатерина -> Екатерины, Владимировна -> Владимировны

#### 4. Обработка ИП в генераторе договоров

В `generateContractHTML()`:
- Проверять, начинается ли название организации с "ИП"
- Если ИП -- убирать блок "в лице ... действующего на основании Устава"
- Для заказчика аналогично: если компания-ИП, убирать эту строку

#### 5. Обновление шаблона по умолчанию

Изменить `DEFAULT_CONTRACT_TEMPLATE` чтобы использовать новые переменные:
```text
в лице {{org_director_position}} {{org_director_name_genitive}}, {{org_director_acting}} на основании Устава
```
