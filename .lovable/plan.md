

## Редизайн конструктора курсов — современный, элегантный UI

### Проблемы сейчас
- Плоский, безликий дизайн без визуальной иерархии
- Карточки типов уроков с emoji выглядят дёшево
- Пустое состояние скудное и неинформативное
- Подписи под кнопками «Импорт» / «AI Структура» болтаются отдельно — выглядят как артефакт
- Нет использования фирменных градиентов и акцентного цвета (Teal/Cyan)

### Что сделать

**Файл: `src/pages/CourseBuilder.tsx`** — полный редизайн контентной части:

#### 1. Карточки типов уроков (правая панель)
- Заменить emoji на Lucide-иконки с цветными фонами (маленький круг `bg-primary/10` с иконкой `text-primary`)
- Добавить hover-эффект с лёгким подъёмом (`hover:shadow-md hover:-translate-y-0.5 transition-all`)
- Подпись с форматами — `text-[11px]` серым, но аккуратно выровнена
- Увеличить padding карточек, сделать `rounded-xl`

#### 2. Секция «Информация о курсе»
- Добавить тонкий градиентный акцент сверху карточки (`border-t-2 border-primary/30`)
- Иконку рядом с заголовком секции (BookOpen)

#### 3. Секция «Содержание курса»
- Кнопки «Импорт» и «AI Структура» — сделать badge-стиль с иконкой, подпись внутри кнопки вторым рядом, а не снаружи
- Убрать отдельные `<span>` подписи под кнопками

#### 4. Пустое состояние (0 уроков)
- Вместо скучного текста — иллюстративный блок:
  - Иконка `Layers` или `BookOpen` крупная, с `text-primary/20`
  - Заголовок: «Начните создавать курс»
  - Подзаголовок: «Добавьте уроки вручную, импортируйте из файлов или сгенерируйте структуру с помощью AI»
  - Три мини-кнопки в ряд: «Добавить урок», «Импорт», «AI Структура»

#### 5. Хедер
- Добавить subtle backdrop-blur к sticky header (`backdrop-blur-sm bg-card/80`)

### Технические детали
- Импортировать Lucide-иконки: `FileText, Video, CheckSquare, Sparkles, Presentation, Headphones, BookOpen, Layers`
- Все стили через Tailwind, без кастомного CSS
- Сохранить всю логику и обработчики без изменений
- Тултипы на хедер-кнопках остаются
