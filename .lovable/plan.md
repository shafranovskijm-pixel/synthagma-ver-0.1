

# План: Встроенная браузерная трансляция для вебинаров

## Проблема
Kinescope не поддерживает WebRTC (трансляцию из браузера). Клиенты обязаны устанавливать OBS или аналогичное ПО, что создает высокий порог входа для проведения вебинаров.

## Варианты решения

### Вариант A: Интеграция браузерного WebRTC→RTMP моста
Встроить в платформу компонент, который через WebRTC захватывает камеру/микрофон ведущего в браузере и отправляет поток на сервер-конвертер (WebRTC→RTMP), который уже передаёт в Kinescope.

**Плюсы:** Ведущий нажимает кнопку — трансляция идёт. Без установки ПО.
**Минусы:** Нужен внешний сервер (LiveKit / медиасервер). Дополнительные затраты на инфраструктуру.

### Вариант B: Zoom как промежуточное звено
Инструкция клиентам: создать Zoom-конференцию с Custom Live Streaming → RTMP-ключ Kinescope. Всё работает через существующий Zoom.

**Плюсы:** Без доп. инфраструктуры. Zoom у многих уже есть.
**Минусы:** Всё равно нужно стороннее ПО (Zoom). Ручная настройка.

### Вариант C: Оставить OBS, но упростить онбординг
Добавить в интерфейс пошаговую инструкцию с автозаполнением RTMP-ключей, ссылками на скачивание OBS, и видео-гайдом.

**Плюсы:** Минимум разработки. Работает уже сейчас.
**Минусы:** Клиентам всё равно нужно ставить OBS.

## Рекомендация
Для быстрого результата — **Вариант C** (улучшенный онбординг с OBS). Для долгосрочного — **Вариант A** через LiveKit Cloud (есть бесплатный tier), что позволит ведущим стримить прямо из браузера без установки чего-либо.
