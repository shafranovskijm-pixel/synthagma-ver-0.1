

# Клиенты скрыты по умолчанию + поиск через «+»

## Что делаем

Клиенты (компании) и плательщики по умолчанию скрыты. Вместо огромного списка чипов показываем только «Синтагма» + кнопку «Клиенты» (сворачиваемая) и «+» для добавления через поиск.

## Изменения в `CounterpartiesSection.tsx`

1. **Скрыть клиентов по умолчанию** — добавить `showClients` state (default `false`). Кнопка «Клиенты» с chevron разворачивает/сворачивает секцию
2. **Убрать вывод всех ungroupedClients чипов** — вместо полного списка показывать только выбранных (те, кто уже был кликнут) или развёрнутый поиск
3. **Кнопка «+» с поиском** — при клике открывается выпадающий список с `Input` поиском по компаниям. Выбранная компания добавляется как чип и становится активной
4. **Аналогично для плательщиков** — скрыты по умолчанию, доступны через «+»
5. **Выбранные клиенты** — хранить в state `visibleClientIds: Set<string>`, сохранять в localStorage. Только они отображаются как чипы

### UX-поток
- Изначально: `[Синтагма]` `| Клиенты [+]` `| Плательщики [+]`
- Нажал «+» у Клиентов → выпадающий поиск по компаниям → выбрал → чип появился
- Чипы можно закрыть крестиком (убрать из видимых)
- Группы остаются как есть, но тоже свёрнуты по умолчанию

### Технические детали
- `visibleClientIds` в localStorage (`visible_clients_${organizationId}`)
- Поиск: фильтрация `companyItems` по вхождению подстроки в name
- Popover с Input для поиска (используем существующий Popover из UI)
