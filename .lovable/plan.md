## Как устроен выпуск (подтверждённый способ)
- Edge-функция выпускается из **текущих файлов рабочей копии** (папка функции + `_shared/` + `supabase/config.toml`), а не из коммита репозитория. Выбрать коммит или ветку при выпуске нельзя.
- Значит, выпустить код из PR head до слияния можно только так: скачать точные байты по SHA `e77f3429…`, записать их в рабочую копию, сверить SHA-256 с манифестом, затем выпустить одну функцию.
- Lovable автоматически сохраняет записанные файлы в историю своего проекта. Получится коммит проекта, но не коммит в GitHub main. Полностью «без коммита» обойтись нельзя. Так уже было с generate-company-card из PR #28.

## Предлагаемые шаги, если разрешите
1. Ещё раз сверить HEAD и чистоту дерева.
2. Скачать по `e77f3429…` только два файла: `batch-skillspace-import/index.ts` и `_shared/privileged-access.ts`. Проверить, что в `privileged-access.ts` нет других локальных импортов. Если есть, остановиться.

4. Только чтением проверить, применена ли миграция `skillspace_job_authorization`. Если нет, остановиться и сообщить.
5. Выпустить только `batch-skillspace-import`.
