
## Что делаем

Когда пользователь во вкладке «Редактор» курса — **полностью скрываем стандартное левое меню организации** («Обучение», «Ученики», «Заявки», «Материалы», … «Редактор», «Настройки», «Напоминания») и **на его место ставим навигацию по урокам** (с кнопкой «← Назад» сверху, чтобы вернуть стандартное меню).

Правая панель «Добавить урок» уже sticky — проверим, что она реально едет со скроллом и в этом сценарии.

## Как это работает сейчас

- `OrganizationCourseDetails` рендерит `CourseDetailsContent`, внутри которого слева — собственное **боковое меню разделов курса** (`Ученики`, `Заявки`, …, `Редактор`, `Настройки`, …) — это и есть «левое меню», которое мешает на скрине.
- Когда `activeTab === "editor"` — справа от этого меню рендерится `<CourseBuilder embedded courseId={...} />`, у которого внутри уже свой 3-колоночный layout с `CourseBuilderLessonsNav` слева и панелью «Добавить урок» справа.
- Получается **2 левые панели подряд**: меню курса + меню уроков. Пользователь хочет, чтобы в режиме редактора было видно только меню уроков.

## Что меняем

### 1. `CourseDetailsContent.tsx` — скрыть стандартный сайдбар в режиме редактора

- Если `activeTab === "editor"` (а позже опционально и `"preview"`) — **не рендерим** левый сайдбар курса вообще. Контент `CourseBuilder` растягивается на всю ширину, и его внутренний `CourseBuilderLessonsNav` встаёт на место исчезнувшего меню.
- Передаём в `CourseBuilder` (embedded) проп `onExitEditor: () => onTabChange("students")` (или прежняя вкладка) — для кнопки «Назад».

### 2. `CourseBuilder.tsx` + `CourseBuilderLessonsNav.tsx` — кнопка «Назад» сверху

- В `CourseBuilderLessonsNav` добавить опциональный проп `onBack?: () => void` и `backLabel?: string`.
- Если передан — над списком уроков рендерим строку:
  ```
  [← Назад к разделам курса]
  ──────────────────────────
  УРОКИ (10)
   1. Знакомство…
   2. Создание…
   …
  ```
- Клик по «Назад» → `onTabChange("students")` (возвращаемся в стандартное меню курса с первой вкладкой) — стандартный левый сайдбар курса снова появляется, активна первая вкладка «Ученики» (или последняя запомненная — по желанию, простой вариант — фиксировано «Ученики»).

### 3. Закрепление обеих боковых панелей при скролле

- Скрытие стандартного сайдбара устраняет вложенный flex-контейнер с потенциальным `overflow`, и `position: sticky; top: 24` для `CourseBuilderLessonsNav` и панели «Добавить урок» начинает работать корректно: обе едут вместе со скроллом.
- Проверим, что родитель (`<div className="flex-1 p-6 min-w-0">` во вкладке `editor`) не имеет `overflow-hidden/auto` — если есть, уберём, чтобы sticky привязывался к window.

**Правки:**

  - Прокидывание `onExitEditor` в `CourseBuilder`.
  - Убедиться, что в ветке `editor` нет лишних `overflow`.
- `src/pages/CourseBuilder.tsx`:
  - Принять проп `onExitEditor?: () => void`, передать в `CourseBuilderLessonsNav` как `onBack`.
- `src/components/course-builder/CourseBuilderLessonsNav.tsx`:
  - Добавить пропы `onBack?: () => void`, `backLabel?: string`.
  - Отрендерить кнопку «← Назад» в шапке навигации, если `onBack` передан.
  - В мобильном `Sheet` — тоже показать кнопку «Назад».

## Этапы

1. В `CourseBuilderLessonsNav` добавить кнопку «Назад» (проп `onBack`).
2. В `CourseBuilder` пробросить `onExitEditor` → `onBack`.
3. В `CourseDetailsContent` скрыть стандартный сайдбар при `activeTab === "editor"` и передать `onExitEditor={() => onTabChange("students")}` в `CourseBuilder`.
4. Проверить sticky-поведение обеих боковых панелей при скролле в этой раскладке (без вложенного overflow).
5. End-to-end:
   - Открыть курс → вкладка «Редактор»: стандартное меню курса исчезло, слева — навигация по урокам с кнопкой «← Назад» сверху;
   - Скролл вниз — обе боковые панели остаются на экране;
   - Клик «← Назад» — стандартное меню возвращается, активна вкладка «Ученики»;
   - На мобильном — навигация по урокам открывается через Sheet, кнопка «Назад» внутри Sheet тоже работает.
