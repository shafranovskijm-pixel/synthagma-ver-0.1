

# Расширение функционала вебинаров

## Что добавляем

На основе возможностей Kinescope API и лучших практик вебинарных платформ, предлагаю расширить раздел вебинаров следующими функциями:

### 1. Встроенный просмотр трансляции/записи (embed-плеер)
Сейчас кнопка «Смотреть» открывает ссылку в новой вкладке. Добавим встроенный плеер прямо на странице — и для админа (предпросмотр), и для студента. Kinescope поддерживает iframe embed.

### 2. Привязка вебинара к курсу
В таблице уже есть поле `course_id`. Добавим в диалог создания возможность привязать вебинар к конкретному курсу — тогда все ученики курса автоматически получат доступ без ручного назначения.

### 3. Редактирование вебинара
Сейчас можно только создать и удалить. Добавим диалог редактирования: изменить название, описание, дату, ссылку, длительность.

### 4. Фильтрация и сортировка
Добавим фильтр по статусу (запланированные / в эфире / завершённые) и поиск по названию. При большом количестве вебинаров это критично.

### 5. Уведомление/напоминание (визуальное)
Показывать бейдж «Скоро начало» для вебинаров, которые начнутся в ближайшие 24 часа. Для студента — выделять такие вебинары цветом.

### 6. Копирование ссылки для студентов
Кнопка «Скопировать ссылку на вебинар» для быстрой отправки ученикам.

### 7. Обложка вебинара
Возможность загрузить обложку (cover_url уже в таблице). Показывать на карточке.

### 8. Дублирование вебинара
Кнопка «Дублировать» — создаёт копию вебинара с новой датой (удобно для повторяющихся занятий).

## Технические детали

### Новые/изменяемые файлы

**`src/components/organization/CreateWebinarDialog.tsx`**
- Добавить поле «Привязка к курсу» (Select из списка курсов организации)
- Добавить загрузку обложки (cover_url)
- Режим редактирования (принимает `webinar` prop для заполнения полей)

**`src/components/organization/WebinarsManager.tsx`**
- Фильтр по статусу (табы: Все / Запланированные / В эфире / Завершённые)
- Поиск по названию
- Кнопки: редактировать, дублировать, скопировать ссылку
- Встроенный embed-плеер при клике на «Смотреть» (Dialog с iframe)
- Бейдж «Скоро» для вебинаров в ближайшие 24 часа
- Показ обложки на карточке

**`src/components/student/StudentWebinarsList.tsx`**
- Встроенный embed-плеер (Dialog с iframe вместо перехода по ссылке)
- Автоматический доступ к вебинарам через курсы (если `course_id` заполнен, проверять enrollments)
- Визуальное выделение «Скоро начнётся»

### Миграция SQL
- Не нужна — все необходимые поля (`course_id`, `cover_url`) уже есть в таблице

### Kinescope Iframe API
Используем стандартный embed: `<iframe src="https://kinescope.io/embed/{video_id}" />` с DRM-авторизацией через существующий `kinescope-drm-auth`.

5. Бейдж «Скоро начало»
