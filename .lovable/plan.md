

## Генерация Акта выполненных работ в разделе тарифов

### Что будет сделано

В раздел «Закрывающие документы» на странице тарифов добавится кнопка **«Сформировать акт»**. Организация заполняет форму:
- **Дата акта** (выбор даты)
- **Основание** (текст — номер договора или счёта)
- **Сумма** (число, в рублях)

Услуга фиксирована: *«Предоставление доступа к платформе Sintagma»*.

Акт подписывается двумя сторонами:
- **Исполнитель**: ИП Шафрановский Максим Михайлович (с печатью и подписью из загруженных изображений)
- **Заказчик**: данные организации (название, ИНН, директор из реквизитов)

### Как это работает

1. Организация нажимает «Сформировать акт» → открывается диалог с полями.
2. По нажатию «Создать» генерируется HTML-документ акта (по аналогии с `generateEnrollmentOrder`).
3. HTML загружается в storage `billing-documents`, запись добавляется в `org_billing_documents` с `doc_type: "act"`.
4. Акт появляется в списке закрывающих документов и доступен для скачивания.

### Технические детали

**Новый файл: `src/utils/generateAct.ts`**
- Функция `generateAct({ organizationId, orgName, orgInn, directorName, directorPosition, actDate, basis, amount })`.
- Генерирует HTML акта выполненных работ стандартного формата.
- Загруженные изображения подписи и печати Шафрановского встраиваются как base64 в HTML (или используются URL из storage).
- Загружает HTML в `billing-documents` bucket, создаёт запись в `org_billing_documents`.

**Изменения: `src/components/organization/SubscriptionTab.tsx`**
- Добавить кнопку «Сформировать акт» рядом с секцией «Закрывающие документы».
- Добавить Dialog с формой: дата, основание, сумма.
- По submit вызывать `generateAct` с данными организации.
- Обновлять список `billingDocs` после генерации.

**Изображения подписи и печати**
- Загруженные пользователем файлы (подпись + печать ИП Шафрановского) копируются в `src/assets/` для встраивания в генерируемый документ.
- Реквизиты исполнителя (ИНН 253615392404, ИП Шафрановский М.М.) зашиваются в шаблон.

**Данные заказчика** берутся из таблицы `organizations` (name, inn, director_name, director_position) — загружаются при открытии диалога.
