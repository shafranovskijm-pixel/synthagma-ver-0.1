

## План: Показать скрытые курсы и авто-распределить по категориям

### Проблема

В группе «Повышение квалификации» показано **212 курсов**, но все подкатегории показывают «0 курсов». Причина: когда у группы есть `subGroups`, UI рендерит **только курсы внутри subGroups**. Некатегоризированные курсы (без `category_id`) добавляются в `group.courses` для подсчёта, но **нигде не отображаются** — они «между» подкатегориями.

### Решение: 2 части

#### Часть 1: Показать некатегоризированные курсы

В `AdminMarketplaceManager.tsx` (строки ~837-897), после рендера всех subGroups, добавить блок **«Без категории»** — если в группе есть курсы, не входящие ни в один subGroup:

```text
SubGroups (DnD-сортировка)
  ├── Промышленная безопасность (N курсов)
  ├── Электробезопасность (N курсов)
  └── ...
[Без категории] ← NEW: свёрнутый аккордеон с оставшимися курсами
  ├── Курс 1 (с кнопкой «Переместить»)
  └── Курс 2 ...
Добавить подкатегорию
```

Логика: вычислить `uncategorizedInGroup = group.courses.filter(c => !subGroups.some(s => s.courses.includes(c)))`.

#### Часть 2: Авто-распределение курсов по ключевым словам

Добавить в `useAdminMarketplace.ts` функцию `handleAutoCategorize()` и кнопку в UI. Логика распределения по названиям курсов:

| Ключевые слова в названии | Целевая категория (parent_type + category) |
|---|---|
| `охрана труда`, `безопасные условия` | ОТ / ПБ → (подкат. «Охрана труда») |
| `пожарная безопасность`, `пожарно-технический` | ОТ / ПБ → (подкат. «Пожарная безопасность») |
| `первая помощь`, `медицин`, `оказание помощи` | ОТ / ПБ → (подкат. «Медицина и первая помощь») **NEW** |
| `промышленная безопасность`, `ростехнадзор` | Повышение квалификации → «Промышленная безопасность» |
| `электробезопасность`, `электроустановк` | Повышение квалификации → «Электробезопасность» |
| `энергетик`, `теплоснабж`, `котельн` | Повышение квалификации → «Энергетика» |
| `экологич`, `отходы` | Повышение квалификации → «Экологическая безопасность» |
| `гидротехнич`, `ГТС` | Повышение квалификации → «Гидротехнические сооружения» |
| `строительный контроль`, `строительн` | Повышение квалификации → «Строительный контроль» |

Алгоритм:
1. Создать недостающие категории в DB (если нет «Медицина и первая помощь» и др.)
2. Для каждого некатегоризированного курса — найти первое совпадение по ключевым словам → `UPDATE courses SET category_id = ? WHERE id = ?`
3. Показать toast с результатом

#### Часть 3: Новые подкатегории через миграцию

Создать подкатегории в DB автоматически при нажатии кнопки «Авто-распределить» (если их ещё нет). Также создать:
- «Медицина и первая помощь» (parent_type = «Охрана труда / Пожарная безопасность», icon = «Heart»)
- «Охрана труда» (parent_type = «Охрана труда / Пожарная безопасность», icon = «ShieldCheck»)
- «Пожарная безопасность» (parent_type = «Охрана труда / Пожарная безопасность», icon = «Flame»)
