

## План: Онбординг-экран для пустого списка компаний

### Что делаем

Заменяем скучное «Нет компаний / Добавьте первую компанию» на красивый продающий блок (аналогично тому, что сделали для курсов), но только когда нет поискового запроса.

### Содержание

**Карточка «Управление компаниями-заказчиками»:**
- Заголовок: «Начните работу с корпоративными клиентами»
- Описание функционала в продающем стиле:
  - Ведение базы компаний-заказчиков с реквизитами
  - Автоматическое формирование договоров, счетов и актов
  - Отслеживание оплат и задолженностей в реальном времени
  - Личный кабинет для каждой компании с доступом к обучению сотрудников
  - Массовое зачисление сотрудников из Excel
  - Планы обучения и контроль переобучения
- Кнопка «Добавить первую компанию» (вызывает `cm.setShowCreateDialog(true)`)

### Визуал

Одна широкая карточка с градиентным фоном, иконками фич в два столбца, и заметной кнопкой внизу. Если есть поисковый запрос — показываем старое «Компании не найдены».
