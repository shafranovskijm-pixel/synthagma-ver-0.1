

# Дополнительные настройки для текстовых блоков

## Текущее состояние
Сейчас текстовые блоки (параграф, заголовки, списки, цитата, коллауты) имеют минимальные настройки -- только ввод текста и преобразование типа. Нет никаких визуальных или поведенческих параметров.

## Предлагаемые настройки

### 1. Выравнивание текста
Кнопки: по левому краю / по центру / по правому краю. Полезно для заголовков и параграфов.

### 2. Цвет фона блока
Выбор из предустановленных цветов (прозрачный, светло-серый, светло-голубой, светло-желтый, светло-зеленый) -- чтобы визуально выделить важный параграф без превращения в коллаут.

### 3. Размер текста
Переключатель: обычный / мелкий / крупный -- для параграфов и списков. Позволяет сделать примечание мелким шрифтом или выделить ключевой абзац.

### 4. Жирный / Курсив для всего блока
Быстрый тумблер, который применяет стиль ко всему содержимому блока, без необходимости оборачивать текст в HTML-теги вручную.

### 5. Разделитель (горизонтальная линия)
Добавить новый тип блока `divider` -- тонкая горизонтальная линия для визуального разделения секций.

## Реализация

### Изменения в типах (ContentBlock)
Добавить новые опциональные поля:
- `textAlign?: 'left' | 'center' | 'right'`
- `bgColor?: string` (из предустановленного набора)
- `textSize?: 'sm' | 'base' | 'lg'`
- `bold?: boolean`
- `italic?: boolean`

Добавить новый BlockType: `divider`.

### UI настроек
Для каждого текстового блока при наведении появляется компактная панель настроек (рядом с существующими кнопками конверсии/удаления):
- Иконка шестеренки, открывающая Popover с переключателями
- Кнопки выравнивания (3 иконки в ряд)
- Палитра фона (цветные кружки)
- Размер текста (3 кнопки: A- / A / A+)
- Тумблеры **B** и *I*

### Обновление рендерера (BlockRenderer)
Применить соответствующие CSS-классы (`text-center`, `text-sm`, `text-lg`, `bg-blue-50`, `font-bold`, `italic`) при отображении блоков студентам.

### Файлы для изменения
- `src/components/course-builder/BlockEditor.tsx` -- типы, редактор, рендерер
- Без изменений в базе данных (блоки хранятся как JSON)
