

# Декоративные AI-иллюстрации + скриншоты + PDF для презентации

## Что будет сделано

1. **AI-иллюстрации** — 6-8 декоративных изображений, сгенерированных через Lovable AI (gemini-3.1-flash-image-preview), для секций: Hero (фоновая абстракция), ИИ-ассистент, Документооборот, ФИС ФРДО, Охрана труда, Мобильное приложение, CTA. Стиль — тот же, что у `special-offer-bg.jpg`: премиальный, абстрактный, teal/cyan-палитра.

2. **Скриншоты из платформы** — сделаю 2-3 скриншота:
   - Магазин курсов (маркетплейс) — красивая витрина
   - Кабинет организации (с хорошей темой)
   - Кабинет ученика

3. **Контентные правки**:
   - «200+ готовых курсов» → «300+ готовых курсов»
   - Обновить количества в категориях (суммарно до 300+)

4. **Статический PDF** — сгенерировать PDF из содержимого презентации (через reportlab/puppeteer) и загрузить в storage `presentation-files` с именем `v3_sintagma-presentation.pdf`, чтобы кнопка «PDF» всегда отдавала готовый файл.

- Использую `lovable_ai.py --image` для генерации 6 изображений в teal/cyan/dark стиле

- Сохраню в `src/assets/presentation/`
