

## Добавить раздел «Договоры» в модуль продаж с шаблоном договора на Синтагму

### Что будет сделано

В админской панели продаж появится новая вкладка **«Договоры»** с возможностью создавать, редактировать, просматривать и скачивать договоры. Первый встроенный шаблон — договор на использование платформы Синтагма (миграция с SkillSpace, годовое обслуживание + доработка функций).

### Реализация

**1. Таблица в БД — `sales_contracts`**
- `id`, `created_at`, `updated_at`
- `company_name`, `company_inn`, `company_kpp`, `company_address`, `company_director`
- `contact_person`, `contact_email`, `contact_phone`
- `contract_number`, `contract_date`
- `tariff_plan`, `contract_duration_months` (по умолч. 12)
- `total_amount`, `prepayment_amount`
- `custom_services` (jsonb — список доработок)
- `status` (draft / sent / signed / active / expired)
- `notes`, `html_content` (сгенерированный HTML договора)
- `manager_id` (uuid)
- RLS: доступ только admin

**2. Шаблон договора** — `src/constants/contractTemplates.ts`

HTML-шаблон с юридическими разделами:
- Предмет договора (предоставление доступа к платформе Синтагма + миграция данных со SkillSpace)
- Обязанности Исполнителя (перенос курсов/учеников, доработка функций, техподдержка)
- Обязанности Заказчика (предоставление доступа к SkillSpace, данных для миграции)
- Стоимость и порядок оплаты (тариф + доработки, предоплата 50%)
- Сроки (миграция — 14 рабочих дней, доработки — по согласованию)
- Гарантии и ответственность
- Конфиденциальность
- Реквизиты сторон

**3. Компонент `SalesContracts.tsx`** — новый файл в `src/components/admin/sales/`

- Список договоров (таблица с номером, компанией, суммой, статусом, датой)
- Кнопка «Создать договор» — форма с полями компании, выбор тарифа, список доработок (добавляемые строки: название + стоимость)
- Генерация HTML по шаблону с автоподстановкой данных
- Просмотр (Dialog с HTML-превью) и скачивание (print-стили)
- Смена статуса договора

**4. Обновление `SalesManager.tsx`** — добавить вкладку «Договоры» с иконкой `ScrollText`

### Файлы
- `src/components/admin/sales/SalesContracts.tsx` — новый
- `src/constants/contractTemplates.ts` — новый (HTML-шаблон)
- `src/components/admin/SalesManager.tsx` — добавить вкладку
- SQL-миграция — таблица `sales_contracts` + RLS
