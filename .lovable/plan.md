

# Добавить кнопку смены темы в хедер для всех ролей

## Проблема
Сейчас смена темы привязана к логотипу Σ, который скрывается, если у организации есть свой логотип. У слушателя на скриншоте есть лого организации — кнопки смены темы нет.

## Решение
Добавить отдельную кнопку смены темы (иконка Sun/Moon) в правую часть хедера (рядом с радио), которая всегда видна, независимо от наличия логотипа организации. Во всех трёх хедерах:

### Файлы

| Файл | Изменение |
|------|-----------|
| `src/components/student/StudentHeader.tsx` | Добавить кнопку Sun/Moon рядом с RadioPlayerButton, с Tooltip "Сменить тему" |
| `src/components/organization/OrgDashboardHeader.tsx` | Добавить кнопку Sun/Moon рядом с RadioPlayerButton |
| `src/components/admin/AdminDashboardHeader.tsx` | Добавить кнопку Sun/Moon рядом с RadioPlayerButton |

### Детали
- Иконка: `Sun` (в тёмной теме) / `Moon` (в светлой теме) из lucide-react
- Стиль: `variant="ghost" size="icon"`, аналогичный соседним кнопкам
- Tooltip: "Сменить тему"
- Логотип Σ слева остаётся как есть (если нет кастомного лого — тоже переключает тему)
