## Что улучшаем

Импорт учеников (`src/components/ImportStudentsForm.tsx`) сейчас понимает только CSV с двумя колонками (ФИО, Email), без логина/пароля, без группы, только один курс на весь файл. Приложенный шаблон Excel устроен богаче:

`Логин | Пароль | Табельный номер | Фамилия | Имя | Отчество | Группа | Курс | Курс | Курс …`

Одна строка = один ученик со своим логином, паролем, ФИО, табельным номером, группой и произвольным количеством курсов (одна или несколько колонок «Курс»).

## Что сделаем

1. **Принимаем .xlsx (и оставляем .csv как fallback)**
   - Используем уже установленный `xlsx` (динамический import, как в `usePipelineExcelImport`).
   - Автоопределение колонок по заголовку (регистронезависимо, синонимы): `логин`, `пароль`, `табельный`/`personnel`, `фамилия`, `имя`, `отчество`, `email`, `группа`, все колонки, начинающиеся с `курс`/`course`, собираем в массив.
   - ФИО собирается как «Фамилия Имя Отчество». Если есть колонка «ФИО» — берём её.
   - Email опционален (шаблон его не содержит — используем `no_login: true`).

2. **Новый шаблон .xlsx для скачивания**
   Кнопка «Скачать шаблон» теперь отдаёт `.xlsx` с заголовками из примера и одной строкой-примером. Старый CSV-шаблон убираем.

3. **Предпросмотр перед импортом**
   После выбора файла показываем таблицу первых 10 строк с распознанными колонками и счётчиком «Найдено N учеников, X групп, Y уникальных курсов». Если какая-то колонка не распознана — предупреждение.

4. **Сопоставление курсов и групп по названию**
   - Курсы: перед импортом матчим значение ячейки к `courses.title` (case-insensitive, trim). Несовпавшие показываем списком «Курс не найден: …» — строка импортируется, но без записи на этот курс (флажком можно «пропустить строки с ненайденными курсами»).
   - Группы: аналогично матчим `student_groups.name`; если группы нет — предлагаем «Создать недостающие группы автоматически» (чекбокс, по умолчанию включён). Создаём через существующий API групп.
   - Селекты «Курс/Компания» на форме остаются как fallback для строк, где колонка пуста.

5. **Импорт**
   Для каждой строки:
   - Вызываем `register-student` с `custom_login`, `custom_password`, `full_name`, `student_group_id`, `course_id` = первый распознанный курс, `no_login: !email`, `company_id` из селекта.
   - Для остальных курсов из строки — создаём `enrollments` записи после успешной регистрации.
   - Табельный номер сохраняем в `profiles.employee_number` (поле уже используется в проекте — проверим и добавим update после создания).
   - Прогресс-бар (X из N), как сейчас.

6. **Результаты**
   Расширяем таблицу результатов: ФИО · Логин · Пароль · Группа · Курсы (кол-во) · статус. Экспорт результатов в `.xlsx` вместо CSV, с колонками из шаблона + фактические логин/пароль.

7. **Лимиты и ошибки**
   Проверка лимита учеников по тарифу (как сейчас) остаётся. Дубли логина показываем как ошибку строки, остальные продолжают импорт.

## Технические детали

- Файл `src/components/ImportStudentsForm.tsx` переписывается: парсер CSV заменяем/дополняем парсером Excel; вводим тип `ParsedStudentRow { login?, password?, employee_number?, last_name, first_name, middle_name?, email?, group_name?, course_titles: string[] }`.
- Утилиту парсинга выносим в `src/utils/studentsExcelImport.ts` (парс + матчинг курсов/групп + генерация шаблона).
- Матчинг курсов/групп: используем `courses` и `student_groups`, уже загружаемые на родительской странице; при необходимости добавляем `student_groups` в props формы (у `useStudentManagement`/`useStudents` данные есть).
- Автосоздание групп: через существующий хук/сервис групп (найдём место, где `student_groups` создаются в UI, и вызовем ту же функцию/insert).
- Множественное зачисление: `supabase.from('enrollments').insert({ user_id, course_id, organization_id })` для каждого дополнительного курса, идемпотентно по `(user_id, course_id)`.
- Табельный номер: `supabase.from('profiles').update({ employee_number }).eq('id', userId)` после регистрации. Проверю, что поле есть в `profiles` (в перечне таблиц у profiles 24 колонки — проверим наличие; если нет, положим в `student_frdo_data` или добавим миграцию).
- Никаких изменений публичных RLS/структур не планируется помимо возможного добавления `employee_number` в `profiles`, если его там нет.

## Ограничения / открытые вопросы

- Если у нескольких учеников совпадёт логин между строк — вторая строка получит ошибку. Ок для v1.
- Если Excel содержит объединённые ячейки в заголовке — берём верхнюю строку. Поддержка кастомных шапок не входит.

- (Опц.) миграция на `profiles.employee_number`, если поля нет.
