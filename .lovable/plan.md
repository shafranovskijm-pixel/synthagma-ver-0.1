

## Уведомление о результате миграции медиа

### Проблема

Сейчас при завершении миграции toast-уведомление появляется, но если пользователь отошёл от компьютера — он его пропускает. Toast исчезает через несколько секунд, и нет никакого постоянного индикатора результата.

### Решение

1. **Toast с длинным временем показа** — увеличить `duration` до 15-30 секунд для результата миграции, чтобы пользователь успел увидеть
2. **Постоянный индикатор на кнопке** — после завершения миграции менять иконку кнопки на ✓ (зелёную галочку) или ✗ (красный крестик) на 10 секунд, чтобы было видно результат визуально
3. **Обработка таймаута** — если запрос упал по таймауту (5 мин), показать понятное сообщение вместо generic ошибки

### Изменения

**`src/components/admin/OrganizationDetailsView.tsx`**

- Добавить state `migrationResult: Record<string, {status: 'success' | 'error', message: string}>` для хранения результата по курсу
- После завершения миграции — записать результат в этот state и показать toast с `duration: 15000`
- Иконка кнопки: `Loader2` во время работы → `CheckCircle` (зелёная) при успехе → `XCircle` (красная) при ошибке → через 10 сек обратно `HardDrive`
- При таймауте — показать «Миграция заняла слишком много времени. Попробуйте ещё раз — уже перенесённые файлы не будут скачаны повторно»
- При ошибке `WORKER_LIMIT` — показать «Файлы слишком большие для автоматического переноса»
