

# Исправление выгрузки ФИС ФРДО: выпадающие списки и точный формат шаблонов

## Проблема
Текущие файлы экспорта создаются без выпадающих списков (data validation) в ячейках. Система ФИС ФРДО не примет такие файлы. Также кнопка "Выгрузить ПО" показывается всегда, даже если нет курсов с настройками ПО.

## Решение

### 1. Замена библиотеки экспорта
Текущая библиотека `xlsx` (SheetJS) имеет ограниченную поддержку data validation. Будет добавлена библиотека **ExcelJS**, которая полноценно поддерживает выпадающие списки в ячейках Excel.

### 2. Выпадающие списки в файле ДПО
Следующие колонки будут содержать выпадающие списки:

| Колонка | Значения |
|---------|----------|
| Вид документа | Удостоверение о повышении квалификации, Диплом о профессиональной переподготовке |
| Статус документа | Оригинал, Дубликат |
| Подтверждение утраты / обмена / уничтожения | Да, Нет |
| Дополнительная профессиональная программа | Повышение квалификации, Профессиональная переподготовка |
| Уровень образования ВО/СПО | Высшее образование, Среднее профессиональное образование, Среднее общее образование, Основное общее образование |
| Пол получателя | Муж, Жен |
| Форма обучения | Очная, Заочная, Очно-заочная |
| Источник финансирования обучения | Платное обучение, Бюджетное обучение |
| Форма получения образования... | в образовательной организации, вне образовательной организации |

### 3. Выпадающие списки в файле ПО
Аналогичные списки для персональных данных, плюс:

| Колонка | Значения |
|---------|----------|
| Вид документа | Свидетельство о профессии рабочего, должности служащего |
| Программа профессионального обучения | 3 типа программ из FRDO_PO_PROGRAM_TYPES |

### 4. Логика отображения кнопки "Выгрузить ПО"
Кнопка "Выгрузить ПО" будет показываться **только если** есть хотя бы один курс с `frdo_program_type === "professional_training"`. Иначе она скрыта.

### 5. Точное соответствие заголовков колонок шаблонам
Заголовки колонок будут приведены в точное соответствие с официальными шаблонами ФИС ФРДО (включая полные названия с пояснениями в скобках).

### Структура экспортной функции (ExcelJS)

```typescript
// Пример создания листа с выпадающими списками
const workbook = new ExcelJS.Workbook();
const worksheet = workbook.addWorksheet('ФИС ФРДО');

// Заголовки
const headers = [...]; // точные названия колонок
worksheet.addRow(headers);

// Данные
for (const row of rows) {
  worksheet.addRow(Object.values(row));
}

// Data validation (выпадающие списки)
const validations = {
  2: { // колонка B - "Статус документа"
    type: 'list',
    formulae: ['"Оригинал,Дубликат"']
  },
  // ... остальные колонки
};

for (const [col, validation] of Object.entries(validations)) {
  for (let row = 2; row <= rows.length + 1; row++) {
    worksheet.getCell(row, Number(col)).dataValidation = validation;
  }
}

// Сохранение
const buffer = await workbook.xlsx.writeBuffer();
const blob = new Blob([buffer], { type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' });
saveAs(blob, filename);
```

### Логика видимости кнопки ПО
```typescript
const hasPOCourses = courses.some(c => c.frdo_program_type === "professional_training");
// Кнопка "Выгрузить ПО" рендерится только если hasPOCourses === true
```
