

## Вертикальное меню «Страница курса» + редактор тарифов

### Что меняем

#### 1. Вертикальное подменю в `CoursePageSettingsContent.tsx`
Сейчас 5 вкладок горизонтально (Страница / SEO / Форма записи / Промокоды / Аналитика). Делаем как у «Учеников»: двухколоночный layout — слева вертикальные пункты с иконкой и подсказкой, справа контент.

Подсказки:
- **Страница** (Globe) — «URL, акцентный цвет и цена курса»
- **SEO** (Search) — «Метатеги для поисковиков, ИИ-генерация»
- **Форма записи** (FileEdit) — «Подзаголовок, кнопка и доп. поля заявки»
- **Тарифы** (Tag) — *новый* — «Несколько ценовых пакетов для лендинга»
- **Промокоды** (Ticket) — «Скидочные коды для покупателей»
- **Аналитика** (BarChart3) — «Яндекс.Метрика, Google Analytics, Meta Pixel»

#### 2. Новая вкладка «Тарифы» (новый файл `CoursePricingTiersTab.tsx`)
Полноценный редактор тарифов прямо в настройках курса (без перехода в визуальный редактор):
- Список карточек тарифов из `landing_content.pricing.tiers` (та же структура, что использует `LandingPricingSection`).
- Каждая карточка: название, цена ₽, чекбокс «Популярный», список фич с возможностью добавить/удалить пункт, кнопка удалить тариф.
- Кнопка «+ Добавить тариф» (макс. 4).
- Кнопка «Сохранить» — пишет `landing_content.pricing` в `courses` через тот же `useCoursePageSettings` (расширим хук методами `updatePricing`, `addTier`, `removeTier`, `updateTier`, `addTierFeature`, `removeTierFeature`, `updateTierFeature` — они уже есть в `useLandingEditor`, скопируем логику).
- Если тарифов нет — empty state с кнопкой «Создать первый тариф» и текстом «Тарифы автоматически появятся на странице курса».

Эти тарифы **уже** рендерятся на публичной странице курса (`CourseLanding.tsx` → `LandingPricingSection`), просто блок `pricing` должен быть в списке секций. Если его нет в `landing_content.blocks`, добавим автоматически при первом сохранении тарифа.

#### 3. Layout — для группы `page` в `CourseDetailsContent.tsx`
Сейчас в `CourseDetailsContent.tsx` вертикальный layout сделан только для `activeGroup === "students"`. Подвкладки группы `page` (Страница курса / Просмотр / Материалы) оставляем горизонтальными — там 3 пункта, всё ок.

**Внутреннее** меню «Страница курса» (5 вкладок Tabs внутри `CoursePageSettingsContent`) переделываем в вертикальное (см. п.1).

### Файлы
- `src/components/course-editor/CoursePageSettingsContent.tsx` — заменить горизонтальные `<TabsList>` на двухколоночный grid с вертикальным меню + подсказки. Добавить вкладку «Тарифы».
- `src/components/course-editor/CoursePricingTiersTab.tsx` — **новый** компонент-редактор тарифов.
- `src/hooks/useCoursePageSettings.ts` — расширить методами для работы с `landing_content.pricing.tiers` (updateTier/addTier/removeTier + features). При сохранении тарифов — если в `landing_content.blocks` нет блока `pricing`, добавить его, чтобы блок отображался на лендинге.

### Результат
- В «Страница курса» внутреннее меню стало вертикальным с подсказками — единый стиль с разделом «Ученики».
- Появилась новая вкладка «Тарифы»: создаёшь несколько ценовых пакетов прямо здесь — они автоматически появляются на публичной странице курса (`/c/slug`).
