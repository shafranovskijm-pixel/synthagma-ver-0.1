

# Предпросмотр шаблонов напоминаний

## Текущее состояние

Функция напоминаний работает корректно:
- Триггер в базе данных `trigger_create_course_reminder` активен на таблице `enrollments` и срабатывает при смене статуса на `completed`
- Edge-функция `process-reminders` обрабатывает как организационные, так и курсовые напоминания
- RLS-политики настроены правильно

Единственное изменение -- сейчас клик по шаблону просто копирует текст в буфер. Нужно добавить диалог предпросмотра.

## Что будет сделано

При клике на шаблон комментария (Badge) вместо копирования в буфер будет открываться диалог предпросмотра с:
- Названием шаблона
- Периодичностью (например, "3 года")
- Полным текстом напоминания
- Кнопкой "Скопировать текст"

## Техническая реализация

### Файл: `src/components/organization/CourseRemindersTab.tsx`

1. Добавить состояние `previewTemplate` (тип `ReminderTemplate | null`) для хранения выбранного шаблона
2. Заменить `onClick` на бейджах шаблонов -- вместо `navigator.clipboard.writeText(...)` вызывать `setPreviewTemplate(t)`
3. Добавить новый `Dialog` с предпросмотром шаблона:
   - Заголовок: название шаблона
   - Бейдж: "Периодичность: N мес."
   - Текст шаблона в блоке с фоном и форматированием (whitespace-pre-wrap)
   - Кнопка "Скопировать" -- копирует текст в буфер
   - Кнопка "Закрыть"

Изменения затрагивают только один файл -- `CourseRemindersTab.tsx`.
