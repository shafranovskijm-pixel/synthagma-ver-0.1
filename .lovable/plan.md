
# Изменения в Настройках организации

## Что будет сделано

### 1. Переименовать "Robokassa" → "Касса"
Вкладка будет называться просто "Касса" — без привязки к конкретной платёжной системе.

### 2. Улучшить визуал "Разделы меню"
Сделать toggle-строки более визуально похожими на иконки бокового меню — крупнее значки, цвета соответствуют реальным иконкам в сайдбаре, добавить мягкие тени/hover-эффекты для узнаваемости.

### 3. Встроить компоненты управления прямо в таб "Управление"
Вместо кнопок-ссылок, которые перекидывают на страницу организации, вкладка "Управление" будет содержать вложенные табы:
- **Сотрудники** → компонент `StaffManager`
- **Документооборот** → компонент `DocumentsTab`
- **Журналы учёта** → компонент `JournalsManager`
- **ФИС ФРДО** → компонент `FRDOManager`

Пользователь переключается между ними прямо в настройках, без перехода на другую страницу.
