
# Проверка уведомлений + добавление записей в «Что нового»

## Уведомления — результат проверки

Система уведомлений работает корректно:
- **Колокольчик** (`OrgNotifications`) — загружает уведомления из `org_notifications`, показывает бейдж с количеством непрочитанных
- **Realtime** — подписка на `postgres_changes` для мгновенного получения новых уведомлений
- **Звук** — генерируется через `AudioContext` при новом уведомлении, если включён в настройках (`notification_preferences`)
- **Чаты** — бейдж непрочитанных чатов на сайдбаре (через `useAdminUnreadChats`)
- **Задания** — фильтрация по типам `TASK_TYPES` во вкладке «Задания»
- **Клик по subscription_expiry** — навигация на `/invoice/:id`

Код выглядит рабочим, проблем не обнаружено.
