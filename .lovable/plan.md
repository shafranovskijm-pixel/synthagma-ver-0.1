
## Что просит пользователь
Не слать отдельное уведомление на каждый комментарий/правку к документу. Сейчас при каждой добавленной правке (комментарий / удалить / заменить / вставить) создаётся отдельная запись в `org_notifications` ("Новый комментарий к документу"). Из-за этого панель уведомлений засоряется — на скриншоте видно 3 уведомления подряд по одному документу.

Нужно: одно итоговое уведомление "Запрошены правки по документу" на отправку всего набора правок, а отдельные карточки на каждый комментарий — убрать.

## Решение

### 1. Найти источник уведомлений
В коде подписания договора (вероятно `ContractReviewBody.tsx` / связанная edge-функция) есть два места создания `org_notifications`:
- на каждый добавленный комментарий → тип примерно `document_comment` / `Новый комментарий к документу`;
- на финальную отправку правок → `Запрошены правки по документу`.

Нужно найти оба и оставить только второе.

### 2. Убрать per-comment уведомления
- Удалить вставку в `org_notifications` при сохранении отдельной правки (insert / replace / delete / comment).
- Оставить только одно уведомление, создаваемое в момент, когда пользователь нажимает "Отправить правки" / завершает рецензию.
- В тексте итогового уведомления указать количество правок: например "Запрошены правки по документу (3)".

### 3. Почистить старое
Существующие "Новый комментарий к документу" в БД не трогаем (исторические), просто перестаём создавать новые.

### 4. Проверить почтовые/звуковые триггеры
Если на каждый комментарий также шёл email или звук — отключить, оставить только на итоговое событие.

## Файлы (предварительно)
- `src/components/signing/ContractReviewBody.tsx` — место добавления комментария/правки.
- `src/components/signing/ReviewableDocument.tsx` — источник вызова сохранения правок.
- Возможно edge-функция, создающая `org_notifications` (`document_comment`).

Точные места найду на этапе реализации через `code--search_files` по `document_comment` и `Новый комментарий к документу`.

## Этапы
1. Найти все места создания `org_notifications` с типом комментария к документу.
2. Удалить per-comment уведомления, оставить только итоговое "Запрошены правки по документу".
3. В итоговое добавить счётчик правок.
4. Проверить, что в панели уведомлений после отправки набора правок появляется ровно одна запись.
