## Что меняем

Сейчас выгрузка идёт из хардкод-массива (5 примеров на направление = ~50 курсов). Делаем так, чтобы кнопки **Word** и **PDF** скачивали **полный список из базы** — ~308 реальных курсов из `marketplace_courses` платформы «Синтагма».

## Реализация

1. **Запрос к БД на странице `RostechnadzorCoursesPage.tsx`**
   - Через React Query (`useQuery`) на маунте грузим:
     ```
     marketplace_courses
       → courses(id, title, description, category_id)
       → course_categories(id, name)
     ```
     где `organization_id = 4ac2c05a-d8b5-4e72-ba31-f2c743091d95` (Платформа Синтагма) и `is_active = true`.
   - Сортируем по категории (в порядке из текущего `categories` массива → известные 14 направлений идут первыми, остальные — в конце), затем по названию курса.

2. **Группировка**
   - Группируем по `course_categories.name`.
   - Для каждой группы: `{ title, count: courses.length, courses: [{ title, description }] }`.
   - В описание берём `marketplace_courses.description_short`, если пусто — `courses.description`, если пусто — пропускаем поле.

3. **Кнопки скачивания**
   - Пока запрос идёт — кнопки disabled, надпись «Загружаем каталог…».
   - После загрузки — передаём в `exportCatalogToDocx` / `exportCatalogToPdf` полный список из БД.
   - В скобках у заголовка показываем реальное число: «Скачать каталог (308 курсов) в Word».

4. **Обновление утилит экспорта** (`src/utils/exportRostechnadzorCatalog.ts`)
   - Расширяем интерфейс `CatalogGroup` так, чтобы курс был объектом `{ title, description? }` (а не строкой).
   - В Word: название жирным + следующей строкой курсивом серым — описание (если есть).
   - В PDF: то же самое, с переносами строк через `splitTextToSize`.

5. **Визуальный каталог на странице не меняем** — продолжает показывать 5 примеров на категорию (иначе страница станет километровой). При желании позже можно сделать «развернуть всё».

## Что НЕ меняется

- Дизайн страницы, хардкод 14 направлений для визуального каталога, RLS, edge-функции.
- Формат и оформление файлов (шапка, направления, подвал) — те же, что согласованы ранее.
