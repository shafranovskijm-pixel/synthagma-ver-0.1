

## Добавить кнопку «Дублировать курс» в интерфейс организации

### Что сейчас
- Функция `duplicateCourse` в `src/api/courses.ts` уже существует — копирует курс и уроки, но **не копирует тест-вопросы** (`test_questions`).
- Хук `useCourses.ts` уже экспортирует метод `duplicate`.
- В UI (выпадающее меню карточки курса в `CoursesTab.tsx`) кнопки «Дублировать» **нет** — только «Редактировать», «Просмотр», «Переместить в категорию».

### План

**1. Доработать `duplicateCourse` в `src/api/courses.ts`**
- После копирования уроков — для каждого урока типа `test` скопировать все `test_questions` из оригинального урока в новый (с маппингом old lesson_id → new lesson_id).
- Это аналогично тому, как работает глубокое клонирование в маркетплейсе (`useCourseStoreManager.ts`, строки 349-356).

**2. Добавить пункт «Дублировать» в `CoursesTab.tsx`**
- В оба `DropdownMenuContent` (compact и grid view) добавить пункт меню с иконкой `Copy`:
  ```
  Дублировать курс
  ```
- При клике — вызвать `duplicate(course.id)` из хука `useCourses`, затем обновить список курсов.
