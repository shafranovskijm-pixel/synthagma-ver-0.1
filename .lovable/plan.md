

# Вебинар как редактор курсов: inline в рабочем столе + брендированная заглушка + читаемые кнопки

## Проблема 1 — Эфир открывается поверх всего, скрывает сайдбар

**Сейчас:** `WebinarLiveOverlay` = `fixed inset-0 z-50` → перекрывает левый сайдбар организации/админки.

**Как сделано у редактора курсов:** компонент `CourseBuilder` имеет проп `embedded` и рендерится **внутри** `CourseDetailsContent` на месте обычного контента вкладки (`activeTab === "editor"`). Сайдбар, шапка и навигация остаются на месте.

**Решение для вебинара — тот же inline-режим:**

В `WebinarsManager.tsx` ввести состояние `liveInlineWebinar` (вместо `liveSheetWebinar`). Когда оно установлено — **возвращать другой JSX** в начале `return`: вместо сетки карточек рендерить inline-блок «эфир»:

```text
┌─────────────────────────────────────┐
│ ← Назад к вебинарам   🔴 LIVE  ⛶  │  ← локальная шапка эфира
├─────────────────────────────────────┤
│                                     │
│      EmbeddedWebinarPlayer          │  ← плеер на всю ширину контента
│                                     │
└─────────────────────────────────────┘
```

Сайдбар организации/админки **остаётся слева**, как при редакторе курсов. Кнопка «← Назад» возвращает к списку вебинаров без завершения эфира. Кнопка «⛶ На отдельной странице» — `navigate('/webinar/:id/live')`.

**Файлы:**
- `src/components/webinars/WebinarLiveInline.tsx` — **новый** inline-компонент с локальной шапкой + `EmbeddedWebinarPlayer` (вместо `WebinarLiveOverlay` с `fixed inset-0`).
- `src/components/organization/WebinarsManager.tsx` — заменить `<WebinarLiveOverlay>` на условный ранний `return <WebinarLiveInline />` когда `liveInlineWebinar` установлен.
- `src/components/admin/AdminWebinarsOverview.tsx` — то же: заменить `<WebinarLiveOverlay>` на inline-режим в начале `return`.
- `WebinarLiveOverlay.tsx` — оставить файл (используется как fallback на `/webinar/:id/live`), либо удалить если больше нигде не нужен.

## Проблема 2 — Белые «пустые» кнопки в шапке плеера

**Сейчас (см. второй скрин):** между «Ссылка для участников» и «Завершить» видны два белых кружка без иконок.

**Причина:** в `EmbeddedWebinarPlayer.tsx` (строки 336–356) кнопки QR и «Настройки доступа» используют `variant="outline"` с размером `h-8 px-2`. На полупрозрачном фоне `bg-background/85 backdrop-blur-sm` поверх чёрной LiveKit-комнаты `outline`-вариант рендерится почти невидимым — иконка `currentColor` и `text-foreground` сливаются с фоном кнопки.

**Решение:** заменить эти две кнопки на `variant="secondary"` с явным `text-foreground` и иконкой стандартного размера `w-4 h-4` (вместо `w-3.5 h-3.5`), либо добавить класс `bg-background text-foreground hover:bg-muted` для гарантированного контраста. Также:
- Кнопке QR добавить рядом текст «QR» на десктопе, чтобы было ясно, что это кнопка.
- Кнопке настроек добавить текст «Доступ» на десктопе.
- Убрать прозрачность шапки `bg-background/85` → `bg-card` (плотный фон).

**Файл:** `src/components/webinars/EmbeddedWebinarPlayer.tsx` — поправить классы кнопок в `LiveKitTopBar` (строки 307, 336–356).

## Проблема 3 — «Сделать главный экран под Синтагму, "Добро пожаловать"»

**Сейчас:** когда хост подключился, но камеру/микрофон ещё не включил (или участники-зрители подключились раньше хоста) — LiveKit `<VideoConference />` показывает чёрный экран с серым силуэтом-человечком (стандартный placeholder `@livekit/components-react`).

**Решение — брендированный overlay поверх плеера, когда нет видео-треков:**

В `LiveKitEmbed` добавить хук `useTracks([Track.Source.Camera, Track.Source.ScreenShare])` из `@livekit/components-react`. Если массив пустой — поверх `VideoConference` (внутри той же `aspect-video`-обёртки) рендерить абсолютный `<div>` с:

- Логотип Синтагма по центру (`<SigmaLogo size="xl" />`).
- Заголовок: **«Добро пожаловать на вебинар Синтагма»**.
- Подзаголовок (название эфира): «{webinarTitle}».
- Подсказка: «Эфир скоро начнётся. Ведущий подключает камеру…»
- Градиентный фон в стиле платформы (Teal/Cyan: `bg-gradient-to-br from-primary/20 via-background to-primary/10`), с лёгкой анимацией `animate-pulse` на лого.

Как только у любого участника появится видеотрек — overlay автоматически скрывается, показывается реальное видео.

**Файл:** `src/components/webinars/EmbeddedWebinarPlayer.tsx` — добавить компонент `WelcomeOverlay` внутрь `LiveKitRoom` рядом с `<VideoConference />`, использовать `useTracks` для определения наличия видео.
