
Нужно добить проблему глубже: прошлое исправление убрало только `<audio preload="auto">`, но в редакторе курса при открытии всё ещё сразу рендерятся другие удалённые медиа-превью. Если источник отдает `Content-Disposition: attachment`, браузер воспринимает их как скачивание.

## Что именно ещё вызывает скачивание

Сейчас в конструкторе при открытии раскрытого урока автоматически грузятся:
- `<video src=...>` в `SortableLessonItem.tsx`
- `<video src=...>` в `BlockEditor.tsx` (`DirectVideoBlock`)
- `<iframe ...>` предпросмотра документов в `BlockEditor.tsx` (PDF/Word viewer)
- `<iframe ...>` предпросмотра PPTX в `SliderLessonEditor.tsx`
- `<img src=...>` для картинок и слайдов в редакторе

То есть проблема уже не только в `preload`, а в самом автопоказе превью удалённых файлов.

## Решение

Сделать безопасный режим превью в конструкторе:
- по умолчанию **не загружать удалённые медиа автоматически**
- вместо этого показывать заглушку/кнопку:
  - «Показать видео»
  - «Показать аудио»
  - «Показать документ»
  - «Показать презентацию»
  - «Показать изображение»
- загружать реальный `src` только после явного клика пользователя

Это полностью уберёт автоскачивание при входе в редактирование.

## Что изменить

### 1. `src/components/course-builder/SortableLessonItem.tsx`
- для видеоурока заменить мгновенный `<video ... src={lesson.content}>` на ленивый предпросмотр по кнопке
- для аудиоурока аналогично: не монтировать `<audio>` сразу, а только после клика
- для изображений не рендерить `<img>` сразу для внешних URL без подтверждения

### 2. `src/components/course-builder/BlockEditor.tsx`
- в `DirectVideoBlock` добавить состояние `isActivated`
- пока не активировано — показывать карточку-заглушку
- только после клика монтировать `<video>`
- для `AudioBlock` и preview audio-блоков сделать тот же подход
- для `DocumentBlock` не монтировать iframe просмотра автоматически; сначала кнопка «Открыть предпросмотр документа»
- в рендере document-блока ниже по файлу тоже сделать ленивую активацию iframe

### 3. `src/components/course-builder/SliderLessonEditor.tsx`
- не загружать iframe просмотра PPTX автоматически
- заменить на кнопку «Открыть предпросмотр презентации»

### 4. `src/components/course-builder/VideoPreviewInline.tsx`
- для direct video file URLs не монтировать `<video>` сразу
- для внешних embed/iframe превью тоже лучше не грузить автоматически в редакторе
- оставить карточку с кнопкой «Открыть предпросмотр»
- Kinescope/YouTube/Vimeo/Rutube тоже открывать только после клика внутри конструктора

## Ожидаемый результат

При входе в «Редактировать курс»:
- браузер больше не начнёт скачивать несколько файлов сам
- все медиа останутся доступны
- загрузка начнётся только после явного действия пользователя

## Техническая деталь
Это правильнее, чем просто менять `preload`, потому что `preload` помогает только для native audio/video, но не защищает от:
- `iframe`-предпросмотров документов и презентаций
- `<img>` с attachment-заголовками
- прямых video/image/document URL, которые браузер запрашивает сразу после монтирования элемента
