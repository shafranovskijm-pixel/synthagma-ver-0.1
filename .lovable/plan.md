

## Email-рассылка организациям из админ-панели

### Контекст

Рассылка нужна для работы с организациями (потенциальные и текущие клиенты), а не с учениками. Цель -- продать платформу или понять, что организация не заинтересована. Письма отправляются на `organizations.email` через существующую SMTP Edge Function `send-email`.

### Шаблоны писем

**1. «Неактивная организация»**
- Фильтр по дате последнего обновления (`updated_at`) -- 7/14/30/60 дней
- Текст: «Здравствуйте! Мы заметили, что вы давно не заходили на платформу Sintagma. Если вам нужна помощь в настройке или консультация -- нажмите кнопку ниже, и мы свяжемся с вами. Если платформа вам больше не нужна, ваш аккаунт будет деактивирован через 7 дней.»
- Кнопка «Мне нужна помощь» -- ведет на Edge Function

**2. «Приветствие / консультация»**
- Для всех или выбранных организаций
- Текст: «Спасибо за регистрацию на платформе Sintagma! Если вам нужна консультация по настройке платформы -- нажмите кнопку ниже.»
- Кнопка «Запросить консультацию»

### Механика кнопки в письме

1. При отправке создается одноразовый токен в новой таблице `email_action_tokens`
2. Кнопка -- ссылка на новую Edge Function `handle-email-action?token=...`
3. Edge Function: проверяет токен, помечает как использованный, отправляет сообщение в `admin_org_messages` от лица организации, отправляет Telegram-уведомление админу, возвращает HTML-страницу «Ваш запрос принят»

### Миграция БД

Таблица `email_action_tokens`:
- `id` uuid PK
- `organization_id` uuid FK
- `organization_email` text
- `action_type` text ('help_request' | 'consultation_request')
- `template_name` text
- `used` boolean default false
- `created_at` timestamptz default now()
- `used_at` timestamptz

RLS: без политик (доступ через service_role в Edge Functions).

### Отправка

Используем существующую `send-email` Edge Function (SMTP). Для каждой организации:
1. Создать запись в `email_action_tokens` (через service role в Edge Function или напрямую)
2. Сгенерировать HTML с кнопкой-ссылкой на `handle-email-action?token=...`
3. Вызвать `send-email` с HTML-письмом на `organization.email`

### Telegram

При нажатии кнопки -- `handle-email-action` вызывает `send-telegram-notification` для уведомления админа. Секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_SUPPORT_CHAT_ID` уже настроены.
