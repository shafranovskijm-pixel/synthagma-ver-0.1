

# Добавление настроек курса для ФРДО и исправление формата листа

## Что будет сделано

### 1. Название листа в файле
Лист уже называется "ФИС ФРДО" -- это соответствует образцу. Проверено.

### 2. Три новых настройки курса для ФРДО
В раздел "Настройки ФИС ФРДО" модального окна курса будут добавлены:

| Настройка | Тип поля | Значения |
|-----------|----------|----------|
| Срок обучения, часов | Числовое поле | Число часов |
| Источник финансирования обучения | Выпадающий список | Платное обучение, Бюджетное обучение |
| Форма получения образования | Выпадающий список | в образовательной организации, вне образовательной организации |

Эти настройки задаются на уровне курса и автоматически подставляются при экспорте для всех учеников данного курса.

### 3. Какие данные откуда берутся

| Поле в файле | Источник |
|-------------|----------|
| Вид документа | Автоматически (из типа программы курса) |
| Статус документа | Автоматически ("Оригинал") |
| Серия/Номер документа | Автоматически (генерация) |
| Дата выдачи | Автоматически (дата завершения) |
| Регистрационный номер | Автоматически (генерация) |
| Тип программы | Из настроек курса |
| Наименование программы | Название курса |
| Область деятельности, группа специальностей, квалификация | Из настроек курса |
| Срок обучения, часов | **Новое** -- из настроек курса |
| ФИО, дата рождения, пол, СНИЛС | Данные ученика (student_frdo_data) |
| Форма обучения | Из настроек курса (training_form) |
| Источник финансирования | **Новое** -- из настроек курса |
| Форма получения образования | **Новое** -- из настроек курса |
| Гражданство | Данные ученика (по умолчанию 643) |
