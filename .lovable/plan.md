

# Демо-скриншоты кабинетов с темами + обновление секции

## Что будет сделано

### 1. Скриншоты через браузер
Залогинюсь через демо-аккаунты (student@demo.sigma, org@demo.sigma) в превью, применю красивые визуальные темы из настроек интерфейса, и сделаю скриншоты:
- **Кабинет ученика** — с одной из тем (например, «Свежесть» или «Монстера»)
- **Кабинет организации** — с другой красивой темой
- **Кабинет компании** — через «Войти как компания» из организации

### 2. Добавление 4-го кабинета — Преподаватель
В секцию «Три кабинета» → «Четыре кабинета» добавлю роль Преподаватель/Проверяющий с возможностями: Проверка заданий, Оценка тестов, Ведение вебинаров, Обратная связь, Журнал успеваемости.

### 3. Обновление секции в PlatformPresentation.tsx
- Заголовок: «Четыре кабинета»
- Сетка 2x2 вместо 3 колонок
- Каждая карточка получит реальный скриншот кабинета сверху (с rounded corners и shadow)
- Под скриншотом — иконка, название роли и список возможностей
