

## Вертикальное подменю «Ученики» с подсказками + улучшения «Достижения»

### Проблема
Внутри карточки курса вкладка «Ученики» использует горизонтальное подменю (Ученики / Заявки / Группы / История / Достижения / Напоминания) — оно занимает место и не объясняет, что внутри. Пользователь хочет:
1. Сделать подменю **вертикальным слева** с подсказкой-описанием для каждого раздела (как empty-state у курсов).
2. На вкладке «Достижения курса» добавить возможность **создавать достижения прямо здесь** + подтянуть готовые **шаблоны** (из `AchievementsManager`), чтобы выбирать тематические наборы.

### Решение

#### 1. Вертикальное подменю в `CourseDetailsContent.tsx`
Только для группы `students` (Ученики) меняем layout: вместо горизонтальной полоски подвкладок — двухколоночный grid:
- Левая колонка (~240px): вертикальный список из 6 пунктов с иконкой, названием и краткой подсказкой (1 строка). Активный пункт — подсветка primary, скруглённая «таблетка».
- Правая колонка: контент активной подвкладки.

Подсказки:
- **Ученики** — «Список зачисленных, прогресс и управление доступом»
- **Заявки** — «Запросы на запись, ожидающие подтверждения»
- **Группы** — «Группировка учеников по потокам и датам»
- **История** — «Хронология зачислений, завершений и отчислений»
- **Достижения** — «Награды и медали, выдаваемые на этом курсе»
- **Напоминания** — «Автоматические письма о сроках переаттестации»

Для остальных групп (`page`, `settings`) подменю остаётся как есть — там 2-3 пункта без сложной семантики.

Файл: `src/components/organization/CourseDetailsContent.tsx` — заменить блок `{showSubTabs && ...}` и обернуть основной контент в условный layout, когда `activeGroup === "students"`.

#### 2. Доработка вкладки «Достижения курса»
В `CourseAchievementsTab.tsx`:
- Добавить шапку с двумя кнопками: «Создать достижение» и «Из шаблона».
- При клике «Создать» — мини-форма прямо на странице (Название, Описание, Эмодзи, Редкость) → `INSERT into achievements` + автопривязка к курсу через `course_achievements`.
- При клике «Из шаблона» — раскрывающаяся секция с 4 готовыми наборами (Строительство / Медицина / IT / Общие) — переиспользуем константу `TEMPLATE_CATEGORIES`. Вынесем её из `AchievementsManager.tsx` в новый файл `src/constants/achievementTemplates.ts` и импортируем в обоих местах.
- При применении шаблона — `INSERT` всех достижений категории в `achievements` + автоматически привязываются к этому курсу через `course_achievements`.
- При пустом состоянии (нет достижений в организации) — показывать empty-state с теми же двумя кнопками вместо текста «Создайте в общих настройках».

Файлы:
- `src/constants/achievementTemplates.ts` — новый, вынести `TEMPLATE_CATEGORIES` + `RARITY_STYLES`.
- `src/components/organization/AchievementsManager.tsx` — импортировать из новой константы (без изменения логики).
- `src/components/organization/CourseAchievementsTab.tsx` — добавить inline-форму создания, секцию шаблонов, кнопки в шапке.

### Результат
- Подменю «Ученики» — вертикальное, с понятными подсказками, как у empty-state курсов.
- На вкладке «Достижения курса» можно создать достижение или применить готовый шаблон без выхода из карточки курса; новые достижения автоматически привязываются к этому курсу.

### Файлы
- `src/components/organization/CourseDetailsContent.tsx` (вертикальный layout для группы `students`)
- `src/components/organization/CourseAchievementsTab.tsx` (создание + шаблоны)
- `src/constants/achievementTemplates.ts` (новый — общая константа шаблонов)
- `src/components/organization/AchievementsManager.tsx` (импорт из новой константы)
