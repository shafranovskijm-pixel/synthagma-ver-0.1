## Что добавляем

На странице `/rostechnadzor-courses` рядом с заголовком каталога (секция `#catalog`) появятся две кнопки:

- **Скачать Word (.docx)**
- **Скачать PDF**

Оба файла содержат полный список курсов, сгруппированный по 14 направлениям (как в каталоге на странице). По каждому курсу выводится:

- Название курса
- Направление/категория
- Краткое описание (`description_short` из marketplace, либо `description` курса как fallback)

Шапка документа: «Каталог программ обучения — Синтагма», дата выгрузки, общее количество курсов и направлений. Подвал: сайт sintagma.com.ru.

## Как это работает технически

1. **Источник данных** — те же курсы, что уже отрисованы на странице (`marketplace_courses` + `courses` + `course_categories`, отфильтрованные по 14 направлениям Ростехнадзора). Никаких новых запросов к БД не нужно — берём массив из существующего хука страницы.

2. **Word (.docx)** — формируется на клиенте через уже подключённый в проекте `docx` (используется в `useWordDocumentGenerator`). Структура: титул → для каждого направления заголовок H2 → список курсов с названием (жирным) и описанием. Файл: `Каталог-курсов-Синтагма-YYYY-MM-DD.docx`.

3. **PDF** — формируется через существующий механизм `printHtmlToPdf` / `htmlToPdfPages` (тот же, что используется для КП и протоколов). Рендерим скрытый HTML-шаблон A4 с тем же контентом и сохраняем как `Каталог-курсов-Синтагма-YYYY-MM-DD.pdf`.

4. **Новый файл** `src/utils/exportRostechnadzorCatalog.ts` с двумя функциями: `exportCatalogToDocx(groups)` и `exportCatalogToPdf(groups)`.

5. **UI** — небольшая правка в компоненте каталога Ростехнадзора (там, где сейчас якорь `#catalog`): добавить блок с двумя кнопками `Download` (lucide-icon) в стиле существующих кнопок страницы (Teal/Cyan, rounded-xl). При нажатии — toast «Формируем файл…» и скачивание.

## Что НЕ меняется

- Дизайн страницы, состав курсов, RLS, edge-функции.
- Никакие данные не уходят на сервер — генерация полностью на клиенте.
