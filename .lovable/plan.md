

# Три режима генерации контента: Быстрый / С картинкой / Полный

## Что делаем

Заменяем кнопку «Написать с AI» на выпадающее меню с тремя вариантами:

1. **⚡ Только текст** — генерирует текстовые блоки без картинки и аудио (самый быстрый)
2. **🖼 Текст + картинка** — генерирует текст и hero-изображение (средний)
3. **🎵 Текст + картинка + аудио** — текущее поведение: текст, картинка, аудио (полный, самый долгий)

## Файлы

| Действие | Файл |
|---|---|
| Изменить | `src/hooks/useLessonMedia.ts` — добавить параметр `mode: "text" | "image" | "full"` в `handleGenerateContent`, оборачивая генерацию картинки и аудио в условия |
| Изменить | `src/components/course-builder/SortableLessonItem.tsx` — заменить кнопку на `DropdownMenu` с 3 пунктами |

## Детали реализации

### useLessonMedia.ts

Добавить параметр `mode` в сигнатуру `handleGenerateContent`:

```typescript
handleGenerateContent(title, type, courseTitle, desc, blocks, mode: "text" | "image" | "full")
```

- `mode === "text"` — пропускает блоки генерации изображения (строки 317-339) и аудио (строки 341-383)
- `mode === "image"` — выполняет генерацию изображения, пропускает аудио
- `mode === "full"` — текущее поведение (изображение + аудио)

### SortableLessonItem.tsx

Заменить одну кнопку на `DropdownMenu`:

```
[✨ Написать с AI ▾]
  ├─ ⚡ Только текст        — Быстрая генерация
  ├─ 🖼 Текст + картинка    — Средняя скорость
  └─ 🎵 Полная генерация    — Текст + картинка + аудио
```

Каждый пункт вызывает `onGenerate(mode)` с соответствующим значением.
