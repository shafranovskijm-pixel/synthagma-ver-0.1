## 1. Слить «Импорт» в одну кнопку «Добавить»

**Файл:** `src/components/organization/OrgDashboardHeader.tsx` (строки 370–381)

Заменить пару кнопок «Импорт» + «Добавить» одной кнопкой «Добавить» с DropdownMenu:
- **Добавить вручную** (иконка `UserPlus`) → `d.studentManagement.setShowAddStudentDialog(true)`
- **Загрузить файлом (Excel/CSV)** (иконка `FileSpreadsheet`) → `d.setShowImportDialog(true)`

Оба пункта прогоняются через существующий `handleStudentAction` (проверка лимитов). Никакой бизнес-логики не трогаем — только UI-обёртка.

Так же обновить `StudentsEmptyState` (кнопки CTA), чтобы визуальная логика была одинаковой — там оставить обе кнопки как есть (это большой пустой стейт, разделение уместно), либо тоже сделать один primary «Добавить» + вторичный текст-ссылку «или загрузить файлом».

## 2. Перегруппировать панель фильтров/поиска в списке учеников

**Файл:** `src/components/organization/tabs/StudentsTab.tsx` (строки 182–215)

Сейчас в одну горизонтальную скролл-полосу свалено всё: bulk-действия (появляются при выделении), «Напомнить», «Экспорт», 4 селекта фильтров, «Группы» и «Поиск». Получается длинная лента, из-за чего часть кнопок уезжает за край.

Предлагаю трёхрядную структуру внутри блока `Header + Filters`:

```text
Row 1: [ Заголовок "Все ученики" .............................. Поиск ▢▢▢▢▢▢ ]
Row 2 (chips): [ Курс ▾ ] [ Статус ▾ ] [ Документы ▾ ] [ Группа ▾ ]  ·  [ Группы ⚙ ]  [ Экспорт ] [ Напомнить ]
Row 3 (появляется только при selectedStudentIds.size > 0, sticky):
       "Выбрано N"  [Зачислить] [Логины] [На почту] [Отчислить] [ФРДО] [Приказ] [Протокол] [Удалить]
```

Конкретно:

1. **Поиск** переносим в первую строку справа от заголовка (сейчас он последний в ленте и часто не виден). На мобильном оставить как сейчас — отдельным блоком под заголовком.
2. **Фильтры** (Курс/Статус/Документы/Группа) + кнопка «Группы» — во вторую строку. Оборачиваем в `flex flex-wrap gap-2` без overflow-x-auto — на десктопе умещаются, на мобильном переносятся.
3. **Дополнительные действия «Экспорт», «Напомнить»** — переносим в правую часть второй строки, отделяем разделителем.
4. **Bulk-действия** (появляются при выделении) — выносим в отдельный третий ряд `sticky top-0 bg-card/95 backdrop-blur` с явным префиксом «Выбрано {N}» и кнопкой сброса выделения. Это устраняет ситуацию, когда фильтры и массовые действия мешаются в одной ленте.

Никакой бизнес-логики или новых пропсов — только перестановка и группировка существующих кнопок в новом layout.

## Технические заметки

- Используем существующий `DropdownMenu` из `@/components/ui/dropdown-menu` для новой кнопки «Добавить».
- Никаких новых хуков/эндпоинтов не создаём.
- Мобильный layout (кнопки уже имеют `text-xs`/`hidden sm:inline`) сохраняется.
- В `OrgDashboardHeader.tsx` иконку `FileSpreadsheet` для кнопки «Импорт» удаляем, если она перестанет использоваться в другом месте файла (проверить импорты).
