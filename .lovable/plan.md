

# Добавление учеников в группу из интерфейса групп

## Проблема
Ученик «Василий Савунов» существует в организации, но его `student_group_id = null` — он не привязан к группе «Курс август-декабрь 2025». Группа показывает «0 учеников», и кнопка «Зачислить» не находит кого зачислять.

Сейчас привязать ученика к группе можно только:
- Через выпадающий список в таблице учеников (StudentsTab)
- Через карточку ученика (CoursesTab)

Но из вкладки групп (CourseGroupsTab) — нельзя, что неинтуитивно.

## Решение
Добавить кнопку «Добавить учеников» в каждую карточку группы на вкладке GroupsTab. При клике — диалог со списком учеников организации, которые ещё не привязаны ни к какой группе. Выбор чекбоксами → массовое обновление `student_group_id`.

### Изменения в файле
**`src/components/organization/CourseGroupsTab.tsx`**:

1. Добавить состояния для диалога добавления учеников (`showAddStudentsDialog`, `selectedGroupForAdd`, `unassignedStudents`, `selectedStudentIds`)
2. При открытии — запрос учеников организации с `student_group_id IS NULL`
3. Чекбокс-список с именами и email
4. Кнопка «Добавить в группу» — массовый `UPDATE profiles SET student_group_id = groupId WHERE user_id IN (...)`
5. В карточке группы — новая кнопка `UserPlus` рядом с «Зачислить»

### UI
- Кнопка «+ Ученики» (иконка UserPlus) в каждой строке группы
- Диалог: заголовок «Добавить учеников в группу "Название"», список с чекбоксами, кнопка подтверждения
- После добавления — автоматический refresh счётчиков
