

# Автоскрытие панели управления видеоплеера

## Проблема
Сейчас панель управления скрывается только через CSS `group-hover` -- то есть она видна всё время, пока курсор над видео. На мобильных устройствах (без hover) панель вообще не скрывается.

## Решение
Реализовать таймер неактивности: панель появляется при движении мыши/касании и автоматически скрывается через 3 секунды бездействия. При паузе панель всегда видна.

## Изменения в `src/components/course-learning/VideoPlayerInline.tsx`

### 1. Добавить состояние и таймер
- Новое состояние `controlsVisible` (boolean, по умолчанию true)
- Ref `hideTimerRef` для хранения таймера
- Функция `showControls()`: устанавливает `controlsVisible = true`, сбрасывает таймер, запускает новый на 3 секунды

### 2. Обработчики событий на контейнере (div `containerRef`)
- `onMouseMove` -- вызывает `showControls()`
- `onMouseLeave` -- если играет, скрыть панель сразу
- `onTouchStart` -- вызывает `showControls()` (для мобильных)

### 3. При паузе -- всегда показывать
- В обработчике `onPause` добавить `setControlsVisible(true)` и очистить таймер
- В обработчике `onPlay` запустить таймер скрытия

### 4. Заменить CSS-логику скрытия
- Строка 277: вместо `isPlaying && allowSeek ? "opacity-0 group-hover:opacity-100"` использовать `controlsVisible ? "opacity-100" : "opacity-0 pointer-events-none"`
- Убрать зависимость от `group-hover` для контролов
- Добавить `cursor-none` на контейнер, когда контролы скрыты (как в YouTube)
