

# Демо-генерация 3 курсов «Профессиональная переподготовка» через Lovable AI

## Что делаем

Прямо из этого чата (без запуска фонового пайплайна GigaChat) генерирую контент 3 показательных курсов через **Lovable AI Gateway (Gemini 3 Flash)** и записываю в базу с полноценным оформлением — обложкой, JSON-блоками, тестом, бейджем «Диплом о профпереподготовке».

## Курсы

1. **Психолог-консультант** — 520 ч, категория «Психология», иконка Brain (фиолетовый акцент)
2. **Специалист по охране труда** — 256 ч, категория «Охрана труда», иконка HardHat (оранжевый)
3. **HR-менеджер (управление персоналом)** — 280 ч, категория «Менеджмент», иконка Briefcase (синий)

## Как генерирую (по каждому курсу)

### Шаг 1. Структура программы
Один вызов Gemini 3 Flash → JSON со списком 12 уроков:
- Вводный модуль (нормативная база, цели программы)
- 8–9 теоретических модулей по специальности
- Практический модуль (кейсы, упражнения)
- Итоговый тест (15 вопросов)

### Шаг 2. Контент уроков
12 параллельных вызовов Gemini → для каждого урока ≥700 слов в формате Markdown → конвертация в JSON-блоки по правилу `block-formatting-rules` (heading1/heading2/paragraph/bullet_list с `dangerouslySetInnerHTML`-совместимой разметкой `<strong>`, `<em>`).

### Шаг 3. Тест
1 вызов Gemini → 15 вопросов с 4 вариантами ответа + объяснением + правильным индексом → запись в `test_questions` с `correct_answer` и `explanation`.

### Шаг 4. Обложка
1 вызов Gemini 3 Flash Image (Nano Banana 2) с промптом в стиле Teal/Cyan + тематика курса → загрузка в storage `course-files` → запись `cover_image_url`.

### Шаг 5. Запись в БД
Транзакция:
- `courses` (title, organization_id = маркетплейс, category_id = соответствующая ПП-категория, duration, is_published = true)
- `course_categories` (создаю «Психология»/«Охрана труда»/«Менеджмент» под parent «Профессиональная переподготовка», если ещё нет)
- `lessons` × 12 (type = `text`, content_blocks = JSON)
- `test_questions` × 15
- `marketplace_courses` (price_student = 0, is_active = true, is_validated = true, badge = «Диплом о профпереподготовке»)
- `marketplace_import_catalog` помечается `imported` со ссылкой на `course_id`

## Как буду выполнять

1. Скопирую `knowledge://skill/ai-gateway/scripts/lovable_ai.py` в `/tmp/lovable_ai.py`
2. Напишу единый Python-скрипт `/tmp/generate_demo_courses.py`, который:
   - Читает 3 заданных курса из массива
   - Для каждого вызывает Gemini (структура → уроки → тест → обложка)
   - Сохраняет промежуточные артефакты в `/tmp/courses/<slug>/` для отладки
   - Делает batch-INSERT в Supabase через `psql`
3. Загружаю обложки через `curl` к Supabase Storage REST API (с service role)
4. В конце вывожу отчёт: ID курсов, ссылки на них в маркетплейсе, размер контента

## Расход токенов Lovable

- Структура: 3 × ~2k = 6k
- Уроки: 36 × ~3k = 108k
- Тесты: 3 × 5k = 15k  
- Обложки: 3 × ~1k (image) = 3k
- **Итого ≈ 130–150k токенов Lovable AI** за один прогон. Это разовый демо-эксперимент, не для масштаба.

## Что вы получите

- 3 готовых курса в админ-маркетплейсе и в публичном каталоге
- Каждый — с обложкой 16:9, 12 уроками ≥700 слов, тестом на 15 вопросов
- Оформление 1 в 1 с существующими карточками маркетплейса (Teal/Cyan, бейдж «Диплом о профпереподготовке»)
- Возможность сразу открыть курс в превью, пройти уроки, сдать тест
- Доказательство концепции — после этого можно решать, запускать ли GigaChat-пайплайн на остальные 600 курсов

## Что НЕ делаем в этом демо

- Не сканируем ipo.msk.ru парсером (названия беру вручную из плана)
- Не трогаем UI — только данные
- Не масштабируем на >3 курсов через мои токены (для масштаба остаётся существующий GigaChat-пайплайн)
