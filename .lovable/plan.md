

# Полноценный контент курса «ИИ как инструмент в бизнесе»

## Проблема
12 из 13 уроков содержат лишь короткие строки вместо полноценного контента в формате JSON-блоков (`ContentBlock[]`).

## Подход
Python-скрипт сгенерирует SQL-файл с `UPDATE` командами для каждого урока, затем выполнит через `psql`. Каждый урок — массив JSON-блоков с `id`, `type`, `content`.

### Особый акцент (по запросу)

**Урок 3 — Большое сравнение LLM** включит:
- Таблицу: GPT-5, Claude 4, Gemini 2.5, Grok 3, Llama 4, DeepSeek, Mistral — контекст, цена, скорость, мультимодальность
- Плюсы/минусы каждой в формате `callout-tip` / `callout-warning`
- Рекомендации: какую модель выбрать для какой задачи

**Урок 5 — Сравнение ИИ-инструментов для маркетинга**:
- Генерация текста: Jasper vs Copy.ai vs ChatGPT
- Генерация изображений: Midjourney vs DALL-E 3 vs Stable Diffusion vs Flux
- Генерация слайдов: Gamma.app vs Beautiful.ai vs SlidesAI vs Tome
- Генерация видео: Runway ML vs Pika vs Sora
- Автоматизация: Make.com vs n8n vs Zapier

### Формат блоков
Каждый урок: 15-25 блоков, ~800-1200 слов, типы: `heading1`, `heading2`, `paragraph`, `bulletList`, `numberedList`, `callout-info`, `callout-tip`, `callout-warning`, `highlight`, `accordion`.

## Технические детали
- Python-скрипт в `/tmp/generate_course.py` формирует SQL
- Выполнение через `psql -f /tmp/course_content.sql`
- Проверка `$PGHOST` перед запуском
- Fallback: вставка через Supabase insert tool
- Изменений в коде проекта нет
