
# Исправление формы радиокнопок в тесте

## Проблема
При длинном тексте ответа кастомный круг-индикатор (div 5x5) сжимается по ширине и выглядит как прямоугольник/скобка вместо круга. Причина -- отсутствие класса `shrink-0` на элементе.

## Решение
Добавить `shrink-0` к div-элементу радиокнопки в блоке ответов на тест (строка 274 в `CourseLearning.tsx`).

**Файл**: `src/pages/CourseLearning.tsx`, строка 274

Было:
```
"w-5 h-5 rounded-full border flex items-center justify-center"
```

Станет:
```
"w-5 h-5 rounded-full border flex items-center justify-center shrink-0"
```

Одно слово -- одно исправление. Круги перестанут сжиматься при длинных ответах.
