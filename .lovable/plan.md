
## Исправления конструктора договоров

### Проблемы
1. **ИП всё равно показывает "Генерального директора"** -- regex удаления не срабатывает после подстановки переменных, потому что переменные уже заменены на реальные данные и паттерн "в лице ... на основании Устава" не матчится корректно
2. **Нет поля "Срок оказания услуг"** -- нужно добавить даты начала и окончания обучения
3. **Часы не подгружаются из курса** -- в БД есть `duration` (текст) и `frdo_duration_hours` (число), но оба не заполнены. Нужно добавить поле "Количество часов" в настройки курса
4. **Срок действия договора** -- должен автоматически ставиться 1 год от даты договора

---

### Решение

#### 1. Исправление логики удаления блока представительства для ИП

Сейчас удаление происходит ПОСЛЕ подстановки переменных, и regex не находит совпадений. Нужно:
- Удалять блок представительства ДО подстановки переменных (на уровне шаблона)
- Или использовать более универсальный regex, который матчит уже подставленный текст

Подход: перед подстановкой переменных вырезать из шаблона весь блок "в лице ... на основании Устава" если организация/компания является ИП.

#### 2. Добавить "Количество академических часов" в настройки курса

В `CourseEditor.tsx` уже есть поле "Продолжительность" (текст), но нет числового поля часов. Нужно:
- Добавить поле `duration_hours` (или использовать существующий `frdo_duration_hours`) в настройках курса
- В конструкторе договора подгружать часы из курса автоматически
- Добавить переменную `{{course_hours}}` для шаблона

Поскольку `frdo_duration_hours` (integer) уже есть в БД, будем использовать его и добавим поле ввода в настройки курса.

#### 3. Добавить поля "Срок оказания услуг" в конструктор договора

Новые поля:
- "Дата начала обучения" (по умолчанию = дата договора)
- "Дата окончания обучения" (по умолчанию = через 1 месяц)
- Переменные: `{{service_start_date}}`, `{{service_end_date}}`

#### 4. Срок действия договора = 1 год автоматически

Добавить переменную `{{contract_valid_until}}`, которая автоматически = дата договора + 1 год. Обновить шаблон по умолчанию.
