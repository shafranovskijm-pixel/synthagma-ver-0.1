

# Хранилище: свёрнутые аккордеоны, предпросмотр и документы слушателей

## Что будет сделано

### 1. Аккордеоны свёрнуты по умолчанию
Сейчас все секции раскрыты при загрузке. Изменим логику так, чтобы все секции были свёрнуты по умолчанию -- пользователь кликает на нужную секцию, чтобы раскрыть её.

### 2. Предпросмотр файлов
Вместо простого открытия файла в новой вкладке -- добавим диалог предпросмотра:
- **Изображения** (jpg, png, gif, webp, svg) -- отображение картинки в модальном окне
- **PDF** -- встроенный iframe-просмотр
- **Видео** (mp4, webm) -- встроенный видеоплеер
- **Аудио** (mp3, wav) -- встроенный аудиоплеер
- **Остальные файлы** -- кнопка скачивания + информация о файле (без предпросмотра)

Кнопка "Открыть в новой вкладке" и "Скачать" останутся доступны в диалоге предпросмотра.

### 3. Документы слушателей
Добавить бакет `student-documents` в список сканируемых бакетов. Этот бакет приватный -- для получения ссылок будем использовать signed URLs (временные ссылки на 1 час), как уже реализовано в системе для документов студентов.
