

# Растяжение печати по ширине/высоте + исправление ПКМ

## Проблемы

1. **Печать масштабируется только пропорционально** — нужно растягивать по ширине и высоте отдельно (два ползунка: «Ширина» и «Высота»)
2. **ПКМ добавляет подпись, но пользователь не видит разницы** — нужно дать выбор: ПКМ показывает мини-меню «Добавить печать / Добавить подпись»

## Изменения в `DocumentSigning.tsx`

### 1. Модель данных — раздельное масштабирование
```ts
interface Overlay {
  id: string;
  type: 'stamp' | 'signature';
  x: number; y: number;
  scaleX: number; // ширина (0.5–3.0)
  scaleY: number; // высота (0.5–3.0)
}
```
Заменить `scale` на `scaleX` + `scaleY` во всех местах: `overlaySize`, `defaultOverlays`, рендеринг canvas, `handleSign`.

### 2. Два ползунка вместо одного
- «Ширина» — управляет `scaleX`
- «Высота» — управляет `scaleY`
- Диапазон 0.3–3.0 для большей гибкости

### 3. ПКМ — контекстное меню с выбором
Вместо автоматического добавления подписи, показать `Popover` или простое абсолютно позиционированное меню с двумя пунктами:
- 🔴 Добавить печать
- ✍️ Добавить подпись

Клик по пункту добавляет соответствующий оверлей в точку ПКМ.

### 4. Обновить подсказку
«ЛКМ — перетащить, ПКМ — добавить печать или подпись»
