
# Полноэкранный редактор шаблона договора

## Проблема
Конструктор шаблона зажат внутри `SettingsTab` с классом `max-w-2xl` (672px). Даже с увеличением высоты до 70vh, ширина ограничена контейнером настроек. Редактор курсов (`CourseBuilder`) -- это отдельная страница `/course-builder` с полноэкранным layout, и конструктору договора нужен такой же подход.

## Решение
Создать отдельную страницу `/contract-editor` по образцу `CourseBuilder`:
- Полноэкранный layout с header (кнопка «Назад», логотип, кнопка сохранения)
- Компактный тулбар с выбором шаблона и действиями
- Основная область: редактор (70%) + панель переменных (30%) на всю ширину экрана
- Валидация в статус-баре внизу

В `SettingsTab` вместо встроенного редактора будет кнопка «Открыть редактор договора», которая ведёт на `/contract-editor`.

## Структура на экране

```text
+------------------------------------------------------------------+
| [<- Назад]  [Logo]                         [Просмотр] [Сохранить] |
+------------------------------------------------------------------+
| [Для юр. лица v] [+Сохранить как] [История] | [Загрузить] [AI] [Сброс] |
+---------------------------------------------+--------------------+
|                                             |  Переменные        |
|   Редактор шаблона                          |  [Договор]         |
|   (полная ширина, ~80vh высота)             |  contract_number   |
|                                             |  contract_date     |
|   ДОГОВОР No {{contract_number}}            |  [Организация]     |
|   ...                                       |  org_name          |
|                                             |  org_inn ...       |
+---------------------------------------------+--------------------+
| Валидация: 12 переменных, шаблон корректен                        |
+------------------------------------------------------------------+
```

## Технические изменения

### 1. Новая страница `src/pages/ContractEditor.tsx`
- Полноэкранная страница по образцу `CourseBuilder`
- Sticky header с навигацией назад к `/organization`
- Передаёт `organizationId` из контекста или URL-параметра
- Включает всю логику из `ContractTemplateEditor` (загрузка/сохранение шаблонов, история, файлы)

### 2. Рефакторинг `ContractTemplateEditor.tsx`
- Добавить проп `fullPage?: boolean` для переключения layout
- В режиме `fullPage` -- убрать внутренние отступы, использовать всю ширину
- Без `fullPage` -- оставить компактный вариант (на случай если понадобится)

### 3. Обновление `SettingsTab.tsx`
- Во вкладке "Договор" вместо встроенного редактора -- карточка с описанием и кнопка "Открыть конструктор договора" (ведёт на `/contract-editor`)

### 4. Роутинг `App.tsx`
- Добавить маршрут `/contract-editor` с `ProtectedRoute requiredRole="organization"`

### 5. Обновление `HighlightedTemplateEditor.tsx`
- Увеличить высоту в полноэкранном режиме до `calc(100vh - 180px)` (вся видимая область минус header и тулбар)
- Панель переменных синхронизируется по высоте
