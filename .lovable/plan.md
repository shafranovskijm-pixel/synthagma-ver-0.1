

# Перегенерация контента курса «ИИ как инструмент в бизнесе»

## Проблема
Из 13 уроков курса только первый имеет полноценный контент в формате JSON-блоков. Остальные 12 содержат лишь однострочные текстовые описания вместо массива `ContentBlock[]`.

## Что будет сделано

Скриптом через `psql` перезаписать поле `content` для каждого из 12 пустых уроков полноценным JSON-массивом блоков. Контент будет написан вручную (без вызова AI API) — каждый урок получит 700+ слов с:

- `heading1`, `heading2` — заголовки
- `paragraph` — основной текст с конкретными инструментами и примерами
- `bulletList`, `numberedList` — списки
- `callout-info`, `callout-tip`, `callout-warning` — выделенные блоки
- `accordion` — раскрывающиеся секции с деталями
- `highlight` — ключевые выводы

Для 3 тестовых уроков — проверить/дополнить вопросы в `test_questions`.

Каждый блок будет иметь уникальный `id` (UUID).

## Технические детали

- Обновление через `UPDATE lessons SET content = '...'::jsonb WHERE id = '...'`
- Тестовые вопросы: `INSERT INTO test_questions` если отсутствуют
- Формат блоков: `[{"id":"uuid","type":"heading1","content":"..."},...]`
- Изменений в коде проекта нет — только данные в БД
