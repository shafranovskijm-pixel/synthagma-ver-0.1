## Что ещё стоит улучшить (план)

### 1. История общения — добавить email и подписи
Сейчас «История общения» показывает звонки/заметки/КП-отправлено/КП-просмотрено. Добавить:
- **Договоры** — `Договор отправлен / подписан` (из `sales_contracts.status` + `updated_at`).
- **Подписи** — `Документ ушёл на подпись / подписан` (из `document_signatures.status`).
- **Счета** — `Выставлен счёт N / оплачен` (из `subscription_invoices`).
Файл: `DealCommunication.tsx`.

### 2. «Записать звонок» / «Заметка» — расширить поля
Сейчас только текст. Полезно:
- **Длительность** (мин) — для звонков.
- **Результат** (radio: дозвонился / занят / не интересуется / договорились о следующем шаге) — отдельным блоком.
- **«Создать задачу-напоминание»** галочкой → создаёт `sales_tasks` с `due_date = +N дней` и привязывает к лиду.
Файл: `LogActivityDialog.tsx`.

### 3. Быстрая кнопка «Открыть карточку сделки» из задачи

### 4. Канбан — drag-n-drop этапов

Использовать `@dnd-kit/core` (уже есть в проекте по другим местам).
