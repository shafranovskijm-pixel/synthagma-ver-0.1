

# Исправление: радиостанции не видны на главной странице

## Проблема
Таблица `radio_stations` имеет RLS-политику, которая разрешает просмотр активных станций только авторизованным пользователям (`authenticated`). На лендинге пользователь не залогинен — запрос возвращает 0 станций.

## Решение
Добавить RLS-политику для анонимного доступа (`anon`) на чтение активных станций. Радиостанции — публичные данные, не содержат PII.

## Технические детали

### 1. Миграция БД
```sql
CREATE POLICY "Anyone can view active stations"
  ON public.radio_stations
  FOR SELECT
  TO anon
  USING (is_active = true);
```

### 2. Файлы — без изменений
Код `useRadioPlayer.ts` и `RadioPlayerButton.tsx` уже корректно работают — проблема только в доступе к данным.
