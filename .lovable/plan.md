

## Исправить «Войти как ученик» из админки

### Проблема
Кнопка «Войти как ученик» в админке существует, но может не работать из-за:
1. **Гонка состояний**: `userRole` может разрешиться в `'admin'` раньше, чем `isAdminView` прочитается из localStorage, и происходит редирект обратно в `/admin`.
2. **RLS**: админ не может читать данные студента (курсы, прогресс), потому что RLS-политики привязаны к `auth.uid()`, а не к `targetUserId`.
3. **Данные не загружаются**: `effectiveUserId` может не успеть обновиться.

### Решение

**1. Гарантировать, что редирект не срабатывает**
Файл: `src/pages/StudentDashboard.tsx`
- Проверять `localStorage.getItem('adminViewAsStudent')` напрямую в компоненте ДО вызова хука, чтобы исключить гонку.

**2. Загружать данные студента через service-role (edge function)**  
Если текущий подход (чтение через клиентский Supabase от имени админа) не работает из-за RLS, то переключить загрузку данных в admin-view режиме на прямой запрос через существующие RLS-override политики (которые уже есть для admin — `has_role('admin', auth.uid())`).

**3. Улучшить UX кнопки**
Файл: `src/components/admin/UsersManager.tsx`
- Сделать кнопку «Войти как ученик» более заметной (как в OrganizationsManager — отдельная кнопка с текстом, а не просто иконка).
- Показывать кнопку не только для `role === 'student'`, но для всех пользователей с ролью student (уже так, но убедиться).

### Файлы
- `src/pages/StudentDashboard.tsx` — защита от редиректа
- `src/hooks/useStudentDashboard.ts` — надёжная загрузка данных для admin-view
- `src/components/admin/UsersManager.tsx` — улучшить UX кнопки
