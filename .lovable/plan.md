
# Подсветка элементов при обучении (Guided Tour)

## Описание

Превратить онбординг-диалог в guided tour: при каждом шаге соответствующая кнопка в боковом меню подсвечивается пульсирующей рамкой, чтобы пользователь видел, о каком разделе идёт речь.

## Как это будет работать

1. На каждом шаге онбординга соответствующий элемент в сайдбаре получает яркую пульсирующую подсветку (кольцо + свечение)
2. Остальной интерфейс слегка затемняется, чтобы фокус был на подсвеченном элементе
3. Диалог остаётся по центру экрана, но целевой элемент явно выделяется

## Что будет сделано

### 1. Добавить `highlightSelector` к шагам онбординга

В `OnboardingStep` добавить поле `highlightSelector` -- CSS-селектор элемента для подсветки. В `studentOnboardingSteps` и `organizationOnboardingSteps` прописать селекторы.

Маппинг шагов на элементы:
- `welcome` -- без подсветки
- `learning` / `courses` -- кнопка "Мои курсы"
- `documents` -- кнопка "Мои документы"
- `video-id` -- кнопка "Идентификация"
- `ai-chat` -- кнопка "ИИ-помощник"
- `students` -- кнопка "Ученики" (для организации)
- `settings` -- кнопка "Настройки" (для организации)

### 2. Добавить `data-onboarding` атрибуты к кнопкам сайдбара

В `StudentDashboard.tsx` (и аналогично в `OrganizationDashboard`) к каждой кнопке навигации добавить атрибут `data-onboarding="courses"`, `data-onboarding="chat"` и т.д.

### 3. Компонент подсветки `OnboardingHighlight`

Новый компонент, который:
- Получает текущий `highlightSelector` из активного шага
- Находит DOM-элемент по селектору
- Рисует пульсирующую рамку вокруг него через portal (абсолютно позиционированный `div` поверх страницы)
- При смене шага плавно перемещает подсветку к следующему элементу
- Если селектор не задан (шаг "welcome") -- подсветка не показывается

### 4. Интеграция

`OnboardingDialog` будет рендерить `OnboardingHighlight` рядом с `Dialog`, передавая текущий `highlightSelector`.

### Логика OnboardingHighlight

```text
1. Получает selector (например "[data-onboarding='courses']")
2. Использует useEffect + getBoundingClientRect() для позиции
3. Рендерит через createPortal в document.body:
   - Полупрозрачный overlay (pointer-events: none)
   - Рамку вокруг целевого элемента с анимацией pulse
4. При resize/scroll пересчитывает позицию
5. Если selector пустой -- ничего не рендерит
```

### Стилизация подсветки

- Рамка: `border-2 border-primary` с `box-shadow: 0 0 20px rgba(primary)`
- Анимация: CSS `@keyframes` пульсация свечения
- Скругление совпадает с кнопками сайдбара (`rounded-xl`)
- Z-index ниже диалога, но выше остального контента
