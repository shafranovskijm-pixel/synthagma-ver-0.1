
## Что хочет пользователь

1. **Поведение «один урок открыт за раз»** (как в Skillspace): клик по уроку слева → этот урок раскрывается, остальные сворачиваются. Сейчас, судя по правому скрину, открыты все/несколько одновременно.
2. **Левое меню должно «зеркалить» правую панель**: добавил урок → он сразу появляется в левой навигации. По описанию — этого не происходит.
3. **Нумерация в левом меню должна совпадать** с правой (на скрине справа уже 12 уроков, слева видно только 7 — это вторичный симптом первой проблемы или устаревший стейт).

## Гипотезы (подтвержу чтением)

**A. «Раскрыт только один урок»** — сейчас `toggleLesson` инвертирует `expanded` у одного урока, не трогая остальные → возможно несколько раскрытых одновременно. Нужно ввести режим «accordion»: при клике в навигации (а опционально и при клике на заголовок карточки) ставить `expanded=true` только у выбранного и `false` у остальных.

**B. «Урок не появляется слева»** — два варианта:
- B1. `CourseBuilderLessonsNav` получает не тот же массив `lessons` (например, мемоизированный снапшот, который не обновляется). Проверю проп-цепочку.
- B2. В embedded-режиме навигация рендерится из отдельного источника (например, разделы курса), а не из текущих `lessons` хука — тогда новый урок физически не попадает в левое меню до сохранения/перезагрузки.

Несовпадение нумерации (7 vs 12 на скриншоте) — прямое следствие B: левый список отстаёт от правого.

## План правок (после подтверждения чтением)

1. **Единый источник правды для левого меню**: убедиться, что `CourseBuilderLessonsNav` получает ровно тот же массив `lessons`, что и правая колонка с карточками. Если есть промежуточный стейт/мемо — убрать его и пробрасывать `lessons` напрямую из хука.
2. **Accordion-поведение**:
   - Добавить в `useCourseBuilder` функцию `expandOnly(id)` — ставит `expanded=true` только у выбранного урока, у остальных `false`.
   - В `CourseBuilderLessonsNav.onLessonClick` вызывать `expandOnly(id)` + `setActiveLessonId(id)` (без скролла, как уже сделано).
   - В карточке урока на правой панели — клик по заголовку/шеврону тоже вызывает `expandOnly(id)` (а не `toggleLesson`), чтобы соблюдалось «открыт только один».
   - Повторный клик по уже открытому уроку — сворачивает его (`toggle` поведение для одиночного).
3. **Синхронизация при добавлении**:
   - После `addLesson(...)` автоматически: новый урок становится активным, `expandOnly(newId)`, прокрутка правой колонки к этой карточке (плавно, через `scrollIntoView` ТОЛЬКО на правой панели контента, не в левой навигации — её мы оставили без автоскролла по требованию).
   - Левая навигация обновится сама, т.к. источник один.
4. **Нумерация**: использовать индекс из того же массива `lessons` и слева, и справа — совпадение гарантировано.
5. **Embedded-режим**: проверить, что `CourseDetailsContent` не оборачивает `lessons` в локальное состояние; если оборачивает — снять.
