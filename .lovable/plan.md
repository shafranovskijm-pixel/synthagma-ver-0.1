

## Статус миграции медиа — убрать фоновый режим, показывать результат

### Проблема

Сейчас Edge Function использует `EdgeRuntime.waitUntil()` и возвращает ответ сразу ("запущена в фоне"), не дожидаясь результата. Пользователь не видит, сколько файлов перенесено и были ли ошибки.

### Решение

Убрать фоновый режим из Edge Function — пусть она дожидается результата и возвращает статистику. Чтобы не упереться в таймаут, функция уже делает только HEAD-запросы для больших файлов и пропускает их быстро, так что основное время — скачивание файлов до 50 МБ.

### Изменения

**1. `supabase/functions/migrate-course-media/index.ts`**
- Убрать блок с `EdgeRuntime.waitUntil` — всегда ждать `await resultPromise` и возвращать полный результат с `filesTransferred`, `filesFailed`, `filesSkipped`

**2. `src/components/admin/OrganizationDetailsView.tsx`**
- Убрать ветку `if (data.background)` — всегда показывать итоговый toast с количеством перенесённых / ошибочных / пропущенных файлов
- Таймаут 5 минут остаётся
