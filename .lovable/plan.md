
## Что спрашивает пользователь
На скриншоте блок «Хранилище — 276 МБ / ∞». Вопрос: учитывает ли индикатор хранилища файлы, которые загружаются через Kinescope (видео), или только то, что лежит во внутренних бакетах Lovable Cloud.

Это вопрос-исследование, не задача на изменение. Отвечаю без плана-имплементации, но всё равно нужно проверить код метрик хранилища, чтобы дать точный ответ.

## Что проверю
- Память: `mem://features/organization/usage-metrics` — там описан источник метрик хранилища.
- Память: `mem://integrations/kinescope/video-and-webinars` и `mem://architecture/media-storage-strategy` — где физически лежат видео.
- Код, считающий 276 МБ (искать по `Хранилище` и функции типа `getStorageUsage` / `usage-metrics`).

## Ожидаемый ответ (предварительно, до проверки)
Индикатор «Хранилище» считает только бакеты Supabase Storage в Lovable Cloud (например `course-files`). Видео, загруженные в Kinescope, хранятся на стороне Kinescope и **в этот счётчик не попадают** — Kinescope-квота отдельная и видна только в админке Kinescope/настройках интеграции. Если нужно показывать суммарно — придётся отдельно тянуть метрики через Kinescope API и складывать в дашборде.

Финальный ответ дам в обычном сообщении после быстрой проверки кода метрик — план тут не нужен, потому что менять ничего не просят.
