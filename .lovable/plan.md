

# ИИ-баннеры и анимированные карусели для партнёрского лендинга

## Что делаем

### 1. ИИ-баннеры для кейсов расчёта (Новичок / Активный / Лидер)
Генерируем 3 иллюстрации через Lovable AI (gemini-3.1-flash-image-preview) — стилизованные персонажи/сцены для каждого кейса. Баннеры встраиваются в верхнюю часть каждой карточки кейса.

### 2. «Преимущества программы» — бесконечная карусель слева направо
Генерируем 4 баннера (по одному на преимущество: 45% дохода, 2 года выплат, Лидерский бонус, Бонус за оборот). Заменяем статичный grid на CSS-marquee (бесконечная прокрутка `@keyframes marquee` слева направо), карточки дублируются для бесшовного эффекта.

### 3. «Как это работает» — карусель справа налево + заголовок по центру
Генерируем 4 баннера (Регистрация, Ссылка, Сеть, Доход). Заголовок «Как это работает» остаётся по центру над каруселью. Карусель движется справа налево (`animation-direction: reverse`).

### 4. «Почему легко привлекать клиентов» — стиль комикса
Перестраиваем секцию в comic-style layout: неровная сетка панелей с яркими рамками, пузырями-речью для текста, dot-pattern фон (Ben-Day dots), акцентные «POW/WOW» элементы. Каждая из 6 карточек — панель комикса с ИИ-иллюстрацией.

## Техническая реализация

- **ИИ-генерация**: Edge-функция `generate-partner-banners` вызывает `gemini-3.1-flash-image-preview`, сохраняет base64 в Storage bucket `partner-banners`. На фронте загружаем publicUrl.
- **Marquee-анимация**: CSS `@keyframes` с `translateX`, дублирование массива элементов для бесшовности. Без JS-таймеров.
- **Комикс-стиль**: CSS-классы с `border-4 border-black`, `rotate(-2deg)`/`rotate(1deg)`, dot-pattern overlay, speech-bubble shapes через `::after` pseudo-elements.
