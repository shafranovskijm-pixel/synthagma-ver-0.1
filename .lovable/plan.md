
# Автогенерация серии/номера документов, определение пола, форма обучения в курсе

## 1. Автогенерация серии, номера и регистрационного номера документа

При экспорте в ФИС ФРДО серия, номер и регистрационный номер документа будут генерироваться автоматически. Одновременно запись будет добавляться в журнал регистрации документов об образовании (`education_document_records`).

**Логика генерации:**
- **Серия документа**: "нет" (стандартное значение, как в текущих шаблонах)
- **Номер документа**: `{ГОД}/{порядковый номер с нулями}` -- например `2026/000001`. Порядковый номер считается по количеству уже существующих записей в журнале за текущий год + 1
- **Регистрационный номер**: `ДОК-{ГОД}/{порядковый номер}` -- например `ДОК-2026/0001`

При экспорте (индивидуальном или массовом) система автоматически:
1. Генерирует номера для каждого студента
2. Создает запись в таблице `education_document_records` с привязкой к enrollment_id
3. Подставляет сгенерированные номера в Excel-файл

## 2. Автоматическое определение пола по отчеству

Пол можно определить автоматически по окончанию отчества:
- Окончание на **"ич"** (Иванович, Сергеевич) --> **Муж**
- Окончание на **"на"** (Ивановна, Сергеевна) --> **Жен**

Это будет применяться:
- При загрузке данных ФРДО, если поле `gender` пустое, а `middle_name` заполнено
- При автозаполнении из профиля (разбор `full_name`)
- В edge-функции `register-student` при создании записи `student_frdo_data`

Если отчество не указано или не удается определить -- поле остается пустым для ручного заполнения.

## 3. Форма обучения в настройках курса

Добавить колонку `training_form` в таблицу `courses` (текст, по умолчанию "Очная"). Значения: "Очная", "Заочная", "Очно-заочная".

Это поле будет отображаться в настройках курса (CourseDetailsModal) рядом с другими ФРДО-настройками. При экспорте форма обучения будет браться из настроек курса, если в данных студента она не переопределена.
