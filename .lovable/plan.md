

# «Что нового» для админа — публичный вид + управление

## Что делаем

Переделываем `PlatformUpdatesManager` так, чтобы админ видел тот же красивый таймлайн, что и все пользователи, но с дополнительными кнопками управления на каждой карточке (редактировать, удалить, скрыть/опубликовать) и кнопкой «Добавить» наверху.

## Изменения

### `src/components/admin/PlatformUpdatesManager.tsx` — полная переработка

- Заменить текущий список карточек на таймлайн из `WhatsNewContent` (timeline с точками, `motion.article`, дата-бейдж, описание, картинка)
- Админ видит **все** записи (включая черновики), черновики визуально отмечены бейджем «Черновик»
- На каждой карточке таймлайна добавить иконки: ✏️ редактировать, 🗑 удалить, переключатель публикации
- Сверху оставить заголовок «Обновления платформы» + кнопки «Посмотреть» и «+ Добавить»
- Форма создания/редактирования остаётся как есть (выезжающая карточка сверху)

Один файл, ~180 строк.
