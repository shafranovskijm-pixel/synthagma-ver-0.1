## Что сделаю

Создам тестового менеджера по продажам, чтобы вы могли зайти и посмотреть интерфейс кабинета (`/sales`).

**Учётка:**
- Email: `sales.test@sintagma.com.ru`
- Пароль: `SalesTest2026!`
- ФИО: «Тестовый менеджер»
- Роль: `sales_manager`

**Как создаю (технически):**
1. Через Auth admin API создам пользователя с подтверждённым email.
2. В `user_roles` поставлю роль `sales_manager`.
3. В `sales_managers` добавлю профиль (`is_active = true`).
4. В `profiles` обновлю `full_name`.

**Что вы увидите после входа на `/login`:**
- Редирект на `/sales` (SalesDashboard).
- Канбан сделок (drag-n-drop КП и договоров), лиды, задачи, лидерборд, услуги, рассылки/SMTP CRM.
- Раздел «Открыть сделку» из задач → Deals360.

**Про загрузку базы и API звонков** — это уже следующий шаг, не входит в этот план. После того как посмотрите интерфейс, скажите:
- какую базу грузим (Excel лидов? компаний? формат колонок),
- какую телефонию подключаем (Манго, UIS, Билайн, Calltouch, своё API) — нужны их креды.

Тогда отдельным планом сделаю импорт + интеграцию звонков.

После создания пришлю готовые логин/пароль в чат.
