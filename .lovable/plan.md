

# Визуальный редизайн Маркетплейса и Магазина курсов — стиль как у кабинета слушателя

## Что делаем

Переоформляем каталог курсов в двух местах — **Маркетплейс (админ)** и **Магазин курсов (организация)** — по образцу `CourseCatalog` / `CourseCardNew` из кабинета слушателя: карточки с обложками, фильтры по категориям, и **секция «Популярные курсы»** вверху с 5 курсами-визитками с AI-обложками.

## Конкретные изменения

### 1. Новый компонент `MarketplaceHeroCards.tsx`

Блок «Популярные курсы» вверху каталога — горизонтальный ряд из 4–5 карточек с крупными обложками и названиями. Курсы захардкожены (Пожарная профилактика, Охрана труда, Медицина, Электробезопасность, Промбезопасность). Обложки берутся из `cover_image_url` курса; если нет — градиентный fallback как в `CourseCardNew`.

### 2. `AdminMarketplaceManager.tsx` — переработка таба «Каталог»

- **Вверху**: вставить `<MarketplaceHeroCards>` с 5 популярными курсами
- **Grid-режим** (`viewMode === "grid"`): заменить текущие Card-ы на `CourseCardNew`-подобные карточки с обложками, категорией, описанием + admin-кнопки (редактирование, удаление)
- **List-режим**: оставить как есть (таблица с категориями для управления)
- По умолчанию viewMode переключить на `"grid"`
- Категории: фильтр-чипы сверху (как у слушателя) вместо только поиска

### 3. `CourseStoreManager.tsx` — аналогичная переработка

- Добавить тот же `<MarketplaceHeroCards>` вверху каталога организации
- Grid-режим: карточки в стиле `CourseCardNew` с кнопкой «Получить» / «Заказать»
- Фильтр по категориям через чипы

### 4. Обложки для 5 популярных курсов

При первой загрузке компонента проверить, есть ли у 5 заданных курсов `cover_image_url`. Если нет — вызвать edge function `generate-cover` для генерации. Список тем для промптов:
- Специалист по пожарной профилактике → огнетушитель, пожарная каска
- Охрана труда → каска, защитные очки, стройплощадка
- Медицина → стетоскоп, медицинское оборудование
- Электробезопасность → высоковольтные линии, изоляция
- Промышленная безопасность → завод, промышленное оборудование
