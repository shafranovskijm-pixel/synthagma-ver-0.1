
Проблема не в том, что кнопки удалены — они всё ещё есть в `StudentSidebar.tsx`. Причина в разметке: sidebar растягивается на всю высоту длинной страницы, а блок `<nav className="... justify-center flex-1">` центрируется по всей этой высоте. Из-за этого три кнопки уезжают намного ниже первого экрана и визуально кажется, что они “исчезли”.

### Что исправлю
1. В `src/components/student/StudentSidebar.tsx` уберу центрирование по всей высоте страницы через `flex-1 + justify-center`.
2. Сделаю стабильную вертикальную структуру:
   - сверху логотип,
   - ниже блок из 3 кнопок,
   - сами кнопки выровнены по центру по горизонтали.
3. Сохраню цветовую подложку sidebar на основе `primaryColor`.
4. Усилю видимость кнопок:
   - неактивные — заметная полупрозрачная подложка в цвет бренда,
   - активная — насыщенная брендовая кнопка,
   - иконки и подписи не будут сливаться с фоном.
5. Проверю отступы для режимов preview/admin, чтобы верхняя плашка не сдвигала меню странно.

### Как именно
Вместо текущей схемы:
```text
aside
 ├ logo
 └ nav (flex-1 + justify-center)  <- из-за этого кнопки улетают вниз
```

Сделаю примерно так:
```text
aside
 ├ top logo
 ├ centered nav wrapper
 │   └ 3 visible buttons
 └ optional bottom spacer
```

- слева снова постоянно видны 3 кнопки,
- они не уезжают вниз при длинной странице каталога,

- расположение будет “по центру” визуально, как вы просили, но без поломки.
