

## План: Расширить автоисправление для всех типов проблем

### Проблема
`autoFixCourse` обрабатывает только пустые уроки и вопросы без ответов. Но валидация также находит:
- **Тесты без вопросов** — autoFix их игнорирует → «Нечего исправлять»
- **Дубликаты заголовков** — не обрабатываются

### Решение

В `autoFixCourse` (`AdminMarketplaceManager.tsx`) добавить обработку всех типов проблем:

1. **Тесты без вопросов** — вызвать `gigachat` с `action: "generate_questions"`, затем сохранить сгенерированные вопросы в `test_questions` (с уже заполненным `correct_answer`)

2. **Дубликаты заголовков** — автоматически добавить числовой суффикс: «Урок» → «Урок (2)», «Урок (3)»

3. **Тесты без вопросов с ответами** — после генерации вопросов `correct_answer` уже заполнен из `generate_questions`, поэтому повторное решение не нужно

### Порядок исправлений в `autoFixCourse`:
1. Генерация контента для пустых уроков (уже есть)
2. **Новое:** Генерация вопросов для пустых тестов → `gigachat` action `generate_questions` → insert в `test_questions`
3. Решение тестов без ответов (уже есть)
4. **Новое:** Исправление дубликатов заголовков → `update` в `lessons`
5. Повторная валидация (уже есть)
