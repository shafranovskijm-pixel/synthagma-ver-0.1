

# Улучшить презентацию: мобильная адаптация и кеширование PDF

## Проблемы
1. На мобильных устройствах слайды 1920×1080 масштабируются до крошечного размера — текст нечитаем
2. PDF каждый раз генерируется заново через html2canvas (долго, нестабильно)

## Решение

### 1. Мобильная адаптация презентации
В `PlatformPresentation.tsx`:
- Увеличить минимальный масштаб на мобильных: при ширине < 768px масштабировать только по ширине (без учёта высоты), чтобы слайд заполнял экран по ширине и скроллился по вертикали
- Альтернативный подход: на мобильных показывать слайды в вертикальном скролле (один за другим) вместо пролистывания — текст будет читаемым
- Уменьшить нижнюю панель навигации: компактнее кнопки, убрать точки-индикаторы (19 штук не помещаются)
- Убрать кнопку fullscreen на мобильных (не поддерживается на iOS)

### 2. Кеширование PDF в хранилище
- При первом скачивании: сгенерировать PDF на клиенте, загрузить в storage bucket (`presentation-files`), сохранить URL в таблицу `platform_settings` (или отдельную)
- При повторном скачивании: проверить наличие файла в storage, если есть — скачать напрямую без генерации
- Добавить версионирование: хранить хеш/версию презентации, при обновлении слайдов пересоздавать PDF
- Админ сможет вручную пересоздать PDF через кнопку

### Технические детали

**Файлы:**
| Файл | Действие |
|---|---|
| `src/pages/PlatformPresentation.tsx` | Мобильная адаптация + логика кеширования PDF |

**Миграция БД:**
- Создать storage bucket `presentation-files` (public read)
- Добавить запись в `platform_settings` для хранения URL кешированного PDF

**Логика скачивания:**
```
1. Проверить наличие PDF в storage
2. Если есть → window.open(url) 
3. Если нет → сгенерировать → загрузить в storage → скачать
```
