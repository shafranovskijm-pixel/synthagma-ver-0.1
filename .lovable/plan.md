

## План: Разделение курсов на «В работе» и «Готовые» в маркетплейсе

### Суть

Сейчас все курсы группируются в один аккордеон «Курсы Ростехнадзора». Нужно разделить на две папки:
- **«В работе»** — курсы где `is_validated` = false/null (по умолчанию все текущие)
- **«Курсы Ростехнадзора»** — курсы прошедшие валидацию (`is_validated` = true)

При клике на название курса запускается проверка (уже работает): наличие уроков, контента, ответов в тестах. Если всё ОК → `is_validated = true` → курс автоматически перемещается в папку «Курсы Ростехнадзора». Если есть проблемы → остаётся «В работе».

### Также: исправление ошибки сборки

Сборка падает с общей ошибкой (x3 retry). Код выглядит корректным — вероятно транзитная ошибка. Минимальное изменение в файле триггернёт пересборку.

### Изменения

#### 1. `src/hooks/useAdminMarketplace.ts` — логика `groupedCourses` (строки ~326-352)

Переработать группировку:
- RTN-курсы с `is_validated === true` → подгруппы внутри **«Курсы Ростехнадзора»** (с зелёным бейджем)
- RTN-курсы без валидации → подгруппы внутри **«В работе»** (с жёлтым бейджем)
- Standalone курсы — без изменений

Добавить поле `status: 'ready' | 'progress'` в тип группы для цветовой индикации.

#### 2. `src/components/admin/AdminMarketplaceManager.tsx` — UI аккордеонов (строки ~253-295)

- Добавить цветные бейджи: жёлтый «В работе» / зелёный «Готово» рядом с названием папки
- После успешной валидации (`handleValidateCourse`) вызвать `h.fetchData()` для автоматического перемещения курса между папками (сейчас `fetchCourses` уже вызывается через `h.courses`)

#### 3. Триггер пересборки

Убрать `as any` в `SettingsTab.tsx` строка 115 — косметика для рестарта билда.
