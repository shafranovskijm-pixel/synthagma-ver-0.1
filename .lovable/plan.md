### Часть 2. Самоонбординг учеников через лендинг — 4 улучшения

Сейчас CTA-форма создаёт `enrollment_requests`, которую менеджер должен подтвердить вручную. Этого мало для самостоятельной регистрации.

**2.1. «Зачисление в один клик» (auto-enroll)**
В настройках лендинга курса (`landing_content.enrollment`) добавить:
- `mode`: `request` (текущее, заявка) | `instant` (мгновенное создание ученика и зачисление) | `payment` (только после оплаты).
- `student_group_id`: куда зачислять (с привязкой к существующим группам).
- `expires_in_days`: автодоступ на N дней.
- `confirm_email`: слать ли пароль на почту (использует существующий SMTP).

При `mode: "instant"`: CTA-форма вызывает edge-функцию `landing-self-enroll` (новая), которая:
1. Создаёт `auth.users` с логином из email или сгенерированным.
2. Создаёт `profiles` с привязкой к организации.
3. Вставляет `enrollments` (status `active`).
4. Отправляет письмо с логином/паролем через тот же SMTP, что и `send-credentials`.
5. Возвращает экран «Вы зачислены, проверьте почту» прямо на лендинге.

**2.2. Привязка лендинга к регистрационной ссылке группы**
В редакторе лендинга — селектор «Группа набора» (выбор из `student_groups` курса). Если задано:
- На лендинге показывается счётчик «Осталось 3 места» и `expires_at` группы.
- При сабмите — увеличивается `used_count` соответствующей `registration_links`.
- Аналитика «откуда пришёл ученик» работает.

**2.3. Кастомизация полей формы**
Сейчас всегда 3 поля (name/email/phone). Добавить в `landing_content.enrollment_form.fields` массив с типами: `text`, `email`, `phone`, `select` (из enum), `checkbox` (согласие на ОПД, обязательное), `inn` (с DaData-подсказкой через имеющийся коннектор). Все CTA-варианты будут читать общий конфиг и отрисовывать поля динамически — один компонент `DynamicEnrollmentForm`.

**2.4. Согласие на обработку ПД + страница «Спасибо»**
- Обязательный чекбокс с ссылкой на оферту/ПДн, если не отмечен — submit заблокирован.
- После сабмита — настраиваемый `success_message` или редирект на `success_url` (для ретаргетинга и Метрики). Событие в `analytics_events`.

### Часть 3. Что предлагаю сверху (по вашему тезису «может быть, такой ещё функционал»)

1. **«Витрина школы»** — публичная страница `/o/<slug>` со всеми опубликованными курсами организации (сетка карточек). Сейчас есть только странички отдельных курсов — нет «магазина школы».
2. **Лид-магнит** — опциональный PDF/чек-лист, который высылается на email сразу после сабмита (как стимул оставить контакты). Файл загружается в редакторе.
3. **Onboarding-чат-бот** — после регистрации ученик получает welcome-сообщение во встроенный чат (используем существующий `support_conversations`).
4. **A/B две версии CTA** — простая ротация (50/50) с подсчётом конверсии в `analytics_events`.
5. **Telegram-уведомление менеджеру** — опционально, при наличии подключённого бота организации мгновенно уведомлять о новой заявке (поверх email).

Из этих пяти в эту сессию делаю **только №1 («Витрина школы»)** — это наиболее прямое продолжение шаблонной логики. Остальные обсудим отдельно.

### Технические детали

**Расширение `landing_content`:**
```ts
enrollment: {
  mode: "request" | "instant" | "payment";
  student_group_id?: string;
  expires_in_days?: number;
  fields: Array<{ key: string; label: string; type: "text"|"email"|"phone"|"select"|"checkbox"|"inn"; required: boolean; options?: string[] }>;
  consent_required: boolean;
  consent_url?: string;
  success_message?: string;
  success_url?: string;
  send_credentials_email: boolean;
}
```

**Edge-функция `landing-self-enroll`:**
- Без verify_jwt (анонимный лендинг).
- Rate-limit через существующую таблицу `rate_limits`.
- Возвращает `{ ok, login, email_sent }` — БЕЗ пароля в ответе (только письмом).

**Безопасность:**
- RLS на `enrollment_requests` уже есть — добавлю проверку, что `course.is_published = true` перед instant-зачислением.
- Все вводы — через zod-схему, длина ≤ 255.
- Сохранение согласия в `student_consents` с timestamp и IP.

### Критерии готовности
1. В галерее шаблонов появляются 4 новых карточки, каждая открывается в превью с нужной палитрой.
2. Категория-чипы автоматически содержат «Эзотерика», «Морские», «Спецтехника» (если решим выделять отдельно), либо они попадают в существующие.
3. В редакторе лендинга есть вкладка «Регистрация» с переключателем режима и выбором группы.
4. На опубликованном лендинге при `mode: "instant"` ученик регистрируется и получает письмо без участия менеджера.
5. На `/o/<slug>` отображаются все опубликованные курсы организации.
