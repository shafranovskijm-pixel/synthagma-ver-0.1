

# Панель разработчика -- полноценная вкладка в админке

## Что будет сделано

Вместо маленькой карты БД в настройках -- создать полноценную вкладку "Dev Tools" в админ-панели с технологичным интерфейсом: карта БД, карта кода, рекомендации, статистика проекта.

## Структура вкладки

```text
+-------------------------------------------+
|  DEVELOPER TOOLS              [Refresh]   |
+-------------------------------------------+
|                                           |
|  [4 карточки-метрики наверху]             |
|  Таблиц: 64  |  Функций: 32  |           |
|  Компонентов: ~120  |  Edge: 32           |
+-------------------------------------------+
|                                           |
|  [Tabs: БД | Код | Функции | Здоровье]   |
|                                           |
|  --- TAB: База данных ---                 |
|  Улучшенная карта с hover-связями         |
|  + доп. статистика (общее кол-во записей) |
|                                           |
|  --- TAB: Карта кода ---                  |
|  Дерево файлов по папкам с кол-вом строк  |
|  src/components/ -- 120+ файлов           |
|  src/hooks/ -- 40+ файлов                 |
|  src/pages/ -- 30+ файлов                 |
|  supabase/functions/ -- 32 функции        |
|                                           |
|  --- TAB: Edge-функции ---                |
|  Список всех 32 edge-функций              |
|  Статус, описание, категория              |
|                                           |
|  --- TAB: Здоровье системы ---            |
|  Рекомендации по улучшению                |
|  Проверка пропускной способности          |
|  Размеры таблиц, индексы                  |
+-------------------------------------------+
```

## Визуальный стиль

- Тёмный технологичный вид с неоновыми акцентами (цвета групп)
- Анимированные progress-бары для размеров таблиц
- Моноширинный шрифт для технических данных
- Градиентные заголовки карточек-метрик
- Пульсирующие точки на активных связях

## Детали по вкладкам

### 1. База данных (улучшенная)
- Текущая карта с hover-связями, но на всю ширину
- Добавить прогресс-бар относительного размера таблиц
- Показывать % от общего объёма записей

### 2. Карта кода
Статически описанная структура проекта (т.к. нет доступа к файловой системе в рантайме):
- `src/components/` -- ~150 компонентов (admin, organization, student, landing, UI, etc.)
- `src/hooks/` -- ~45 хуков
- `src/pages/` -- ~30 страниц
- `src/utils/` -- утилиты
- `supabase/functions/` -- 32 edge-функции
- Общее кол-во строк (приблизительное)

### 3. Edge-функции
Список всех 32 функций с категориями:
- Auth (register-student, reset-password, etc.)
- Notifications (send-email, send-telegram, etc.)
- AI (generate-course, generate-blog, etc.)
- Documents (process-contract, etc.)

### 4. Здоровье системы
- Проверка больших таблиц (>1000 записей)
- Рекомендации: "Добавить пагинацию", "Оптимизировать запросы"
- Статус storage buckets (10 бакетов)
- Количество секретов (16 настроено)
