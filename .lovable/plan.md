
## Полноценная страница описания курса

Сейчас при клике на карточку курса открывается маленький диалог, который плохо видно (особенно на тёмной теме). Заменим его на полноценный встроенный экран внутри магазина курсов.

### Что изменится

**Вместо диалога** при клике на карточку курса отобразится полноценная страница с описанием прямо внутри вкладки "Каталог":
- Кнопка "Назад" для возврата в каталог
- Заголовок курса и организация-продавец
- Полное описание (краткое + полное)
- Длительность курса
- Блок с ценами (для студентов / для организаций)
- Кнопки "Просмотр" и "Оставить заявку" внизу

### Техническая реализация

**Файл:** `src/components/organization/CourseStoreManager.tsx`

1. Использовать состояние `selectedCourseDetail` как переключатель вида: если курс выбран -- вместо сетки карточек рендерится полноценная страница описания
2. Удалить `Dialog` для деталей курса (строки 372-418)
3. В `TabsContent value="catalog"` добавить условие:
   - Если `selectedCourseDetail` установлен -- показать полный экран описания с кнопкой "Назад к каталогу"
   - Иначе -- показать текущий каталог (поиск, карточки, объявления)
4. Страница описания включает:
   - Кнопку `ArrowLeft + "Назад к каталогу"` с `onClick={() => setSelectedCourseDetail(null)}`
   - Полное описание курса с нормальным форматированием
   - Блок цен
   - Кнопки "Просмотр" и "Заявка"
