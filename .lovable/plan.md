

## Проблема

Таблица организаций содержит 6 колонок с большим количеством данных (название, ИНН, промокод, статус оплаты, тариф, контакты, учётные данные с кнопками копирования/показа/сброса, статистика, действия). Всё это не помещается на экране — горизонтальный скролл, обрезка данных.

## Решение: карточный layout вместо таблицы

Заменить `<Table>` на **список карточек** (card-based layout). Каждая организация — отдельная карточка с грамотной компоновкой:

```text
┌─────────────────────────────────────────────────┐
│ [Icon] ООО "АВРОРА"            [Оплачено] [Год] │
│        ИНН: 2721223198          до 5 мар 2026   │
│                                                  │
│ 📧 mail@avrora27.ru  📱 +79147770042            │
│ 🔑 admin@avrora.ru  ••••••  [👁] [📋] [🔄]     │
│                                                  │
│ 👥 1   📚 0   📄 0                              │
│                                                  │
│ [Просмотр]  [✏️]  [🗑]  [👁 Войти как]          │
└─────────────────────────────────────────────────┘
```

### Изменения в `src/components/admin/OrganizationsManager.tsx`:

1. **Заменить `<Table>` блок** (строки ~731-960) на `div` с `grid grid-cols-1 md:grid-cols-2 xl:grid-cols-3 gap-4`
2. **Каждая организация — `<Card>`** с секциями:
   - **Header**: иконка + название + ИНН + промокод + статус оплаты/тариф
   - **Body**: контакты (email, телефон) + учётные данные (с теми же кнопками копирования/показа/сброса)
   - **Footer**: статистика (пользователи, курсы, документы) + кнопки действий
3. **Клик по карточке** → `setViewingOrg(org)` (как сейчас по названию)
4. Вся логика (фильтрация, поиск, CRUD, пароли) остаётся без изменений — меняется только рендеринг списка
