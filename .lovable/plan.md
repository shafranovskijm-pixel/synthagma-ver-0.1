

# План: 3 новых курса профпереподготовки с богатой структурой (через токены Lovable)

## Что выбираем — 3 курса из каталога ipo.msk.ru

Чтобы не дублировать уже сделанные (Психолог-консультант / Специалист по охране труда / HR-менеджер) и не пересекаться с электроэнергетикой/ростехнадзором, беру **3 широкие востребованные ниши** профпереподготовки:

1. **Бухгалтер** (Бухгалтерский учёт, налогообложение и отчётность) — 256 ч.
2. **Менеджер по маркетингу** (Digital + классический маркетинг) — 256 ч.
3. **Юрист в сфере договорной работы** (Гражданско-правовые отношения и претензионная работа) — 256 ч.

Если хотите другие — скажите перед стартом, я заменю.

## Куда сохраняем

Организация **«Платформа Синтагма»** (`4ac2c05a-d8b5-4e72-ba31-f2c743091d95`) — там же, где лежат прежние 3 демо-курса. Категория: создам/использую «Профессиональная переподготовка».

## Структура каждого курса

```text
┌─ Курс ─────────────────────────────────────┐
│ Обложка (AI, 16:9, teal/cyan)              │
│ Описание + длительность 256 ч              │
├─ Модуль 1. Основы (4 урока + тест)         │
│ Модуль 2. Практика (4 урока + тест)        │
│ Модуль 3. Углублённо + кейсы (4 урока)     │
│ Итоговая аттестация (15 вопросов)          │
└────────────────────────────────────────────┘
```

**Каждый из 12 уроков сразу содержит:**
- AI-иллюстрация в шапке (Nano Banana 2, 16:9, единый стиль)
- 700+ слов основного текста (Gemini 3 Flash)
- 3 callout (info: нормативка / tip: совет / warning: типичная ошибка)
- 1-2 accordion с реальными кейсами
- 1 mini-quiz по ходу урока
- 2-3 button-блока со ссылками на книги/нормативку (белый список URL)
- Финальный callout-success «Что вы узнали» + кнопки «Куда дальше»

**Дополнительно на курс:**
- 2 промежуточных теста (после модулей 1 и 2, по 5 вопросов)
- 1 итоговый тест (15 вопросов)
- 5-7 PDF-материалов в `course_documents` (глоссарий, чек-листы, шаблоны, список литературы, нормативная база)

## Технология реализации

1. Восстанавливаю в `/tmp/` ранее наработанные скрипты:
   - `/tmp/lovable_ai.py` (копия из `knowledge://skill/ai-gateway/scripts/lovable_ai.py`)
   - `/tmp/demo_helpers.py` — обёртки над psql, Gateway, edge-функцией `upload-demo-asset`
   - `/tmp/build_course.py` — главный пайплайн «создать курс с нуля → 12 уроков → тесты → PDF»
2. Edge-функция `upload-demo-asset` уже задеплоена с прошлого раза — переиспользую.
3. Для каждого из 3 курсов:
   - INSERT в `courses` + `course_modules` + 12 × `lessons (type=text)` + 3 × `lessons (type=test)`
   - Generate cover (Nano Banana 2) → upload в `course-files/covers/`
   - На каждый урок: текст (Gemini Flash) → блоки JSON → image (Nano Banana 2) → собрать финальный массив блоков → UPDATE `lessons.content`
   - 25 test_questions (15 итоговых + 2×5 промежуточных)
   - 5-7 PDF (ReportLab) → upload → INSERT в `course_documents`
4. Чекпоинты после каждого урока (если кончатся кредиты — продолжу с того же места).
