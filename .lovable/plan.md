Итого в базе будет **9 готовых КП**.

### 2. Новое окно «Отправить КП» (галерея карточек)
Создать `src/components/admin/sales/SendProposalDialog.tsx` — `Dialog` во всю высоту:

- **Шапка:** название компании + email получателя (редактируемый, prefilled из lead).
- **Фильтр по категориям** (chips): «Все», «Платформа», «Услуги», «Корпоратив», «Инфра/сайты», «Коробочная».
- **Галерея карточек (grid, 2–3 колонки):**
  Для каждого шаблона:
  - Крупный заголовок
  - Короткое описание (из intro_html, первые ~120 символов)
  - Список услуг (иконка • + название + цена)
  - Итоговая сумма крупно (₽)
  - Бейдж категории
  - Действия: `Отправить` (primary) + `Предпросмотр` (открывает `/proposal/:id` в новой вкладке)
- **После отправки:** toast + запись в `sales_lead_activities` + галочка «Отправлено» на карточке.

Заменить текущий поповер «✉ КП» в `CompanyDrawer.tsx` на кнопку, открывающую этот диалог. Второй быстрый блок в табе «Документы» — тоже вести на диалог.
