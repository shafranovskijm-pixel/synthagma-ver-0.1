

# Разбор ошибок после прохождения теста

## Что будет сделано

После сдачи теста студент увидит кнопку "Показать разбор ответов", которая раскрывает список всех вопросов с подсветкой:
- Правильный ответ студента -- зелёный
- Неправильный ответ студента -- красный, рядом показан правильный вариант зелёным
- Пояснение к вопросу (если есть) -- под каждым вопросом

## Что уже есть

Вся необходимая информация уже доступна на клиенте после сдачи теста:
- `testQuestions` содержит `correct_answer` (индекс правильного ответа)
- `answers` содержит выбранные студентом ответы
- Edge-функция `get-test-results` возвращает `explanations` -- но они пока не сохраняются в state

  - Список всех вопросов теста с вариантами ответов

  - Под вопросом -- текст пояснения (если есть)

### Визуальная логика подсветки

Для каждого варианта ответа `oi` в вопросе `q`:
- Если `oi === q.correct_answer` -- зелёная рамка и фон (правильный ответ)
- Если `oi === answers[q.id]` и `oi !== q.correct_answer` -- красная рамка и фон (ошибка студента)
- Иначе -- обычный стиль
