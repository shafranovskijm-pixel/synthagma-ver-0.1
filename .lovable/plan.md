

# Переработка интерфейса «Документы» — чистый минималистичный дизайн

## Проблема
Сейчас 9 кнопок-табов расположены горизонтально и переносятся на 2 строки — выглядит перегруженно. Нужен чистый интерфейс как на референсе: горизонтальные текстовые табы в одну линию, без кнопочного стиля.

## Что будет сделано

### Заменить кнопки на лёгкие текстовые табы
Вместо массива `Button` с иконками — использовать стандартный `TabsList` + `TabsTrigger` (как в референсе). Табы будут текстовыми с иконками, в одну-две строки, с подчёркиванием активного. Без заливки кнопок.

### Структура табов (как на референсе)
```text
🔧 Конструктор  |  📄 Документы орг.  |  👥 Приказы  |  📋 Протоколы АК  |  🎓 Удостоверения  |  🎓 Дипломы
📜 Свидетельства  |  📚 Программы  |  📁 Закрывающие
```

Используем компонент `Tabs` из shadcn вместо ручного state + `Button`. Это даст:
- Единый стиль с подчёркиванием
- Компактность
- Автоматическое управление контентом через `TabsContent`

### Убрать HintCard из каждой вкладки
Подсказки занимают много места. Оставить только для «Конструктора» (там они полезны). Остальные — убрать для чистоты.

### Конструктор — суб-табы как на референсе
Внутри конструктора суб-табы (Реквизиты, Договор, Протокол АК, Удост./Диплом, Согласие ПД, Печать) уже есть и выглядят хорошо — оставить как есть.
