
## Что делаем

Три задачи для приветственного курса «Добро пожаловать в СИНТАГМА»:

### 1. Сгенерировать обложку и применить ко всем существующим копиям

В БД у всех организаций есть курс с названием «Добро пожаловать в СИНТАГМА» (был автоматически создан при регистрации). Сейчас у многих копий `cover_image_url` пустой — отсюда серая заглушка с иконкой книги.

Что сделаем:
- Сгенерировать **одну** красивую обложку через `generate-cover` (Lovable AI → Gemini image, fallback GigaChat) — премиальный приветственный баннер в Teal/Cyan стиле платформы.
- Сохранить файл в `course-files` storage **один раз** (общий публичный URL).
- Запустить миграцию, которая выставит этот `cover_image_url` всем курсам организаций, чьё название = «Добро пожаловать в СИНТАГМА» (и у которых обложка пуста или указывает на старый placeholder).

### 2. Чтобы у новых организаций обложка тоже была сразу

Найти место, где при регистрации новой организации создаётся приветственный курс (триггер/функция/edge или код во фронте регистрации) — и подставить тот же общий URL обложки в момент создания, чтобы у всех новых организаций курс сразу появлялся с картинкой.

### 3. Вид «Сетка» по умолчанию для новых пользователей

Сейчас у курсов в кабинете ученика/организации есть переключатель `grid/list` (`CourseViewMode`). Найти место, где хранится этот выбор (вероятно `localStorage` ключ типа `coursesViewMode` / `studentCoursesView`) и убедиться, что **значение по умолчанию = `"grid"`**, если ничего не сохранено. Если уже так — ничего не делаем; если нет — поправить инициализацию состояния.

## Что нужно проверить (этап 1, исследование перед изменениями)

1. SQL: сколько организаций имеют курс «Добро пожаловать в СИНТАГМА» и у скольких пустая `cover_image_url`.
2. Найти, где создаётся приветственный курс (поиск по строке «Добро пожаловать в СИНТАГМА» / «welcome» в `supabase/functions` и в коде регистрации).
3. Найти, где задаётся дефолтный `viewMode` для списка курсов студента/организации.

## Файлы / изменения

- **SQL-миграция** — `UPDATE courses SET cover_image_url = '<общий URL>' WHERE title = 'Добро пожаловать в СИНТАГМА' AND (cover_image_url IS NULL OR cover_image_url = '');`
- **Создание обложки** — единоразовый вызов `generate-cover` (или загрузка готового PNG в `course-files/welcome/cover.png`), URL фиксируем как константу.
- **Edge-функция / триггер регистрации** — добавить `cover_image_url = <константный URL>` при создании курса.
- **Frontend default view** — поправить инициализацию `useState<CourseViewMode>("grid")` там, где сейчас по умолчанию `list` (если такое есть).

## Этапы

1. Прочитать БД и код, чтобы понять: где создаётся приветственный курс и где задаётся дефолтный `viewMode`.
2. Сгенерировать обложку через `generate-cover`, получить публичный URL.
3. Миграция: применить URL ко всем существующим копиям курса с пустой обложкой.
4. Поправить место создания приветственного курса — чтобы новые организации получали курс сразу с обложкой.
5. Поправить дефолт `viewMode = "grid"` для новых пользователей (где это ещё не так).
6. Проверка end-to-end:
   - У существующих организаций обложка курса появилась (без ручной перегенерации).
   - У новой тестовой организации курс «Добро пожаловать в СИНТАГМА» создаётся уже с обложкой.
   - Новый пользователь видит каталог курсов в виде сетки по умолчанию.
