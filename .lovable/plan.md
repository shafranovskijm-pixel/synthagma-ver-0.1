

# Перенос «Рассылок» в раздел «Продажи» + шаблон-приглашение на презентацию

## Что не так сейчас

1. **«Рассылки» спрятаны** в отдельном пункте бокового меню админки (`broadcast`), отдельно от «Продаж». Менеджер по продажам не видит их рядом с КП/Лидами/Договорами — ломается логика «всё про продажи в одном месте».
2. **Нет готового шаблона «Приглашение на презентацию»** — каждый раз приходится верстать письмо вручную.
3. **При создании рассылки нельзя в один клик** прикрепить ссылку на наш будущий вебинар (нужно сначала создать вебинар в другом разделе, скопировать ссылку, вставить в письмо).
4. **Демо-ссылки** убраны — но теперь сайдбар «Продаж» неравномерный, надо добить смыслом.

## Что сделаю

### 1. Перенести рассылки в «Продажи»

Добавлю в `SalesSidebar` новый пункт **«Рассылки»** (icon `Send`) сразу после «КП». Откроет полноценный `BroadcastManager` (тот, что сейчас в отдельной вкладке админки) — уже с двумя подзакладками: «Email-кампании» и «Шаблоны email». Старый пункт `broadcast` в `AdminSidebar` оставлю на месте (для совместимости и чтобы не ломать привычку), но добавлю дублирующий вход из «Продаж» — менеджер найдёт его там, где искал.

Структура нового сайдбара «Продажи»:
```
Сделки 360°
КП
Рассылки         ← НОВОЕ (значок Send)
Услуги
Менеджеры
Лиды
База компаний
Договоры
Подписание
Контроль
Сравнение
Карточка
```

### 2. Добавить готовый шаблон «Приглашение на презентацию»

В `useEmailTemplates.ts` добавлю новую категорию `presentation` («Приглашение на презентацию»). При первой загрузке `EmailTemplatesManager` (если шаблона ещё нет в системных) создам системный шаблон с переменными:

- `{{name}}` — имя получателя
- `{{date}}` — дата презентации
- `{{time}}` — время
- `{{webinar_url}}` — ссылка на вебинар/Zoom/внешнюю встречу
- `{{host_name}}` — имя ведущего

Письмо будет выглядеть как «luxury minimalism» в Teal/Cyan: лого, заголовок «Приглашаем на презентацию платформы Sintagma», дата/время крупным блоком, кнопка «Присоединиться к встрече» (ведёт на `{{webinar_url}}`), краткая программа из 3 пунктов, подпись.

### 3. Виджет «Прикрепить вебинар» в `CampaignEditor`

В редакторе кампании (`CampaignEditor.tsx`) добавлю секцию **«Ссылка на встречу»** с тремя радиокнопками:

1. **Внешняя ссылка** (Zoom, Google Meet, ВК-звонки) — поле ввода URL.
2. **Существующий вебинар Sintagma** — выпадающий список из таблицы `webinars` (только статус `scheduled` и `live`), показывает название + дату. Подставит публичную ссылку `/w/<token>`.
3. **Создать новый вебинар** — открывает быстрый диалог: название, дата+время, длительность. Создаёт запись в `webinars` со статусом `scheduled`, генерирует guest-token, возвращает ссылку. Затем подставляет её в письмо.

Выбранная ссылка автоматически подставится в `{{webinar_url}}` шаблона. Дата/время — в `{{date}}` и `{{time}}`. Также автоматически добавится **iCal-вложение** (`.ics`) — получатель сможет добавить встречу в календарь одним кликом (используем уже существующий `webinar-reminders-cron` хелпер генерации iCal).

### 4. Кнопка «Создать рассылку из шаблона» прямо на карточке шаблона

В `EmailTemplatesManager` рядом с «Редактировать/Дублировать/Удалить» добавлю кнопку 📤 **«Запустить рассылку»** — откроет `CampaignEditor` с уже заполненными темой и HTML из шаблона. Это минус 2 клика для менеджера.

### 5. Убрать визуальную «пустоту» в сайдбаре «Продаж»

Объединю смежные пункты в визуальные группы (с тонкими разделителями и заголовками-лейблами):

- **Сделки**: Сделки 360°, Лиды, База компаний, Карточка
- **Документы**: КП, Договоры, Подписание, Услуги
- **Коммуникации**: Рассылки
- **Аналитика**: Контроль, Сравнение, Менеджеры

Это сделает меню осмысленным, а не «простыня из 11 пунктов».

## Технические детали

**Файлы:**
- `src/components/admin/sales/SalesSidebar.tsx` — новый пункт, группировка с лейблами.
- `src/components/admin/SalesManager.tsx` — добавить ключ `broadcast` → `<BroadcastManager />`.
- `src/hooks/useEmailTemplates.ts` — категория `presentation`, авто-сидинг системного шаблона.
- `src/components/shared/sales/EmailTemplatesManager.tsx` — кнопка «Запустить рассылку».
- `src/components/admin/broadcast/CampaignEditor.tsx` — секция «Ссылка на встречу» (3 опции) + чекбокс «Прикрепить .ics».
- `src/components/admin/broadcast/CreateWebinarQuick.tsx` — **новый** мини-диалог быстрого создания вебинара.
- `supabase/functions/run-email-campaign/index.ts` — поддержка attachments (iCal) в SMTP-отправке, подстановка переменных `{{date}}`, `{{time}}`, `{{webinar_url}}`, `{{host_name}}`.

**БД:** миграции не нужны. Таблицы `email_templates`, `email_campaigns`, `webinars` уже подходят — переменные кампании пишем в существующее JSON-поле или добавим колонку `email_campaigns.meeting_url text` (одно небольшое ALTER TABLE).

**Безопасность:** RLS для `webinars` уже даёт админу полный доступ. Быстрое создание вебинара использует `auth.uid()` как `host_user_id`, проверяет роль через существующий security-definer.

## Что НЕ делаю

- Не трогаю общую логику warmup и rate-limit рассылок (`useEmailWarmup`) — она уже есть.
- Не делаю drag-n-drop редактор писем — это отдельная большая задача.
- Не удаляю пункт `broadcast` из главного `AdminSidebar` — оставлю как «прямой вход» для тех, кто привык, плюс добавлю его в «Продажи».
