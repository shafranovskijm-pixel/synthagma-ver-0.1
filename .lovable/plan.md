

## Автосохранение и сохранение перед предпросмотром в конструкторе курсов

### Проблема
Пользователь импортирует материалы, нажимает «Предпросмотр», а курс не сохранен — данные теряются.

### Решение
Два механизма: автосохранение при ключевых действиях + обязательное сохранение перед предпросмотром.

### Изменения

| Файл | Что меняется |
|------|-------------|
| `src/hooks/useCourseBuilder.ts` | 1) Добавить `useEffect`, который вызывает `saveCourse()` после: импорта файлов (`isImporting` false→true→false), AI-генерации (`isGenerating` false→true→false), drag-and-drop (`handleDragEnd`), удаления урока (`deleteLesson`). Используем `useRef` для отслеживания завершения операции. 2) Добавить статус автосохранения `autoSaveStatus: 'idle' | 'saving' | 'saved' | 'error'` для UI-индикатора. 3) При ошибке сохранения — показывать toast с ошибкой |
| `src/pages/CourseBuilder.tsx` | 1) Кнопка «Предпросмотр» — при `hasUnsavedChanges` сначала вызывает `saveCourse()`, ждет завершения, затем навигирует. 2) Добавить текстовый индикатор рядом с кнопкой сохранения: «Сохранено ✓» / «Сохранение...» / «Ошибка сохранения» |

### Детали реализации

**Автосохранение при ключевых действиях** — в `useCourseBuilder.ts`:
- После `handleFileImport` (уже есть finally-блок) — добавить `saveCourse()` в конец
- После `handleGenerateStructure` — добавить `saveCourse()` после добавления уроков
- После `handleAIGenerate` — добавить `saveCourse()` после `updateLessons`
- В `handleDragEnd` — добавить `saveCourse()` после `arrayMove`
- В `deleteLesson` — добавить debounced `saveCourse()` через 500ms

**Предпросмотр с сохранением** — в `CourseBuilder.tsx`:
- Заменить навигацию на async-функцию: `await saveCourse(); navigate(...)`.
- Если `saveCourse` завершается ошибкой — не навигировать, показать toast.

**Индикатор статуса** — маленький текст под/рядом с кнопкой «Сохранить курс»:
- `saving` → «Сохранение...» (серый)
- `saved` → «Сохранено ✓» (зеленый, исчезает через 3 сек)
- `error` → «Ошибка сохранения» (красный)

**Возврат результата из saveCourse** — сейчас `saveCourse` ничего не возвращает, нужно вернуть `boolean` (успех/неудача) для проверки перед предпросмотром.
