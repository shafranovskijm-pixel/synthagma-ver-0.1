

# Этап 2: Планирование обучения, документы, напоминания в кабинете компании

## Обзор

Расширяем кабинет компании тремя крупными блоками:
1. **Планирование обучения** -- компания видит, кому и когда нужно на какой курс, и может планировать обучение
2. **Документы взаиморасчётов** -- компания видит свои договоры, счета и акты
3. **Напоминания о переобучении** -- компания видит напоминания для своих сотрудников
4. **Массовый импорт сотрудников** -- загрузка списка из Excel/CSV

---

## 1. База данных

### 1.1 Таблица `training_plans` (новая)
```sql
CREATE TABLE public.training_plans (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  company_id UUID NOT NULL REFERENCES companies(id) ON DELETE CASCADE,
  organization_id UUID NOT NULL REFERENCES organizations(id),
  user_id UUID NOT NULL REFERENCES auth.users(id), -- сотрудник
  course_id UUID REFERENCES courses(id),
  course_name TEXT, -- если курс ещё не выбран, можно указать текстом
  planned_date DATE,
  status TEXT DEFAULT 'planned' CHECK (status IN ('planned', 'enrolled', 'completed', 'overdue')),
  notes TEXT,
  created_by UUID REFERENCES auth.users(id), -- кто создал план
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);
```

### 1.2 RLS-политики

- Компания: SELECT/INSERT/UPDATE/DELETE для своих записей (`company_id = current_company_id()`)
- Организация: полный доступ для записей своей организации
- Админ: полный доступ

### 1.3 RLS для `company_documents`
Уже есть политика SELECT для компании. Добавить нечего -- компания может только просматривать, загружает организация.

### 1.4 RLS для `course_reminders`
Добавить политику SELECT для компании: `company_id = current_company_id()`.

## 2. Кабинет компании -- новые вкладки

### Структура навигации (боковое меню или табы):
- **Главная** -- статистика (уже есть)
- **Сотрудники** -- список с прогрессом (уже есть, выносим в отдельную вкладку)
- **Планирование** -- таблица планов обучения с фильтрами по статусу и дате
- **Документы** -- договоры, счета, акты (read-only из `company_documents`)
- **Напоминания** -- предстоящие напоминания о переобучении

### 2.1 Вкладка «Планирование»
- Таблица: Сотрудник, Курс, Плановая дата, Статус (Запланировано / Зачислен / Завершено / Просрочено)
- Кнопка «Добавить план» -- выбор сотрудника, курса (из доступных), даты
- Автоматическое обновление статуса при зачислении и завершении курса
- Цветовая индикация просроченных планов

### 2.2 Вкладка «Документы»
- Три секции: Договоры, Счета, Акты
- Просмотр и скачивание файлов (не загрузка -- это делает организация)
- Отображение статуса оплаты счетов

### 2.3 Вкладка «Напоминания»
- Список предстоящих напоминаний о переобучении для сотрудников компании
- Фильтр по статусу (предстоящие / просроченные)
- Данные из существующей таблицы `course_reminders` (фильтр по `company_id`)

## 3. Массовый импорт сотрудников

- Кнопка «Импорт из Excel» в списке сотрудников
- Парсинг XLSX/CSV (колонки: ФИО, Email)
- Предпросмотр списка перед импортом
- Массовый вызов `register-student` для каждого сотрудника
- Прогресс-бар импорта
