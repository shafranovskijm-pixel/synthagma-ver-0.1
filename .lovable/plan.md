

# Импорт учеников с привязкой к курсам (до парсинга)

## Что будет сделано

Загружаете Excel-файл с учениками, создаёте для каждого аккаунт. Указываете курсы (даже ещё не спарсенные) — система создаёт «отложенные записи». Когда курс появится (после импорта со SkillSpace), ученики автоматически зачислятся и прогресс сохранится.

## Архитектура

```text
┌────────────────────┐     ┌─────────────────────┐
│  Excel-файл        │     │  Пакетный импорт    │
│  с учениками       │     │  курсов SkillSpace  │
│  + названия курсов │     │  (batch import)     │
└────────┬───────────┘     └──────────┬──────────┘
         │                            │
         ▼                            ▼
┌────────────────────┐     ┌─────────────────────┐
│  profiles          │     │  courses             │
│  (создаются сразу) │     │  (появляются позже)  │
└────────┬───────────┘     └──────────┬──────────┘
         │                            │
         ▼                            ▼
┌─────────────────────────────────────────────────┐
│  pending_enrollments                             │
│  (student_profile_id, course_title, org_id)     │
│  → при появлении курса → создаётся enrollment   │
└─────────────────────────────────────────────────┘
```

## Шаги

### 1. Таблица `pending_enrollments`
- `id`, `organization_id`, `profile_id` (→ profiles), `course_title` (текст — название ожидаемого курса), `course_id` (nullable — заполнится при матче), `status` (pending / enrolled / failed), `created_at`
- RLS: admin и org-менеджеры видят свои записи

### 2. DB-триггер/функция на `courses`
- При INSERT в `courses` — ищет в `pending_enrollments` записи с совпадающим `course_title` и `organization_id`
- Находит → создаёт `enrollment`, обновляет `pending_enrollment.status = 'enrolled'` и заполняет `course_id`

### 3. Обновить Excel-импорт учеников
- В `EmployeeImportDialog` (или новый компонент в OrganizationDetailsView) добавить столбец **«Курсы»** из Excel
- Формат файла: ФИО, Email, Курс1, Курс2, ... (или столбец «Курсы» через запятую)
- При импорте каждого ученика → создаём профиль + записи в `pending_enrollments`
- Если курс уже существует → сразу создаём `enrollment`

### 4. UI: индикатор ожидающих записей
- В карточке организации (вкладка Ученики) — бейдж «X ожидают зачисления»
- Возможность просмотреть список ожидающих и вручную сматчить курс
