
## Что меняем на `/sales`

Цель — превратить рабочий экран в один поток: «Привет → скрипт → следующие 10 компаний по времени → звонок».

### 1. Свернуть сайдбар в одну кнопку

`src/components/admin/sales/SalesSidebar.tsx`:
- По умолчанию сайдбар collapsed (иконки скрыты). В шапке `SalesDashboardHeader` — одна кнопка-гамбургер (`SidebarTrigger` / `Menu` иконка), раскрывающая меню оверлеем/поповером.
- На мобильном/планшете — то же поведение (Sheet).
- Пункты меню остаются те же, просто спрятаны за одной кнопкой.

### 2. Новый первый экран — «Смена»

Новый компонент `src/components/admin/sales/SalesShiftView.tsx`, показывается по умолчанию вместо текущего списка лидов. Секции сверху вниз:

**A. Приветствие**
- `Привет, {имя менеджера}!`
- Строка плана: `Сегодня у тебя {plan} дозвонов · сделано {done} · осталось {plan - done}` + прогресс-бар.
- Источник плана: `app_settings.sales_daily_plan` — JSON `{ "default": 80, "byManager": { "<manager_id>": 80 } }`. Для Алёны — 80 фиксировано.
- `done` = звонки менеджера сегодня из `sales_lead_activities` (type call).

**B. Скрипт первого касания (знакомство)**
- Компактная карточка на основе существующего `ColdCallScriptCard` / `coldCallScript.ts`, но сразу открыт первый этап «Знакомство» с текстом приветствия под текущего лида: «Здравствуйте, {ФИО/компания}, меня зовут {менеджер}, компания Синтагма…».
- Кнопки «Дальше по скрипту» и «Записать результат».

**C. Лента «Кому звонить сейчас»**
- Заголовок + сабтайтл «Отсортировано по местному времени 09:00–18:00, сначала где день скоро закончится, потом свежие лиды».
- Строки компаний: название · регион · **локальное время сейчас** (badge) · телефон · кнопки «Позвонить» / «Открыть».
- Клик по строке — открывает существующий `CompanyDrawer` со скриптом и таймлайном.
- **Пагинация по 10** (Pagination из shadcn). Никаких бесконечных скроллов.

### 3. Логика отбора «сейчас удобно звонить»

Новый util `src/utils/salesShiftQueue.ts`:
1. Берём лидов из `sales_leads` (+ join к `sales_companies_db` при необходимости), исключаем `status in ('won','not_interested','callback_later')` с будущим `next_action_at`.
2. Для каждого определяем таймзону через существующий `regionTimezones.ts` → локальное время сейчас.
3. Фильтр окна: 09:00–18:00 локального. Остальные откладываются («не сейчас»).
4. Сортировка гибридная:
   - primary: минут до 18:00 по возрастанию (те, где день скоро закончится — сверху);
   - secondary: `created_at desc` (свежие).
5. Возвращаем массив; UI режет по 10 на страницу.

### 4. Админский вопрос про план в день

В админке (`SalesOverview.tsx` или новая карточка в разделе Менеджеры / настройки продаж) добавляем:
- Поле `Дозвонов в день (по умолчанию)` — сохраняется в `app_settings.sales_daily_plan.default`.
- Таблица «Индивидуальный план» с колонками менеджер · план · сохранить (пишем в `byManager[manager_id]`).
- Для менеджера Алёны — вручную выставим 80.

Хранение: одна строка `app_settings` c ключом `sales_daily_plan`, значение JSON. Читается на `/sales` через существующий helper.

### 5. Что не меняется

- Логика звонков, `LogActivityDialog`, `CompanyDrawer`, отправка КП, таймлайн — как есть.
- Существующие вкладки (Лиды, Задачи, Компании, Менеджеры) остаются доступны через свёрнутое меню.
