

# Группы и регистрация учеников прямо из курса

## Две задачи

### 1. Блок «Ближайшие группы» в конструкторе курса
После сохранения нового курса (когда `courseId` появляется) — показать секцию «Группы» прямо на странице CourseBuilder, под списком уроков. Пользователь сразу задаёт название группы, даты начала/окончания и создаёт группу без перехода в карточку курса.

**Файл**: `src/pages/CourseBuilder.tsx`
- После блока с уроками добавить секцию «Ближайшие группы» (видна только когда курс уже сохранён, т.е. `resolvedCourseId` существует)
- Переиспользовать `CourseGroupsTab` компонент, передав `courseId` и `organizationId`
- Или сделать упрощённый inline-блок: список существующих групп + форма быстрого создания (название + даты)

**Файл**: `src/hooks/useCourseBuilder.ts`
- Экспортировать `organizationId` из хука, чтобы передать в компонент групп

### 2. Регистрация нового ученика из вкладки групп
Сейчас «+ Ученики» показывает только существующих нераспределённых учеников. Добавить возможность создать нового ученика (ФИО + email) прямо из этого диалога.

**Файл**: `src/components/organization/CourseGroupsTab.tsx`
- В диалоге `addStudentsDialog` добавить кнопку/форму «Добавить нового ученика» (имя, email)
- При отправке: вызвать edge function для создания пользователя (invite) или использовать существующий механизм регистрации
- После создания — автоматически привязать к группе (`student_group_id`) и обновить список

### Реализация создания ученика
Проверю, есть ли уже edge function для invite/создания ученика. Если нет — создам простую форму, которая:
1. Создаёт запись в `profiles` с `organization_id` и `student_group_id`
2. Использует `supabase.auth.admin.createUser()` через edge function для создания auth-записи
3. Отправляет приглашение на email
