
# Исправление назначения групп и улучшение загрузки видео

## Проблема 1: Нельзя назначить группу ученику

### Причина
В таблице `profiles` отсутствует RLS-политика, разрешающая менеджерам организации обновлять профили студентов в своей организации. Существующие политики позволяют UPDATE только самому пользователю (свой профиль) и суперадмину.

### Решение
Добавить RLS-политику для UPDATE, разрешающую менеджерам организации обновлять профили студентов в своей организации:

```sql
CREATE POLICY "Org admins can update profiles in their org"
  ON public.profiles FOR UPDATE
  USING (
    (organization_id = current_organization_id() AND has_role('organization', auth.uid()))
    OR has_role('admin', auth.uid())
  )
  WITH CHECK (
    (organization_id = current_organization_id() AND has_role('organization', auth.uid()))
    OR has_role('admin', auth.uid())
  );
```

Это одна SQL-миграция, без изменений в коде.

## Проблема 2: Видео зависает на загрузке

### Причина
Видеофайл может быть недоступен, слишком большой, или сервер отвечает медленно. Плеер показывает бесконечный спиннер без возможности действий.

### Решение
Добавить таймаут загрузки видео (15 секунд): если видео не начало воспроизводиться, показывать кнопки "Попробовать снова" и "Открыть в новом окне".

**Файл**: `src/components/course-learning/VideoPlayerInline.tsx`
- Добавить `useEffect` с таймером на 15 секунд после монтирования
- Если `videoLoading` все ещё `true` через 15 секунд, показать fallback с кнопками действий
- Это не ломает текущую логику — просто даёт пользователю выход из ситуации зависания
