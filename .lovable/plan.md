
## Диагностика и исправление PWA установки на Android

### Проблема
PWA не предлагает установку на Android в Chrome. Возможные причины:
- Service worker может не регистрироваться корректно
- Манифест может быть недоступен или содержать ошибки
- Страница `/install` показывает только текстовые инструкции без активной кнопки установки

### Что нужно сделать

#### 1. Улучшить страницу `/install` для Android
Сейчас, если `beforeinstallprompt` не срабатывает, на Android показываются только текстовые инструкции. Нужно:
- Всегда показывать чёткую пошаговую инструкцию с визуальными подсказками
- Добавить кнопку "Обновить страницу" — иногда промпт не срабатывает с первого раза
- Показать подсказку: "Откройте меню Chrome (три точки) -> Установить приложение"

#### 2. Добавить регистрацию Service Worker в main.tsx
Сейчас `vite-plugin-pwa` настроен с `registerType: "autoUpdate"`, но в `main.tsx` нет явной регистрации. Плагин должен генерировать виртуальный модуль автоматически, но добавим явный импорт для надёжности.

#### 3. Показывать инструкцию "всегда видимую" на Android
Вместо зависимости от `beforeinstallprompt` (который может не сработать), показывать Android-инструкцию всегда, а кнопку автоустановки — как бонус сверху.

### Технические детали

**Файлы для изменения:**

1. **src/main.tsx** — добавить импорт `import { registerSW } from 'virtual:pwa-register'` и вызов `registerSW()` для явной регистрации service worker

2. **src/pages/Install.tsx** — изменить логику отображения:
   - На Android: всегда показывать пошаговую инструкцию с меню Chrome
   - Кнопку автоустановки показывать дополнительно, если `beforeinstallprompt` сработал
   - Добавить кнопку "Обновить страницу и попробовать снова"
   - Убрать условие `!deferredPrompt` для Android-инструкций — показывать их всегда

3. **src/vite-env.d.ts** — добавить типы для `virtual:pwa-register`
