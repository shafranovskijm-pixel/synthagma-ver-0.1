

# Настройка доступа к курсу и урокам

## Что будет сделано

### 1. Срок доступа к курсу (по умолчанию)
В настройках курса (`CourseDetailsContent.tsx`, вкладка «Настройки») добавить поле:
- **«Срок доступа к курсу (дней)»** — число дней, на которое даётся доступ после зачисления
- Пустое значение = безлимитный доступ
- Это значение будет автоматически применяться при зачислении новых учеников (записываться в `enrollments.access_days`)

Миграция: добавить колонку `default_access_days` (integer, nullable) в таблицу `courses`.

### 2. Доступ к отдельным урокам (платные/бесплатные уроки)
Добавить возможность ограничивать доступ к конкретным урокам:
- Новая колонка `is_locked` (boolean, default false) в таблице `lessons` — урок заблокирован, доступен только при отдельной покупке/разблокировке
- В редакторе курса рядом с каждым уроком — иконка замка для переключения доступа
- В предпросмотре заблокированные уроки показываются с замком и сообщением «Этот урок доступен отдельно»

### 3. Индивидуальный срок доступа для ученика
Уже реализовано в `CoursesTab.tsx` (вкладка «Курсы» в карточке студента). Доработка: при зачислении ученика автоматически подставлять `default_access_days` из курса, если оно задано.

## Миграции

```sql
-- Курс: срок доступа по умолчанию
ALTER TABLE public.courses ADD COLUMN default_access_days integer;

-- Уроки: блокировка доступа
ALTER TABLE public.lessons ADD COLUMN is_locked boolean NOT NULL DEFAULT false;
```
