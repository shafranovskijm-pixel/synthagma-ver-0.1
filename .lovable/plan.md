
# Виджет "ИИ-запросы по организациям"

Новый виджет в AdminAnalytics, показывающий рейтинг организаций по количеству ИИ-генераций.

## Что будет отображаться

- Таблица-рейтинг: название организации, количество генераций за текущий месяц, токены использованные
- Горизонтальная гистограмма (BarChart) для визуализации топ-10
- Сортировка по убыванию количества запросов

## Технические детали

### Файл: `src/components/admin/AdminAnalytics.tsx`

1. **Загрузка данных**: в `fetchAnalytics` добавить запрос к таблице `organization_usage` с полями `organization_id, ai_generations_count, ai_tokens_used, month_start`
2. **Интерфейс**: расширить `AnalyticsData` полем `aiUsage`
3. **useMemo**: создать `aiUsageByOrg` — агрегация по организациям, джойн с названиями из `data.organizations`, сортировка по убыванию
4. **Виджет**: карточка с заголовком "ИИ-генерации по организациям", содержащая:
   - Горизонтальный BarChart (топ-10)
   - Таблица с колонками: Организация, Генерации, Токены
5. Разместить виджет на вкладке "Обзор" рядом с существующими графиками

Данные берутся из существующей таблицы `organization_usage` — никаких миграций не требуется.
