
# Группировка курсов по категориям в диалогах зачисления

## Проблема

При назначении учеников на курсы отображается плоский список всех курсов. Когда курсов много, найти нужный сложно — приходится долго листать.

## Решение

Во всех трёх диалогах зачисления курсы будут сгруппированы по категориям. Каждая категория отображается как раскрываемый блок (Collapsible) с цветной меткой и счётчиком курсов. Курсы без категории выводятся в отдельной группе «Без категории» в конце списка. Поиск по-прежнему работает — при вводе текста группировка сохраняется, но пустые категории скрываются.

## Что изменится

### 1. `StudentCoursesDialog.tsx` — диалог «Курсы ученика»

Секция «Зачислить на курсы» (строки 209-244):
- Курсы группируются по `category_id`
- Каждая группа — Collapsible-блок с заголовком-категорией (цветная метка + название + количество)
- Внутри блока — список курсов с чекбоксами (как сейчас)
- Группа «Без категории» в конце для курсов без `category_id`
- Все группы раскрыты по умолчанию

### 2. `OrgDialogs.tsx` → `EnrollDialog` — диалог массового зачисления

Список курсов (строки 283-334):
- Аналогичная группировка по категориям
- Радио-выбор (один курс) сохраняется
- Категории как визуальные разделители с цветными метками

### 3. `BulkEnrollDialog.tsx` — зачисление компании на курсы

Список курсов (строки 81-119):
- Группировка по категориям
- Нужно прокинуть `categories` и `getCategoryById` из `CompaniesManager`

### Логика группировки (общая для всех диалогов)

```text
1. Получить список категорий из courses (уникальные category_id)
2. Для каждой категории — отфильтровать курсы
3. Курсы с category_id = null → группа "Без категории"
4. Отрисовать Collapsible для каждой группы
5. При поиске — скрывать пустые группы
```
