

# Уведомление на email о завершении курса

## Описание

Добавить в настройки курса (вкладка "Напоминания") переключатель для автоматической отправки email при завершении курса. Письмо будет содержать ФИО слушателя и результаты тестирования, отправляясь на email организации и/или компании-заказчика.

## Что будет сделано

### 1. Новые поля в таблице `courses`

Добавить два столбца:
- `notify_on_completion` (boolean, default false) -- включить email-уведомление о завершении
- `completion_notify_emails` (text, nullable) -- дополнительные email-адреса для уведомлений (через запятую)

### 2. Edge-функция `notify-course-completion`

Новая функция, которая:
- Принимает `enrollment_id`, `course_id`, `user_id`, `test_score`, `test_max_score`
- Получает данные: ФИО слушателя, название курса, организацию, результаты тестов
- Собирает все результаты тестов по урокам курса из `test_attempts`
- Формирует красивое HTML-письмо с:
  - ФИО слушателя
  - Название курса
  - Дата завершения
  - Таблица результатов тестов (урок, баллы, процент)
  - Итоговый результат
- Отправляет через SMTP на email организации и дополнительные адреса

### 3. Интерфейс настроек (CourseRemindersTab)

Новый блок в верхней части вкладки "Напоминания":
- Переключатель "Уведомлять о завершении курса по email"
- Поле для ввода дополнительных email-адресов
- Описание: "При завершении курса слушателем на указанные адреса будет отправлено письмо с ФИО и результатами тестирования"

### 4. Интеграция при завершении курса

В `CourseLearning.tsx` в функции `handleCourseCompletion` -- вызвать edge-функцию `notify-course-completion`, если у курса включена настройка `notify_on_completion`.

### Формат письма

```text
+----------------------------------------------+
|  [Градиент] Курс завершён!                  |
|  Организация "ООО Знание"                    |
+----------------------------------------------+
|                                              |
|  Слушатель Иванов Иван Иванович              |
|  завершил курс "Охрана труда"                |
|  Дата завершения: 13.02.2026                 |
|                                              |
|  Результаты тестирования:                    |
|  +--------+--------+---------+               |
|  | Тест   | Баллы  | Результ |               |
|  +--------+--------+---------+               |
|  | Тест 1 | 8/10   |  80%    |               |
|  | Тест 2 | 9/10   |  90%    |               |
|  +--------+--------+---------+               |
|  Итого: 17/20 (85%)                          |
|                                              |
+----------------------------------------------+
```

### Логика CourseRemindersTab

Компонент получит дополнительные пропсы:
- `notifyOnCompletion: boolean`
- `completionNotifyEmails: string | null`
- `onNotifyOnCompletionChange: (value: boolean) => void`
- `onCompletionNotifyEmailsChange: (value: string) => void`

Эти значения будут сохраняться в таблице `courses` через существующую функцию обновления курса.
