

# Доделать раздел «Финансы» — полный план

## Что сейчас есть
- **PaymentsTab** (орг): баланс, таблица оплат, таблица транзакций, настройки Т-Банк (TBankSettings) — базовая форма с 3 полями
- **AdminFinanceOverview**: сводка + таблица всех платежей с фильтрами
- **tbank-init / tbank-webhook**: edge-функции уже работают, редирект на страницу Т-Банк

## Что нужно сделать

### 1. Улучшить TBankSettings — полноценная настройка кассы

Текущий виджет слишком простой. Нужно добавить:

- **Выбор режима оплаты**: редирект на страницу Т-Банк (текущий) или встроенный виджет (T-Bank Payment SDK — `pay.tbank.ru/sdk/3.0/payment.js`, открывает модалку прямо на сайте)
- **Визуальный статус подключения** — зелёная/красная индикация: «Подключено» / «Не настроено»
- **Тестовые данные карты** — блок с номером тестовой карты для удобства тестирования
- Поле `payment_mode` в `organization_payment_settings` (redirect / widget)

### 2. Добавить вкладку «Инструкция» в PaymentsTab

Новая вкладка с пошаговой инструкцией:
- Как получить TerminalKey и пароль в ЛК Т-Банк Бизнес
- Как пройти 3 тестовых платежа (успешный, неуспешный, возврат)
- Данные тестовой карты (4300 0000 0000 0777, срок 12/25, CVC 000)
- Как переключиться на боевой режим
- FAQ по статусам платежей

### 3. Виджет оплаты Синтагма (встроенный)

Альтернатива редиректу — красивая модалка оплаты прямо на сайте:
- Если `payment_mode = "widget"`: подключается T-Bank Payment SDK через `<script>`, вызывается `pay.tbank.ru/sdk` с `paymentId` из Init
- Если `payment_mode = "redirect"` (по умолчанию): текущий редирект на `PaymentURL`
- **Собственная обёртка**: модальное окно в стиле Синтагма с информацией о курсе, суммой, логотипом организации, и внутри — iframe/виджет Т-Банка или кнопка «Перейти к оплате»

### 4. Расширить AdminFinanceOverview

Добавить вкладки:
- **Настройки касс организаций** — таблица: организация, terminal_key (маскированный), тестовый/боевой режим, дата настройки
- **Транзакции баланса** — все `balance_transactions` по всем организациям

### 5. Миграция БД

Добавить поле `payment_mode` (text, default `'redirect'`) в таблицу `organization_payment_settings`.
