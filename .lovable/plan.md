

# Тултипы, анимации и разделение Профиль/Настройки

## Что будет сделано

### 1. Тултипы и анимации на кнопках хедера (OrgDashboardHeader)
- Обернуть кнопку уведомлений и аватар профиля в `Tooltip` с подсказками "Уведомления" и "Профиль"
- Добавить `hover:scale-105 transition-transform` на кнопки для визуальной обратной связи при наведении

### 2. Кнопка «Настройки» в выпадающем меню профиля
В dropdown профиля (OrgDashboardHeader) добавить пункт **"Настройки"** с иконкой Settings, который ведёт на `/organization` с `state: { tab: "staff" }` (или отдельную страницу настроек). Итого в меню: Профиль, Настройки, Что нового?, Помощь, Выйти.

### 3. Разделение контента: Профиль vs Настройки
**Профиль** (`/organization/profile`) — всё, что связано с внешним видом:
- Тема оформления
- Брендирование (обложка, логотип, цвета)
- Брендирование страницы входа
- Настройки ЛК ученика (достижения, ИИ-чат)
- Данные для входа

**Настройки** (через пункт меню → переход на dashboard с нужной вкладкой) — бизнес-разделы:
- Сотрудники, Документооборот, Журналы, ФИС ФРДО
- Разделы меню
- Robokassa

Перенесу секции «Разделы меню», «Robokassa» и «Управление разделами» из Профиля в отдельную страницу/вкладку «Настройки».

### 4. Новая настройка: режим отображения для учеников
В секцию «Настройки ЛК ученика» добавить переключатель:
- **"Сначала каталог курсов"** — ученик видит витрину всех курсов (по умолчанию)
- **"Сначала назначенные курсы"** — ученик видит только курсы, на которые его назначили

Сохраняется в `student_dashboard_settings.catalogMode: "catalog" | "assigned"`. В `StudentDashboard` — считывается и определяет начальную вкладку/фильтр.
