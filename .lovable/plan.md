

# Четкие атмосферные фрагменты + новая тема «Монстера»

## Проблема

1. **AtmosphericBleed слишком размытый** — blur 40px превращает изображение в цветное пятно. На скриншоте видно, что фрагменты баннера (монстера, офис) должны быть **четкими и детализированными** в углах страницы
2. **Нет темы с монстерой** — на скриншоте офис с крупной монстерой в правом углу, это отдельная тема
3. **Баннеры недостаточно детализированы** — нужны более качественные URL (w=1920 вместо w=1200)

## Изменения

### 1. `src/components/ui/AtmosphericBleed.tsx` — четкие фрагменты

Полностью переделать логику:
- **Убрать blur по умолчанию** — если `atmosphereSharp: true`, фрагменты рендерятся без blur вообще (четкое изображение)
- Нижний правый угол: четкий фрагмент баннера с `mask-image` fade, opacity 0.4-0.6 — видно детали (листья монстеры, здания и т.д.)
- Нижний левый угол: аналогично, чуть слабее
- Размытый режим оставить как fallback для тем без `atmosphereSharp`

### 2. `src/constants/admin-themes.ts` — новая тема + качество

- Добавить тему **«Монстера»** (id: `monstera`, group: `nature`): фото офиса с крупными тропическими растениями. Unsplash: фото с монстерой в интерьере
- Увеличить качество всех баннеров: `w=1200` → `w=1920&q=85`
- Все темы получают `atmosphereSharp: true` и повышенный `atmosphereOpacity: 0.35-0.5`
- Тема «Бирюза» — добавить `atmosphereSharp: true`

### 3. Баннер `backgroundSize` — замостить для офиса

Добавить опциональное поле `bannerFit?: "cover" | "tile"` в `AdminTheme`. Для офисных тем с текстурой стены можно использовать `tile` (repeat). По умолчанию — `cover`.

## Технические детали

- AtmosphericBleed: когда `sharp=true`, рендерить фрагменты с `filter: saturate(1.2)` без blur
- Маски остаются (radial-gradient), но с более резким fade (70% → 50%)
- Opacity увеличивается до 0.4-0.5 чтобы детали были видны
- ~3 файла, ~60 строк изменений
