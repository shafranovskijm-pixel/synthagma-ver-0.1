

## План: виджет статистики тестов в курсах маркетплейса

### Что нужно

Добавить компактный виджет внутри `BulkPipelineWidget`, который покажет сводку по тестовым вопросам для всех курсов маркетплейса — разбитую на «В работе» и «Готово».

### Данные

Запрос к БД: для каждого курса из маркетплейса подсчитать количество тестовых вопросов и количество вопросов с заполненными `correct_answer` (не null и != -1). Разделить по `is_validated`.

SQL-логика (выполняется на клиенте через Supabase):
1. Получить все `marketplace_courses` с `course_id` и `is_validated`
2. Получить все `lessons` типа `test` для этих курсов
3. Для каждого lesson подсчитать `test_questions` (всего) и с `correct_answer >= 0` (решённых)

### UI

Компактная строка или мини-карточка в `BulkPipelineWidget`, под прогресс-баром:

```text
📊 Тесты: В работе — 1 240 вопросов (890 решено, 72%) | Готово — 56 вопросов (56 решено, 100%)
```

| `src/components/admin/AdminMarketplaceManager.tsx` | Передать `allCourses={h.courses}` в `BulkPipelineWidget` |

### Логика загрузки (в `BulkPipelineWidget`)

1. При монтировании (или по кнопке «Обновить») выполнить:
   - Получить `course_id` и `is_validated` из переданных `allCourses`
   - Запросить `lessons` с `type = 'test'` для всех `course_id`
   - Запросить `test_questions` для всех найденных `lesson_id`, подсчитать total и solved (где `correct_answer >= 0`)
2. Разбить по группам: «В работе» (is_validated !== true) и «Готово» (is_validated === true)
3. Показать в компактном виде с прогресс-полосками

### UI-деталь

Разместить сразу после прогресс-бара конвейера, перед секцией «Очередь курсов». Компактная горизонтальная строка с двумя блоками и процентами.
