
## Что просит пользователь
Добавить четвёртый тип правки — **«Добавить»** (вставка нового текста/пункта в позицию курсора, без выделения существующего фрагмента). Сейчас тулбар появляется только при выделении текста и предлагает 3 действия: Комментарий / Удалить / Заменить. Опции «Вставить новое» нет.

## Решение

### 1. Новый режим «Вставить» в `ReviewableDocument.tsx`
- Добавить отслеживание **позиции курсора** (caret) — клик в тексте без выделения создаёт «точку вставки» с одним offset (`startOffset === endOffset`).
- Когда есть точка вставки (а не диапазон), показывать **отдельный мини-тулбар** с одной кнопкой ➕ **«Добавить пункт здесь»**.
- При клике — открыть textarea для ввода нового текста, при сохранении писать комментарий с `position_anchor.kind = "insert"` и `replacement = <новый текст>`.

### 2. Когда выделен фрагмент — добавить 4-ю кнопку
В существующий тулбар (Комментарий / Удалить / Заменить) добавить **➕ «Вставить после»** — вставка нового текста сразу после выделенного фрагмента, без его изменения. Это удобно для «добавить пункт после этого».

### 3. Визуализация в документе
- Для `kind === "insert"` рендерить в позиции `startOffset` зелёный маркер `<ins data-kind="insert-only">+ <текст></ins>` прямо в потоке текста.
- Цвет — изумрудный фон, без перечёркивания, с иконкой «+» в начале.
- В боковой панели — бейдж **«➕ Добавить»** зелёного цвета и блок «Новый текст: …».

### 4. Сброс состояния
- После сохранения insert-комментария так же чистить caret-позицию, draft, selection (как уже сделано для других типов).
- Клик вне документа скрывает caret-тулбар.

## Файлы
- `src/components/signing/ReviewableDocument.tsx` — caret-detection, новый мини-тулбар, рендер `<ins data-kind="insert-only">`, обработка submit для `kind: "insert"`.
- `src/components/signing/ContractReviewBody.tsx` — бейдж «Добавить» в карточках комментариев.

## Этапы
1. Добавить определение caret-позиции (selection без range) и состояние `insertCaret`.
2. Тулбар «Добавить пункт здесь» при caret + 4-я кнопка «Вставить после» в обычном тулбаре.
3. Рендер зелёной вставки `<ins>` в нужной позиции.
4. Бейдж «Добавить» в боковой панели.
5. End-to-end проверка: кликнуть в текст → «Добавить пункт» → ввести текст → увидеть зелёную вставку в документе и карточку в панели.
