

# Капитальная переработка менеджера достижений

## Проблема
Текущий менеджер — маленький Dialog с минимальным дизайном, без визуальной привлекательности. Шаблоны не отображаются сразу, нет красивых карточек с цветовым кодированием по редкости.

## Что будет сделано

### 1. Полноразмерное модальное окно
Заменить `max-w-2xl` на `max-w-4xl` с фиксированной высотой. Левая сайдбар-навигация (иконки + текст) + основная область контента справа. Полноценный интерфейс, а не "маленькое окошечко".

### 2. Шаблоны видны сразу при открытии
Начальный вид — не пустой список, а **витрина**: если нет своих достижений, показываем красивые карточки шаблонов по категориям с предложением добавить. Каждая категория — визуальная карточка с градиентом и иконкой.

### 3. Красивые карточки достижений с визуальным кодированием
Каждое достижение — карточка с цветной рамкой/фоном по редкости:
- **Обычное** — серый фон, простая рамка
- **Редкое** — синий градиент, лёгкое свечение
- **Эпичное** — фиолетовый градиент, свечение
- **Легендарное** — золотой градиент, анимированное свечение, блёстки

Эмодзи-иконка крупно (48px), название жирным, описание мелко, бейдж редкости с цветом.

### 4. Сетка вместо списка
Достижения в grid 2-3 колонки (карточки), а не скучный вертикальный список. Так визуально богаче.

### 5. Шаблоны — красивые тематические блоки
Каждая категория шаблонов — большая карточка с тематическим градиентом, иконкой, описанием и превью всех достижений внутри. Можно раскрыть/свернуть и посмотреть каждое достижение перед применением.

### 6. Улучшенная форма добавления
Превью карточки достижения в реальном времени при заполнении формы — пользователь сразу видит, как будет выглядеть результат.

### 7. Кнопка «Настроить» в SettingsStudentDashboardTab
Заменить невзрачную маленькую кнопку на заметную кнопку с градиентом и иконкой.
