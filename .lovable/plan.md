
## Исправление: убрать студенческую регистрацию

### Проблема
Файл `src/pages/Register.tsx` (регистрация студентов) все ещё существует в проекте. Хотя маршрут `/register` уже указывает на `RegisterOrganization`, кнопка "Начать обучение" на лендинге (в `ForStudents.tsx`) ведёт на `/register`, что может вводить в заблуждение. Кроме того, `signUp` в `useAuth` создаёт пользователя без роли — по умолчанию он становится студентом.

### Что будет сделано

#### 1. Удалить файл `src/pages/Register.tsx`
Страница студенческой регистрации больше не нужна — студентов регистрируют только организации через свой кабинет.

#### 2. Убрать импорт в `src/App.tsx` (строка 21)
Удалить строку:
```
const Register = lazy(() => import("./pages/Register"));
```

#### 3. Обновить `src/components/landing/ForStudents.tsx` (строка 73)
Кнопка "Начать обучение" будет вести на `/login` вместо `/register`:
```
<Link to="/login">
```

#### 4. Проверить и удалить тестового пользователя
Если аккаунт "biz" (скриншот) был создан случайно — удалить его из базы данных.

### Затрагиваемые файлы

| Файл | Действие |
|------|----------|
| `src/pages/Register.tsx` | Удалить |
| `src/App.tsx` | Убрать импорт Register |
| `src/components/landing/ForStudents.tsx` | Изменить ссылку `/register` на `/login` |
