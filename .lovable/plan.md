
# Переписать страницу «Магазин курсов» с фокусом на выгоды

## Что изменится

Текущая страница описывает функции (каталог, заявки, уведомления). Нужно переписать контент с акцентом на **выгоды** для двух аудиторий.

## Новый контент

### Hero-секция
- Заголовок: «Дополнительный канал продаж ваших курсов»
- Подзаголовок: акцент на то, что курсы организации увидят все ученики Синтагмы — это готовая аудитория без затрат на рекламу. Доступно на всех тарифах, включая бесплатный.

### Секция «Выгоды для организаций» и «Выгоды для слушателей» (вместо «Два режима работы»)
- Заголовок секции: «Выгодно для всех участников»
- **Для организаций**: выложите курс в маркетплейс — его увидят все ученики Синтагмы. Это дополнительный канал продаж без затрат на рекламу. Устанавливайте свои цены, получайте заявки и расширяйте аудиторию.
- **Для слушателей**: откройте для себя курсы на разные темы от проверенных учебных организаций. Больше вариантов обучения — больше возможностей для роста.

### Секция «Как это работает» (вместо «Возможности маркетплейса»)
- Заголовок: «Как это работает»
- Подзаголовок: «Простой путь от публикации до продажи»
- Элементы переписать с фокусом на выгоды:
  1. Организация публикует курс — он сразу виден всей аудитории платформы
  2. Слушатели находят курс по теме и отправляют заявку
  3. Организация получает уведомление и обрабатывает заявку
  4. Гибкие цены — разные тарифы для организаций и частных слушателей
  5. Аналитика продаж — отслеживайте спрос и доход
  6. Полный контроль — публикуйте, редактируйте, снимайте с продажи в любой момент

### CTA-секция
- Заголовок: «Расширьте аудиторию ваших курсов»
- Подзаголовок: «Выложите свой первый курс в маркетплейс — это бесплатно»
