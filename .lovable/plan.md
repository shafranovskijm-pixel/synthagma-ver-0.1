## Изменения

### 1. `SalesSidebar.tsx` — новый пункт меню
- Добавить `{ id: 'company-card', label: 'Карточка', icon: CreditCard }` в `menuItems`

### 2. `SalesManager.tsx` — подключить новый таб
- Добавить `'company-card': <CompanyCard />` в `TABS`

### 3. Новый компонент `CompanyCard.tsx`
- При загрузке вызывает `dadata-company` с ИНН `253615392404`
- Отображает премиальную карточку с секциями:
  - **Основные реквизиты** — Наименование, ИНН, ОГРНИП, статус
  - **Руководитель** — ФИО, дата рождения
  - **Адрес** — из DaData
  - **Контакты** — email, домен
  - **Лицензии** — если есть в DaData
  - **Банковские реквизиты** — заглушка с пометкой «Требуется заполнить»
- Дизайн: тёмная карточка с тиловыми акцентами, иконки, разделители, копирование по клику

### 4. Стиль
- Luxury-минимализм, teal/cyan акценты, shadow (без backdrop-blur), rounded-[28px] элементы

## Технические детали

- DaData вызывается через существующую edge-функцию `dadata-company`
- Жёстко заданные поля (дата рождения, email, домен) — константы в компоненте
- Банковские реквизиты — пустые поля с иконкой «заполнить»
- Копирование значений в буфер по клику на каждое поле
