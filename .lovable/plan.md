

## План: кнопка «Проверочный прогон» на одном курсе

### Что нужно сделать

Добавить кнопку «Тест на 1 курсе» рядом с «Запустить», которая:
1. Берёт первый курс из очереди
2. Запускает `processCourse` только для него
3. Автоматически раскрывает секцию «Очередь курсов» и показывает лог в реальном времени — какая фаза идёт, сколько тестов решено, сколько уроков заполнено
4. По завершении показывает результат (зелёная/красная иконка + детали)

### Изменения в `BulkPipelineWidget.tsx`

**Новое состояние:**
- `isTestRunning` — отдельный флаг для тестового прогона (чтобы не путать с массовым запуском)

**Новая кнопка** — рядом с «Запустить», с иконкой `FlaskConical` или `TestTube2`:
```
[🧪 Тест 1 курса]  [▶ Запустить все]
```

**Логика `handleTestRun`:**
- Берёт `courses[0]`
- Устанавливает `isTestRunning = true`, `queueOpen = true`
- Вызывает `processCourse(courses[0])`
- Записывает результат в `completedLog`
- `isTestRunning = false`

**UI:** Во время тестового прогона кнопка «Запустить все» заблокирована, и наоборот. Текущая фаза и прогресс отображаются как обычно — в строке статуса и в таблице очереди.
