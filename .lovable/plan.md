

# Улучшение дизайна sidebar документов + добавление разделов

## Что будет сделано

### 1. Анимации и hover-эффекты на кнопках навигации
В desktop-sidebar (`DocumentsTab.tsx`):
- Добавить `transition-all duration-200` на все кнопки навигации
- При наведении — циановый (primary) цвет иконки и фона: `hover:text-primary hover:bg-primary/10`
- Активная кнопка — более насыщенный фон `bg-primary/15` с плавным переходом
- Добавить `hover:translate-x-0.5` для лёгкого сдвига при наведении

### 2. Визуальное выделение разделов «Документы орг.»
Группировать пункты навигации визуально:
- **Блок 1**: «Документы Синтагма», «Плательщики» — без дополнительного оформления (основные)
- **Блок 2**: «Документы орг.», «Приказы», «Протоколы АК», «Удостоверения», «Дипломы», «Свидетельства» — выделить лёгким циановым акцентом: тонкая полоска слева или иконки в цвете `text-primary/70`, мелкий заголовок-разделитель «Документооборот» сверху
- **Блок 3**: «Программы», «Конструктор» — внизу, разделитель

### 3. Декоративные элементы
- Мелкие разделители между группами (тонкая линия + мини-заголовок секции)
- Иконки документооборота (приказы, протоколы, удостоверения, дипломы, свидетельства) окрасить в мягкие индивидуальные цвета для визуального различия
- Лёгкий градиентный фон sidebar

### 4. Текущий список уже включает все нужные пункты
Проверено: «Документы орг.», «Приказы», «Протоколы АК», «Удостоверения», «Дипломы», «Свидетельства» — уже есть в `NAV_ITEMS`. Никаких новых разделов добавлять не нужно.
