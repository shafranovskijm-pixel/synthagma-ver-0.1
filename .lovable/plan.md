## Проблема

Когда нажимаешь «Создать курс», после создания открывается отдельная страница `/course-builder/:id` (с кнопкой «Назад» сверху — это видно на скриншоте). А когда открываешь уже существующий курс из списка — открывается встроенная вкладка внутри кабинета организации (через `onOpenCourseDetails` → вкладка `course-details`).

Поведение должно быть одинаковым: и новый, и существующий курс должны открываться **в том же окне**, без перехода на отдельную страницу.

## Что менять

Один файл: `src/components/organization/tabs/CoursesTab.tsx`, функция `handleCreateCourse`.

Заменить вызов:
```ts
navigate(`/course-builder/${course.id}`);
```
на:
```ts
handleCourseClick(course);
```

Это откроет только что созданный курс через тот же механизм, что и клик по существующему курсу — внутри дашборда (вкладка «Содержание курса»), без выхода в отдельное окно с «Назад».

## Технические детали

- `handleCourseClick(course)` вызывает `onOpenCourseDetails(course)` (передан из `TabContentRenderer.tsx`), который переключает `activeTab` на `course-details` и устанавливает `selectedCourseId`.
- Других мест навигации в `/course-builder/...` после создания нет — кнопка «Создать курс» в `OrganizationDashboard` идёт через тот же диалог.
- Кнопки «Редактировать» в строчном виде (`navigate('/course-builder/:id')`) НЕ трогаем — это отдельный сценарий редактирования.
