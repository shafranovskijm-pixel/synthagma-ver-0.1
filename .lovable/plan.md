

# Полноценный договор по 273-ФЗ + FAQ-инструкция в документообороте

## Что делаем

### 1. Новый шаблон договора, соответствующий 273-ФЗ и Правилам №1441

Заменяем текущий шаблон «Для юр. лица» и добавляем новый шаблон «273-ФЗ (полный)» с **всеми обязательными условиями**:

- **Преамбула**: полное наименование Исполнителя с ОГРН, ИНН, местом нахождения, лицензией (номер, дата, кем выдана)
- **Предмет договора**: вид/уровень/направленность программы, форма обучения (электронное/дистанционное), объём часов, сроки освоения
- **Обучающиеся**: отдельный пункт — ФИО, место жительства, телефон (или ссылка на Приложение №1)
- **Стоимость и порядок оплаты**: полная стоимость, запрет увеличения, порядок оплаты
- **Права и обязанности**: развёрнутый раздел для Исполнителя, Заказчика и Обучающихся
- **Ответственность сторон**: неустойки, форс-мажор
- **Документ об образовании**: вид выдаваемого документа (удостоверение/диплом/свидетельство)
- **Порядок изменения и расторжения**: основания одностороннего расторжения Исполнителем (просрочка оплаты и т.д.)
- **Особые условия для СДО**: порядок доступа к СДО Sintagma, требования к оборудованию, электронное обучение
- **Реквизиты и подписи**: все плейсхолдеры ({{org_license_number}}, {{org_license_date}}, {{org_license_issuer}}, {{document_type_name}}, {{education_form}})

Шаблон автоматически подставляет реквизиты организации из формы реквизитов.

### 2. Новые плейсхолдеры

Добавляем в массив `PLACEHOLDERS` в `ContractTemplateEditor.tsx`:
- `{{org_license_number}}` — номер лицензии
- `{{org_license_date}}` — дата лицензии
- `{{org_license_issuer}}` — кем выдана лицензия
- `{{document_type_name}}` — вид выдаваемого документа
- `{{education_form}}` — форма обучения

### 3. FAQ-инструкция по договорам (новая вкладка «Справка» в Конструкторе)

Добавляем вкладку `info` в конструктор документов (`DocumentsTab.tsx`, секция `constructor`) с содержанием:

- **Какие пункты обязательны** — таблица из 15 пунктов п.13 Правил №1441
- **Что будет если не указать** — договор считается незаключённым
- **Что нельзя включать** — условия, ухудшающие положение обучающихся
- **Как работает автоподстановка** — инструкция по переменным
- **Какой шаблон выбрать** — описание каждого шаблона
- **Ссылки на законы** — 273-ФЗ ст.54, Правила №1441

Оформление — Accordion с секциями, стилизованные Alert-блоки для предупреждений.
