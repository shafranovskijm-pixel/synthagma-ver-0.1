
# Улучшение меню добавления блоков

## Проблема
Меню добавления блоков содержит ~20 пунктов в одном длинном списке, что делает его неудобным для использования.

## Решение
Заменить плоский DropdownMenu на Popover с категориями (вкладками), сгруппировав блоки по типам:

**Категории:**
- **Текст** — Параграф, Заголовок 1, Заголовок 2, Списки, Цитата
- **Выделение** — Информация, Предупреждение, Совет, Выполнено, Ошибка, Выделение
- **Медиа** — Изображение, Видео, Аудио, Слайдер
- **Прочее** — Сворачиваемая секция, Мини-квиз, Разделитель

## Технические детали

### Файл: `src/components/course-builder/BlockEditor.tsx`

1. **Переписать компонент `AddBlockButton`** (строки 356-430):
   - Заменить `DropdownMenu` на `Popover` с `Tabs` внутри
   - Использовать уже импортированные `Popover`, `Tabs`, `TabsList`, `TabsTrigger`, `TabsContent`
   - Каждая вкладка содержит компактную сетку (grid 2 колонки) с кнопками блоков
   - Popover закрывается при выборе блока через управление состоянием `open`

2. **Обновить inline-меню "+" в блоке** (строки 831-843):
   - Аналогично заменить DropdownMenu на Popover с категориями
   - Или использовать DropdownMenu с SubMenu для группировки

3. **Структура UI:**

```text
+----------------------------------+
| Текст | Выделение | Медиа | Ещё  |   <-- TabsList
+----------------------------------+
| [Параграф]   [Заголовок 1]      |
| [Заголовок 2] [Маркир. список]  |   <-- Grid 2 cols
| [Нумер. список] [Цитата]        |
+----------------------------------+
```

Каждый элемент сетки — компактная кнопка с иконкой и названием. Максимальная высота ограничена, чтобы меню не выходило за экран.
