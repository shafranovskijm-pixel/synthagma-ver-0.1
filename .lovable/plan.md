

# Система подсказок и обучения для новых пользователей

## Описание

Интерактивная система онбординга, которая поможет новым организациям и ученикам разобраться на платформе. Включает пошаговые подсказки при первом входе и постоянно доступный раздел "Помощь".

## Что будет реализовано

### 1. Онбординг для организаций (первый вход)

При первом входе в панель организации появляется модальное окно-приветствие с пошаговым "туром" по основным разделам:

- **Шаг 1**: "Добро пожаловать!" -- краткое описание платформы
- **Шаг 2**: "Курсы" -- как создать первый курс
- **Шаг 3**: "Ученики" -- как добавить учеников и создать группы
- **Шаг 4**: "Документы" -- автоматизация документооборота
- **Шаг 5**: "Настройки" -- брендирование, тарифы, меню

Каждый шаг содержит иконку, заголовок, краткое описание и кнопку "Перейти к разделу". Можно пропустить тур кнопкой "Пропустить".

### 2. Онбординг для учеников (первый вход)

При первом входе ученика -- приветственное окно с объяснением:

- Как начать обучение (нажать на курс)
- Как загрузить документы
- Как пройти видеоидентификацию
- Как использовать ИИ-помощника

### 3. Кнопка "Помощь" (постоянная)

В боковом меню организации и на панели ученика добавляется кнопка "Помощь" (иконка `HelpCircle`), которая открывает диалог со списком подсказок по текущему разделу.

### 4. Запоминание статуса

В базе данных (таблица `profiles`) добавляется поле `onboarding_completed` (boolean, default false). После завершения/пропуска тура поле обновляется, и тур больше не показывается.

## Технические детали

### База данных

Миграция: добавить колонку `onboarding_completed boolean default false` в таблицу `profiles`.

### Новые компоненты

| Файл | Назначение |
|---|---|
| `src/components/onboarding/OnboardingDialog.tsx` | Главный компонент тура (пошаговый диалог с прогрессом) |
| `src/components/onboarding/OnboardingStepCard.tsx` | Карточка одного шага |
| `src/components/onboarding/HelpButton.tsx` | Кнопка "Помощь" + диалог с контекстными подсказками |
| `src/constants/onboardingSteps.ts` | Данные шагов для организации и ученика |

### Интеграция

- **OrganizationDashboard.tsx**: при загрузке проверяет `onboarding_completed` из профиля. Если `false` -- показывает `OnboardingDialog` с шагами для организации. По завершении обновляет поле в БД.
- **StudentDashboard.tsx**: аналогичная логика с шагами для ученика.
- **OrgSidebar.tsx**: добавляется кнопка "Помощь" (`HelpCircle`) в нижнюю часть сайдбара.
- **StudentDashboard.tsx**: кнопка "Помощь" в навигации ученика.

### Дизайн

- Диалог тура использует существующий `Dialog` компонент с анимациями `framer-motion` между шагами
- Прогресс-бар сверху диалога показывает текущий шаг
- Стиль соответствует "Luxury Minimalist" -- золотые акценты для иконок шагов, шрифт Playfair Display для заголовков
- Кнопка "Помощь" -- ненавязчивая, в стиле остальных пунктов меню
