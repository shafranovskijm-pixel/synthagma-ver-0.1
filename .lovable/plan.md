

# Исправление кнопки «Зачислить» в группах

## Проблема
Кнопка «Зачислить» отключена (`disabled`) когда в группе 0 учеников (`total === 0`). Пользователь не понимает, почему кнопка не работает — нет обратной связи.

## Решение
Убрать `disabled` при `total === 0` и вместо этого показывать toast с пояснением при клике (функция `handleEnrollGroup` уже делает это: `toast.warning("В группе нет учеников")`). Оставить `disabled` только во время загрузки (`isEnrolling`) и когда все уже зачислены (`allEnrolled`).

## Изменение

**Файл**: `src/components/organization/CourseGroupsTab.tsx`, строка 416

Было:
```
disabled={isEnrolling || allEnrolled || total === 0}
```

Станет:
```
disabled={isEnrolling || allEnrolled}
```

Одна строка — кнопка станет кликабельной, а при 0 учеников пользователь увидит предупреждение «В группе нет учеников».
