

## План: Автоисправление курса в один клик (без диалога BulkContentGenerator)

### Суть

Вместо открытия сложного окна «Массовая генерация» по кнопке «Исправить ИИ», система сразу запустит автоматическое исправление найденных проблем прямо из тоста — без промежуточных окон и ручного выбора.

### Как будет работать

1. Валидация курса находит проблемы (уроки без контента, тесты без ответов)
2. В тосте появляется кнопка **«Исправить ИИ»**
3. По клику — сразу запускается фоновый процесс:
   - Генерация контента для пустых уроков (через `generate-lesson-content`)
   - Решение тестов без ответов (через `gigachat` с `generate_answers`)
4. Прогресс показывается через toast-уведомления: «Исправляю 1/5...», «Исправляю 2/5...»
5. По завершении — автоматическая повторная валидация и перемещение курса в «Готовые»

### Изменения

#### `src/components/admin/AdminMarketplaceManager.tsx`

1. Добавить функцию `autoFixCourse(courseId, issues)` прямо в компоненте:
   - Получает уроки курса из БД
   - Находит пустые text/practice уроки → генерирует контент через edge function `generate-lesson-content`
   - Находит тесты без ответов → решает через `gigachat` (action: `generate_answers`)
   - Показывает прогресс через `toast.loading` с обновлением текста
   - По завершении запускает `handleValidateCourse` повторно

2. В тосте с ошибками заменить открытие `BulkContentGenerator` на вызов `autoFixCourse`

3. Диалог `BulkContentGenerator` остаётся доступным через кнопку ✨ (для ручного контроля), но кнопка «Исправить ИИ» в тосте теперь работает автономно
