

## Добавить выбор организации из базы при создании договора

### Что будет сделано

В форму создания договора добавится **выпадающий список** зарегистрированных организаций (из таблицы `organizations`). При выборе организации поля «Название компании», «ИНН», «КПП», «Адрес», «Директор», «Контактное лицо», «Email», «Телефон» автозаполняются. Можно также оставить ручной ввод (не выбирая организацию).

### Изменения

**Файл: `src/components/admin/sales/SalesContracts.tsx`**

1. Добавить состояние `organizations` — загрузка списка из таблицы `organizations` (id, name, inn, kpp, legal_address, director_name, contact_name, email, phone) при монтировании
2. Добавить в начало формы (перед «Данные заказчика») поле **«Выбрать организацию»** — `Select` с поиском по названию + вариант «Ввести вручную»
3. При выборе организации — автозаполнение полей формы из данных организации:
   - `company_name` ← `name`
   - `company_inn` ← `inn`
   - `company_kpp` ← `kpp`
   - `company_address` ← `legal_address`
   - `company_director` ← `director_name`
   - `contact_person` ← `contact_name`
   - `contact_email` ← `email`
   - `contact_phone` ← `phone`
4. Поля остаются редактируемыми после автозаполнения

### Результат
Одним кликом можно выбрать существующую организацию и все реквизиты подтянутся автоматически — не нужно вводить вручную.
