
# Улучшения конструктора шаблонов договора

## 1. Вставка переменных по клику

Рядом с редактором появится панель со списком всех переменных, сгруппированных по категориям (Договор, Организация, Заказчик, Курс, Физ. лицо, Оплата). Клик по переменной вставит её в текст на позицию курсора в textarea.

**Реализация:**
- В `HighlightedTemplateEditor` добавить боковую панель (или выпадающую панель под легендой) со списком переменных
- Отслеживать `selectionStart` в textarea через ref
- При клике на переменную — вставлять `{{variable_name}}` в позицию курсора и обновлять value через `onChange`
- Панель будет сворачиваемой, чтобы не мешать при редактировании

## 2. Валидация шаблона

Под редактором появится блок диагностики, показывающий:
- Обязательные переменные, которых нет в шаблоне (например, `contract_number`, `org_name`, `company_name`)
- Неизвестные переменные (опечатки вроде `{{compny_name}}`)
- Предупреждения (например, есть `{{price}}`, но нет `{{total_price}}`)

**Реализация:**
- В `HighlightedTemplateEditor` добавить функцию `validateTemplate`, которая:
  - Извлекает все `{{...}}` из текста
  - Сравнивает с известным списком переменных
  - Проверяет наличие обязательных переменных
- Результаты отображаются как цветные бейджи (зеленый — ОК, желтый — предупреждение, красный — ошибка)

## 3. Библиотека шаблонов

Добавить возможность сохранять и загружать несколько шаблонов:
- Предустановленные шаблоны: «Для юр. лица», «Для физ. лица», «Для ИП»
- Возможность сохранить текущий шаблон под своим именем
- Выбор шаблона из выпадающего списка

**Реализация:**
- Шаблоны хранятся в поле `branding` организации как массив `contractTemplates: [{ id, name, text, isDefault }]`
- Текущий `contractTemplate` (строка) мигрирует в `contractTemplates[0]` при первой загрузке
- В UI добавить Select для выбора шаблона + кнопки «Сохранить как...» и «Удалить»
- Три встроенных шаблона (юр. лицо, физ. лицо, ИП) доступны всегда и не удаляются

## 4. История версий шаблона

При каждом сохранении автоматически сохраняется предыдущая версия.

**Реализация:**
- В `branding` добавить поле `contractTemplateHistory: [{ text, savedAt, name }]` (до 10 последних версий)
- При нажатии «Сохранить» текущий шаблон добавляется в историю перед перезаписью
- Кнопка «История» открывает диалог со списком версий (дата + первые 100 символов текста)
- Клик по версии загружает её в редактор

## Технические детали

### Файлы для изменения:
1. **`src/components/organization/HighlightedTemplateEditor.tsx`** — добавить панель вставки переменных + валидацию
2. **`src/components/organization/ContractTemplateEditor.tsx`** — библиотека шаблонов, история версий, интеграция новых функций

### Структура данных в `branding`:
```text
branding: {
  contractTemplates: [
    { id: "default", name: "Для юр. лица", text: "...", isBuiltIn: false },
    { id: "individual", name: "Для физ. лица", text: "...", isBuiltIn: true },
    ...
  ],
  activeContractTemplateId: "default",
  contractTemplateHistory: [
    { text: "...", savedAt: "2026-02-27T12:00:00Z", templateName: "Для юр. лица" },
    ...
  ]
}
```

### Встроенные шаблоны:
- **Юр. лицо** — текущий DEFAULT_CONTRACT_TEMPLATE (с блоком «в лице... на основании Устава»)
- **Физ. лицо** — адаптированный шаблон без представительства, с переменными `{{individual_*}}`
- **ИП** — шаблон без блока устава, с корректным «именуемый» вместо «именуемое»

### Обязательные переменные для валидации:
`contract_number`, `contract_date`, `org_name`, `company_name` (или `individual_name`), `course_title`, `price`, `total_price`
