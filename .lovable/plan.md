

# Биллинг в админке — вертикальное меню + выбор организации

## Что делаем

Переделываем `AdminBillingOverview` по образцу `DocumentsTab` организации: двухколоночный макет с вертикальным сайдбаром слева. Добавляем возможность выбрать организацию и управлять её документами (договоры, счета, акты) — по сути, админ видит то же, что и организация в разделе «Документы Синтагма», но для всех организаций сразу + может создавать документы от имени любой из них.

## Структура

```text
┌──────────────────┬──────────────────────────────────┐
│ Боковое меню     │ Контент                          │
│                  │                                  │
│ ── Обзор ──      │ (зависит от выбранного раздела)  │
│ • Все расчёты    │                                  │
│                  │                                  │
│ ── Организация ──│                                  │
│ [Выбор орг-ции]  │                                  │
│ • Договоры       │                                  │
│ • Счета          │                                  │
│ • Акты/Закрыв.   │                                  │
└──────────────────┴──────────────────────────────────┘
```

## Изменения

### `src/components/admin/AdminBillingOverview.tsx` — полная переработка

1. **Двухколоночный макет** — скопировать структуру из `DocumentsTab`: `nav` слева (lg:w-56), контент справа, с разделителями групп и подсветкой `bg-primary/15 border-r-2 border-primary`

2. **Боковое меню**:
   - Группа «Обзор»: пункт «Все расчёты» — текущий общий вид (договоры/счета/закрывающие всех организаций)
   - Разделитель
   - Группа «Организация»: Select/Combobox с поиском для выбора организации
   - После выбора появляются пункты: «Договоры», «Счета», «Закрывающие»

3. **Раздел «Все расчёты»** — текущий контент (таблицы с фильтром по поиску) без изменений

4. **Раздел выбранной организации** — при выборе организации админ видит её документы (как в DocumentsTab billing секции), но с возможностью:
   - Создавать договоры (уже есть)
   - Выставлять счета (кнопка «Сформировать счёт» → открывает `/invoice/...` или диалог)
   - Создавать акты (кнопка «Сформировать акт»)
   - Видеть все существующие документы организации

Один файл, полная переработка ~350 строк.
