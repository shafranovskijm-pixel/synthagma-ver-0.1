
# Переработать именно расположение страницы «Документы»

## Что не так сейчас
Изменился только стиль табов, но не композиция страницы. Навигация по-прежнему стоит сверху и переносится, поэтому визуально всё осталось почти как было. По вашим примерам нужен не «ряд вкладок сверху», а полноценная layout-перестройка.

## Что будет сделано

### 1. Переделать страницу в 2-колоночный layout
Страница `/organization/documents` станет похожа на настройки/рабочий кабинет:

```text
[ Левая колонка ]
Документы
- Конструктор
- Документы орг.
- Приказы
- Протоколы АК
- Удостоверения
- Дипломы
- Свидетельства
- Программы
- Закрывающие

[ Правая колонка ]
Заголовок раздела
Локальные фильтры / поиск / действия
Основной контент выбранного раздела
```

То есть навигация переедет влево, а контент будет справа — как в ваших референсах.

### 2. Убрать верхнюю “простыню” из табов
В `DocumentsTab.tsx` больше не будет длинной верхней полосы со всеми разделами.  
Вместо этого:
- слева компактный вертикальный список разделов;
- справа только контент активного раздела;
- на мобильных можно оставить горизонтальный fallback или dropdown.

### 3. Сделать правую часть чище и спокойнее
Для выбранного раздела:
- единый заголовок и краткое описание;
- действия вынести в header-content area;
- убрать лишние обёртки, где они дублируют друг друга;
- оставить подсказку только там, где она действительно нужна.

### 4. Подчистить «Конструктор»
Внутренние подтабы конструктора оставить, но оформить как отдельную локальную навигацию внутри правой панели, чтобы они не спорили с основной навигацией страницы.

### 5. Согласовать стиль с текущим дизайном платформы
Сделать интерфейс в духе «чистые настройки / рабочая панель»:
- светлый минималистичный фон;
- мягкие бордеры;
- акцент teal/cyan, без тяжёлых кнопочных плашек;
- более спокойные отступы и визуальная иерархия.

## Какие файлы нужно изменить

| Файл | Что поменять |
|---|---|
| `src/pages/OrganizationDocuments.tsx` | Перестроить контейнер страницы под 2-колоночный layout |
| `src/components/organization/tabs/DocumentsTab.tsx` | Убрать верхний ряд табов и сделать левую вертикальную навигацию + правую контентную область |
| `src/components/organization/OrgDocumentsManager.tsx` | При необходимости упростить верхнюю часть контента, чтобы она вписалась в новый layout |
| `src/components/organization/DocumentArchiveView.tsx` | Подчистить header/filters под новый правый контентный блок |
| `src/components/organization/EducationDocumentsJournal.tsx` | При необходимости адаптировать верхнюю панель под новый layout |

## Технически
- текущее изменение в `DocumentsTab.tsx` затронуло только `TabsTrigger`, но не layout;
- следующий шаг — менять не косметику, а структуру контейнера;
- основную навигацию лучше сделать либо через `Tabs` в вертикальной версии, либо через собственный controlled sidebar-like menu;
- активный раздел должен управлять правой панелью без переноса элементов наверх.

## Результат
После этого страница действительно поменяет расположение, а не только стиль:
- навигация будет слева;
- контент — справа;
- интерфейс станет легче, понятнее и ближе к вашим примерам.
