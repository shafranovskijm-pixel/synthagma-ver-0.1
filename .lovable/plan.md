

# Этап 1: Роль «Компания» — вход, кабинет, управление сотрудниками

## Обзор

Добавляем новую роль `company` в систему. Компания получает собственный логин/пароль и личный кабинет с возможностью просматривать своих сотрудников, добавлять новых и видеть их прогресс обучения.

---

## 1. База данных (SQL-миграции)

### 1.1 Добавить роль `company` в enum
```sql
ALTER TYPE public.app_role ADD VALUE IF NOT EXISTS 'company';
```

### 1.2 Расширить таблицу `companies`
- Добавить `user_id UUID` — связь с auth.users (пользователь-аккаунт компании)
- Добавить `login_email TEXT` — email для входа
- Добавить `generated_password TEXT` — зашифрованный пароль (через существующий механизм encrypt_password)

### 1.3 Функция `current_company_id()`
По аналогии с `current_organization_id()` — SECURITY DEFINER функция, возвращающая `id` компании текущего пользователя.

### 1.4 RLS-политики для роли `company`
- `profiles`: SELECT для сотрудников своей компании (`company_id = current_company_id()`)
- `enrollments`: SELECT для зачислений своих сотрудников
- `courses`: SELECT для курсов своей организации (read-only)
- `companies`: SELECT/UPDATE для своей записи
- `company_documents`: SELECT для документов своей компании

### 1.5 Триггер шифрования пароля
Подключить существующий механизм `encrypt_password` к полю `companies.generated_password`.

---

## 2. Edge-функция `create-company-user`

Создание аккаунта компании (вызывается организацией из карточки компании):
- Принимает `company_id`, `email`, `password`
- Создает пользователя в auth.users
- Назначает роль `company` в `user_roles`
- Создает запись в `profiles` с `company_id` и `organization_id`
- Сохраняет `user_id`, `login_email`, `generated_password` в таблице `companies`

## 5. Кабинет компании — `CompanyDashboard.tsx`

**Новая страница**: `src/pages/CompanyDashboard.tsx`

### Структура кабинета:
- **Онбординг** — приветственный блок при первом входе
- **Статистика** — количество сотрудников, средний прогресс, завершенные курсы
- **Список сотрудников** — таблица с ФИО, email, курсами, прогрессом
- **Добавление сотрудника** — форма (ФИО, email) для регистрации нового сотрудника через существующую edge-функцию `register-student` с привязкой к `company_id`

### Хук `useCompanyDashboard.ts`
- Загрузка данных компании
- Загрузка списка сотрудников с прогрессом
- Добавление нового сотрудника
