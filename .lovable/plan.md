

## Перестроить иерархию: модуль — главный, урок — только внутри модуля

Сейчас в сайдбаре кнопка «+ Добавить урок» висит сверху как самостоятельная, и уроки могут лежать в корне («Без модуля»). На скриншоте Skill Space — другая логика: сверху только модули, кнопка «+ Занятие» появляется **внутри раскрытого модуля**, а в самом низу — большая кнопка «+ Модуль».

### Что меняем в `CourseBuilderLessonsNav.tsx`

1. **Убрать из шапки** кнопку «+ Добавить урок» (открывающую popup типов). Остаётся только заголовок «Уроки (N)» и переключатель свернуть/развернуть всё.

2. **Убрать секцию «Без модуля»** в её текущем виде (как самостоятельный аккордеон сверху). Вместо этого:
   - Если в курсе есть уроки без `module_id` (старые курсы) — при первом открытии автоматически создать модуль «Основной» и перенести их туда (одна транзакция: insert module + update lessons set module_id). Делаем тихо, без диалогов.
   - Дальше любой новый урок может появиться **только внутри модуля**.

3. **Внизу сайдбара** — большая кнопка-плитка «**+ Модуль**» (полная ширина, teal-фон как на референсе). Клик → создаёт новый модуль с дефолтным названием «Новый модуль», сразу разворачивает его и включает inline-редактирование названия.

4. **Внутри раскрытого модуля** (как сейчас) — список уроков и кнопка «**+ Занятие**» (мягкий teal-фон, как на скрине). Клик открывает существующий popup выбора типа урока, новый урок создаётся с `module_id` этого модуля.

5. Если в курсе **нет ни одного модуля** — показываем только большую кнопку «+ Модуль» по центру + подсказку «Создайте первый модуль, чтобы добавить уроки».

### Логика в `useCourseBuilder.ts`

- `addLesson(type, moduleId)` — `moduleId` становится **обязательным** (а не опциональным). UI не даёт вызвать без модуля.
- При загрузке курса: если `lessons.some(l => !l.module_id)` И `modules.length === 0` → автосоздать модуль «Основной» и проставить `module_id` всем сиротам (insert + update в БД, обновить локальный state).
- Если есть сироты, но модули уже есть — переложить сирот в первый модуль по `order_index`.

### Что НЕ трогаем
- Popup выбора типа урока (`AddLessonButton` Dialog) — переиспользуем как есть, просто вызываем из контекста модуля.
- БД-схему — `module_id` уже nullable, миграция не нужна.
- AI-генерацию курса — она и так создаёт уроки; после генерации применится та же миграция «сирот в Основной модуль».
- Drag-and-drop модулей и уроков — работает как сейчас.
- Меню «...» урока (Просмотр/Редактировать/Обложка/ИИ/Удалить) — не меняется.
- Дублирование курса, прогресс, автосейв — без изменений.

### Файлы под изменение
- `src/components/course-builder/CourseBuilderLessonsNav.tsx` — перестройка layout: убрать верхнюю «+ Добавить урок», убрать секцию «Без модуля», добавить нижнюю кнопку «+ Модуль», стилизовать «+ Занятие» внутри модуля.
- `src/hooks/useCourseBuilder.ts` — авто-миграция сирот при загрузке; сделать `moduleId` обязательным в `addLesson`.
