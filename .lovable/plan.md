

## Редизайн кабинета ученика в стиле SkillSpace

### Что сейчас
Текущий кабинет — классический sidebar + контент с прогрессом и списком «Мои курсы». Нет каталога курсов организации, нет библиотеки как отдельного раздела, нет лендингов курсов.

### Что нужно (по образцу SkillSpace)

**Три раздела через левый sidebar (иконки):**
1. **Каталог курсов** — ВСЕ опубликованные курсы организации, сгруппированные по категориям, с поиском. Курсы, на которые студент не записан, показываются с бейджем «Доступен для покупки / записи»
2. **Библиотека** — только курсы, на которые студент записан (аналог текущих «Мои курсы»), с прогрессом и кнопкой «Продолжить обучение»
3. **Чат** — существующий функционал (ИИ + чат с организацией)

**Баннер-шапка:**
- Большой баннер с обложкой организации, логотипом, названием и описанием
- На странице «Библиотека» — аватар ученика, счётчик курсов, прогресс-бар

**Карточки курсов:**
- Обложка курса (изображение)
- Бейдж категории
- Название, описание
- Статус: «Доступен для покупки» / «X% пройдено»
- Кнопка: «Записаться» / «Продолжить обучение»

**Лендинг курса (новая страница):**
- Полноэкранный hero с обложкой, названием, описанием, ценой
- Блоки: описание, программа (список уроков), отзывы
- Кнопка «Записаться / Купить»
- Организация может настроить лендинг или указать внешнюю ссылку

**Профиль ученика (dropdown):**
- Выпадающее меню по клику на аватар в правом верхнем углу: имя, роль, ссылки на профиль, настройки, выход

### Изменения в БД

- Добавить поле `cover_image_url` в таблицу `courses` (обложка курса)
- Добавить поле `landing_content` (JSONB) в `courses` — контент лендинга курса (hero-текст, блоки, внешняя ссылка)
- Добавить поле `description` в таблицу `organizations` (если нет) — описание организации для баннера

### Визуальный стиль

Как в SkillSpace: чистый белый фон, тонкий sidebar с иконками (60px), большой баннер, карточки с изображениями в сетке 4 колонки, бейджи зелёного цвета для статусов, мягкие тени и скругления.
