

## Исправление белого экрана на опубликованном сайте

### Проблема
Опубликованный сайт (`synthagma-bloom.lovable.app`) показывает белый экран в Chrome и Яндекс Браузере. Причина -- Service Worker (PWA) кэширует устаревшие файлы сборки, и новые JS/CSS бандлы не загружаются. Lovable показывает "нет изменений для публикации", потому что код не менялся.

### Решение

1. **Добавить cache-bust комментарий в `index.html`** -- это создаст "изменение" для системы публикации и вызовет новую сборку с новыми хэшами файлов.

2. **Улучшить обработку обновлений Service Worker в `src/main.tsx`** -- добавить `onNeedRefresh` callback, чтобы при появлении нового SW сразу обновлять страницу. Это предотвратит повторение проблемы в будущем.

### Технические детали

**Файл `index.html`:**
- Обновить cache-bust комментарий на текущую дату (`2026-02-24`)

**Файл `src/main.tsx`:**
- Использовать `onNeedRefresh` и `onOfflineReady` callbacks в `registerSW` для более надежного обновления
- Автоматически вызывать `updateSW(true)` при обнаружении нового Service Worker

После этих изменений система обнаружит обновление и позволит опубликовать новую версию.
