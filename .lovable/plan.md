

# Оплата тарифов через Т-Банк + обновление тарифов на лендинге

## Что делаем

### 1. Виджет оплаты тарифов через Т-Банк (SubscriptionTab)

Сейчас при нажатии «Перейти» открывается диалог «Отправить заявку». Нужно добавить возможность оплатить сразу через Т-Банк:

- В диалоге повышения тарифа добавить кнопку **«Оплатить онлайн»** рядом с «Отправить заявку»
- При нажатии — вызов новой edge-функции `tbank-init-subscription`, которая создаёт платёж за тариф (не за курс)
- После успешной оплаты (webhook) — автоматическое обновление `subscription_plan` и `paid_until` организации

### 2. Новая edge-функция `tbank-init-subscription`

Аналог `tbank-init`, но для подписок:
- Принимает `organization_id`, `plan`, `period_months` (1 или 12)
- Создаёт запись в `subscription_invoices` со статусом `pending`
- Инициирует платёж через T-Bank API
- Возвращает `PaymentURL` или `PaymentId` для виджета

### 3. Обновление `tbank-webhook` — обработка подписок

Добавить обработку OrderId, начинающегося с `sub_` (или отдельная логика по таблице `subscription_invoices`):
- При статусе CONFIRMED: обновить `subscription_plan`, `paid_until` в `organizations`
- Обновить статус счёта в `subscription_invoices`

### 4. Обновление тарифов на лендинге (PricingPlans.tsx)

Сейчас все фичи показывают галочки для всех планов. Нужно синхронизировать с таблицей в SubscriptionTab:

- **Вебинары** — добавить строку, доступна только с «Профессиональный»+
- **ФИС ФРДО** — уже есть, но показывает `true` для всех. Исправить: показывать по `enabledCategories`
- Все строки с категориями (Компании, Журналы, Документооборот, Охрана труда, Магазин курсов, Хранилище файлов) — привязать к `enabledCategories` вместо `() => true`
- Кнопки CTA на лендинге — обновить: бесплатный → «Начать бесплатно», платные → «Подключить»
