

# Скрытие курсов/категорий с витрины + уведомления о заказах

## Задача 1: Скрытие курсов и категорий с витрины

### Проблема
Нет способа скрыть отдельный курс или целую категорию из каталога для учеников. Также в списке курсов много кнопок-иконок (глазик, видео, замок, перемотка), которые пользователь хочет упростить.

### Решение

**Миграция БД:**
- Добавить колонку `hidden_from_catalog BOOLEAN DEFAULT false` в таблицу `courses`
- Добавить колонку `hidden_from_catalog BOOLEAN DEFAULT false` в таблицу `course_categories`

**UI в CoursesTab (список курсов):**
- Убрать отдельные кнопки-иконки (глазик-просмотр, видеоидентификация, замок, перемотка) из карточек курсов — перенести в dropdown-меню (⋮)
- Добавить кнопку-иконку «Глазик» (Eye/EyeOff) для скрытия/показа курса на витрине
- На заголовке категории (сворачиваемой группе) — кнопка скрытия всей категории

**Фильтрация в витрине:**
- В `useStudentDashboard.ts`: добавить `.eq("hidden_from_catalog", false)` к запросу каталога
- Также фильтровать по `hidden_from_catalog` категорий

**Настройки курса (CourseBuilder):**
- В настройках курса добавить чекбокс «Скрыть из витрины»

### Файлы
| Файл | Изменение |
|------|-----------|
| Миграция | `ALTER TABLE courses ADD hidden_from_catalog boolean DEFAULT false` + то же для `course_categories` |
| `src/types/course.ts` | Добавить `hidden_from_catalog?: boolean` |
| `src/components/organization/tabs/CoursesTab.tsx` | Убрать иконки-кнопки, добавить Eye toggle для витрины, кнопку скрытия категории |
| `src/hooks/useStudentDashboard.ts` | Фильтровать `.eq("hidden_from_catalog", false)` |

## Задача 2: Уведомления о заказах

### Проблема
При создании заказа (`marketplace_orders.insert`) не создаётся уведомление в `org_notifications`. Организация не видит новые заказы в колокольчике.

### Решение
В обоих местах создания заказа добавить вставку в `org_notifications`:

**`src/components/student/StudentCourseStore.tsx`** (заказ от студента):
- После успешного insert в `marketplace_orders` — создать `org_notifications` с `type: "order"`, `title: "Новый заказ"`, `message` с названием курса, именем ученика и контактами (email)

**`src/hooks/useCourseStoreManager.ts`** (заказ от организации):
- Аналогично — уведомление продавцу

### Данные в уведомлении
- Тип: `order`
- Заголовок: `Новый заказ: {название курса}`
- Сообщение: `{ФИО ученика} ({email}) оформил заказ на курс "{название курса}" — {цена} ₽`
- `related_id`: ID заказа
- `organization_id`: ID организации-продавца

### Файлы
| Файл | Изменение |
|------|-----------|
| `src/components/student/StudentCourseStore.tsx` | Добавить insert в `org_notifications` после создания заказа |
| `src/hooks/useCourseStoreManager.ts` | Аналогично |

## Технические детали

Тип `order` уже есть в `PAYMENT_TYPES` в `OrgNotifications.tsx` (строка 41), поэтому уведомления автоматически попадут во вкладку «Оплаты» в колокольчике.

Для скрытия курсов используется `is_published` для черновик/опубликован, а новое поле `hidden_from_catalog` — именно для скрытия опубликованного курса из витрины ученика (курс остаётся рабочим для уже зачисленных).
