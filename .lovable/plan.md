
## Реферальная система для СИНТАГМА

По аналогии со SkillSpace: партнёр получает реферальную ссылку, привлекает организации, получает % от их оплат за подписку в течение 2 лет.

### Условия (как у SkillSpace)
- **5–25%** от оплат привлечённых организаций (зависит от статуса партнёра)
- Начальный уровень — 10%
- Закрепление на 2 года с момента регистрации
- Минимальная выплата — 1 000 ₽
- Cookie — 90 дней

### Что создаём

**1. Таблицы в БД (миграция)**

- `referral_partners` — партнёры (user_id, code, commission_percent, balance, total_earned, status, bank_details)
- `referral_registrations` — привлечённые организации (partner_id, organization_id, registered_at, cookie_expires_at)
- `referral_commissions` — начисления (partner_id, organization_id, payment_source, amount, commission_amount, status, created_at)
- `referral_payouts` — выплаты (partner_id, amount, status, paid_at)
- `referral_promo_materials` — рекламные материалы (title, description, image_url, type: banner/text/video, size)

RLS: партнёр видит только свои данные; админ видит всё.

**2. Публичная партнёрская страница** `/partner`

Лендинг для привлечения партнёров:
- Описание программы, процентов
- Кнопка «Стать партнёром» (регистрация/вход)
- Блок с рекламными материалами (баннеры, тексты для соцсетей)

**3. Партнёрский кабинет** `/partner/dashboard`

Страница для зарегистрированного партнёра:
- Статистика: переходы, регистрации, оплаты, баланс
- Реферальная ссылка + код (копирование)
- Таблица привлечённых организаций
- Таблица начислений
- Запрос на вывод средств
- Раздел «Рекламные материалы» — готовые баннеры и тексты для скачивания/копирования

**4. Трекинг реферала**

- При переходе по `?ref=CODE` сохраняем код в cookie на 90 дней
- При регистрации организации проверяем cookie → создаём запись в `referral_registrations`
- При оплате подписки организацией → автоматическое начисление комиссии в `referral_commissions`

**5. Edge function `referral-commission`**

Вызывается при оплате подписки — считает комиссию партнёра и записывает начисление.

**6. Админка — управление партнёрами**

Новая вкладка в AdminDashboard:
- Список партнёров, их статистика
- Управление % комиссии
- Одобрение выплат
- Управление рекламными материалами (загрузка баннеров, текстов)

**7. Рекламные материалы**

Предзаполненные материалы:
- 3 баннера разных размеров (728×90, 300×250, 160×600) — генерируем через HTML/CSS
- Готовые тексты для постов в соцсетях (3 варианта)
- HTML-код для вставки баннера на сайт
- UTM-ссылки

**8. Оферта партнёрской программы** `/partner/offer`

Юридический документ по аналогии со SkillSpace, адаптированный под СИНТАГМА.
