

## Доработка страницы установки для Яндекс Браузера и других браузеров

### Проблема
Пользователь открывает `/install` в Яндекс Браузере на Android. Автоматическая установка (beforeinstallprompt) не срабатывает, а инструкции говорят "откройте в Chrome" — но нет удобного способа это сделать.

### Что будет сделано

#### 1. Определение Яндекс Браузера (src/pages/Install.tsx)
Добавить проверку `navigator.userAgent` на наличие `YaBrowser` или `YaSearchBrowser`.

#### 2. Специальный блок для Яндекс Браузера
Если пользователь в Яндекс Браузере — показывать:
- Предупреждение: "Вы используете Яндекс Браузер. Для установки приложения откройте эту страницу в Chrome"
- Кнопка "Скопировать ссылку" — копирует URL страницы в буфер обмена, чтобы вставить в Chrome
- Инструкции для Яндекс Браузера (меню -> Добавить на главный экран), если такая функция доступна

#### 3. Инструкции для Яндекс Браузера
Яндекс Браузер тоже поддерживает "Добавить на главный экран" через своё меню. Добавить отдельную карточку с инструкциями:
1. Нажмите меню (три точки) внизу справа
2. Выберите "Добавить на главный экран"
3. Подтвердите добавление

#### 4. Кнопка копирования ссылки для всех браузеров
Добавить кнопку "Скопировать ссылку" под инструкциями — полезна для случая, когда нужно открыть в другом браузере.

### Технические детали

**src/pages/Install.tsx — изменения:**

Новая переменная:
```typescript
const isYandex = /YaBrowser|YaSearchBrowser/.test(navigator.userAgent);
```

Новая функция:
```typescript
const handleCopyLink = async () => {
  await navigator.clipboard.writeText(window.location.href);
  // показать toast "Ссылка скопирована"
};
```

Логика отображения:
- Если `isYandex` — показывать карточку "Установка через Яндекс Браузер" с инструкциями для меню Яндекс Браузера + кнопку "Скопировать ссылку для Chrome"
- Если `isAndroid && !isYandex` — показывать стандартные инструкции для Chrome
- Если `isIOS` — показывать инструкции для Safari
- Если ничего не определено — показывать все варианты

Карточка для Яндекс Браузера будет содержать:
1. Шаги установки через меню Яндекс Браузера (три точки -> Добавить на главный экран)
2. Альтернатива: блок "Или откройте в Chrome" с кнопкой копирования ссылки
