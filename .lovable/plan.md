
# План: Интерактивная демо-секция редактора курсов

## Концепция

Создать новую секцию на главной странице между Features и Roadmap, которая покажет посетителям **живой мини-редактор курса** с демонстрацией ключевых возможностей:

1. **Блоковый редактор** — пользователь видит готовые блоки контента (текст, заголовок, callout)
2. **AI-генерация** — интерактивная кнопка, показывающая анимацию "печатания" текста
3. **Озвучка (TTS)** — кнопка воспроизведения с реальным голосом ElevenLabs

## Детали реализации

### 1. Новый компонент `EditorDemo.tsx`

**Структура:**
- Заголовок секции с описанием
- Интерактивная карточка-редактор
- 3-4 демо-блока с иконками типов
- Кнопка AI-генерации (анимация печатания)
- Кнопка озвучки (реальный TTS через ElevenLabs)

**Интерактивность:**
- При нажатии "Сгенерировать" — появляется новый блок с эффектом typewriter
- При нажатии "Озвучить" — воспроизводится аудио текста блока

### 2. Демо-данные

Предзаполненные блоки:
```typescript
const demoBlocks = [
  { type: "heading1", content: "Охрана труда на производстве" },
  { type: "paragraph", content: "Согласно Трудовому кодексу РФ, работодатель обязан обеспечить безопасные условия труда..." },
  { type: "callout-warning", content: "Нарушение требований охраны труда влечёт за собой дисциплинарную, административную и уголовную ответственность." }
];
```

### 3. AI-генерация (имитация для демо)

Для лендинга использую **локальную анимацию** без реального API-вызова:
- Заранее подготовленный текст
- Typewriter-эффект через `framer-motion`
- Визуальный спиннер "Генерация..."

### 4. Озвучка (реальный TTS)

**Используем существующий edge function `elevenlabs-tts`:**
- Озвучивается текст активного блока (или весь урок)
- Голос: George (JBFqnCBsd6RMkjVDRZzb) — русский мужской голос
- Кнопка Play/Pause с индикатором воспроизведения

```tsx
const playAudio = async (text: string) => {
  const response = await fetch(
    `${import.meta.env.VITE_SUPABASE_URL}/functions/v1/elevenlabs-tts`,
    {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        apikey: import.meta.env.VITE_SUPABASE_PUBLISHABLE_KEY,
      },
      body: JSON.stringify({ text, voiceId: "JBFqnCBsd6RMkjVDRZzb" }),
    }
  );
  const audioBlob = await response.blob();
  const audio = new Audio(URL.createObjectURL(audioBlob));
  audio.play();
};
```

### 5. Стилизация

- Карточка с `glass-card` эффектом (backdrop-blur)
- Свечение accent-цвета при hover
- Иконки типов блоков с цветовой кодировкой
- Анимации entrance через `framer-motion`
- Респонсивный дизайн (на мобильных — компактный вид)
