

# Магазин курсов: улучшение интерфейса

## Для слушателя (студента)

Текущая проблема: студент видит тот же 4-табовый интерфейс, что и организация ("Каталог", "Мои курсы", "Заявки", "Мои покупки"), включая функции продавца. Студенту нужен только каталог и его заявки.

### Что изменится

**Новый компонент `StudentCourseStore`** -- отдельный, упрощённый интерфейс:

- Красивая шапка с градиентом и заголовком "Магазин курсов"
- Поиск по каталогу
- Сетка карточек курсов (только активные, от других организаций)
- Каждая карточка: название, организация-продавец, описание, длительность, цена для студента
- Кнопка "Оставить заявку" -- открывает диалог с формой (комментарий + отправка)
- Внизу -- секция "Мои заявки" со статусами (ожидает, одобрена, оплачена, завершена, отменена)
- Диалог успешной отправки заявки

### Дизайн карточки курса

```text
+----------------------------+
| [Название курса]           |
| Организация "ООО Знание"   |
| Описание курса...          |
| [72 часа]                  |
|                            |
| Цена: 5 000 Р              |
|                            |
| [  Оставить заявку  ]     |
+----------------------------+
```

## Для организации

Организация продолжает использовать текущий `CourseStoreManager` без изменений (4 таба, управление своими курсами, входящие заявки и т.д.).

### Структура StudentCourseStore

Компонент получает `userId` и `organizationId` (из профиля студента).

Данные:
- Каталог: `marketplace_courses` с join на `courses` и `organizations`, фильтр `is_active = true`
- Заявки студента: `marketplace_orders` с `buyer_user_id = userId`

Интерфейс:
- Верхний блок: поиск
- Сетка карточек (2-3 колонки)
- Секция "Мои заявки" внизу -- компактный список с бейджами статусов
- Диалог оформления заявки: название курса, организация, цена, поле для комментария, кнопка "Отправить"
- Диалог подтверждения: галочка + "Заявка отправлена!"

### Ключевые отличия от текущего интерфейса

1. Нет табов "Мои курсы" и "Заявки" (это функции продавца)
2. Цена показывается только для студента (не для организации)
3. "Мои заявки" отображаются прямо под каталогом, а не в отдельном табе
4. Убрано "Разместить объявление" и виджет "Ищут курсы" -- это для организаций
5. Упрощённая карточка без двух колонок цен
