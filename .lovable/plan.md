
## Исправить Word-экспорт договора с печатью и без печати

### Что сломано
Сейчас проблема в двух местах:
1. В Word экспортируется уже готовый HTML-документ, а сверху он ещё раз оборачивается в новый `<html><body>...`, из-за чего Word рендерит его криво.
2. Блок подписей использует браузерную вёрстку (`flex`) и общие стили для всех `table`, поэтому в Word печать/подпись разъезжаются и могут растягиваться на страницу.
3. Вариант “без печати” сейчас вырезает печать через regex по сырому HTML, поэтому удаление срабатывает нестабильно.

### Что будет сделано

**1. Сделать Word-совместимый блок подписей**  
Файл: `src/constants/contractTemplates.ts`
- заменить flex-вёрстку подписей на Word-safe структуру;
- отделить обычные таблицы договора от таблицы печати/подписи;
- добавить для печати отдельный маркер/класс и фиксированные размеры, чтобы на неё не влияли общие стили таблиц.

**2. Исправить генерацию Word-файла**  
Файл: `src/components/admin/sales/SalesContracts.tsx`
- разбирать сохранённый HTML через `DOMParser`;
- брать отдельно стили и содержимое `body`, а не вкладывать весь HTML-документ внутрь другого;
- собирать корректный Word HTML без вложенных `<html>` и `<body>`.

**3. Надёжно убрать печать в режиме “без печати”**
- отказаться от regex-замены строки;
- удалять именно помеченный блок печати из DOM;
- вместо него вставлять обычную линию для подписи.

**4. Сохранить работу для уже созданных договоров**
- логика будет работать и для старых договоров из базы;
- добавлю fallback для уже сохранённых HTML, если в них ещё нет нового маркера.

### Файлы
- `src/constants/contractTemplates.ts`
- `src/components/admin/sales/SalesContracts.tsx`

### Результат
- Word “с печатью” будет открываться без растягивания печати на страницу;
- Word “без печати” действительно будет скачиваться без печати;
- браузерный предпросмотр останется как сейчас.
