

## Добавить видимые подписи с форматами и ограничениями к карточкам типов уроков

### Что сделать

Заменить скрытые тултипы на карточках типов уроков **постоянно видимыми подписями** с указанием поддерживаемых форматов и ограничений. Тултипы на кнопках хедера (Назад, Предпросмотр, Сохранить) остаются.

### Файл: `src/pages/CourseBuilder.tsx`

Убрать обёртки `Tooltip` с 6 карточек типов уроков. Вместо этого добавить внутрь каждой кнопки мелкую подпись серым цветом:

| Карточка | Подпись |
|----------|---------|
| 📝 Текст | Блочный редактор с медиа |
| 🎥 Видео | MP4, WebM · YouTube, VK, Rutube |
| ✅ Тест | Вопросы с вариантами ответов |
| ✨ AI Генерация | Создать урок с помощью ИИ |
| 🖼️ Слайды | PPTX или создать вручную |
| 🎧 Аудио | MP3, WAV, OGG · или ссылка |

Также добавить подписи к кнопкам действий «Импорт» и «AI Структура»:

| Кнопка | Подпись (мелким текстом под кнопкой или внутри) |
|--------|---------|
| Импорт | DOCX, TXT, MD, HTML |
| AI Структура | По названию и описанию курса |

### Техническая реализация

Каждая карточка получит дополнительный `<span>`:
```tsx
<Button variant="outline" className="h-auto py-4 flex flex-col gap-1 ...">
  <span className="text-2xl">🎥</span>
  <span className="text-xs font-medium">Видео</span>
  <span className="text-[10px] text-muted-foreground leading-tight">MP4, WebM · YouTube, VK, Rutube</span>
</Button>
```

Для кнопок «Импорт» и «AI Структура» — добавить мелкую подпись снизу:
```tsx
<div className="flex flex-col items-center">
  <Button variant="outline" size="sm">...</Button>
  <span className="text-[10px] text-muted-foreground mt-1">DOCX, TXT, MD, HTML</span>
</div>
```
