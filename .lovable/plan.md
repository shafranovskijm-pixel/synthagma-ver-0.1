

# Регистрация по тарифам с промокодами (обновлённый план)

## Что будет сделано

### 1. Таблица промокодов в базе данных

Создать таблицу `promo_codes`:

```text
id               UUID (PK)
code             TEXT UNIQUE NOT NULL
discount_percent INTEGER NOT NULL (1-100)
is_active        BOOLEAN DEFAULT true
max_uses         INTEGER (NULL = безлимит)
used_count       INTEGER DEFAULT 0
valid_until      TIMESTAMPTZ (NULL = бессрочно)
created_at       TIMESTAMPTZ DEFAULT now()
```

RLS: чтение для всех (проверка кода), полное управление только для админов.

### 2. Кнопки тарифов на лендинге

В `PricingPlans.tsx` каждая кнопка "Подключить" ведёт на `/register-organization?plan={planId}`.

### 3. Страница регистрации

В `RegisterOrganization.tsx`:
- Читать параметр `plan` из URL
- Показывать карточку выбранного тарифа с ценой
- Поле промокода с кнопкой "Применить"
- При валидном коде (например, SYNTASALE) -- зачёркнутая старая цена и новая со скидкой
- Сохранение `subscription_plan` при создании организации

### 4. Управление промоакциями в админке

В `AdminSettings.tsx` новая секция "Промоакции":
- Таблица промокодов: код, скидка %, статус, использований, **срок действия**
- Форма добавления: код, процент скидки, макс. использований, **дата начала и окончания акции**
- Отображение оставшегося времени акции (например, "Осталось 5 дней")
- Индикатор: зелёный -- активна, жёлтый -- скоро истекает, красный -- истекла
- Переключатель активации / деактивации
- Удаление промокода

---

## Технические детали

| Компонент | Изменения |
|---|---|
| Миграция БД | Таблица `promo_codes` + RLS + вставка SYNTASALE (50%) |
| `PricingPlans.tsx` | CTA-ссылки `/register-organization?plan={id}` |
| `RegisterOrganization.tsx` | Карточка тарифа, промокод, скидка, сохранение плана |
| `AdminSettings.tsx` | Секция "Промоакции" с CRUD, сроками действия, статусами |

### Логика сроков действия

- При создании/редактировании промокода админ выбирает дату окончания через календарь
- В списке отображается статус: "Бессрочно", "До 31.03.2026", "Истёк"
- Просроченные коды автоматически не применяются при регистрации (проверка `valid_until >= now()`)
- Визуальная подсветка: активные -- зелёные, истекающие в течение 7 дней -- жёлтые, истёкшие -- красные
