
# Добавить сравнительную таблицу конкурентов в раздел «Продажи»

## Что будет сделано
Новая вкладка «Сравнение» в `SalesManager.tsx` с интерактивной таблицей сравнения Синтагмы с конкурентами (GetCourse, iSpring, Moodle). Таблица разбита по парам: «Синтагма vs GetCourse», «Синтагма vs iSpring», «Синтагма vs Moodle» — переключение через Select.

## Структура таблицы

Критерии (строки):
| Категория | Критерии |
|---|---|
| **LMS** | Конструктор курсов, Тесты, Вебинары, Домашние задания, Сертификаты, Мобильная версия |
| **Документооборот** | Договоры, Акты, Счета, Протоколы, Приказы |
| **ИИ** | Генерация курсов, Генерация тестов, Озвучка (TTS), Обложки |
| **ФИС ФРДО** | Выгрузка данных, Автозаполнение |
| **Интеграции** | Платёжные системы, Email-рассылки, Kinescope |
| **Тарифы** | Бесплатный тариф, Стартовая цена, Макс. учеников |
| **Поддержка** | Техподдержка, Обучение, Документация |

Значения: ✅ есть / ❌ нет / ⚠️ частично / текст (цена и т.д.)

- Данные сравнения — статический массив объектов (не БД), т.к. это справочная информация для менеджеров
- Фильтр по конкуренту через Select сверху
