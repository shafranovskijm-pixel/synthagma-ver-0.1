## Что есть сейчас в нашем маркетплейсе

- Тип «Профессиональная переподготовка» представлен **одной** категорией `dbed329e-…` с **2 курсами**.
- Уже работает: `BulkCourseImporter` (создание курса + урока + теста + записи в `marketplace_courses`), `useBulkPipeline` (массовая AI-генерация уроков и решения тестов через GigaChat / Gemini fallback), `useContentGenerator` (генерация контента по категории), валидация курсов.
- Дизайн карточек в маркетплейсе уже стандартизирован (`AdminMarketplaceCatalogView`, `MarketplaceHeroCards`) — Teal/Cyan, обложка 36 px высоты, бейдж категории, Switch активности, кнопки AI/уроки/редактировать.

## Что делаем — поэтапно

### Этап 1. Парсер и каталог-сидинг (Edge Function `import-ipo-catalog`)

- Edge-функция обходит 3 страницы каталога ipo.msk.ru и для каждой родительской категории — её страницу подкатегорий, затем страницы курсов.
- Извлекает: название курса, длительность (часы), цена (для справки), краткое описание, slug.
- Сохраняет результат в новую служебную таблицу `marketplace_import_catalog` (название, parent, sub, hours, source_url, status `pending|imported|skipped`) — это позволит выбирать какие курсы импортировать из админки и не плодить дубли.
- Запуск из админки кнопкой **«Сканировать ИПО»** на новой вкладке «Импорт ИПО».

### Этап 2. Создание категорий и подкатегорий

- В `course_categories` под `parent_type = "Профессиональная переподготовка"` добавляем все 55 направлений как родительские разделы (с иконками: Bookkeeping → DollarSign, Менеджмент → Briefcase, Психология → Brain, Медицина → Heart, Стройка → HardHat, IT → Cpu и т.д. — расширим `iconMap`).
- Для направлений с подкатегориями (Медицина, Диетология, Педагогика, Менеджмент в разных сферах…) создаём вложенные категории — у нас уже поддерживается двухуровневая иерархия в `AdminMarketplaceCatalogTab`.
- Hero-блок `MarketplaceHeroCards` дополним 5 топ-карточками по самым востребованным направлениям ПП (Психология, Бухгалтерия, ГМУ, Логопедия, Менеджмент в образовании) с фотографиями из стока.

### Этап 3. Массовое создание курсов

- В админке, вкладка **«Импорт ИПО»**: таблица всех найденных программ с фильтром по категории, чекбоксами, кнопкой «Создать выбранные».
- Для каждой выбранной программы создаём:
  - запись в `courses` (title, organization_id = «Платформа Синтагма», category_id = соответствующая ПП-подкатегория, is_published = false до проверки, duration);
  - 12–20 пустых уроков (text) + 1 итоговый тест по структуре стандартной программы ПП (введение / теория / практика / нормативка / итог);
  - запись в `marketplace_courses` (price_student = 0, is_active = false до AI-генерации, is_validated = false).
- В `marketplace_import_catalog` ставим `status = 'imported'` и сохраняем `course_id` для отслеживания.

### Этап 4. AI-генерация контента (используем готовый `useBulkPipeline`)

- На созданные курсы запускаем существующий пайплайн порциями по 20–30 курсов:
  - GigaChat генерирует структуру (до 35 уроков), контент (≥700 слов на урок), тесты по 15 вопросов;
  - Gemini 2.5 Pro как fallback и для финальной валидации;
  - блоки сохраняются в JSON-формате (правило `block-formatting-rules`);
  - AI-обложка через `generate-cover` (тип `course`, аспект 16:9).
- В админке — кнопка **«Сгенерить всю категорию»** на каждой ПП-подкатегории (уже есть в `useContentGenerator.handleGenerateAll`, переиспользуем).

### Этап 5. Контроль качества и публикация

- После генерации — массовая валидация через `useMarketplaceValidation.handleBulkValidate` (проверяет наличие контента, ответов на тесты, обложки).
- Курсы с `is_validated = true` автоматически становятся `is_active = true` и публикуются.
- В админке — отчёт «✅ N готово / ❌ M с проблемами», с возможностью точечно перегенерить проблемные.

### Этап 6. Оформление каталога для пользователя

- На публичной странице маркетплейса блок «Профессиональная переподготовка» выводится отдельной секцией с сеткой карточек 4 в ряд (как сейчас в `AdminMarketplaceGridView`, стиль Teal/Cyan, обложка → название → длительность → цена).
- Для каждой родительской категории — отдельная страница `/marketplace/pp/<slug>` со списком курсов и хлебными крошками.
- Бейдж «Диплом о профессиональной переподготовке» в правом верхнем углу карточки.

## Объём и оценка

- **~600 курсов** в среднем (можно начать с топ-100 направлений).
- AI-генерация: ~2–3 минуты на курс через GigaChat → ~25–30 часов на полный каталог фоновыми сессиями по 20 курсов.
- Стоимость: укладывается в текущий пул из 3 ключей GigaChat + Gemini fallback (rate-limit 10/min уже настроен).

## Риски и как их закрываем

1. **Антибот ipo.msk.ru** — Edge-функция использует User-Agent + задержки 1–2 с между страницами; при блоке fallback на ручную загрузку HTML-файлов в админке.
2. **Дубли названий** — проверка по `marketplace_import_catalog.source_url` перед созданием курса.
3. **Юридика (тексты с чужого сайта)** — мы берём только названия и часы; весь контент уроков генерируем сами через ИИ, фотографии — из нашей AI-генерации обложек.
4. **Перегруз UI** — 600 курсов в одном списке: сразу группируем по родительским категориям с collapsible-блоками (уже работает).
