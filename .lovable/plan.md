

# Уведомление в Telegram при регистрации новой организации

## Что будет сделано

После успешной регистрации организации (шаг 4 в `RegisterOrganization.tsx`) добавить вызов edge-функции `send-telegram-notification` с информацией о новой организации.

## Детали

В файле `src/pages/RegisterOrganization.tsx` после строки 244 (после обновления роли) добавить отправку уведомления в Telegram:

```text
Сообщение в Telegram:
---
Новая организация зарегистрирована!

Название: {orgName}
Контактное лицо: {contactName}
Email: {email}
Телефон: {phone}
ИНН: {inn}
Тариф: {selectedPlan}
Промокод: {promoCode} (если есть)
---
```

Вызов будет использовать уже настроенную edge-функцию `send-telegram-notification`, которая отправит сообщение в бота поддержки (через секрет `TELEGRAM_SUPPORT_CHAT_ID`). Ошибка отправки уведомления НЕ будет блокировать регистрацию -- она будет залогирована в консоль, но пользователь продолжит нормально.
