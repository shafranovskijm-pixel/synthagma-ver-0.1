

## Добавить кнопки действий на карточки пустого состояния вкладки «Ученики»

### Проблема
На вкладке «Курсы» карточки пустого состояния имеют кнопки действий («Создать курс», «Перейти в магазин»), а на вкладке «Ученики» три карточки («Добавить ученика», «Контроль обучения», «Документооборот») — просто информационные, без кнопок.

### Решение
Добавить кнопки внизу каждой карточки пустого состояния:

| Карточка | Кнопка | Действие |
|----------|--------|----------|
| Добавить ученика | `+ Добавить ученика` | Открыть диалог добавления студента |
| Контроль обучения | `Импорт учеников` | Открыть диалог импорта |
| Документооборот | `Перейти в ФИС ФРДО` | Переключить на вкладку ФРДО |

### Изменения

| Файл | Что меняется |
|------|-------------|
| `src/components/organization/tabs/StudentsTab.tsx` | 1) Добавить два новых пропса: `onAddStudent` и `onImportStudents`. 2) Добавить `useOrgDashboard` или пропс для навигации на вкладку ФРДО. 3) Внутри каждой карточки добавить `<Button>` после `<ul>` |
| `src/components/organization/tabs/TabContentRenderer.tsx` | Передать новые пропсы: `onAddStudent={() => d.studentManagement.setShowAddStudentDialog(true)}` и `onImportStudents={() => d.studentManagement.setShowImportDialog(true)}` |

### Детали
- Для карточки «Документооборот» используем `useOrgDashboard` (уже доступен в CoursesTab по аналогии) для переключения вкладки: `d.tabNavigation.setActiveTab("frdo")`
- Стиль кнопок — аналогичный кнопкам в CoursesTab: `w-full rounded-xl` с иконками
