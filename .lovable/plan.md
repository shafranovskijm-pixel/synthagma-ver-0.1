
# Исправить исчезающее меню ссылки и неработающее оборачивание текста

## Что нашёл

Проблема состоит из двух частей:

1. В проекте сейчас есть две разные логики ссылок:
   - в `BlockEditor.tsx` — новая логика через `Popover`
   - в `RichTextEditor.tsx` — старая логика через `prompt()` и поведение с `alert()`

Скрин с системным окном «Сначала выделите текст...» как раз показывает, что у пользователя срабатывает старая логика из `RichTextEditor`, а не новая.

2. В `BlockEditor.tsx` кнопка ссылки одновременно:
   - вручную открывает поповер через `setLinkPopoverOpen(true)`
   - и обёрнута в `PopoverTrigger`

Из-за этого Radix может сразу переключать состояние обратно, поэтому меню “мигает” и исчезает.

## Что нужно сделать

### 1. Привести создание ссылок к одной логике
Убрать старую `prompt()`-логику из `RichTextEditor.tsx`, чтобы больше не было системных окон и конфликтов.

### 2. Починить открытие поповера ссылки
В `BlockEditor.tsx` оставить один источник управления состоянием:
- либо полностью controlled `Popover` без `PopoverTrigger`
- либо открытие только через trigger, без ручного toggle

Предпочтительно: controlled `Popover` + обычная кнопка, чтобы меню не закрывалось сразу.

### 3. Надёжно сохранять выделение текста
Перед открытием формы ссылки:
- сохранить `Range`
- проверить, что выделение находится внутри текущего `contenteditable` именно этого блока
- при применении ссылки восстановить range и только потом выполнять `createLink`

Это нужно, чтобы уже написанный текст реально оборачивался в ссылку.

### 4. Поддержать оба сценария
В форме ссылки сделать два режима:
- если текст выделен — поле URL + действие “Обернуть в ссылку”
- если текста нет — поля “Текст ссылки” + “URL”, чтобы вставлять ссылку прямо из формы

### 5. Обновить HTML после вставки
После `createLink` / `insertHTML`:
- проставлять `target="_blank"` и `rel="noopener noreferrer"`
- диспатчить `input`, чтобы `RichTextEditor` точно сохранил изменения в состояние

## Файлы

- `src/components/course-builder/BlockEditor.tsx`
  - убрать конфликт `PopoverTrigger` + ручного открытия
  - доработать проверку/восстановление selection
  - стабилизировать создание ссылки по выделенному тексту и вставку новой ссылки

- `src/components/course-builder/RichTextEditor.tsx`
  - убрать старую `prompt()`/`alert()`-логику ссылки
  - либо полностью отключить встроенную кнопку ссылки, либо перевести её на ту же новую механику без системных диалогов

## Ожидаемый результат

После правки:
- меню ссылки перестанет исчезать сразу после нажатия
- выделенный текст будет реально оборачиваться в ссылку
- можно будет вставлять ссылку даже без предварительного выделения текста
- больше не будет системных alert/prompt окон, которые ломают выделение
