

# Редизайн профиля ученика: боковое меню как в организации

## Что сейчас
Профиль ученика (`/student/profile`) использует горизонтальные табы вверху страницы (Профиль, Уведомления, Идентификация и т.д.). Выглядит просто и не совпадает с дизайном кабинета организации.

## Что будет
Левая боковая панель с иконками (как `OrgSettingsSidebar.tsx`), навигация по разделам через неё. Контент справа с отступом `pl-[88px]`. Та же визуальная стилистика: pill-shaped навигация, тултипы, закруглённые иконки, shadow.

## Изменения

### 1. Новый компонент `StudentProfileSidebar.tsx`
По образцу `OrgSettingsSidebar.tsx`:
- Логотип организации или SigmaLogo сверху
- Кнопка «Назад» → `/student`
- Вертикальная навигация с иконками в pill-контейнере:
  - Профиль (User)
  - Уведомления (Bell)
  - Идентификация (Video)
  - Согласие на ПД (FileCheck) + badge
  - Документы (FileText) + badge
  - Достижения (Trophy) — если включено
  - Тема (Palette)
  - Партнёрская программа (Users)
- Кнопка «Выйти» / «Вернуться в панель» (для admin view) внизу
- Мобильная адаптация: overlay + hamburger

### 2. Переработка `StudentProfile.tsx`
- Убрать горизонтальные `Tabs` / `TabsList` / `TabsTrigger`
- Убрать верхний баннер с аватаром (перенести аватар в раздел «Профиль»)
- Использовать `activeTab` + условный рендер контента вместо Tabs
- Обернуть в layout: sidebar (88px) слева + контент справа
- Настройки профиля оформить красиво как в организации: rounded-2xl карточки, `rounded-xl` инпуты, секция аватара с hover-overlay

### 3. Файлы
| Файл | Действие |
|---|---|
| `src/components/student/StudentProfileSidebar.tsx` | Создать — боковая навигация |
| `src/pages/StudentProfile.tsx` | Переписать layout: убрать табы, добавить sidebar, улучшить стили карточек |

Примерно ~180 строк нового кода (sidebar) и ~100 строк изменений в StudentProfile.
