

# Многоуровневая партнёрская программа (MLM)

## Суть изменений

Трансформация одноуровневой реферальной системы (10-25% от прямых) в 3-уровневую сеть с бонусами за оборот и лидерский рейтинг.

## Структура комиссий

| Уровень | Ставка | Описание |
|---------|--------|----------|
| 1 (прямой) | 20% | Организация пришла по вашей ссылке |
| 2 | 10% | Партнёр уровня 1 привёл эту организацию |
| 3 | 5% | Партнёр уровня 2 привёл эту организацию |
| Бонус оборота | +5% | Если оборот сети партнёра > 100 000 ₽/мес |
| Лидерский бонус | +3% | Топ-10 партнёров месяца |

Максимальный пул: ~45%.

## Изменения в базе данных

### 1. Таблица `referral_partners` — новые поля
- `referred_by_partner_id uuid` — кто привёл этого партнёра (для построения дерева)
- `level1_percent integer DEFAULT 20`
- `level2_percent integer DEFAULT 10`
- `level3_percent integer DEFAULT 5`
- `monthly_network_revenue numeric DEFAULT 0` — оборот сети за текущий месяц
- `has_turnover_bonus boolean DEFAULT false`
- `is_top_partner boolean DEFAULT false`

### 2. Таблица `referral_commissions` — новые поля
- `level integer DEFAULT 1` — уровень комиссии (1, 2 или 3)
- `source_partner_id uuid` — партнёр прямого уровня, от которого пришла комиссия
- `bonus_type text` — `null`, `'turnover'` или `'leader'`

### 3. Новая таблица `partner_monthly_stats`
- `id`, `partner_id`, `month date`, `network_revenue numeric`, `direct_revenue numeric`, `total_commission numeric`, `rank integer`, `is_top boolean`, `created_at`

## Изменения в коде

### Edge-функция `referral-commission/index.ts` — полная переделка
Логика расчёта:
1. Найти прямого партнёра (уровень 1) → начислить 20%
2. Проверить `referred_by_partner_id` у прямого партнёра → уровень 2 → начислить 10%
3. Проверить `referred_by_partner_id` у партнёра уровня 2 → уровень 3 → начислить 5%
4. Для каждого партнёра в цепочке: если `monthly_network_revenue > 100000` → доп. +5%
5. Если `is_top_partner = true` → доп. +3%

### Новая Edge-функция `referral-monthly-stats/index.ts`
CRON-задача (или ручной вызов из админки) для расчёта ежемесячной статистики:
- Считает оборот сети каждого партнёра (все уровни)
- Определяет топ-10 по обороту → ставит `is_top_partner = true`
- Пересчитывает `has_turnover_bonus` (оборот > 100k)
- Сохраняет в `partner_monthly_stats`
