# Проверка выходных документов UC021

Универсальная выгрузка Word создаёт OOXML DOCX, сохраняет кириллицу, порядок текста, таблицы и объединения, вложенные списки и PNG/JPEG подписи. Поддерживаются основные шрифты, размеры, выравнивание, цвета, поля страницы и ширины столбцов. Это редактируемый универсальный документ: отдельный компилятор Word-шаблона клиента остаётся источником точного оформления OOXML. SVG, canvas, внешние таблицы стилей и неподдерживаемые изображения не исчезают молча — выгрузка сообщает ошибку.

Печать создаёт изолированный документ без скриптов, сохраняет CSS и проверяет загрузку изображений. QR создаётся локально. Вызов печати и передача скачивания браузеру не подтверждают физическое сохранение файла. При смене аккаунта или наблюдаемого доступа незавершённая выгрузка прерывается.

В Word обычная строка таблицы переносится целиком, а заголовок повторяется на следующей странице. Строку выше целой страницы редактор может разделить. Таблицы реквизитов сохраняются без рамок; границы ячеек берутся из исходных CSS-правил, включая явные `none` и `0`.

Генератор приказов и протоколов создаёт проекты. Он не утверждает правовое основание, состав комиссии, подлинность подписи и результат аттестации. Неуказанный результат показывается явно. Сохранение в реестре проверяется отдельно от печати/Word; ошибка последней не должна создавать документ повторно.

Для локальных синтетических артефактов подготовьте точный исходник под тестом scripts/qa/prepare-uc021-output-fixture.mjs, затем используйте scripts/qa/uc021-output-fixture.mjs с управляемыми Node/Playwright/JSZip. Реальные клиентские данные не используются. Перед созданием файлов выполняются markers навыков documents/pdf. DOCX рендерится штатным render_docx.py настоящим LibreOffice; все страницы DOCX/PDF проверяются визуально. Одних XML-проверок недостаточно.

Изображения DOCX допускаются из текущего origin, настроенного Supabase и канонического storage-прокси платформы только по object/sign или object/public. Проверка адреса не выполняет запросов; credentials и Referer не отправляются. Карта внешних изображений печати относится к UC027: HTTPS-изображения печати используют no-referrer, внешние CSS-ресурсы не принимаются.
