# ГОРЭЛТЕХ: безопасная проверка пакета документов

## Назначение

Ревизия `goreltech-group-package-dry-run-v14` добавляет проверку полного пакета из 9 Word-документов без загрузки файлов в Storage, без записи в `group_documents` и без смены статусов ранее сформированных документов.

Кнопка показывается только для организации ГОРЭЛТЕХ. Перед передачей реальных данных клиент выполняет обезличенную проверку ревизии Edge-функции и прекращает операцию, если сервер не сообщает точную ревизию v14.

## Порядок выпуска

1. Развернуть Edge-функцию `compile-group-class-journal` из серверного коммита.
2. Проверить, что неавторизованный POST возвращает `401` и заголовок `X-Sintagma-Compiler-Revision: goreltech-group-package-dry-run-v14`.
3. Опубликовать фронтенд с кнопкой «Проверить 9 Word-документов без сохранения».
4. Авторизованно запустить проверку на группе ГОРЭЛТЕХ и убедиться в ответе: `dryRun=true`, `writesPerformed=false`, `documentCount=9`, девять корректных SHA-256.
5. Отдельно убедиться, что список документов и версии в интерфейсе не изменились после проверки.

## Ограничение доказательства

Локальные тесты подтверждают контракт и отсутствие записей в dry-run-ветке. Полный production E2E считается завершённым только после шага 4 на реальной группе и повторной проверки отсутствия изменений.
