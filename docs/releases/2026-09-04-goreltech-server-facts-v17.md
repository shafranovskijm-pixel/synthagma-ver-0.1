# ГОРЭЛТЕХ: пропуск и титул, кандидат v17

Статус: проверяемый кандидат разработки, не доказательство публикации или
готовности всего комплекта. Продолжает v16, не меняет исходные DOCX.

## Что исправлено

- Пропуск: ФИО и почта из проверенного состава группы; телефон и связь с компанией
  перечитываются с JWT пользователя. Название компании определяется отдельно для
  каждого ученика по ID и организации. Больше нет одной компании на весь состав.
- Даты пропуска — только сохранённые `student_groups.training_dates`. Автоматическое
  вычисление первых четырёх будних дней и подстановка номера пропуска как номера
  договора в этом серверном пути исключены. Неподтверждённое основание договора
  остаётся пустым с замечанием, отметки посещения не выдумываются.
- Некорректный/повторяющийся/обратный набор дат, более четырёх дат или противоречие
  периоду группы дают конкретное замечание, не скрытое исправление или обрезание.
  Неполный период не стирает реальные сохранённые даты, но отмечается отдельно.
- Титул: период из сохранённой группы; город только из однозначного юридического
  адреса, без выдуманного города по умолчанию. Год — из выбранной даты оформления,
  не из часов браузера. Неоднозначный адрес не превращает улицу в название города.
- Дополнительные контакты и компании читаются через существующий caller RLS,
  с tenant/group/ID-фильтрами, проверкой полноты страниц. Нет service-role fallback.
  Ошибка источника отбрасывает его частичные данные, но не другие документы.
- Пропуск и титул включены в серверную карту данных. Подложенные HTML-строки и
  скрытые переменные браузера не служат их источником. Замечания и ID источников
  сохраняются вместе со снимком документа. Подписант остаётся явным полем черновика.

Таким образом, серверные факты используются для семи типов общего компилятора:
приказы зачисления/отчисления, список, ведомость, книга регистрации, пропуск и титул.
У журнала ранее уже был серверный состав и даты; фактические отметки — отдельная
задача. Это не означает, что семь документов уже юридически финализированы.

## Отдельная правка XML охраны труда

Коммит `559ea73ca` запрещает создавать невалидный XML 1.0: управляющие символы,
непарные UTF-16-суррогаты, U+FFFE/U+FFFF. Значения не исправляются молча; ошибка
указывает запись/поле/позицию, без вывода персонального значения. Обе кнопки
экспорта организации обрабатывают отказ до Blob/скачивания и не показывают успех.
Дополнительно экранируется `protocol_source`. Обычный Unicode и допустимые XML-
символы сохраняются. Интерфейс ученика не изменён.

Это исправление корректности внутреннего XML, **не** реализация официальной XSD.
Официальная инструкция Минтруда указывает на
https://akot.rosmintrud.ru/sout/info → «Обучение по ОТ». Сам файл XSD, его зависимости,
версия и официальный пример пока не получены. Тестового импорта в реестр не было.
Нельзя обещать прямую отправку или официальную совместимость.
