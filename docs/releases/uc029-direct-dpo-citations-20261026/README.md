# Прямые основания трёх проектов ДПО

Карточки зачёта, внутренней оценки качества и календарного учебного графика дополняют ссылки на п.17,22–23,15 приказа №266 от24.03.2025. Это положения прочитанной государственной копии, а не утверждение текущей официальной консолидации. Все17 проектов остаются примерами для адаптации и правовой проверки; помощник не утверждает и не подписывает их.

Прочитанная копия №266: https://mchs.gov.ru/uploads/document/2025-12-22/20f20f229c014d35cc094a9765e7f6e9.docx (57 352 байта; SHA-256: 9af3a87fe14e29b73aba5fc1ec29229461774b4aa2f72b4af16f276541d24728). Полный текст копии прочитан25.10.2026 UTC. №438: https://mchs.gov.ru/uploads/document/2025-06-09/8ebaed2c83d6d3b8c73236db65c739b6.pdf — в заголовке дата сохранения05.06.2025. Срок, утрата силы/замена после01.09.2026 и текущая цепочка изменений №438 и№845/369 не подтверждены. Упоминание последнего в сноске №266 не доказывает его действие; новый самостоятельный источник №845/369 не добавлен.

Изменены только данные ссылок и описания прочитанных копий. Функции, типы, содержание85 разделов, права, документы клиентов, нормативные статусы, решения центров и прежние редакции сохранены. Четыре обычные проверки экспорта выполняются отдельно; результат указывается в сопровождающем доказательстве выпуска. Повтор полной проверки приложения для строковых данных не требовался.

Проверка: первый обычный Vitest —4/4, natural exit0, исходники не изменились, без SDK/сети/SQL/провайдеров. Первый Node24-запуск прежнего входа использовал .ts-конфигурацию. Изменённая редакция v2 проверяется новым запуском той же четвёрки с публикуемым .mjs — побайтовой JavaScript-копией конфигурации; фактический результат сохранён отдельно. Node20 не запускался. Полная текущая правовая актуальность по-прежнему не подтверждена.

Уточнения оснований входят в новую редакцию проектов uc029-substantive-drafts-2026-10-26-v2. Ранее скачанные файлы v1 и сохранённая история не переписываются. ADAPTATION_EDITION обозначает редакцию текста проекта; формальная CATALOG_VERSION, нормативные статусы и решения центра не меняются. В четвёртой проверке строка v2 проверяется в реальном экспорте каждого из17проектов.

Фактическая проверка изменённой v2: 4/4, обычный Vitest с публикуемым .mjs на Node 24, natural exit 0, без пропусков и изменения пяти входных файлов. В CB04 проверяется строка новой редакции в каждом из 17 экспортов. Прежний результат v1 сохранён отдельно.
