## Реализовано

- COURSE-01: ошибки загрузки блокируют сохранение неполного состояния. Ошибки запросов, дочерних записей и отмена не становятся сообщением об успехе и не очищают черновик.
- COURSE-02: удаляются только известные редактору удалённые ID уроков, включая последний урок; новые уроки из другой вкладки не удаляются массовым DELETE. Сохранения сериализованы; «Сохранить и выйти» дожидается последних правок. Первое создание курса разделяется между сохранением и созданием модуля. После выхода отложенный ответ не запускает очередное полное сохранение и не очищает черновик.
- ENROLL-01: массовое зачисление проверяет срок существующих записей до INSERT. Истёкший доступ не объявляется действующим и не продлевается. Существующая семантика completed и legacy-статусов сохранена.
- ENROLL-02: создание из группы не повторяет неидемпотентный вызов при потере ответа; требует ID, повторно читает принадлежность профиля/группы/курса и зачисление. Неопределённый результат показывается предупреждением. Поздний ответ другой группы или закрытого диалога не закрывает текущую форму и не показывает ложный успех.
- Восстановлены 13 строк TypeScript-описания уже существующей SQL-колонки/RPC. Это тот же восстановленный контракт исходного checkout, не включение Т-Банка.

Кабинет ученика, стиль лендинга, тарифы, исходные DOCX и backend этим новым пакетом не меняются. Готовый v24-клиент документов уже находится в базовой ветке и повторно не переписывался.

### Ограничение локального окружения

Общее `node_modules` изменилось относительно lockfile: Supabase 2.115.0 вместо 2.90.1, TypeScript 5.9.3 вместо 5.8.3, новые вложенные peer-типы Three. Обычный `tsc` на этом дереве вышел с ошибками совместимости.

Исходные Supabase 2.90.1, TypeScript 5.8.3, Fiber 8.18.0 и Drei 9.122.0 сохранились в `.ignored` общего каталога. Временная конфигурация `.audit-cache/tsconfig.locked-check.json` использует эти реальные типы через aliases, наследуя остальные проверки приложения. Никакие проверки типов не отключались, фиктивные декларации не добавлялись, общие зависимости не заменялись.

Успешный изолированный TypeScript-check не равен чистому `npm ci` всего lockfile. Воспроизводимая установка и сборка на хостинге остаются отдельным релизным условием. Локальные сборки не загружаются на production вместо сборки из проверенного Git SHA.

## Что не объявляется готовым

1. Первая запись курса остаётся неидемпотентной на сервере при потерянном ответе; mutex защищает параллельные вызовы данного редактора, а не гарантирует exactly-once после перезагрузки.
2. Записи уроков/вложений не объединены общей SQL-транзакцией. Частичное сохранение сообщает ошибку и сохраняет черновик, но не откатывает ранее завершившиеся запросы.
3. Защита повторной регистрации из группы хранится в памяти компонента. После полного reload она не гарантируется; существующие профили нельзя повторно создавать без проверки результата.
4. Все девять документов ГОРЭЛТЕХ на реальном кейсе, длинные/пустые варианты и точное соответствие исходникам Дарьи требуют отдельной приёмки. Черновик не является подписанным или выданным документом.
5. Разделение чернового экспорта ФРДО и выдачи, оценка интерфейса 8/10, актуализация КП и официальный XML/API Минтруда этим пакетом не выполнены.
