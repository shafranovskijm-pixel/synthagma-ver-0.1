## Исправления

1. Подставляемая русская дата больше не добавляет точку, уже имеющуюся в обоих
   исходных приказах. Retained DOCX и их manifest-хэши не изменены.
2. Пока нет авторитетных решений по каждому зачислению, формируется именно
   ручной бланк отчисления: в обеих таблицах нет автоматически назначенных ФИО.
   Завершение курса и браузерные переменные не доказывают выдачу документа.
3. Сервер сохраняет предупреждение `expulsion_classification_not_confirmed`,
   режим `blank`, статус `draft`, без номера. Остальные восемь документов и
   отдельный приказ о зачислении не заменяются пустыми бланками.
4. В кабинете ГОРЭЛТЕХ новый бланк имеет явное пояснение. Прежний/неполный
   snapshot требует проверки, но исторический файл остаётся доступен.
   Сохранённые документы не переписываются и не удаляются.

Это временная защита, НЕ завершение автоматического отчисления. Для полного
сценария нужны сохранённые решения по `user_id + enrollment_id`, их проверка,
подстановка в два исходных раздела и подтверждение результата после перезагрузки.
Отсутствие удостоверения не означает автоматически «отчислить без выдачи».
