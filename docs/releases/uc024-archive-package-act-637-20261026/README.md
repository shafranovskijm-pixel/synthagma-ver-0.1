# UC024: полный пакет с историей ACT (637)

Новый пакет schema 2 фиксирует потолок последовательности ACT, все редакции до него, точные JSON-тексты и контрольные суммы, дополнительные доказательные версии документов и их байты. Исходный снимок дела не переписывается. Повтор прежнего request UUID сохраняет прежний снимок; новый UUID фиксирует новую историю даже при той же редакции дела.

Запечатанные schema 1 сохраняют прежние байты, хеши, чтение и изолированное восстановление. Начатый до 637 незапечатанный пакет без дополнения при наличии ACT отклоняется как SOURCE_CHANGED; нужен новый запрос. Восстановление переносит ACT только в историческую проекцию карантина, без вставки ACT/решений в рабочие таблицы.

Проверяются текущие права исходного пользователя, участники ACT и дополнительные источники; отзыв ACT-only участника запрещает повтор, чтение v2 и запечатывание после чтения. Старый v1, не содержащий этого участника, остаётся доступным. Прямой доступ authenticated/service_role к новой таблице и частным помощникам закрыт. Снимки неизменяемы и учитываются в блокировке удаления персональных данных.
