# Защита документов, анализа курса и источники договоров

Частные учебные файлы используют прямой просмотр и скачивание; закрытые PDF и Office URL не отправляются Google/Microsoft viewer. Подтверждённые журналы AI больше не содержат prompt, тела ответа провайдера или исходного текста ошибок. Анализ курса проверяет активного пользователя и разрешение `lesson_write_guard_allowed` с исходным токеном до доступа к содержимому и вызова AI. Справка по договорам получает отдельную редакцию источников, сохраняя прежние редакции и оформление.

Проверено: scoped AI12, viewer11, paired-native16, paired-log13, Auth20 и FAQ4. Прежние неуспешные запуски сохранены отдельно. Общий TypeScript: 5 116 файлов, 0 диагностик, естественное завершение и отсутствие изменения исходников. SQL и настройки SDK не меняются; миграция 633, существующие документы и условия СГТ сохраняются.

Файлы native публикуются отдельно от frontend. `DEPLOYMENT_MAPPING.json` перечисляет ровно 21 затронутую функцию и полное замыкание 32 локальных модулей с точными хешами. Перед публикацией сверяются все исходники; существующие gateway settings сохраняются, доступное фактическое подтверждение публикации записывается отдельно. Отсутствие блока в исходном config не доказывает действующее значение настройки.

После публикации нужна проверка на рабочем сайте: реальный частный PDF в ученике и редакторе, прямое открытие/скачивание, синтетические разрешённый и запрещённый анализ курса, справка по договорам. Проверки TypeScript и DOM не подтверждают работоспособность браузерного PDF plugin. Правовая применимость, договоры обработчиков и регионы базы/резервов учитываются отдельно.
