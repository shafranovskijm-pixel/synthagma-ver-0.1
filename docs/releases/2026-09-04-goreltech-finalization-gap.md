# ГОРЭЛТЕХ: что отделяет пакет Word от окончательного оформления

Проверено по коду `0924c863242dcbba6b9e661ba64cb8cd6b14bb40`, без запросов
к production и без изменения клиентских шаблонов.

## Текущее ограничение

Пакет из 9 DOCX собирается, но намеренно сохраняется как `draft`, без официальных
номеров. Это не полная готовность для окончательного оформления.

- `GroupDocumentsFolder.tsx` запрашивает для ГОРЭЛТЕХ черновик и не резервирует номера.
- `compile-group-class-journal/index.ts` передаёт `serverVerifiedCriticalRequisites: false`.
- Миграция `20260902141149_f6ca4d7b-d95c-4a00-ad7c-b29e85b40e46.sql` запрещает
  обойти это ограничение через браузерный или service-role batch RPC.
- `generation_status: generated` подтверждает сборку DOCX, а не проверку фактов.

## Карта источников

| Документ | Пока приходит из браузерных строк | Источники, которые нужно перечитать на сервере |
| --- | --- | --- |
| Приказы | Программа, часы, период, основание | `student_groups`, `courses`, точные `enrollments`; основание по согласованию оставлять пустым |
| Список учеников | Email, паспорт, образование | `profiles.email`, `student_frdo_data` с фильтром организации и user_id |
| Итоговая ведомость | Процент и оценка | `lessons` и `test_attempts`, точный итоговый тест и IDs учеников |
| Книга регистрации | Реквизиты выдачи, серия/номер, даты, пол, гражданство, паспорт, приказ | `education_document_records` через точные enrollment IDs, `student_frdo_data` |
| Пропуск | Компания, контакты, основание договора, даты, отметки | `profiles`, `companies`, `org_contracts`; источник очных отметок в этом потоке не установлен |
| Расписание | Дата, время, тема, часы, преподаватель | Есть `training_dates`, `instructor_name`, `schedule_text`, но структурированное расписание не подтверждено |
| Общие поля | Часть дат, город, override подписанта | Поля группы/организации и `org_signatories` с полномочиями и областью документов |

Проверка одинакового ФИО недостаточна: возможны однофамильцы, повторные
зачисления, разные курсы и несколько выданных документов. Нужны связи по IDs.
Книга регистрации сейчас проверяет принадлежность ФИО составу группы, но не
доказывает выдачу, полноту и отсутствие повторов.

## Порядок завершения

1. Серверный типизированный снимок: организация, группа, курс, активный состав,
   точные зачисления и все необходимые фактические источники. Ошибка источника
   должна давать конкретное замечание, не подменять значение пустым или выдуманным.
2. Строить строки документов из этого снимка вместо browser HTML. Сначала
   приказы и список учеников, затем ведомость и книга регистрации, затем остальные.
3. Явно хранить ручные данные: подписант, дата оформления, расписание и очные
   отметки. Автор/версия нужны для повторного чтения и защиты от перезаписи.
   Не заменять посещаемость завершением онлайн-урока, не выдумывать подписи.
4. После проверки всех источников добавить отдельную атомарную финализацию:
   резервирование номеров, сохранение единой версии девяти документов и
   неизменяемого снимка. До этого forceDraft не снимать.
5. На тестовой группе ГОРЭЛТЕХ: сохранение → перезагрузка → скачивание всех
   девяти файлов → визуальная сверка с оригинальными DOCX и согласованными правками.
   Отдельно проверить заголовки, дословные формулировки, подписи и ориентацию страниц.

Это следующая работа по основной цели, не замена её требованием «черновик собрался».
Исходные шаблоны и рабочий интерфейс ученика сохраняются.

## Не создавать лишние блокировки

Готовность определяется для конкретного документа и стадии работы, не одним
требованием заполнить всё сразу. Отсутствие итоговых оценок или ещё не выданного
удостоверения не должно блокировать создание курса, зачисление и подготовку
документов начала обучения. Пустые поля, прямо предусмотренные оригинальным
шаблоном для ручного заполнения, не заменять выдуманными значениями и не считать
автоматически ошибкой источника. Неизвестный результат нельзя превращать в «сдал».
В одном пакете могут быть документы разной готовности; интерфейс должен объяснять
конкретное ограничение каждого, сохраняя доступ к уже рабочим операциям.
