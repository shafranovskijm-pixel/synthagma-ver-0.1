# Итоговые решения ГОРЭЛТЕХ — локальный релиз-кандидат

## Что изменено

В «Документы группы» добавлена свёрнутая карточка «Итоговые решения».
Сотрудник выбирает ученика, вводит итоговую оценку и отдельно выбирает
«с выдачей / без выдачи». Значений по умолчанию нет. Номер/дата протокола и
примечание необязательны; они не выдумываются. Сохранение подтверждается
повторным чтением сервера. Чужая вкладка, изменённый контекст или сомнительный
ответ требуют перечитывания, а не повторного создания решения вслепую.

Эти решения не изменяют прогресс, не открывают/закрывают курс, не подписывают
приказ и не создают удостоверение. Отсутствие онлайн-теста не запрещает ввести
результат очной аттестации. Процент теста не пересчитывается в произвольную оценку.

В заполненном Word-комплекте:

- Оценка ведомости берётся из подтверждённого решения для точного зачисления.
- У приказа об отчислении два независимых списка: «с выдачей» и «без выдачи».
- Без актуального решения или ФИО ученик не попадает ни в один список;
  видны число включённых и имена пропущенных, документ остаётся черновиком.
- «Основание» остаётся пустым по согласованной клиентской правке.
- Рабочий бланк не заполняется решениями. Старые файлы не переписываются.

## Сохранность и источники

Точные UUID организации/группы/ученика/зачисления, версия источника, период,
версия решения и автор проверяются сервером. Есть неизменяемая история и CAS.
Reset и пересоздание зачисления делают прежнее решение устаревшим. Чистый учёт
времени/updated_at — нет. Новые столбцы enrollments требуют обновления списка
UPDATE OF в триггере; подробности в backend-контракте.

Edge читает решения через JWT реального пользователя, не повышая права service
role. Серверный снимок повторно сверяет поколение и started_at зачисления с
данными группы. Ошибка чтения не превращается в придуманную оценку/выдачу.

Только expulsion template имеет новую версию `1.2.0-expulsion-decisions`:
`532DD6DA7C91CF3B2E00AB197006C4B6696433EF6E7FB5144940C9D5AF9D6799`.
Исходный source DOCX неизменен, остальные восемь шаблонов сохранены.
Новая версия ещё не имеет визуального допуска Word.
