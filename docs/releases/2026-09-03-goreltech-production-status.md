## Что намеренно не запускалось на реальной группе

Новая авторизованная кнопка является настоящим dry-run: сервер собирает девять DOCX в памяти, возвращает их SHA-256 и обязан подтвердить `writesPerformed=false`, не загружая пакет в Storage и не создавая строки `group_documents`.

Этот dry-run ещё не запускался на действующей группе клиента: он читает реальный состав и персональные данные, поэтому нужен отдельный явный запуск. Для полного production-E2E необходимо получить `documentCount=9`, девять корректных SHA-256, `writesPerformed=false`, сравнить состояние до/после и визуально проверить полученные DOCX. Обычную пересборку с записью запускать для этой проверки не требуется.

## Риск статической публикации

На `синтагма.рф` отсутствующий путь `/assets/<hash>.js` сейчас возвращает SPA `index.html` с HTTP 200 вместо 404. Нельзя заменять только `index.html`: весь `dist` должен переключаться атомарно с сохранением rollback-копии. Для `/assets/*` нужен настоящий 404, для hashed assets — immutable cache, для `index.html` — no-cache.
