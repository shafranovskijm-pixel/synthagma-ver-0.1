Это локальный кандидат, **не опубликованная версия**. Код: `1cb670a9123021c5ed5f483091691ff9fb94b4fe`;
дополнительная защита удаления группы: `36847eb5161a3cefdeb5ef8be446f95a1ade3a3d`.
Публикация фронтенда, Edge и применение миграции не подтверждены.

## Что изменено

- В настройках группы появился отдельный редактор четырёх блоков расписания: дата, начало, окончание, тема.
- Сохранение выполняется отдельной кнопкой. Успех показывается только после ответа RPC и повторного чтения той же версии из базы.
- При одновременной работе в двух вкладках устаревшая версия не перезаписывает новую. При смене курса требуется явная проверка расписания пользователем.
- Черновик сохраняется при переключении вкладок настроек. Общее сохранение и закрытие защищены от случайной потери расписания; удаление группы недоступно во время записи расписания.
- Сервер получает расписание по ID группы/организации через права вызывающего пользователя. Браузерный HTML не используется как источник данных расписания.
- Word использует четыре фиксированных блока исходного бланка. Пятый блок не обрезается молча. Пустые поля не заполняются вымышленными данными.
- Даты журнала, режим доступа к урокам, прохождение курса и интерфейс ученика не изменены.
- Текст темы проверяется на совместимость с XML 1.0. Буквальный текст вида `[[PROGRAM_TITLE]]` остаётся текстом, а не повторной командой шаблона.

## Путь пользователя после выпуска

1. Ученики → Группы → нужная группа → Настройки → Общие → «Данные для документов — расписание».
2. Если нужно изменить курс или период, сначала сохранить настройки группы и открыть их снова.
3. Заполнить до четырёх блоков. Нажать «Сохранить расписание», дождаться подтверждения, затем обновить и убедиться, что данные остались.
4. Документы группы → «Заполнить по данным Синтагмы» → «Проверить 9 Word-документов без сохранения».
5. Проверить замечания и сформировать комплект. Режим «Рабочий бланк» намеренно оставляет занятия пустыми.

В исходном расписании нет отдельных полей часов/преподавателя для каждого занятия. Не представлять их как реализованные.
