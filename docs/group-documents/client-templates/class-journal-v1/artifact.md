# Журнал учета занятий ГОРЭЛТЕХ v1

## Авторитетный источник

- Файл клиента: `6. Журнал учета занятий.docx`.
- SHA-256 исходника: `F22A2C6C5D0368C19FE744041BDAAC1702574AAE6FE69264141D5C52BF3729B1`.
- Исходный файл является единственным источником юридического текста, верстки и фирменной шапки.
- Рабочий шаблон: `supabase/functions/_shared/group-doc-templates/goreltech/class-journal/v1/template.docx`.
- Генератор шаблона меняет только `word/document.xml`; колонтитул, изображение, стили, размеры, связи и остальные части OOXML сохраняются.

## Поля СИНТАГМЫ

| Токен | Источник | Правило |
|---|---|---|
| `[[GROUP_NUMBER]]` | `student_groups.group_number` | Обязательно |
| `[[PROGRAM_TITLE]]` | группа или явно привязанный курс | Обязательно |
| `[[PROGRAM_HOURS]]` | группа или явно привязанный курс | Обязательно |
| `[[INSTRUCTOR_SHORT]]` | `student_groups.instructor_name` | Только явное ФИО, директор не подставляется |
| `[[DIRECTOR_SIGNATURE]]` | `organizations.director_name` | Формат `И.О. Фамилия` |
| `[[DATE_1]]`…`[[DATE_4]]` | `student_groups.training_dates` | Ровно четыре явные даты, как в форме клиента |
| `[[N]]` | вычисляется | Номер строки |
| `[[STUDENT_NAME]]` | `profiles.full_name` | По участникам выбранной группы |
| `[[MARK_1]]`…`[[MARK_4]]` | посещаемость или пусто | Завершение онлайн-урока не считается посещаемостью |

## Повторитель

Таблица `0`, первые две строки — заголовки, строка `2` — прототип слушателя. Прототип клонируется по фактическому составу группы, остальные демонстрационные строки исходника удаляются.

## Блокирующие проверки

- Нет номера группы, программы, часов, преподавателя или руководителя организации.
- Указано не ровно четыре даты занятий. Даты не обрезаются молча.
- В группе нет слушателей или у слушателя отсутствует ФИО.
- После компиляции остался хотя бы один токен.

## Проверка результата

1. SHA-256 шаблона сверяется с `manifest.json`.
2. После заполнения DOCX повторно открывается как ZIP и проверяется на отсутствие токенов.
3. Контрольные суммы всех частей, кроме `word/document.xml`, должны совпадать.
4. Файл рендерится установленным Microsoft Word в PDF.
5. Проверяется каждая страница: альбомный A4, фирменная шапка, одна таблица, подписи без наложений и обрезания.
