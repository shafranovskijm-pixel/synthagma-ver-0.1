# UC020 persisted packet workflow

This module contains the strict original-actor client, command and response contracts, canonical capture, current-scope guards, file broker and read-only UC018 registry bridge. The operator interface is in components/organization/frdo-packets; trusted HTTP orchestration and the same canonical J writer are in supabase/functions/frdo-packet-artifact. DTO parsing or a checksum never grants authority.

A packet captures genuine current UC019 issued records, exact frozen facts and reviewed supplement/evidence revisions through the single canonical mapper. Source authorization includes every retained original and selected person, actor/org/group scope and deletion fences. Explicit reviewed actual training dates can supplement only missing frozen dates; planned calendar dates, group membership and issue dates are not inferred as actual training. Original K snapshots remain immutable.

The client retains an unconfirmed command with its exact request UUID for recovery. Actor/org/scope/permission/offline epoch changes clear retained UI data. Mutations, previews, file reads and replay are independently checked by current server authority. Private historical artifacts remain immutable and distinct from a new current capture; correction is limited to rejected rows and has an explicit retained abandonment path before external submission.

Operator appointment, internal administrative handover, the declared fact of an already performed external upload and its outcome receipt are separate facts. The platform does not submit to FIS FRDO. An internal appointment does not verify external delegation; a receipt transcription does not verify external origin. Workbook signing stays not_verified. Issuer regime defaults to unconfirmed, joint issuance is unsupported, and governance-owner appointment does not approve legal text.

The UC018 read union recognizes the exact frdo_packet_artifact/frdo_packet tags and verifies packet/artifact/snapshot/binding consistency. Generic document forms cannot create or correct these records; registration is allowed only through the packet dispatcher. Files use the original bearer, bounded byte reads, exact hashes and a final current-state recheck. Ordinary private-version registry behavior is preserved.

Local evidence records genuine native backend workflows, compatible affected TypeScript cases, 109 operator/registry/UI cases across their scoped runs, complete application typechecking and isolated Deno11 compatibility. These are distinct receipts, not a single combined run. Current624 retained-removal privacy guards are composed before S3; historical proofs are preserved. None of these local results claims cloud release, customer acceptance, legal approval or an actual FIS submission.
