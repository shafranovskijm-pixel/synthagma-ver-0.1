# UC020 canonical workbook foundation

This is the single canonical J mapper, official-donor writer and complete readback shared by the UC020 client foundation and trusted packet worker. Historical source holds and failed-run evidence are preserved separately. Local foundation checks do not establish hosted release or completion of UC020.

The strict wire is the reviewed V1 plus finite V2. Its endpoint cross-object/state predicates remain obligations for a future trusted implementation; parsing a JSON object grants no rights. The mapper accepts only fresh current-authorized genuine UC019 frozen projections and a separate versioned supplement. Caller-supplied cells, profiles, current course joins, guessed defaults and shortened values are rejected. Captured actor/org/scope epochs must remain current across every await. There is no browser local cache, RPC, public API, SQL, worker, signing integration or external submission here.

Exact donors from the federal education regulator are preserved as test fixtures:

- DPO: https://obrnadzor.gov.ru/wp-content/uploads/2023/01/dpo20230116.xlsx (40 physical columns).
- PO: https://obrnadzor.gov.ru/wp-content/uploads/2026/10/shablonpo16102026.xlsx (35 physical columns).

Donor file hashes and all 14 decompressed ZIP part hashes are pinned. A new archive may recompress parts; unchanged parts' **decompressed bytes** must remain identical. Only pre-existing blank cells in rows 2..1001 of the main sheet can change. No dimension change is needed inside the native capacity. Dictionary rows, duplicate entries, significant spaces, tables, shared strings, names, validations, relationships and styles are preserved. Dates are numeric Excel1900 serials with the donor's existing built-in format14; Excel localizes its display. No custom style is silently added to force a different display locale. Inline strings preserve exact identifiers and XML escaping and never become formulas or hyperlinks. The final green column remains null.

Generation refuses a blocked batch, bounds JSON/ZIP/XML/actual inflated bytes/rows and uses a single 45-second operation deadline. Full readback checks the exact part set, unchanged parts, target-sheet bytes outside intended cells, all 75 literal cell values/types/order/styles, headers, every used native named dictionary and numeric date formats. Archive SHA256 and size refer to actual generated bytes. Actual original foundation tests and subsequent scoped period-fallback regressions are recorded in the release evidence; the same writer/readback also passed isolated Deno DPO and PO roundtrips.

The supplement snapshot domain is explicit in supplementFactsDomain: schema version, org, exact record and subject, frozen-facts SHA, revision, all reviewed fields and actual sealed evidence refs/byte hashes/sizes. Nullable reviewer attribution and mutable display note are excluded so deleting an attributed account does not rewrite immutable pupil facts. A future append-only persistence implementation must use this exact reviewed domain, exact current rights and replay semantics. A digest does not authenticate a caller, evidence or source.
